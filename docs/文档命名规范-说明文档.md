1. **文档位置**: `docs/需求文档/` 目录下。
2. **命名规范**: `{日期}-{时分}-{功能名}-需求文档.md`
   - 日期格式：YYYYMMDD（例如：20260327）
   - 时分格式：HHMM（例如：1430）
   - 功能名：简短的中文功能描述
   - 示例：`20260327-1430-用户登录-需求文档.md`、`20260327-1530-项目查询-需求文档.md`
3. **文件格式**: Markdown (.md)

## SQL文件

1. **文档位置**: `docs/SQL文件/` 目录下。
2. **命名规范**: `{日期}-{时分}-{功能名}-sql.sql`
   - 日期格式：YYYYMMDD（例如：20260327）
   - 时分格式：HHMM（例如：1430）
   - 功能名：简短的中文功能描述
   - 示例：`20260327-1430-用户登录-sql.sql`、`20260327-1530-项目查询-sql.sql`
3. **文件格式**: SQL (.sql)
4. **数据库规范**:
   - 符合mysql5.6的规范
   - 所有表为千万级数据量设计
   - 索引设计要充分考虑查询效率
   - 所有表名使用小写，多个单词用下划线连接，避免使用中文
   - 字段名也使用小写，多个单词用下划线连接，避免使用中文。
   - 字段类型使用 InnoDB 存储引擎
   - 字段类型使用 UTF8MB4 字符集
   - 表需要有中文注释
   - 字段需要有中文注释
   - 字段类型使用 INT(11) 作为主键
   - 自增主键
   - 涉及到状态和类型的字段，请使用 TINYINT(4) 类型，并且每个状态和类型都对应一个固定的值且有中文注释，方便查询和维护。
   - 时间字段使用 bigint(20) 类型，单位为秒，存储 Unix 时间戳,时间字段的名的格式为 {功能}_time，例如：create_time、update_time、delete_time,分别表示创建时间、更新时间和删除时间 delete_time默认为0。

## 字典值

1. **文档位置**: `docs/SQL文件/` 目录下，与 SQL 文件一起管理。
2. **命名规范**: 与 SQL 文件一致，`{日期}-{时分}-{功能名}-sql.sql`，字典内容作为该功能 SQL 脚本的一部分。
3. **文件格式**: SQL (.sql)
4. **新增字典值规范**:
   - 新建字典时必须同时包含「字典类型表」和「字典项表」两条 INSERT 语句。
   - 使用 `ON CONFLICT ... DO NOTHING` 保证幂等，脚本可重复执行。
   - 字典 `code` 命名格式：`DIC_{功能/业务大写}`，例如 `DIC_MERCHANT_WALLET_CREDIT_STATUS`、`DIC_ORDER_TYPE`。
   - 字典项 `value` 使用固定数值（从 1 开始递增），`sort` 与 `value` 保持一致，`dic_status` 默认 1（启用）。
   - 每个字典项 `remark` 写明所属字典，格式为：`{字典name}-{字典项label}`。
   - 参考格式：

```sql
-- ============================================================
-- 字典类型表
-- ============================================================
INSERT INTO "public"."sys_dict_type" ("code", "name", "remark") VALUES
('DIC_MERCHANT_WALLET_CREDIT_STATUS', '商户钱包结算余额入账状态', '商户钱包结算余额入账状态')
ON CONFLICT ("code") WHERE deleted = 0 DO NOTHING;

-- ============================================================
-- 字典项表
-- ============================================================
INSERT INTO "public"."sys_dict_item" ("type_id", "label", "value", "sort", "remark", "dic_status")
SELECT t.id, v.label, v.value, v.sort, v.remark, 1
FROM "public"."sys_dict_type" t
CROSS JOIN (VALUES
  ('DIC_MERCHANT_WALLET_CREDIT_STATUS', '待入账', '1', 1, '商户钱包结算-余额入账状态-待入账'),
  ('DIC_MERCHANT_WALLET_CREDIT_STATUS', '已入账', '2', 2, '商户钱包结算-余额入账状态-已入账'),
  ('DIC_MERCHANT_WALLET_CREDIT_STATUS', '入账失败', '3', 3, '商户钱包结算-余额入账状态-入账失败')
) AS v(code, label, value, sort, remark)
WHERE t.code = v.code AND t.deleted = 0
ON CONFLICT ("type_id", "value") WHERE deleted = 0 DO NOTHING;
```
