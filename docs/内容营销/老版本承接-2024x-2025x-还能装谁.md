## 你可能不是不想升级，而是升不了

IDEA 升不升级，常常不由一个人定：公司项目锁着老 JDK、团队镜像统一推版本、 upgrade 清单排到半年后。当你的 IDEA 停在 2024.x 或 2025.x，再想装一个 MyBatis SQL 类插件时，能装的还有谁？这个问题值得一张表说清楚。

## 一张表：各家新版兼容区间（截至 2026-09-30）

| 插件 | 新版兼容区间 | 折算成 IDEA 版本 | 对 2024.x~2025.x 用户意味着什么 |
|---|---|---|---|
| MyBatisX（baomidou 官方） | 251–263 | 2025.1~2026.3 | 2025.1 及以下装不了新版 1.7.7（2026-09-15 发布），2024.x 用户停留在旧版 1.7.6 |
| MyBatis Log Free | 262+ | 2026.2+ | 2024.x~2026.1 全部装不了，新版直接放弃了这些用户 |
| MybatisLogFormat | 233–262 | 2023.3~2026.2 | 2024.x~2025.x 名义上可装，2026.3 装不了；262 上有实报错案例（见下节） |
| MyBatis Log Ultra | 222–263 | 2022.3~2026.3 | 老版本反而都能装；但 2026-05-25（4.0.20）后未再更新，评论区最新一条是停更质问 |
| Mybatis-Flex-Helper | 261–262 | 2026.1~2026.2 | 2024.x~2025.x 装不了，262 以下与 263 也都不在其区间 |
| SQL Visualizer（本插件） | 243 无上限 | 2024.3~2026.x | 全线可装 |

补一条事实免得表格显得太 selective：免费线里兼容区间最宽的是 Jtools-Mybatis-Log（171–265，截至 2026-09-30），2024.x~2025.x 用户也能装。本稿的立场就是把各家区间原样摆出来，读者自己对着自己的 IDEA 版本查。

## 三个实锤与样本

**一、MybatisLogFormat 在 IU-262 上的报错评论。** 2026-09-09，一位用户打了 5 星，内容却是报错反馈：在 `IU-262.10315.125` 上插件抛 `java.lang.NoClassDefFoundError: org/apache/commons/collections/CollectionUtils`（原文见第十八轮评论端点实抓）。182,056 下载量级的老牌插件（截至 2026-09-30），区间写着支持 262，实际跑起来仍有类加载失败。评论区另有用户留言「新的idea 不能用呢，可否兼容下呢」（原文照录）。这说明两件事：兼容区间标注和实际可用之间有距离；老版本用户之外，新版本用户同样在等适配。

**二、fork 分叉承接已经发生。** MybatisLogFree（Marketplace 插件页 33100）是 MyBatis Log Free（17898，548,033 下载，截至 2026-09-30）的 fork。原版兼容线收缩到 262+ 之后，有第三方出手开 fork 承接被留在旧版本上的用户——这个 fork 截至 2026-09-30 已有 263 下载。有人愿意用开 fork 的方式接住这批用户，侧面说明「老版本 IDEA 用户没地方去」是真需求，不是我们单方面的叙事。

**三、上架即死与付费成交的两极样本。** 同一时期的新货架供给里：Mybatis Terminator（34574）上架即 1.0.6，截至 2026-09-30 零成交；EF Log2SQL（34032）作为付费插件成交 3 份。免费且全线兼容、认真迭代的位置，在当前供给里反而是少数。

## 我们的主张（明示：这是主张，不是事实陈述）

如果你的 IDEA 在 2024.3~2026.x 之间，本插件是一条不用先升级 IDE 才能用的路：

- **全线可装**：since-build 243 无上限，IDEA 2024.3~2026.x 兼容由 verifyGate 三目标（243/253/262）每次发行实测背书，读数随批次落 `docs/验收文档/`。
- **免费开源**：无付费版，无功能锁，无弹窗激活。
- **诚实标注的门槛**：MCP 工具面需要 IDEA 2025.2+（依赖 MCP Server 插件），未装该环境零影响，其余功能照常；SQL 执行等 Ultimate 专属能力在 Community 版优雅降级。
- **如实限定的能力叙事**：mapper XML 注入高亮一类收益，在 IntelliJ Ultimate 主航道会因平台自带 SQL 语言注入器在位而让位，此类能力的适用场景须限定为 Community 或无竞品注入的环境——能做什么就说什么。

老版本用户等的不是又一个「新版才装得上」的插件。区间表摆在这里，选择权在读者。
