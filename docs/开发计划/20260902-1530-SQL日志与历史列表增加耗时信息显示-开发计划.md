## 一、问题清单

| # | 问题 | 影响 | 根因 |
|---|------|------|------|
| P1 | SQL 日志列表不显示耗时 | 无法识别慢查询 | `ExecutionTimeParser` 格式覆盖不足；`null` 时无兜底展示 |

## 二、根因分析

### P1：SQL 日志列表不显示耗时

`LogSqlEntry.executionTimeMs` 完全依赖 `ExecutionTimeParser.parse()` 从日志文本解析。当前仅覆盖 p6spy/MP TimeCount/通用 time 格式。用户日志格式不匹配时解析为 `null`，`formatDurationHtml` 返回空串。

**修复**：增强 `ExecutionTimeParser` 覆盖 druid/MP ExecuteTime/行尾纯数字；`null` 时展示 `—` 占位符。

### P2：SQL 历史列表不显示耗时

`SqlHistoryEntry` 数据模型不含耗时字段，历史条目来源（`PreviewResult`）也不含耗时。

**修复**：`SqlHistoryEntry` 增加 `executionTimeMs` 字段；`HistoryCellRenderer` 增加耗时渲染；保存历史时从 `SqlLogManager` 匹配补全。

### P3：SQL 缺少结束符

`withTerminator()` 已存在（`SqlLogPanel.kt:74`），但仅在复制/预览时调用。列表展示直接用 `entry.summary`（原始 SQL 文本），不含结束符。

**修复**：列表展示时对 `summary` 调用 `withTerminator()`。

### P4：历史文件被覆盖

`SqlLogAutoSaver.openWriterForCurrent()` 使用 `Files.newBufferedWriter(file.toPath(), Charsets.UTF_8)` —— 默认 `CREATE_TRUNCATE` 模式，每次启动覆盖已有文件。

**修复**：改为 `StandardOpenOption.CREATE, StandardOpenOption.APPEND` 模式。

### P5：历史面板按钮为文字

`HistorySqlLogPanel` 的刷新按钮是 `JButton("刷新")` 纯文字；返回按钮是 `JButton("返回")` 文字 + 图标。与日志面板的 `ActionToolbar` + `AnAction` 图标风格不一致。

**修复**：改为 `JButton` 仅图标（`null` text）+ `toolTipText`，复用 `AllIcons.Actions.Refresh` / `AllIcons.Actions.Back`。

## 三、修复方案

### 3.1 P1：增强 ExecutionTimeParser + 兜底展示

**`log/ExecutionTimeParser.kt`** —— 新增三种格式：

| 格式 | 示例 | 正则 |
|------|------|------|
| druid | `executeMillis:123` | `(?i)executeMillis["']?\s*[:=]\s*(\d+)` |
| MP ExecuteTime | `ExecuteTime: 456ms` | `(?i)\bExecuteTime\s*[:=]\s*(\d+)\s*ms?\b` |
| 行尾纯数字 | `select ... ] 789ms` | `[\]\s]\s*(\d+)\s*ms\s*$`（MULTILINE） |

**`log/SqlLogConsoleBridge.kt`** —— 解析耗时时复用 `LogDurationParser` 作为次级解析器：

```kotlin
val lineDuration = ExecutionTimeParser.parse(line, timePrefix)
val duration = lineDuration ?: LogDurationParser.parse(e)
```

**`log/SqlLogPanel.kt`** —— `formatDurationHtml` 改为：

```kotlin
private fun formatDurationHtml(ms: Long?, isSelected: Boolean): String {
    val threshold = PluginSettings.getInstance().state.slowQueryThresholdMs
    val color = when {
        isSelected -> "#FFFFFF"
        ms == null -> "#9E9E9E"            // 灰：无耗时
        ms >= threshold -> "#D32F2F"      // 红：慢查询
        ms >= threshold / 2 -> "#E67E22"  // 橙：偏慢
        else -> "#4CAF50"                 // 绿：正常
    }
    val text = ms?.let { "${it}ms" } ?: "—"
    return "<span style='color:${color}'>$text</span> "
}
```

新增 `showDurationInLogList` 开关判断：

```kotlin
val durationHtml = if (PluginSettings.getInstance().state.showDurationInLogList)
    formatDurationHtml(entry.executionTimeMs, isSelected) else ""
```

### 3.2 P2：SQL 历史列表增加耗时

**`history/SqlHistoryEntry.kt`** —— 新增字段：

```kotlin
var executionTimeMs: Long? = null,
```

**`history/SqlHistoryPanel.kt`** —— `HistoryCellRenderer` 增加耗时渲染：

```kotlin
val durationColor = when (SlowQueryDetector.level(entry.executionTimeMs)) {
    SlowQueryDetector.DurationLevel.SLOW -> "#D32F2F"
    SlowQueryDetector.DurationLevel.MODERATE -> "#E67E22"
    SlowQueryDetector.DurationLevel.FAST -> "#4CAF50"
    SlowQueryDetector.DurationLevel.NONE -> "#9E9E9E"
}
val durationText = entry.executionTimeMs?.let { "${it}ms" } ?: "—"
val durationPart = "  <span style='color:$durationColor'>$durationText</span>"
```

渲染结构改为：`★ SQL摘要 123ms 时间戳 (来源) [标签]`

**`ui/SqlPreviewService.kt`** —— `recordHistory()` 从 `SqlLogManager` 匹配补全耗时：

```kotlin
val logManager = anchor.project.getService(SqlLogManager::class.java)
val executionTimeMs = logManager.entries.snapshot()
    .firstOrNull { it.restoredSql == result.sql }
    ?.executionTimeMs
```

### 3.3 P3：SQL 结束符

**`log/SqlLogPanel.kt`** —— `LogEntryListCellRenderer` 渲染 summary 时追加结束符：

```kotlin
val sqlHtml = SqlListHtmlRenderer.render(withTerminator(entry.summary))
```

**`history/SqlHistoryPanel.kt`** —— `HistoryCellRenderer` 渲染 summary 时追加结束符：

```kotlin
val summary = withTerminator(entry.summary())
```

**`log/HistorySqlLogPanel.kt`** —— 二级面板 `HistoryCellRenderer` 渲染 summary 时追加结束符：

```kotlin
val sqlHtml = SqlListHtmlRenderer.render(withTerminator(entry.summary))
```

### 3.4 P4：历史文件覆盖

**`log/SqlLogAutoSaver.kt`** —— `openWriterForCurrent()` 改为 APPEND 模式：

```kotlin
writer = Files.newBufferedWriter(
    file.toPath(), Charsets.UTF_8,
    StandardOpenOption.CREATE, StandardOpenOption.APPEND
)
```

### 3.5 P5：历史面板图标按钮

**`log/HistorySqlLogPanel.kt`** —— 刷新/返回按钮改为图标 + tooltip：

```kotlin
// 返回按钮（已有图标，去掉文字）
private val backButton = JButton().apply {
```

按钮尺寸统一为 `Dimension(28, 28)`，`EmptyBorder(2, 2, 2, 2)`，与日志面板工具栏图标按钮视觉一致。

## 七、风险评估

- **风险等级**：低
- **影响面**：列表渲染 + 数据模型新增可选字段 + 设置项 + 文件写入模式
- **兼容性**：
  - `SqlHistoryEntry` 新增字段为可选（`Long? = null`）
  - `showDurationInLogList` 默认 `true`，行为向前兼容
  - APPEND 模式仅影响文件写入，不影响读取
- **回滚难度**：git revert 单行提交即可
