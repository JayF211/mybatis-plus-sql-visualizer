# 设置页修复与增强 + 弹窗自适应 + 插件名统一——开发计划（M14）

> 本文档是 **MyBatis-Plus SQL Visualizer** 的 M14 增量开发计划，承接用户反馈的四件事：
> ① **设置页在正式安装的 IDEA 中不显示**（第三次反馈，需深挖根因并修复）；
> ② 设置页增强：**中英文切换** + **快捷键修改**入口；
> ③ **SQL 预览弹窗偏小**，加大并**自适应**（按屏幕比例 + 记忆用户调整尺寸）；
> ④ **旧插件名全局统一**为 `MyBatis-Plus SQL Visualizer`。
>
> 配套文档：[主开发计划](../开发计划/20260812-1058-MP-SQL可视化-开发计划.md)（M0~M13 已交付）、[M13 开发计划](../开发计划/20260812-2210-动态条件简化与参数值类型推断-开发计划.md)。
> 当前基线：Kotlin 2.3.20 + IntelliJ Platform Gradle Plugin 2.18.1 + IDEA 2025.3.5，v1.7（M13）已提交（commit 79b09d4），后续 M13.1（全选/全不选、图标、插件名）已提交（14a840b / 72ada48 / adcb819）。

## 1. 概述与目标

**用户反馈（四项）**：

1. **设置页不显示**：`./gradlew buildPlugin` 打包 → 从磁盘安装进 IDEA → Settings 中无插件相关设置。此前已两轮排查（runIde 场景），本轮聚焦**正式安装环境**的根因（IDEA 日志、纯净环境复现、注册方式加固）；
2. **设置页能力**：至少提供**中英文切换**与**快捷键修改**（当前 bundle 仅跟随 IDE 语言、快捷键需去 Keymap 手改）；
3. **弹窗尺寸**：SQL 预览弹窗 720×480 偏小，需加大并**自适应**（默认按屏幕比例，记忆用户手动调整）；
4. **插件名统一**：全局搜索替换旧名 `MP SQL Visualizer` → `MyBatis-Plus SQL Visualizer`（运行时文案全部、文档按策略统一）。

**范围控制**：
- 设置页显示问题：先**证据驱动排查**（idea.log + 纯净安装复现），确认根因后修复；不盲目改动注册方式（现有 `parentId="tools"` 为 IDEA 标准做法）；
- 中英文切换：**插件级语言配置**（默认**简体中文**，可选跟随系统 / English），仅影响本插件 UI，不动 IDE 语言；
- 快捷键：第一版提供「显示当前快捷键 + 一键跳转 Keymap 设置」入口（标准做法，不直接改写用户 keymap）；
- 弹窗：不改面板功能，仅调整默认尺寸策略与尺寸记忆；
- 插件名：运行时（代码/资源/bundle）全部统一；历史文档（需求/开发计划记录）按「当前视角统一替换」处理（原记录为历史事实，统一后不影响可读性）；内部标识（plugin id、`Storage("mp-sql-visualizer.xml")`、类名 `MpSqlVisualizerBundle`）**不随插件名变更**（避免破坏用户配置与 API）。

### 3.2 中英文切换（T-M14-02）

**模型**：`PluginSettings.State.language: String = "zh"`（**默认中文**；AUTO=跟随 IDE / zh / en）。

**bundle 改造**（`MpSqlVisualizerBundle` 自管理 ResourceBundle）：

```kotlin
object MpSqlVisualizerBundle {
    private const val BUNDLE_NAME = "messages.MpSqlVisualizerBundle"

    @JvmStatic
    fun message(key: String, vararg params: Any?): String {
        val locale = currentLocale()
        val bundle = ResourceBundle.getBundle(BUNDLE_NAME, locale, loader)
        val pattern = bundle.getString(key)
        return if (params.isEmpty()) pattern else MessageFormat.format(pattern, *params)
    }

    /** 插件级语言：默认中文（zh）；AUTO 跟随 IDE；测试环境（settings 未注册）兜底中文。 */
    private fun currentLocale(): Locale = runCatching {
        when (PluginSettings.getInstance().state.language) {
            "en" -> Locale.ENGLISH
            "AUTO" -> BundleBase.getLocale()   // 跟随 IDE 界面语言
            else -> Locale.SIMPLIFIED_CHINESE  // 默认中文（zh 或未知值）
        }
    }.getOrElse { Locale.SIMPLIFIED_CHINESE }
}
```

- 依赖方向：bundle → PluginSettings（单向，无循环）；测试环境 service 未注册时 `runCatching` 兜底**中文**（与默认值一致）；
- **切换即时生效**：设置页保存语言后重建表单（`PluginSettingsPanel.rebuild()`）使设置页自身文案切换；其余 UI（弹窗/gutter tooltip/提示）均为下次渲染时取 bundle，天然即时生效；
- bundle 缓存：`ResourceBundle.getBundle` 对同 locale 有缓存，不同 locale 会重新加载，**无需主动清缓存**。

**设置页**：新增「界面语言」下拉（3 项：跟随系统/简体中文/English），保存即生效。

### 3.3 快捷键展示与修改入口（T-M14-03）

设置页新增一行：

### 3.4 弹窗尺寸自适应（T-M14-04）

`SqlPreviewDialog`：
```kotlin
init {
    ...
    // M14：默认按屏幕比例（自适应），并记忆用户调整尺寸
    val screen = Toolkit.getDefaultToolkit().screenSize
    val w = (screen.width * 0.62).toInt().coerceIn(900, (screen.width * 0.85).toInt())
    val h = (screen.height * 0.65).toInt().coerceIn(600, (screen.height * 0.85).toInt())
    setSize(w, h)
    setMinimumSize(Dimension(640, 420))
}

/** 记忆用户拉伸后的窗口尺寸（DialogWrapper 机制）。 */
override fun rememberLastWindowSize(): Boolean = true
```

- `rememberLastWindowSize=true` 后，DialogWrapper 通过 `DimensionService` 自动记忆/恢复用户调整尺寸（后续打开保持）；
- 左栏 `JSplitPane` 的 `resizeWeight=0.3` 已有，弹窗变大后两侧同步放大。
