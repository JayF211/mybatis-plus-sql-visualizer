## 0. 目标

在预览弹窗中增加「JOIN 关系图」标签页，从 `SelectStatement.joins`（已有模型）生成可视化的表关系图，直观展示多表 JOIN 关系、别名映射、ON 条件。

**用户价值**：复杂联表查询（3+ 表 JOIN）时，一眼看清表之间的关系、JOIN 类型、ON 条件，不需要从 SQL 文本中脑补。

## 1. 技术方案

### 1.1 方案选型（调研结论）

| 方案 | 体积 | JCEF | 交互性 | 推荐阶段 |
|------|------|------|--------|:--------:|
| PlantUML `entity` 图 | +5MB | 否 | 静态图 | **MVP** |
| Mermaid `erDiagram` + JCEF | +300KB | 是 | 缩放/平移 | **v2** |
| Graphviz-Java DOT | +10MB | 否 | 静态图 | 备选 |
| JGraphX 交互图 | +1MB | 否 | 拖拽/缩放 | 备选 |

**决策**：MVP 用 PlantUML（纯 Java 渲染，零环境依赖），v2 升级到 Mermaid+JCEF（交互更佳，体积更小）。

## 2. PlantUML 文本生成规则

### 2.1 基本映射

```kotlin
fun generatePlantUml(stmt: SelectStatement): String {
    val sb = StringBuilder()
    sb.append("@startuml\n")
    sb.append("!theme plain\n")
    sb.append("hide circle\n")
    sb.append("skinparam linetype ortho\n\n")
    
    // 主表
    val mainAlias = stmt.tableAlias ?: "t"
    sb.append("entity \"${stmt.table.tableName} ($mainAlias)\" as $mainAlias {\n")
    for (col in stmt.table.columns) {
        val marker = if (col.isId) " * " : "   "
        sb.append("$marker${col.columnName} : ${col.fieldType}\n")
    }
    sb.append("}\n\n")
    
    // JOIN 表
    for (join in stmt.joins) {
        val joinAlias = join.alias ?: "t${stmt.joins.indexOf(join) + 1}"
        sb.append("entity \"${join.tableName} ($joinAlias)\" as $joinAlias {\n")
        // 列信息可选（如果有）
        sb.append("}\n\n")
        
        // 关系线
        val rel = when (join.type) {
            JoinType.LEFT -> "||--o{"
            JoinType.RIGHT -> "}o--||"
            JoinType.INNER -> "||--||"
            JoinType.FULL -> "}o--o{"
        }
        val onCondition = join.onConditions.joinToString(" AND ") { it.toString() }
        sb.append("$mainAlias $rel $joinAlias : \"$onCondition\"\n")
    }
    
    sb.append("\n@enduml\n")
    return sb.toString()
}
```

### 2.2 样式增强

- 主表绿色边框，JOIN 表蓝色边框
- LEFT JOIN 实线，INNER JOIN 虚线
- ON 条件显示在关系线上
- 列名标注 PK/FK

## 5. 边界与降级

- 单表查询（无 JOIN）：不显示「JOIN 图」标签页
- PlantUML 渲染失败：显示错误提示 + 原始 PlantUML 文本（可复制调试）
- JCEF 不可用（v2）：自动降级到 PlantUML 静态图
- 超大列数（>50 列）：只显示主键 + 外键列，避免图过大
