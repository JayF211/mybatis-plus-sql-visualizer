## 0. 目标

自动记录每次预览的 SQL，支持收藏、标签、搜索，跨会话持久化。方便开发者回溯之前的预览记录。

**用户价值**：调试过程中经常需要对比不同版本的 SQL，手动保存低效。收藏常用 SQL 供团队参考。

---

## 1. 功能设计

### 1.1 自动记录

**方案**：
- 每次预览完成后自动写入历史记录
- 记录内容：SQL 文本、参数、时间戳、来源文件+行号
- 存储上限：默认 200 条（可配置），超出自动删除最旧
- 持久化：`PersistentStateComponent` 序列化到 XML

### 1.2 收藏机制

**方案**：
- 每条记录左侧星形图标，点击收藏/取消
- 收藏列表独立 tab 或筛选视图
- 收藏无数量上限

### 1.3 搜索与标签

**方案**：
- 搜索框支持 SQL 文本模糊搜索
- 标签系统：用户可为记录添加自定义标签（如 "慢查询"、"联表"、"待优化"）
- 按标签筛选

### 1.4 UI 布局

```
┌─────────────────────────────────────────┐
│ [搜索框...]  [全部 ▼]  [标签 ▼]  [清除] │
├─────────────────────────────────────────┤
│ ⭐ SELECT ... FROM user WHERE...  12:30 │
│    SELECT ... FROM order WHERE...  12:25 │
│ ⭐ UPDATE user SET ...            12:20 │
│    DELETE FROM ...                12:15 │
├─────────────────────────────────────────┤
│ 双击预览 | 右键：收藏/复制/删除/加标签    │
└─────────────────────────────────────────┘
```

## 6. 边界与降级

- 持久化文件损坏：捕获异常后清空历史，不阻塞插件
- 历史为空：显示空状态提示「暂无预览记录」
- 搜索无结果：显示「无匹配记录」
