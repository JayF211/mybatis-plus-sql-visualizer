### 问题一：SQL 日志列表渲染导致 EDT freeze 20-30 秒

**冻结类型 B — BasicHTML.createHTMLView（类型 A 的下游放大）**：
```
BasicHTML.createHTMLView (Swing HTML 引擎)
  → BasicHTML$Renderer.<init>
    → BlockView.getPreferredSpan

        → ParagraphView.calculateMinorAxisRequirements
```

**根因（三重叠加）**：

1. **SQL 词法分析在 EDT 上执行**：`getListCellRendererComponent` 被调用时，每条 SQL 都 `new SqlLexer()` + `advance()` 全量分词（`SqlLexer.kt:69` → `classifyWord:188`）。这是 O(N×L) 的 CPU 操作（N=条目数，L=SQL 长度），全在 EDT 上。
2. **addElement 逐条触发事件风暴**：`rebuildListModel()` 用 `forEach { listModel.addElement(it) }` 逐条添加，每次 `addElement` 触发 `fireIntervalAdded` → `updateLayoutState` → 对所有可见 cell 调 `getListCellRendererComponent`。这是 O(N²) 的事件风暴。
3. **HTML 文本触发 Swing HTML 引擎**：`JLabel.setText("<html>...")` 走 `BasicHTML.createHTMLView` → `StyleSheet.getFont` → `CSS.getFont` → `MuxingAttributeSet` 多层属性查找。Swing HTML 渲染是知名瓶颈，被 O(N²) 放大后每次 freeze 20-30 秒。

## 解决方案概览

| 改动 | 文件 | 解决问题 | 预期效果 |
|------|------|----------|----------|
| ① 可配置 logMaxCount | PluginSettings + Panel + 2 bundle | 问题二 | 用户可调低上限防卡顿 |
| ② buffer 装配 maxEntries | SqlLogManager | 问题二 | 配置生效 |
| ③ maxEntries 改 var | SqlLogEntryBuffer | 问题二 | 支持运行时调整 |
| ④ 批量刷新模型 | SqlLogPanel.rebuildListModel | 问题一 | N 次 addElement → 1 次 addAll，减少 N-1 次布局计算 |
| ⑤ cell renderer 纯文本化 | SqlLogPanel.getListCellRendererComponent | 问题一 | 去除 HTML 布局开销 + 移除 EDT 上的 SQL 词法分析 |

**预期效果量化**：
- 改动 ④ 将 O(N²) 事件 → O(N)，消除 N-1 次布局重算
- 改动 ⑤ 移除 EDT 上的 SQL 词法分析（O(N×L) → 0）+ 消除 Swing HTML 引擎调用
- 组合后：从 20~30 秒冻结 → 列表刷新 < 100ms

### 改动 ⑤：SqlLogPanel.kt — 批量刷新 + 渲染优化

**文件**：`src/main/kotlin/cn/song/mybatisplus/visualizer/log/SqlLogPanel.kt`

#### 5.1 rebuildListModel 批量化

当前实现（第 641-649 行）逐条 `addElement`，每次触发布局重算。改用临时列表 + 一次性 `addAll`：

```kotlin
private fun rebuildListModel() {
    val elements = ArrayList<LogSqlEntry>(groupedEntries.size * 2)
    groupedEntries.forEach { ge ->
        if (ge.expanded) {
            elements.addAll(ge.entries)
        } else {
            elements.add(ge.template)
        }
    }
    listModel.clear()
    // 一次性替换全部内容：fireIntervalAdded 仅触发一次布局计算
    if (elements.isNotEmpty()) {
        listModel.addAll(elements)
    }
}
```

> **原理**：`DefaultListModel.addAll()` 内部一次性 fireIntervalAdded(0, n)，
> `WideSelectionListUI` 仅触发一次 `updateLayoutState`，避免 N 次逐条布局。
> **效果**：将 O(N²) 事件风暴降为 O(N)。

#### 5.2 getListCellRendererComponent 纯文本化

当前 renderer（第 505-539 行）每条构建完整 `<html>` 字符串（含多 span 嵌套语法着色），
触发 Swing HTML 全量布局 + 在 EDT 上做 SQL 词法分析。改为**纯文本 + 单一颜色标记**：

```kotlin
override fun getListCellRendererComponent(
    list: javax.swing.JList<*>?,
    value: Any?,
    index: Int,
    isSelected: Boolean,
    cellHasFocus: Boolean,
): java.awt.Component {
    super.getListCellRendererComponent(list, value, index, isSelected, cellHasFocus)
    val entry = value as? LogSqlEntry
    text = null
    if (entry != null) {
        val timestamp = formatTimestamp(entry.timestamp)  // 纯文本 "[2026-08-24 10:00:01] "
        val duration = formatDuration(entry.executionTimeMs)  // 纯文本 " 12ms "
        val foldedBadge = findFoldedGroup(entry)?.let { " ⨉${it.count} " } ?: ""
        this.text = "$timestamp$duration${entry.summary}$foldedBadge"
        toolTipText = entry.restoredSql
        // 耗时着色（仅前景色，不走 HTML）
        foreground = durationColor(entry.executionTimeMs, isSelected)
    }
    border = BorderFactory.createCompoundBorder(
        BorderFactory.createMatteBorder(0, 0, 1, 0, JBColor.border()),
        EmptyBorder(5, 8, 5, 8),
    )
    return this
}

private fun formatTimestamp(timestamp: Long): String {
    val state = PluginSettings.getInstance().state
    if (!state.logTimestampEnabled) return ""
    val formatted = try {
        SimpleDateFormat(state.logTimestampFormat).format(Date(timestamp))
    } catch (_: IllegalArgumentException) {
        SimpleDateFormat(DEFAULT_TIMESTAMP_FORMAT).format(Date(timestamp))
    }
    return "[$formatted] "
}

private fun formatDuration(ms: Long?): String {
    if (ms == null) return ""
    return " ${ms}ms "
}

private fun durationColor(ms: Long?, isSelected: Boolean): java.awt.Color {
    if (isSelected) return list.selectionForeground
    if (ms == null) return list.foreground
    val threshold = PluginSettings.getInstance().state.slowQueryThresholdMs
    return when {
        ms >= threshold -> JBColor.RED
        ms >= threshold / 2 -> JBColor.ORANGE
        else -> list.foreground
    }
}
```

> **原理**：
> - `JLabel` 纯文本不创建 `BasicHTML$Renderer`，直接走 `BasicLabelUI` 原生绘制，
>   跳过 `FlowView`/`BlockView`/`ParagraphView` 整条 HTML 布局链路——即 freeze 栈顶的完整路径。
> - 移除 `SqlListHtmlRenderer.render()` 调用后，EDT 上不再执行 SQL 词法分析（`SqlLexer.advance` + `classifyWord` 的 O(N×L) 操作消失）。
> - 耗时信息改用 `foreground` 前景色（绿/黄/红）表达，无需 HTML span。

#### 5.3 保留 SqlListHtmlRenderer 供详情预览使用

> `SqlListHtmlRenderer` 仍用于工具提示（tooltip）或详情面板的语法着色，
> 仅从列表 cell renderer 中移除，不影响预览弹窗等着色场景。
