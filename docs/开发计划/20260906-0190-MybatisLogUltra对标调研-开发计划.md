# Mybatis Log Ultra 对标调研 开发计划

- **任务ID**：T-UltraRecon
- **立项时间**：2026-09-06 01:50
- **分支**：`dev`
- **前置**：第二轮调研报告（`docs/开发计划/20260906-0120-竞品横向对比与功能建议-第二轮调研报告.md`）§3.3 数据基线；对应建议 N-10（P2）

## 1. 问题

Mybatis Log Ultra（Marketplace ID 26550）是日志赛道 2026 年新品中唯一健康增长者：4,740 下载、4.76 分（新品中最高）、兼容 222–263（下限比本插件更低、上限探到 263），2026-05-25 发 4.0.20，月度活跃（第二轮报告 §3.3）。上轮文档已记录其「点击跳代码行」方向，当时量级尚小；现在它是最可能长出来的下一个对手，纳入跟踪。

信息缺口在于：只知其名与量级，不知其功能边界——日志还原之外是否已走向捕获/执行、跳转是执行期标记还是事后搜索、迭代方向指向哪里。不摸清这三点，就无法给出威胁评级，也无法判断哪些交互形态值得吸收、是否需要响应动作。本任务是调研型计划，无生产代码改动。

## 2. 方案

五步采集-对照-实测-结论-入库，产出一份独立调研报告。

### 2.1 Marketplace 证据采集

- 更新历史 API：`curl https://plugins.jetbrains.com/api/plugins/26550/updates`，取发版节奏、每版 changeNotes、兼容范围演变（222→263 的推进轨迹尤其值得看——它比本插件更早支持 263）。
- 页面抓取：`https://plugins.jetbrains.com/plugin/26550-mybatis-log-ultra`，取功能清单、描述、截图。
- 网络不通时走本地代理：`curl -x http://127.0.0.1:7890`（运行环境既有代理）。
- 原始 JSON/HTML 存本地临时目录不入仓库，报告只引关键数字、日期与原文引文。

### 2.2 功能边界四维对照矩阵

四维度 × 本插件/Ultra 两列，逐项标注有/无/实现形态，并在报告引用证据来源：

| 维度 | 对照要点 |
|------|----------|
| 日志还原 | 还原触发方式（手动粘贴/自动捕获）、参数填充、格式化能力 |
| 捕获 | 是否自动捕获控制台日志、是否需要用户配置过滤规则 |
| 跳转 | 「点击跳代码行」的实现形态：执行期标记（本插件 F-44-6 `SQLVIS-SOURCE` 路线）还是事后按行号/文本搜索回退 |
| 执行 | 是否可从还原 SQL 原地执行、有无数据源联动 |

同时核实两个边界问题：是否做静态预览（预期无，若有无异于赛道剧变）、是否有付费/激活墙。

### 2.3 安装实测（可选但强烈建议）

runIde 沙盒启动后从磁盘安装 Ultra zip（Marketplace 下载）试用：跑一段真实 MyBatis 日志还原流程，记录交互形态（工具窗布局、还原入口、跳转点击后的行为、设置项数量与默认值）。实测环节涉及 runIde 构建与沙盒占用，须按项目约定注册并行沙盒；若环境不具备实测条件，报告如实标注「未实测」并降级结论置信度，不以页面想象代替实测。

### 2.4 结论三段式

1. **威胁评级**：高中低 + 理由（与三合一闭环的重合度、迭代速度、兼容宽度、是否撞本插件核心差异区——静态预览）。
2. **值得吸收的交互精华清单**：每条注明去向（进金样矩阵场景 / 进需求池候选 / 明确不吸收及理由）——「竞品精华反哺」已有 M37/M38 先例。
3. **是否需要响应动作**：三选一——无需动作（继续观察）/ 防御性验证（N-8 式把它的高频场景补进金样矩阵）/ 功能响应（另立开发计划）。

### 2.5 报告入库与回链

报告落 `docs/开发计划/20260906-0230-MybatisLogUltra对标-调研报告.md`（命名沿 `20260902-0120-MyBatis-Flex支持可行性-调研报告.md` 先例；日期时间以实际提交为准）；第二轮调研报告 §3.3 Ultra 表行补一行「对标调研详见」链接。

- **不做功能响应预设立**：结论未出前不排任何功能任务，响应动作是报告的输出而非输入。
- **不抓取竞品源码/反编译**：只依据公开页面、公开 API 与黑盒试用，与 Flex 调研同一口径。

## 5. 风险

- Marketplace API 字段不完整或评分端点缓存异常（第一轮调研已遇 rating 端点返回全局缓存异常值）：评分以页面展示值为准，报告注明取值口径与抓取时间。
