## 一、现状与目标

### 1.1 现状

**描述三处**：
- `README.md`（单份，无中英变体）：已有「还原成可执行 SQL」表述，但卖点分散在功能表内，无首屏锚点。
- `src/main/resources/html/marketplace-custom-page.html`（416 行）：功能表格逐项说明，无醒目标语带。
- `plugin.xml` `<description>`：内联英文 CDATA，有 "resolved parameters" 无 "executable SQL" 字样。

**参数还原代码**（`log/` 包）：
- MyBatis：`MyBatisLogParser.parseParams()`——非贪婪正则+右边界断言，已处理值内逗号/括号、null 无标注、无标注回落逗号粗分。
- Hibernate：`HibernateLogParser.extractBindingParam()`——`binding parameter [n] as [TYPE] - [val]` 三态状态机。
- JdbcTemplate：`JdbcTemplateLogParser.renderUntyped()`——数值原样/null→NULL/其余引号。
- 填充核心：`LogSqlRestorer.restore()`（按序替换 `?`）+ `sql/ParameterReplacer.buildExecutableSql()`（ParamHint/ParamQuote 引号控制）。

**既有回归**（`src/test/.../log/`、`/sql/`）：已覆盖值内逗号与括号、null 居中、无标注回落、单引号转义、IN 多占位符、时间类型引号、值含问号不干扰。**差距**：无「值含空格且无类型标注」「日期时间值含逗号/空格」用例；`JdbcTemplateLogParserTest` 边界覆盖薄。

**方言验证通道**：`DialectTest.kt`（单文件 9 方言）+ `sql/verify/` 引擎级五类（H2/SQLite/Testcontainers/金样/导出）；真机走 `DialectRenderDumpTest` 导出 JSON → DBX MCP 执行（MySQL/PG/Oracle/DM/KingBase 已于 2026-08-29 通过）。

### 1.2 目标

1. 三处描述统一携带新锚点：**「别的插件给你文本，我们给你可执行的 SQL」**（英文 "Other plugins give you text. We give you executable SQL."），支撑点三条：Wrapper 静态预览全市场唯一、预览即执行闭环、国产数据库方言。
2. 竞品翻车场景回归集全绿并纳入常规分片。

### 1.3 非目标

- 不重构解析器逻辑——用例先行，红了才修，且修复单独立项。
- 不做 README 全面重写（只加定位段）。

## 二、实现设计

### 2.1 描述改版（三处同步）

| 文件 | 改动 |
|------|------|
| `plugin.xml` `<description>` | 英文 CDATA 重写：首段锚点句 + 三支撑点 bullet + 「2024.3+ 全版本持续适配」承诺句（O-1 借此落地） |
| `README.md` | 标题下新增定位段（锚点句 + 三支撑点），现有功能表不动 |
| `html/marketplace-custom-page.html` | 首屏标题下加标语带（现有表格保留） |

改版后自查 Marketplace 审核规范：description 内不携带商店外购买/评价链接。

### 2.2 参数拼接回归集

新增 `src/test/kotlin/.../log/ParamEdgeCaseRegressionTest.kt`（JUnit3 风格，方法内逻辑移私有 helper，避免 testXxx$lambda 陷阱）。场景矩阵：

| 维度 | 场景 |
|------|------|
| 值形态 | 含空格无类型标注、含逗号、含括号、含单引号、含问号、null 居中 |
| 类型 | LocalDate/LocalDateTime/Timestamp 带与不带空格分隔、IN 多值引号、NULL |
| 解析器 | 三族各跑同一矩阵中适用子集 |

断言方式：`restore()` 输出 SQL 字面量精确匹配（不是 contains）。

### 2.3 真机背书

`DialectRenderDumpTest` 导出清单中追加「参数还原后 SQL」样本（复用既有导出 JSON 工作流），DBX 通道真实执行——把「参数还原经真实引擎验证」写成发行说明固定话术。
