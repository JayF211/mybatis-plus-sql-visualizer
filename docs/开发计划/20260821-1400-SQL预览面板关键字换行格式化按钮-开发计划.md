## 需求摘要

SQL 预览面板右上角工具栏新增一个按钮，将 SQL 格式化为「关键字换行」模式：只在主子句关键字（SELECT / FROM / WHERE / ORDER BY 等）处换行，子句内容同行逗号/空格连接。

与现有功能的区别：

| 功能 | 行为 |
|------|------|
| 「格式化」（Format）按钮 | 全展开：列清单换行、AND/OR 缩进换行 |
| 「单行/多行」切换 | 全部挤一行 / 保持原始多行 |
| **新增「关键字换行」** | 子句顶格换行 + 同行内容压一行 |

### 示例

格式化前（多行展开）：
```sql
SELECT
    id,
    password,
    age,
    email,
    role_id,
    dept_id,
    status,
    username,
    create_time,
    update_time,
    deleted,
    version
FROM `user`
WHERE username = ?
    AND status = ?
    AND age >= ?
    AND deleted = 0
ORDER BY id DESC
```

格式化后（关键字换行）：
```sql
SELECT id,password,age,email,role_id,dept_id,status,username,create_time,update_time,deleted,version
FROM `user`
WHERE username = ?  AND status = ?  AND age >= ?  AND deleted = 0
ORDER BY id DESC
```

## 技术方案

### 核心算法

复用 `SqlFormatter` 的 `SqlLexer` 分词器，新增 `formatClauseLine()` 方法，规则：
- 关键字大写（复用 `NEW_LINE_KEYWORDS` 集合）
- 主子句关键字（SELECT / FROM / WHERE / GROUP / ORDER / HAVING / LIMIT / JOIN / UPDATE / SET / DELETE / INSERT / INTO / VALUES / UNION）各占一行
- SELECT/SET 后列清单同行，逗号+无空格连接（`id,password,age`）
- WHERE 后条件同行，AND/OR 前双空格（`=?  AND status=?`）
- LIMIT/GROUP/ORDER 参数同行，逗号+空格
- JOIN 修饰符（LEFT/RIGHT/INNER/FULL/CROSS）与 JOIN 同行
- 括号内内容同行（子查询不展开）
- 字符串/数字/标识符原文保留

### 关键实现差异（vs 现有 `format()`）

| 规则 | `format()`（全展开） | `formatClauseLine()`（关键字换行） |
|------|---------------------|----------------------------------|
| SELECT 后列清单 | 换行缩进 4 | 同行逗号无空格 |
| AND/OR | 换行缩进 4/8 | 同行双空格 |
| 逗号 | 换行 | 同行（SELECT/SET 无空格；其余空格） |
| 子查询括号 | 换行缩进 | 同行 |
| 括号追踪 | 需要（缩进栈） | 不需要 |

## 改动清单

### 1. `ui/highlight/SqlFormatter.kt` — 新增 `formatClauseLine()`

新增方法（Kotlin `object` 内）：

```kotlin
/**
 * 关键字换行格式化：只在主子句关键字处换行，子句内容同行。
 * 与 [format]（全展开）互补——前者用于阅读细节，后者用于快速总览。
 */
fun formatClauseLine(sql: String): String
```

实现要点：
- 复用 `lex()` 分词
- 维护 `currentClause` 状态（与 `format()` 相同思路）
- 关键字换行：顶格（顶层）或同行（子查询内不展开）
- SELECT/SET 内逗号：`append(',')` 无空格 + `pendingSpace = false`
- 其余顶层逗号：`append(',')` + `pendingSpace = true`
- AND/OR：不换行，双空格前缀
- 括号：不追踪深度，内容直接输出

### 2. `ui/SqlPreviewPanel.kt` — 工具栏新增按钮

在 `toolbar()` 方法中，「格式化」按钮右侧插入：

```kotlin
add(smallButton(MpSqlVisualizerBundle.message("panel.keywordWrap")) { formatClauseLine() })
```

新增 `formatClauseLine()` 方法（private，与 `formatSql()` 对称）：

```kotlin
/** 关键字换行格式化：子句顶格换行、同行内容压一行（[SqlFormatter.formatClauseLine]）。 */
private fun formatClauseLine() {
    val editor = editor ?: return
    val formatted = SqlFormatter.formatClauseLine(editor.document.text)
    if (formatted != editor.document.text) {
        WriteCommandAction.runWriteCommandAction(project) { editor.document.setText(formatted) }
    }
}
```

按钮顺序（左→右）：Copy error | 单行/多行 | 格式化 | **关键字换行** | 导入参数 | 刷新

## 测试计划

### 新增测试（`SqlFormatterTest.kt`）

| 用例 | 输入特征 | 预期输出 |
|------|---------|---------|
| 基本 SELECT | 多行展开 SELECT/FROM/WHERE/ORDER BY | 子句顶格换行、列同行逗号无空格 |
| SELECT 列清单 | `SELECT\n  id,\n  name` | `SELECT id,name` |
| WHERE AND/OR | `WHERE a=1\n  AND b=2` | `WHERE a=1  AND b=2` |
| 反引号表名 | `` FROM `user` `` | 保留反引号 |
| 单行输入 | 已是单行 | 关键字处拆行 |
| 子查询 | `WHERE id IN (SELECT id FROM t)` | 括号内容不展开 |
| JOIN | `LEFT JOIN o ON u.id=o.user_id` | LEFT JOIN 同行 |
| UPDATE SET | `UPDATE t SET\n  a=1,\n  b=2` | SET 后同行逗号无空格 |
| INSERT VALUES | `INSERT INTO t (a,b) VALUES (1,2)` | 同行 |
| LIMIT | `LIMIT 10, 20` | 同行逗号空格 |
| 空输入 | `""` / 空白 | 原样返回 |

## 风险与注意

1. **不与 renderSql 联动**：此按钮是对编辑器内容的直接操作（与 `formatSql()` 同模式），不影响渲染管线（`showSql` 中的自动格式化保持不变）
2. **compactMode 无关**：按钮始终可用（单行/多行模式下也可操作，直接改写编辑器内容）
3. **`WriteCommandAction` 包裹**：编辑器写入必须在 WriteCommandAction 内（与 `formatSql()` 一致）
4. **逗号后空格**：SELECT/SET 列清单逗号后**无空格**（用户示例 `id,password,age`），其余逗号后有空格
