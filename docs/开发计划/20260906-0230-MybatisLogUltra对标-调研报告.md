## 1. 对象概况

Mybatis Log Ultra（Marketplace ID 26550，xmlId `org.tiktok.plugin`），作者 yalonglee（杭州，个人 vendor，已实名验证，EULA 主体 YaLongLee）。定位是「实时字节码增强」的 MyBatis Log Plugin：不是经典控制台日志解析路线，而是运行期 agent 挂载拦截 SQL——文档站副标题原话「献给每一位在繁杂日志里认真排查问题的开发者」，SEO 关键词明写 bytecode enhancement。

## 2. 四维对照矩阵

「本插件」列依据本地代码与 CHANGELOG（分支 feature/r2-n10-ultra-recon，基线 0edb7b9），Ultra 列依据上节证据。

### 2.1 日志还原

| 项 | 本插件 | Mybatis Log Ultra |
|----|--------|-------------------|
| 还原触发 | 控制台出现 MyBatis 日志即自动进捕捉态，首条 SQL 自动展开（控制台桥 `SqlLogConsoleBridge`）；另支持手动粘贴/文件读取（`SqlLogFileReader`） | 运行期 agent 拦截，SQL 带参数直接呈现；4.0.13 起 SQL 不再打进默认控制台，即还原发生在插件工具窗而非控制台回显（证据：文档站「运行应用以查看拦截的 SQL」+ 4.0.13 notes） |
| 参数填充 | 按字段类型回填（PreparedStatement 参数逐类型转换） | 「自动将参数组装到预处理语句」（页面描述原话），形态一致；agent 拿到的是运行期实参，理论上无解析失败场景（未实测，推断） |
| 格式化 | SqlFormatter 关键字分派（v2026.9.4 changeNotes） | 工具窗内嵌 SQL 语法高亮（文档站构建产物含全套 SQL 方言关键字表），格式化能力未见明述（未实测） |
| 范围 | MyBatis/MyBatis-Plus/JPA/HQL/JdbcTemplate 等 9 框架族静态+日志双路 | 仅 MyBatis 生态（JDK1.8+/MyBatis 必选，Spring 可选，README badge） |

### 2.2 捕获

| 项 | 本插件 | Mybatis Log Ultra |
|----|--------|-------------------|
| 自动捕获 | 控制台桥监听运行配置输出，零配置自动捕获 | agent 挂载 JVM 拦截（「实时字节码增强」），同样零配置，且不依赖用户日志格式；可在设置里关掉 agent（2.0 notes），关掉后回退形态未见文档（未实测） |
| 过滤规则 | 无需配置即捕获；面板内类型过滤 + Ctrl+F 实时搜索（`SqlLogPanel.kt`） | 三种捕获策略：接口请求级输出（按 HTTP 请求聚合）、关键词实时过滤（表名/操作类型）、方法级聚焦（Service/Controller 方法执行期 SQL）（文档站「三种高效模式」文案）；4.0.14 起支持按请求和关键词过滤 |

关键差异：本插件捕获依赖用户工程的日志输出格式（p6spy/原生 MyBatis 日志），Ultra 的 agent 路线在字节码层拿数据，用户日志怎么配都不影响——这是捕获维度的真实代差，但代价是 59.7 MB 包体与「向用户 JVM 注入 agent」的信任成本。

### 2.3 跳转

| 项 | 本插件 | Mybatis Log Ultra |
|----|--------|-------------------|
| 实现形态 | 执行期标记：自动向用户项目注入 MyBatis-Plus InnerInterceptor 源码（F-44-7 `SqlSourceInterceptorAutoInjector`，幂等），拦截器捕获调用栈打 `SQLVIS-SOURCE|路径|行号` 标记行（F-44-6 `SqlSourceMarker`），桥解析后精确跳转 file:line；拦截器被删则回退表名搜索 | 「点击任何日志条目即可直接跳转到编辑器中的确切代码行」（页面原话）；agent 在运行期已知 caller，无需改动用户工程。4.0.15「新增代码行级别的导航」 |
| 跳转目标 | Java 调用行 | Java 与 XML mapper 双目标（文档站 i18n：`jump_to_xml`/`jump_to_java`） |
| 部署成本 | 需注入拦截器+应用重启生效；好处是无 agent 注入的信任顾虑、代码可见可删 | 零改动零重启；代价是闭源 agent 挂载生产/开发 JVM |

形态判断：两边都是执行期信息，不是事后文本搜索回退；差别在「用户项目内生成可见拦截器代码」对「用户进程外挂闭源 agent」。知乎「2025 必装 IDEA 插件清单」评价（搜索快照转引，原页 403 未直接核实）：「Mybatis Log 系列中体验做的最好的一款插件，唯一支持跳转到 SQL 执行代码行的」——「唯一」的说法在 2025 年语境成立，本插件 F-44-6 之后此差异已被拉平。

### 2.4 执行

| 项 | 本插件 | Mybatis Log Ultra |
|----|--------|-------------------|
| 原地执行 | SQL 预览面板内嵌 IDEA 原生 Database 控制台（v2026.9.2），EXPLAIN 七方言矩阵 | 无数据源联动证据；「可执行 SQL 还原」明说「为您提供可直接在数据库客户端运行的 SQL 查询」——即复制到外部客户端执行。工具窗文案含「Restful 接口工具」（send/params/auth/headers/body 等），疑内嵌 HTTP 请求工具用于触发接口采集 SQL（未实测，形态不确定） |

### 2.5 两个边界核实

- 静态预览：无。页面、README、文档站全部功能叙事都围绕运行期捕获（字节码增强/agent/请求聚合），无任何 Wrapper/XML/HQL 静态推导能力迹象。预期成立，赛道未剧变。
- 付费墙：成立。API `pricingModel: PAID` + `purchaseInfo.trialPeriod: 30` + EULA（商业闭源许可，禁反编译，含「free trial」条款）。具体价格未取得：Marketplace 页面为 SPA（静态抓取无价格渲染），API 无价格字段，文档站与 README 均无价格文案。第二轮报告当时未识别出付费属性，此为本轮新发现。

## 3. 结论

### 3.1 威胁评级：中

理由。重合度：日志赛道四维中还原/捕获/跳转三维正面重叠，Ultra 在捕获形态（agent 与日志格式解耦）和跳转部署成本（零改动）上各有真优势，付费墙则限制其在中文学生/小团队盘子的渗透速度。迭代力：4.0 大版本证明其有三个月连发三个大版本、随后一年憋出跨六个小版本大重构的能力，不是蹭名式竞品；但 2026-05 后进入平台期，年更节奏难以快速吞掉赛道。核心差异区：静态预览+原地执行+EXPLAIN 完全未被触及，三合一闭环无正面冲突。体量与属性：4.7k 下载、个人闭源付费 vendor，与本插件免费+开源可查+Marketplace/Gitee 双通道的错位竞争格局未变。升级为中而非低的触发点是兼容宽度（222 起步接住了本插件 243 以下接不住的存量用户）与 agent 路线的体验上限；未升级为高的原因是付费墙+无静态预览+体量尚小三者叠加，两年内不构成本插件核心盘的正面威胁。

### 3.2 值得吸收的交互精华清单

1. 跳转目标扩到 XML mapper（Ultra `jump_to_xml`）：本插件 SQLVIS-SOURCE 标记目前只打 Java 调用行，MappedStatement 到 XML 节点的跳转是空白。去向：金样矩阵场景候选，随 N-8 防御性验证一并锁定场景。
2. SQL 执行报错与 SQL 同列展示（4.0.14）：执行期异常堆栈行控制台桥天然可见，解析成本低、调试价值高（参数绑定报错 Ultra 自己也不支持，可一并覆盖形成反超）。去向：需求池候选（P2）。
3. 请求级聚合视图（按 HTTP 请求分组 SQL）：调试单个 API 的完整 DB 交互是真实场景，但实现依赖运行期请求上下文，控制台桥拿不到边界，除非同样走拦截器/agent 注入标记行——可在现有 SqlSourceInterceptor 模板上扩展请求标记行，成本中等。去向：需求池候选（P2，注明依赖拦截器协同）。
4. 关键词/类型过滤：本插件已有（类型过滤+Ctrl+F 实时搜索），非差距，不吸收。
5. 远程环境 Arthas 路线：面向远程排障场景，超出本插件「IDE 内闭环+静态分析」定位，且引入 agent 分发与安全审查负担。明确不吸收。
6. agent 字节码增强捕获路线：捕获形态确实更优，但与本插件「用户项目零依赖、代码可见」的产品伦理相悖，且 59.7 MB 包体、闭源注入的信任成本在个体开发者盘子里未必是净收益。明确不吸收，保持控制台桥+拦截器模板双路线。

### 3.3 响应动作：防御性验证（N-8 式）

无需另立开发计划。把 Ultra 已验证的高频场景（XML 双目标跳转、执行报错同列、请求级聚合）补进金样矩阵锁场景，同时两条低成本事实修正：第二轮报告 §3.3「月度活跃」表述按本报告 §1 口径修正为「4.0 后平台期年更」；对外物料（README/Marketplace 描述）可显性强调「免费+精确跳转+静态预览」三连，正好压在 Ultra 的付费墙与能力空白上——此为文案动作，非功能任务。继续跟踪其下一次大版本（预计 2027 上半年节奏），若其补静态预览或开免费层，触发重评。
