## 二、目标与非目标

**目标**：releaseGate 总墙钟压缩，预期 −1.5~4 分钟（对 13m11s 约 10%~30%，最终以 A/B 读数为准）。手段只动编排与并行度，不动任何门禁语义。

**非目标（红线）**：
- 门禁内容零删减：三目标 × 2 道兼容门禁（离线 verifyGate + 在线 verifyMarketplace）、全量测试、testExternal 护栏桶、agent 测试、e2eFakeIde 探针，一个不少；
- 不动测试执行语义（T15 地板声明：全量测试本体物理面零入口，本轮不碰 `mpv-testing.gradle.kts` 的分片算术；仪表化锚点除外）；
- 不复活 T-ReleasePerf-02 已否决的 verifyGate 与 testShards 整体并行（内存 Commit 判据：testShards 5 片峰值 65.0GB、余量 9.7GB，硬判据 8GB，再塞 verifier JVM 进同窗大概率破线）。

**验收判据（parity 三断言）**：终轮 releaseGate 全绿读数中，①测试例数 ≥ dev 基线（6395 例/566 计划类，只增不减）、failures=0；②兼容门禁三目标全部 Compatible 且问题块与基线一致（0 未登记块）；③e2eFakeIde PASS=26 FAIL=0。

## 四、待验证前提（实施者先证伪再动手）

- **前提 A（同项目任务并行）**：Gradle 9.7 + org.gradle.parallel=true 下同项目任务真并发——T-TestPerf-05 已用 START/END 锚点实证两片/三片重叠（T-TestPerf2 计划 §T-TestPerf-05 节，旧「同项目内任务不并行」口径已证伪）。实施 L1 后以三进程锚点复核，若不重叠则 L1 直接销案。
- **前提 B（verifier 并发无锁互踩）**：verifier-cli 并发进程在**各自独立 verify-home 子目录**下无缓存写冲突。依据=T-VerifierHomeIso：冲突历史只发生在全局 ~/.pluginVerifier 共享 extracted-plugins 场景；独立 home 目录各写各的。反证点=三份 verdict 文本与串行轮逐字一致（reports 根目录共享，但各目标写各自 IDE 子目录，无共享写点）。
- **前提 C（内存判据）**：三 verifier JVM 并发的 Commit 峰值不把全机余量压破 8GB 判据。L1 A/B 轮全程采样 Commit（5s 间隔），破线即 L1 销案回退串行（`-PverifyGateParallel=false` 或删改动）。
- **前提 D（verifyMarketplace 现状浮动态）**：仪表读数确认它当前到底落在哪个窗口。若已与 testShards/verifyGate 重叠且总墙钟没有因它变长，L2 销案不动。
- **前提 E（一次性税不进样本）**：新工作树首轮全量自带 buildSrc 编译税 + 权重表冷启动 + verify-home idb 冷建（T15 教训⑤），记 R1 弃样；计时 A/B 全部用 warm 轮同窗交错（T5 定例：效应 <10% 的调参必须同窗交错，禁单窗成对对照）。
- **前提 F（verifier 离线读数时效）**：3m06s 是 2026-09-15 读数，插件体量已增（MCP 工具面、agent、K2J 移植），S2 重测为准。

| verifyGate（离线三目标） | **252.9s** | 三目标完成时刻 169.7/239.9/246.1s（243/262/253），全部 Compatible，计数与 v2026.10.6 发行读数一致（弃用 25/87/31、实验 94/92/92、移除中 4/7/5） |

| testShards 窗（5 片叶子） | 236.0s（最长片） | 片墙钟 s1=221.8 / s2=236.0 / s3=209.9 / s4=188.9 / s5=204.9；testExternal 89.8s 早收 |

三个改变认知的读数：

1. **L1 销案（前提 A 镜像证伪）**：verifier-cli 单进程内对多目标**本来就是并发分析**——verifyGate 墙钟 252.9s，而三目标时长若串行应合计 655.7s（169.7+239.9+246.1）；verifyMarketplace 同构（合计 1970.7s vs 墙钟 873.2s）。拆三进程不增加并行度，反而 3× JVM + 3× idb 冷建；且 R1 窗口 Commit 峰值已到 73.31GB（上限 74.7GB，余量 1.4GB，破 8GB 判据）——再叠三路 verifier 本就危险。L1 连同开关一起取消，不写代码。
2. **叶子任务浮动，链路比注释更并行**：testShard1~5 的 START（424186~424193）早于 buildPlugin 的 END（424599）——mustRunAfter 只钉聚合任务名（verifyGate/testShards/e2eFakeIde），分片叶子/testExternal/agent 测试无序约束，调度器就绪即启。真实结构＝`总墙钟 ≈ max(verifyMarketplace, verifyGate, 分片窗, 编译) + e2e`。v2026.10.6 的 13m11s 与本结构一致（当时 marketplace 缓存较暖）。
3. **瓶颈唯一落点＝verifyMarketplace 在线解析**：冷 873s 是第二长杆 verifyGate（253s）的 3.4 倍，且它无序约束、从链路起点就并发横跑全程。R2 的 warm 读数定后续杠杆（verifier 若在 home 内缓存 marketplace 元数据，warm 应显著回落；若无缓存效应，在语义不许变红线下如实登记「在线口径不可压缩」，转攻次级项）。

其余记录：
- agent `SenderLoopBackoffTest` 1 例红（连上即被关_退避增长且达上限后放弃该端口），**隔离复跑 11s BUILD SUCCESSFUL**——在册 flake 家族（agent 退避竞速，负载敏感；R1 冷窗 Commit 73GB 尖峰窗口），非真回归。
- releaseGate 聚合任务的 START 锚点语义修正：releaseGate 是汇点任务，doFirst 在全部依赖完成后才触发（与 END 几乎同时）——整链起点读 Gradle 自身 BUILD 行，锚点只用于内部分解。不改代码，记录语义。
- 采样器首次启动被执行策略拦截（`-ExecutionPolicy Bypass` 解决）；Commit 全程峰值 73.31GB / 上限 74.7GB（R1 冷窗尖峰），稳态 60~64GB。

### R2 warm 台账（20261006 03:14~03:26，作废轮——内存耗尽窗）

**R2 失败非代码问题**：同一构建脚本（S1 后）R1 可过、R2 挂 4 任务（verifyGate / verifyMarketplace / testShard1 / testShard5）。证据链：

- Commit 采样：03:18:02 冲到 **74.69GB / 上限 74.7GB 顶格**（余量 0.01GB）；轮前底噪 60.4GB（R1 峰值 73.31，同任务图）。
- testShard1/5 执行器 `java.lang.OutOfMemoryError` + `FileSystemException: 系统资源不足，无法完成请求的服务`（打不开 253 发行版文件）；verifyMarketplace `Connection reset by peer` ×2 + `SSL peer shut down incorrectly`（代理链路同窗被拖死）。
- 机器底噪：513 进程、空闲 Commit 56~64GB——历史定例的 8~10GB 余量判据在本日环境下被环境占用吃掉，门禁自身峰值（双 verifier + 5 测试 JVM + agent 子 JVM 叠加，浮动叶子全并发）再叠 10~15GB 正好触顶。
- **事后对表发现双车道相撞**：并行登记表显示另一会话 `t-synck2jm29`（k2j 同步）03:15:11 启动、预计 04:15 结束——与 R2 窗口（03:14~03:26）完全重叠。R2 的 +14.3GB 峰值增量（R1 同任务图只 +10.3GB）与成片 OOM 首要嫌疑是双 gradle 车道并跑，其次才是底噪。R2 的峰值 74.69GB 里含对方车道的贡献，作废轮处置不变，但「本机双车道跑两份全量门禁必然顶格」成为本轮实测结论（历史定例「构建并发上限 2 路」指的是 testFast 级双路，两份 releaseGate 级全量门禁叠跑超出了该定例的适用面）。

结论与影响：
1. **本日全机门禁轮在内存天花板上是走钢丝**——R2 作废（耗时窗无效），复跑改用小足迹探针分环节取数，全链权威轮等底噪回落再跑。
2. 浮动叶子结构下「5 测试 JVM + 双 verifier 全并发」是峰值推手；这是**既有结构**（mustRunAfter 只钉聚合任务），不是本轮引入。峰值并发与墙钟压缩存在张力（串行化降峰值但拉长墙钟），本轮不动作，如实登记供后续轮裁决。
3. R2 部分锚点仍有效：buildPlugin 动作 0.4s；testExternal 77.7s 早收；片窗 s2=205s / s3=226s / s4=246s（s1/s5 阵亡无 END）；verifyGate/verifyMarketplace 均 START 于 03:14:08 与分片同窗，无 END。
