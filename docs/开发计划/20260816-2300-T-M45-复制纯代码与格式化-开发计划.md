- 背景来源：用户反馈——「SQL→Java 结果区复制按钮复制出注释/说明文字，应该只复制 Java 代码」+「希望能一键格式化生成的代码」+「行尾说明注释应改为独立行注释」

## 1. 需求分析

| # | 需求 | 现状 | 目标 |
|---|------|------|------|
| 1 | 复制只复制 Java 代码 | 结果区「复制」按钮复制整个预览文本（含注释行 `// 实体类: User`、`// 调用类: UserService` 等） | `JavaCommentStripper` 纯文本剥离：整行注释行删 / 行尾注释保代码 / 字符串内斜杠不误伤 / 空行保留；弹窗 + 面板复制统一 |
| 2 | 行尾说明注释改独立行注释 | 生成器输出行尾注释 `...eq(User::getUsername, "admin") // 用户名 = admin` | 改为独立行注释（注释单独一行，代码语句不跟行尾注释），可读性更好 |
| 3 | 结果区「格式化代码」按钮 | 结果区无格式化按钮，用户需手动粘贴到编辑器格式化 | `JavaCodeFormatter`：**代码包合成类方法体再 reformat——顶层裸表达式语句在文件级是解析错误、格式化乱码实证**；PSI 创建包 `ReadAction.compute`；默认风格不折行，折行依赖用户风格 |

## 2. 实现要点

- `JavaCommentStripper`：正则 + 状态机双路径（字符串内斜杠不误伤）
- `JavaCodeFormatter`：`PsiFileFactory.createFileFromText` 包合成类 + 方法体 → `CodeReformatProcessor` reformat → 剥离合成包裹提取纯代码
- 预览面板 + 弹窗两处复制按钮统一走 `JavaCommentStripper`
