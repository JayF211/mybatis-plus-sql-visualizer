# 日志转 SQL Tab 开发计划（T-M38）

- 日期：2026-08-16
- 状态：**立项（需求已确认，实施中）**
- 前置：T-M37 已交付（5c0b223，1017 全绿）；T-M31 日志工具窗口三标签页范式（SQL 日志 / SQL 预览 / SQL→Java）
- 背景来源：用户需求——侧边栏工具窗口的「SQL 预览」tab 改为「log 转 SQL」：粘贴 MyBatis 日志（`Preparing:` / `Parameters:` 行）→ 批量还原为可执行 SQL

## 1. 需求分析（用户视角，三项已确认）

1. **交互形态 = 输入转换工具**（与「SQL → Java」tab 对称）：上下分栏——上：日志输入区（粘贴 MyBatis 日志文本）；下：可执行 SQL 结果区（SQL 高亮 + 复制 + 格式化切换）；Tab 1 列表右键菜单加「发送到日志转 SQL」；
2. **多组语句批量转换**：一段日志含多组 `Preparing:` / `Parameters:` 对时全部转换，组间 `-- SQL #N` 注释分隔；
3. **输出默认多行格式化**：输出即 `SqlFormatter.format` 多行缩进，工具栏「单行/多行」切换按钮。

## 2. 技术方案

### 2.1 核心事实：解析还原能力已存在（T-M31）

「log 转 SQL」链路在自动捕获中已完整实现，本次**直接复用**：

| 能力 | 复用来源 | 说明 |
|------|---------|------|
| 日志行配对解析 | `MyBatisLogParser`（log/） | `feed` 逐行 + `closePending` 闭合 + `takeEntries` 取条；宽容匹配（mixedPrefix）天然支持 `==>  Preparing:` / 原生 / 带时间戳前缀 |
| 参数解析 | `MyBatisLogParser.parseParams`（internal） | `1(Long), abc(String), null` → `LogSqlParam` 列表 |
| `?` → 字面量还原 | `LogSqlRestorer.restore` | 数值/布尔原样、String 引号 + `'`→`''`、null → NULL、无类型启发式 |
| 数据模型 | `LogSqlEntry` / `LogSqlParam`（LogSqlModels.kt） | 新增 `LogSqlEntry.toLogText()`（条目 → 日志文本，与 parser 互逆，供「发送到此处」） |
| SQL 格式化 | `SqlFormatter.format`（ui/highlight） | 输出多行缩进 |
| SQL 高亮编辑器 | 既有 createPreviewEditor 范式 | `EditorFactory` + `LexerEditorHighlighter(SqlSyntaxHighlighter())` |

### 2.2 新面板 `LogToSqlPanel`（log/LogToSqlPanel.kt，仿 SqlToJavaPanel）

```
Splitter 上下分栏
├── 上：日志输入区（普通 Editor——日志含前缀/时间戳噪声，不设 SQL 高亮；行号开）
│     └── 行内 ActionToolbar：转换 / 清空
├── 下：SQL 结果区（可编辑 Editor + SQL 词法高亮）
│     └── 行内 ActionToolbar：复制 / 单行↔多行切换 / 清空
└── 底部：状态行（JLabel 错误红字 / 提示灰字）
```

**转换流程（EDT 同步纯函数——文本解析无 PSI/实体查找，无需异步）**：

```
转换按钮 / loadFromEntry
→ 输入 blank → 红字「请先粘贴 MyBatis 日志」
→ 前缀从 PluginSettings 读（logSqlPrefix/logParamPrefix/logMixedPrefix/logMaxParseLength，与自动捕获同源）
→ 逐行 feed MyBatisLogParser → closePending → takeEntries
→ 0 条 → 红字「未解析到 Preparing/Parameters 行」+ 示例提示
→ N 条 → 每组 withTerminator + 格式化（toggle 决定），多组 `-- SQL #N` 分隔，WriteCommandAction 写结果区
→ 含 `?`（参数不足）→ 红字警告「N 条 SQL 仍含 ? 占位符」；否则灰字「已转换 N 条 SQL」
```

**「发送到日志转 SQL」联动**：`loadFromEntry(entry)` → `entry.toLogText()` 渲染回日志文本填入输入区 → 立即转换。渲染与 parser 宽容匹配互逆（round-trip 单测覆盖）。

## 5. 风险与注意

- **并行会话**：T-M37 P1（发送到 SQL→Java + 副表多候选）同期开发，`SqlLogToolWindowFactory.kt` / properties 为共享文件——编辑只动自己的行，编译验证需等对方提交（对方中间态会阻塞 compileKotlin，非本任务问题）；
- 输入编辑器不设 SQL 词法高亮（日志文本含前缀/时间戳，高亮误导）；
- 转换同步执行（maxParseLength 防超长行卡顿）。
