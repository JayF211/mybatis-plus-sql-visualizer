# Wrapper 链实时提示（inspection + inlay hint）开发计划（T-M32）

- 日期：2026-08-15
- 状态：**立项（需求与方案已收集，暂缓实施——先交付 T-M31 日志还原 / T-M36 反向转换系列）**
- 任务源：docs/开发计划/20260815-1900-日志SQL还原与Wrapper实时提示及P2深化-开发计划.md（T-M31~T-M35）
- 背景：插件独占品类 = Wrapper 链 / XML / 注解 → SQL 静态预览（主动触发）。T-M32 把能力从**主动预览**升级为**被动实时反馈**——写代码时 IDE 直接提示问题与 SQL，无需任何操作。

## 1. 需求（用户视角）

**1.1 代码检查（inspection）**——Wrapper 链上的实时波浪线：
- 字段引用错误：`.eq(User::getNmae, x)` / 字符串列名拼错 → 错误波浪线（现状：预览 SQL 时才发现）；
- 全表操作风险：UPDATE/DELETE 无 WHERE 条件 → 警告波浪线（现状：仅预览弹窗内有提示）；
- 链未消费：`lambdaQuery().eq(...)` 后无终结方法（list/one/count/remove 等）→ 提示"链式调用未消费，SQL 不会执行"；
- 类型不匹配：`.eq(User::getAge, "abc")` 数字列比字符串 → 警告。

**1.2 内嵌提示（inlay hint）**——Wrapper 链旁边实时显示当前 SQL 摘要：
- 写完 `.eq(...).like(...)` 即刻在链式调用旁浮现灰色小字 SQL（复用预览引擎，改参数实时更新）；
- 长 SQL 截断 + tooltip 全文；与现有预览弹窗互补（inlay 常驻、弹窗深查）。

## 2. 技术方案

- **复用存量引擎**：WrapperLocator 定位 + ConverterRegistry 转换 + SqlGenerator 渲染（938 测试覆盖的成熟链路）——inlay/inspection 均调用同一 `SqlPreviewService.preview` 管线，语义与预览完全一致；
- **性能红线**（对齐 gutter O(1) 约定）：inlay 计算仅当文件含 Wrapper 链首语法形态时触发（复用 `WrapperAnchorDetector` 快速判定）；计算结果按文件 modificationStamp 缓存（复用 WrapperCache）；
- **inspection 注册**：`LocalInspectionTool` + `InspectionToolProvider`（settings 页可开关、严重级别可调）；快捷修复（QuickFix）首期仅"跳转预览"；
- **inlay 注册**：`InlayParameterHintsProvider`（2025.3+ API）或 `EditorFactory` listener（243 兼容需核实——T-M32 实施时以 243 构建基准验证 API 可用性，必要时降级方案）；
- **MPJ 场景**：与预览引擎同源天然覆盖（MPJLambdaWrapper 链同样提示）。

## 4. 边界

- 不阻塞编辑（纯提示，不自动改码）；inlay 显示开关可独立关闭；
- 动态条件（布尔重载）inlay 按默认启用渲染，与预览面板一致；
- 2025.3+ 慢操作守卫：inlay/inspection 计算全部后台 ReadAction（复用 previewAsync 模式）。
