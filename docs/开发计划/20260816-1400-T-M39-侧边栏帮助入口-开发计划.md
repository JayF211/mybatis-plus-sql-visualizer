# 侧边栏面板帮助入口开发计划（T-M39）

- 日期：2026-08-16
- 状态：**✅ 已交付（2026-08-16，1056 测试全绿）**
- 前置：T-M31~T-M38 已交付（工具窗口承载 SQL 日志/预览/SQL→Java 多 tab，标题已改插件名）
- 背景来源：用户需求——侧边栏插件面板加帮助入口（新 tab 或问号按钮），点击显示**核心功能、使用方法、默认快捷键**等

## 1. 需求分析

面板已承载多项能力（SQL 日志捕获还原 / SQL 预览 / SQL→Java 反向转换），用户需要一处集中查看：插件能做什么、怎么用、默认快捷键是什么。

**入口方案选型**：
| 方案 | 优点 | 缺点 |
|------|------|------|
| 新 tab「帮助」 | 常驻可见 | 面板已有 3 tab 再增显臃肿；帮助属低频查看 |
| **工具栏「?」按钮 → 帮助弹窗**（选定） | 符合 IDE 惯例（Help 类内容临时查看）；不占面板空间；实现轻量 | 每次点击弹出 |

**选定方案**：工具栏问号按钮（`AllIcons.General.Help`，位于设置按钮旁）→ 弹 `HelpDialog`（DialogWrapper + HTML 渲染只读内容）。

## 2. 帮助内容（i18n 双语，bundle 存 HTML 块）

### 2.1 核心功能（6 项）
1. **Wrapper → SQL 预览**：Java 代码中的 MyBatis-Plus/MPJ Wrapper 链实时转可读 SQL（9 方言、动态条件开关、逻辑删除/乐观锁注入）；
2. **SQL 日志捕获与还原**：监听运行控制台，Preparing/Parameters 还原可执行 SQL（去重/过滤/时间戳/逻辑删除值）；
3. **SQL → Java 反向转换**：SQL 转 QueryWrapper/LambdaQueryWrapper/Wrappers 工厂/MPJ 代码——支持增删改查、多表 JOIN、可选 Service/Mapper 调用类与返回 VO；
4. **XML/注解动态 SQL 预览**：mapper XML 与 @Select 等注解的 if/foreach/OGNL 动态 SQL 预览（复刻 MyBatis 3.5.19 算法）；
5. **SQL 代码补全**：预览面板/输入区 SQL 关键字补全（打字即弹）、XML/注解 SQL 内补全；
6. **执行 SQL 与更新**：弹窗内一键执行（Ultimate + Database）、设置页检查更新与自动安装。

### 2.2 使用方法（按功能给入口与步骤，各 1~2 行）
- 预览：光标置于 Wrapper 链 → 右键 Convert to SQL / Alt+Shift+Q / 行号区图标；
- 日志：打开侧边栏「MP SQL 日志」→ 点击捕捉 → 运行应用；右键条目复制/删除/发送到 SQL→Java；
- 反向转换：选中 SQL 文本 → Alt+Shift+J，或侧边栏「SQL → Java」tab 粘贴转换（可调形态/调用类/VO）；
- 配置：Settings → Tools → MyBatis-Plus SQL Visualizer（方言/格式化/逻辑删除/表前缀/更新）。

### 2.3 默认快捷键表
| 功能 | Windows/Linux | macOS |
|------|--------------|-------|
| Convert to SQL | Alt+Shift+Q | Alt+Shift+Q |
| Convert SQL to MP Java Code | Alt+Shift+J | Cmd+Shift+J |

（可在 Settings → Keymap 修改；两 action 的注册见 plugin.xml 实证。）

### 2.4 其他
- 反馈入口：Gitee Issues 链接（复用 plugin.xml description 中的 URL）；插件语言切换入口。

## 3. 技术方案

1. **HelpAction**（SqlLogToolWindowFactory.kt 内，仿 SettingsAction）：工具栏组末尾；icon `AllIcons.General.Help`；`actionPerformed` → `HelpDialog(project).show()`；
2. **HelpDialog**（新文件 log/HelpDialog.kt）：DialogWrapper——中心面板 = `JEditorPane`（`text/html`，只读，`JScrollPane` 包裹，preferredSize 约 560×460）；内容来自 bundle；
3. **i18n**：新增 keys（`help.dialog.title`、`help.content.html` 等；HTML 块含中文/英文各一份 bundle；properties 内 HTML 用 `\n` 续行、引号转义——参照现有长文案惯例）；
4. **HTML 渲染细节**：JEditorPane 的 HTML 子集（h2/ul/table 支持有限——用 h3 + ul + 简单表格或不依赖表格样式，宁可朴素）；字体跟随 IDE（内容用相对字号）；
5. **测试**：HelpDialog 创建后内容非空 + 关键片段存在（面板测试风格，BasePlatformTestCase）；HelpAction 存在性（工具栏组内）。

## 4. 边界

- 帮助为静态内容（不随设置动态变化——快捷键修改提示用户去 Keymap 查看）；
- 不做 Web 页面/外部浏览器跳转（弹窗内展示，离线可用）；
- Gitee 链接仅文本展示（用户可复制；不做超链接跳转避免平台差异——或 JEditorPane 支持可点击链接则启用，实现时评估）。
