## 三、解决原则

1. **架构基准 = master 片段渲染管线**。T-LogListFreeze04 是刚根治的 EDT 冻结问题（16 秒），HTML 通道（`SqlListHtmlRenderer`/`cachedListHtml`/`<br>` 折行）随 master 删除，不复活。
2. **dev 特征语义全部嫁接到新管线上**：T-ListMode 三显示模式、T-TwoLine 双行结构（master 9223f44 已保留双行片段结构，语义等价）、T-ErrReport、hbm、AutoShow 等一行不丢。
3. 注释类冲突（同一句话 master 多「（自 dev 移植）」后缀）取 master 版。
4. 双侧独立新增取并集：`normalizeSqlWhitespace`（master）、AutoShow 三字段与 ToolWindowManagerListener（dev）、dispose 中 `clickPreview.dispose()` 与 `searchDebounceTimer.stop()` 等。
5. `runRunner` 双参融合：`silent: Boolean`（T-DsCover：预览静默失败 + 清 last-runner 记忆）与 `onError: ((String) -> Unit)?`（T-Perf-01：面板行内红字恢复「执行中」态）正交，签名合并为 `runRunner(runner, silent = false, onError = null)`；静默路径只走 onError 不弹模态，显式执行路径保留 master 的模态引导并同样回调 onError。
6. plugin.xml 描述取 master（v2026.9.8 已发行文案，能力清单更全）；扩展点区自动合并后核对 T-ErrReport errorHandler EP 在位。
7. docs 三处：变更记录双侧顶插行按日期倒序并集；docs/MEMORY.md 并集；T-ErrReport 计划取 dev 版（含 §九 实施记录，master 版是纯定稿）。
8. 测试文件：两侧断言并集，master 已迁移的断言体系（片段渲染语义）为基准，dev 新增用例按新管线语义改写。

## 四、核心设计决策：三显示模式 × 固定行高

两份已交付的计划文档在此正面冲突：

- T-LogListFreeze04（master，09-08 上午）：可变行高 × HTML 排版 = 16 秒冻结根因，刻意决策「多行换行展示不再保留，全文查看由单击预览/双击弹窗承接」，`fixedCellHeight` 实测固定换 WideSelectionListUI O(1) 快路径。
- T-ListMode（dev，09-08 中午）：应用户要求「三种显示模式可切换、默认关键字换行」，关键字换行/格式化模式本质是多行条目（`\n` 转 `<br>` 变高行），依赖的正是旧可变行高通道。

**定案：行高策略按模式分流。**

- `SINGLE_LINE`：固定行高（meta + 1 SQL 行，与 master 现状完全一致，O(1) 快路径保留）。
- `KEYWORD_WRAP` / `FORMATTED`：可变行高（`fixedCellHeight = -1`），但渲染走片段通道且**条目级缓存变换后分行的片段列表**（键含模式，模式变更即失效）——旧冻结的量级主因是每行每次测量的 BasicHTML 视图构建，片段 + 缓存后测量只剩轻量组件布局，与旧 16 秒冻结相差数量级以上。
- 模式切换时重设 `fixedCellHeight` 并整表刷新；列表元数据（选择、过滤、增量刷新、单击预览坐标换算走 `getCellBounds`）不受行高模式影响。
- 默认模式维持 T-ListMode 交付值 KEYWORD_WRAP（用户明确要求的默认态，不因合并回退）。
- 兜底预案：若真机大日志实测仍有卡顿，后续独立任务对多行模式加行数上限裁剪（超出部分提示走预览），本次合并不做。

旧 T-LogListFreeze04 的「`fixedCellHeight > 0` 布局快路径断言」测试按新语义改为模式感知断言（SINGLE_LINE 断固定、多行模式断可变），防回归语义不丢。
