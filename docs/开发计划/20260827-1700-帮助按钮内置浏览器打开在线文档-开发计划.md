# 调整：帮助按钮 → 内置浏览器打开在线文档 — 开发计划

> **日期**：2026-08-27
> **目标**：将 SQL 日志侧边栏工具栏「?」帮助按钮的行为，从打开硬编码 HTML 弹窗改为在 IDEA 内嵌浏览器中打开官方文档页面。
> **目标 URL**：`https://plugins.jetbrains.com/plugin/33633-mybatis-plus-sql-visualizer/documentation`
> **约束**：不得破坏工具栏组结构（5 项顺序不变）；JCEF 不可用时降级到系统浏览器。

---

## 一、现状

### 1.1 当前行为

`SqlLogPanel.HelpAction.actionPerformed` → `HelpDialog(project).show()` → 弹窗内 `JEditorPane` 渲染硬编码 HTML（来自 bundle 的 `help.content.*` 四个 key）。

**涉及文件**：

| 文件 | 作用 |
|------|------|
| `SqlLogPanel.kt:603-612` | `HelpAction` 内部类，`actionPerformed` 调用 `HelpDialog.show()` |
| `HelpDialog.kt:24-85` | `DialogWrapper` 子类，`JEditorPane` + `JBHtmlEditorKit` 渲染 bundle HTML |
| `HelpDialogTest.kt` | 4 个测试：内容渲染 / 四节结构 / 主题化 / 工具栏组 |
| `MpSqlVisualizerBundle*.properties` | `help.dialog.title` / `help.dialog.close` / `help.content.features` 等 key |

### 1.2 项目已有浏览器入口

`BrowserUtil.browse(url)` 已有两处使用（`UpdateSection.kt:82`、`ShareDialog.kt:142`），但走的是**系统默认浏览器**（外部进程），非用户要求的"IDEA 内嵌"。

---

## 二、方案选型

### 方案：JBCefBrowser 内嵌浏览器弹窗

IntelliJ Platform 2024.3+ 内置 JCEF（Java Chromium Embedded Framework），通过 `com.intellij.ui.jcef.JBCefBrowser` 可在对话框/面板中嵌入完整 Chromium 浏览器。

**选型理由**：
- IDEA 内嵌体验（不跳出 IDE、跟随 IDE 主题色）✓
- 平台 2024.3 已捆绑 JCEF（`com.intellij.ui.jcef` 包），无额外依赖 ✓
- 与现有 `HelpDialog` 结构一致（仍是 `DialogWrapper`，只是内容组件从 `JEditorPane` 换成 `JBCefBrowser.component`）✓
- 项目目标为 IntelliJ IDEA Ultimate，JCEF 恒可用 ✓

**降级策略**：`JBCefApp.isSupported()` 返回 false 时（罕见，如 headless / 部分 Linux 环境），回退到 `BrowserUtil.browse(url)` 打开系统浏览器。

## 四、A 类：HelpDialog 重写

**文件**：`src/main/kotlin/cn/song/mybatisplus/visualizer/log/HelpDialog.kt`

### 4.1 目标实现

```kotlin
package cn.song.mybatisplus.visualizer.log

import cn.song.mybatisplus.visualizer.util.MpSqlVisualizerBundle
import com.intellij.ide.BrowserUtil
import com.intellij.openapi.project.Project
import com.intellij.openapi.ui.DialogWrapper
import com.intellij.ui.jcef.JBCefApp
import com.intellij.ui.jcef.JBCefBrowser
import java.awt.BorderLayout
import java.awt.Dimension
import javax.swing.Action
import javax.swing.JComponent
import javax.swing.JPanel

/**
 * 帮助弹窗（T-M39）：侧边栏工具栏「?」按钮 → IDEA 内嵌浏览器打开在线文档。
 * - JCEF 可用时：内嵌 Chromium 浏览器（IDEA 内渲染，跟随主题）；
 * - JCEF 不可用时：降级 BrowserUtil.browse（系统浏览器）。
 */
class HelpDialog(project: Project?) : DialogWrapper(project, true) {

    private val url = "https://plugins.jetbrains.com/plugin/33633-mybatis-plus-sql-visualizer/documentation"

    init {
        title = MpSqlVisualizerBundle.message("help.dialog.title")
        isModal = false  // 非模态（可切回 IDE 继续操作）
        init()
        setCancelButtonText(MpSqlVisualizerBundle.message("help.dialog.close"))
    }

    override fun createCenterPanel(): JComponent {
        if (!JBCefApp.isSupported()) {
            // 降级：JCEF 不可用，开系统浏览器后关闭弹窗
            BrowserUtil.browse(url)
            return JPanel().apply {
                preferredSize = Dimension(DIALOG_WIDTH, 60)
            }
        }
        val browser = JBCefBrowser()
        browser.loadURL(url)
        return browser.component.let { comp ->
            JPanel(BorderLayout()).apply {
                add(comp, BorderLayout.CENTER)
                preferredSize = Dimension(DIALOG_WIDTH, DIALOG_HEIGHT)
                minimumSize = Dimension(DIALOG_MIN_WIDTH, DIALOG_MIN_HEIGHT)
            }
        }
    }

    override fun createActions(): Array<Action> = arrayOf(cancelAction)

    companion object {
        const val DIALOG_WIDTH = 900
        const val DIALOG_HEIGHT = 680
        const val DIALOG_MIN_WIDTH = 600
        const val DIALOG_MIN_HEIGHT = 400
    }
}
```

### 4.2 关键设计决策

| 决策 | 理由 |
|------|------|
| `isModal = false`（非模态） | 用户可能边看文档边操作 IDE，非模态更符合参考文档的使用场景 |
| 弹窗尺寸 900×680 | 文档页面需要更大视口（原 560×460 偏小，JCEF 渲染网页需要足够宽度） |
| 降级开系统浏览器后仍显示空弹窗 | 保持 `HelpAction` 调用签名不变；空弹窗有关闭按钮，用户可立即关闭 |
| `JBCefBrowser()` 无参构造 | 2024.3 平台可用；无需 `JBCefClient` 自定义 |

### 4.3 关于 JCEF 是否需额外 Gradle 依赖

`com.intellij.ui.jcef` 在 2024.3 平台中属于 `intellij.ui.jcef` 模块，捆绑在 IDEA 发行版内。需在 `build.gradle.kts` 验证：

- 若编译期报 `unresolved reference: jcef`，需添加 `bundledPlugin("com.intellij.ui.jcef")` 或 `bundledModule("intellij.ui.jcef")`。
- 实际编译期大概率不需要（`intellijIdeaUltimate("2024.3.7.1")` 的 platform classpath 已含 JCEF jar）。

**验证方式**：改完后 `./gradlew compileKotlin`，通过即可。
