# MyBatis 注解 SQL 预览（M25）开发计划

> 状态：✅ 已交付（2026-08-14，629 测试全绿）
> 需求来源：M24 XML 预览交付后，用户继续要求支持 MyBatis 注解（@Select 族 + Provider 族）。
> 权威依据：**本地 mybatis-3.5.19-sources.jar**（MapperAnnotationBuilder / XMLLanguageDriver / ProviderSqlSource / ParamNameResolver 逐行分析），无重复远程检索。

## 1. 范围（已确认）

- **XML 补完（M24 遗留）**：光标不在语句内 → 全部语句候选选择（SqlSelectionDialog 泛化）。
- **注解预览**：`@Select/@Insert/@Update/@Delete`（含 `<script>` 动态标签）+ `@SelectProvider/@InsertProvider/@UpdateProvider/@DeleteProvider`（**L1 常量折叠**）。

## 2. 注解构建规则（源码结论 → 实现）

| 规则 | 源码依据 | 实现 |
|------|----------|------|
| 数组拼接 | `String.join(" ", value).trim()`（MapperAnnotationBuilder.java:590-593） | value 元素经平台常量求值器（computeConstantExpression）逐元素求值 → join(" ") + trim |
| script 检测 | `startsWith("<script>")`（XMLLanguageDriver.java:51） | 包 `<script>` 根 → **复用 XmlScriptBuilder.parse**（与 XML 同路径） |
| 非 script 纯文本 | 不经 XMLScriptBuilder（XMLLanguageDriver.java:56-61） | `MixedSqlNode([TextSqlNode(text)])` → 同一渲染管线 |
| script 内无 include | 3.5.19 XMLScriptBuilder 无 applyIncludes | 天然一致（`<include>` 报 Unknown element） |
| 多参数 mock | ParamMap：@Param 名/实际名 + `param1..N`（ParamNameResolver.java:36-43） | `_parameter` = MockObject(props = 参数名 + param1..N)；**变量/参数名双写 bindings 顶层**（对齐 ContextMap → `_parameter` fallback） |
| Provider L1 | ProviderSqlSource：type/method 定位、无参构造、CharSequence 返回 | type→PsiClass（PsiClassType.resolve）、method→同名/`provideSql`、return 表达式 → computeConstantExpression；失败 → 降级提示 |
| @Lang | getLanguageDriver（MapperAnnotationBuilder.java:359-366） | value 非 XMLLanguageDriver → 提示不支持 |
| @Options/@Results/@SelectKey | 不影响 SQL 文本 | 忽略 |
| 语句 kind | 注解类型 → SqlCommandType | 直接映射 |

## 3. 入口

- `AnnotationSqlGutterLineMarkerProvider`（plugin.xml `lineMarkerProvider language="JAVA"` 第二条，与 Wrapper gutter 共存）：
  **leaf 锚点 = 注解 `@` token（JavaTokenType.AT）**，O(1) 判定（token 类型 + 父链 PsiAnnotation 的 qualifiedName 末段 ∈ SQL 注解集合，零 resolve）；
- ConvertToSqlAction Java 分支前置：光标元素祖先 PsiAnnotation 且为 SQL 注解 → 注解预览；
- XML 多语句候选：SqlSelectionDialog 泛化 `List<T>`（PsiMethodCallExpression/XmlTag 通用），候选列表后台 ReadAction 预计算（行号 + 摘要 + 行文本）。

## 4. 边界（文档明示）

- Provider 仅 L1 常量折叠（字面量/文本块/`+` 拼接/静态 final 引用）；含参数依赖/循环/无 return → 降级提示「动态 SQL 由 Java 生成，无法静态预览」；SQL builder 链式模拟（L2）后续立项；
- `<script>` 内 `<`/`>` 需 XML 转义（与 MyBatis 一致）；非 script 模式直写合法；
- 注解 `databaseId` 变体（@Select.List）→ 取默认变体（未实现变体选择，预览场景一致）；
- 文件级多注解候选选择后续迭代（当前光标在方法内定位单注解）；
- `@SelectKey` 附加语句不预览（主语句 SQL 不变）。
