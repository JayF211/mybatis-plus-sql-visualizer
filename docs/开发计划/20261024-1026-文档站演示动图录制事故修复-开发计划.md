## 四、系统性问题（比单张重录更重要）

审查暴露的不是"某几张拍错了"，而是**录制管线缺三道闸门**：

1. **输入法未强制校验**。本机只装了中文输入法一种布局（`zh-CN / Chinese (Simplified) - US`），没有英文键盘可切。凡是用 `pyautogui.typewrite` 打英文的脚本都有风险（已中招 2 张）。
   → 处置：**管线层统一改用 `gifkit.paste()`**（剪贴板写入，天然绕开 IME），并对存量脚本做一次 `typewrite` 清查。
2. **跳行弹窗泄漏**。`Go to Line:Column` 是脚本"跳行"动作的副产物，会在画面上停留数秒（已中招 3 张）。
   → 处置：跳行改为不弹窗的方式（`gutter` 点击 / `Ctrl+F` 搜索 / 直接用 `goto_line` 的免弹窗变体），或在录制段外完成跳行。
3. **验收只对机械指标、不看画面**。上一轮验收文档只记了帧数/体积/接缝，导致 20% 的事故图被判定为"通过"。
   → 处置：验收清单增加**必看项**——首帧、关键动作帧、尾帧三处人工目视，逐张登记"看到了什么"，不接受"帧数对得上"当作通过。

## 五、录制规格与前置（沿用既有管线，不新造）

- 窗口 1370×984 @ (277,25)，IDE 缩放 120%，编辑器 13pt，Islands Dark，导出宽 1280（`wrapper-preview` 保持 1440），15fps
- 单张 GIF ≤2MB，时长 6~15s（`log-community` 需放宽到 ~15s 以等二维码）
- **启动沙盒必须用 `gradle runIde`**（`fallback` 脚本会丢许可 javaagent 补丁，会话会弹 `Start Free Trial`）
  ```bash
  ./gradlew runIde -PgifRecord=true -PgifRobotServer=true \
    --args=F:/code/Java/Gitee/SongRenShuo/mybatis-plus-sql-visualizer-demo \
    -Pkotlin.compiler.execution.strategy=in-process
  ```
- **开录前七项自检**（承接已沉淀的许可坑 checklist）：`config/idea64.exe.vmoptions` 含 qwdn 行 → 进程验证 `HAS qwdn` → 标题栏无 `Start Free Trial` → 无许可弹窗 → Database 工具窗可用 → robot-server 8580 可达 → **无任何残留弹窗**
- 数据源：演示库用 `mp_demo@localhost`（`user` 表含全部列）；`mpj_demo` 缺 `username` 等列，仅适合 mpjdemo 模块的语句
- 文本输入一律 `gifkit.paste()`，**禁用 `pyautogui.typewrite` 打英文**

## 七、验收口径（本次修正）

上一轮验收只对机械指标，是本轮事故的直接原因。新口径：

1. **逐张三帧目视**：首帧、关键动作帧、尾帧各截一张存证，逐张写明"画面上看到了什么功能动作"，写不出具体功能动作即判不通过。
2. **反向自证**：对每张成片问一句"如果这张图挂了，用户能从这个画面学到 alt 承诺的事吗"——答不上来即重录。
3. **alt 与画面强一致**：alt 里每个名词（按钮名、面板名、弹窗名）都必须能在画面里找到。
4. **机械指标保留但不作为通过依据**：帧数、体积、接缝只用于排除技术故障。
5. **管线闸门验证**：批 1 完成后先验"输入法不再污染"（任一含英文输入的成片无候选框）与"无跳行弹窗"，再继续后续批次。

## 八、待验证前提（实施者先证伪再动手）

| # | 前提 | 证伪方式 |
|---|---|---|
| P1 | `gifkit.paste()` 能替代 `typewrite` 完成"边打边弹补全"的演示效果 | 剪贴板粘贴是整段一次性写入，**可能不触发逐字符补全弹层**。若属实则 `code-completion` 需要"逐字符发送但绕开 IME"的第三种手段（如逐字符 `paste` 单字、或临时切到英文键盘布局） |
| P2 | `xml-preview` 重录时点 OK 能稳定出预览面板 | `report` 里 OK 坐标可能漂移；需现场先用 robot 组件树定位 OK 按钮，确认能点中 |
| P3 | `jpa-preview` 目标画面可达 | 需先确认 demo 工程里哪个类的方法真能渲染 JPA 派生查询预览（`UserRepository` 的派生方法），别又录成 XML |
| P4 | `log-community` 二维码最终能加载 | 若沙盒网络受限导致二维码永远加载不出来，则需改分镜为"弹窗结构展示"并在 alt 里如实说明，不能假装加载完成 |
| P5 | 跳行可以不弹 `Go to Line:Column` | 需确认 `gifkit.goto_line` 是否有免弹窗变体；没有则改用 gutter/Ctrl+F |
| P6 | `dialect-gate` 三出口能在一条片里点完 | 上轮实测「切换数据源后仍需再确认」且「渲染方言仍不匹配会再次阻断」，三个出口可能无法在一次录制里全部走通，需现场判断取舍 |

| 风险 | 影响 | 处置 |
