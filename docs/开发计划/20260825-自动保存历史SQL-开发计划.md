## 需求描述

在设置页「SQL 日志最大条数」下方新增「自动保存历史 SQL」配置。

| 场景 | 行为 |
|------|------|
| **开启** | SQL 超出上限被淘汰时，自动写入保存文件（而非直接丢弃） |
| └ 自定义路径 | 用户指定保存目录 + 文件名模板 |
| └ 未自定义 | 默认目录 `.idea/mybatis-plus-sql-visualizer/sql-history/` + 默认文件名模板 |
| **关闭** | 保持现有行为——超出上限直接丢弃最早条目 |

### 文件规则

- **默认目录**：`.idea/mybatis-plus-sql-visualizer/sql-history/`
- **默认文件名模板**：`sql-history-$yyyy-MM-dd$.sql`（按日期每天一个文件）
- **文件滚动**：单文件超过 100MB 时，自动滚动生成新文件（`.2.sql`、`.3.sql`…）
- **文件名模板**：支持 `$变量$` 占位符，详见下方模板语法

### 文件名模板语法

模板中使用 `$变量$` 包裹的占位符，解析时替换为当前日期时间：

| 占位符 | 含义 | 示例值 |
|--------|------|--------|
| `$yyyy$` | 4 位年 | `2026` |
| `$MM$` | 2 位月 | `08` |
| `$dd$` | 2 位日 | `25` |
| `$HH$` | 2 位时（24h） | `14` |
| `$mm$` | 2 位分 | `30` |
| `$ss$` | 2 位秒 | `22` |

**示例**：

| 模板 | 解析结果 |
|------|----------|
| `sql-history-$yyyy-MM-dd$.sql` | `sql-history-2026-08-25.sql` |
| `log_$yyyy$_$MM$_$dd$.sql` | `log_2026_08_25.sql` |
| `sql-$yyyy-MM-dd$_$HH$-$mm$-$ss$.sql` | `sql-2026-08-25_14-30-22.sql` |

> 不在上表中的 `$...$` 原样保留不替换（容错——不存在的占位符保持原样）。

### 文件格式

每条 SQL 以 `-- 时间戳` 开头，紧跟 SQL 正文，条目间空行分隔：

```sql
-- 2026-08-25 10:00:00
select * from user

-- 2026-08-25 10:00:01
update user set name = 'Alice' where id = 1
```

## 需求分析

### 核心问题

当前 `SqlLogEntryBuffer.addEntry()` 在 `entries.size > maxEntries` 时直接 `removeFirst()` 丢弃最早条目。用户希望这些被淘汰的 SQL 有机会被持久化保存，避免重要调试 SQL 丢失。

### 关键设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 淘汰回调位置 | `SqlLogEntryBuffer` 内增加 `onEvicted` 回调 | 纯逻辑层不依赖平台，可单测；与现有 `addListener` 模式一致 |
| 文件写入方 | `SqlLogManager` 装配回调 → 委托 `SqlLogAutoSaver` | Manager 持有 project 上下文（项目基路径、dispose 生命周期），适合管理文件资源 |
| 写入格式 | `-- 时间戳\nSQL\n\n` 纯文本 | 用户指定格式，简洁可读，可直接在数据库工具中打开 |
| 文件命名 | 模板解析 + 日期变化检测 + 大小滚动 | 灵活可配，按时间定位，磁盘管理可控 |
| 默认路径 | `.idea/mybatis-plus-sql-visualizer/sql-history/` | 符合插件惯例，项目级隔离，不污染根目录 |
| 写入失败处理 | `runCatching` 吞异常 + LOG.warn，不阻塞缓冲 | 文件 IO 失败不应影响 SQL 捕获主链路 |
| 导入/导出 | 不包含新字段 | 与现有 `settings.log.*` 一致，不导出日志类设置 |

### 文件名模板解析逻辑

```
模板: "sql-history-$yyyy-MM-dd$.sql"
        ↓ 正则 \$([^$]+)\$ 匹配占位符
替换: "sql-history-2026-08-25.sql"
        ↓ 文件 ≥100MB
滚动: "sql-history-2026-08-25.2.sql"
```

### 数据流

```
PluginSettings.state
  ├── logAutoSaveEnabled: Boolean (default false)
  ├── logAutoSavePath: String (default "" → .idea/mybatis-plus-sql-visualizer/sql-history/)
  └── logAutoSaveFileNamePattern: String (default "sql-history-$yyyy-MM-dd$.sql")
        ↓ applySettings()
SqlLogManager
  ├── buffer.onEvicted = if (enabled) { entry → saver.write(entry) } else null
  └── saver.configure(path, pattern, projectBasePath)
        ↓ 淘汰时
SqlLogAutoSaver
  ├── 解析模板 → 当前目标文件名
  ├── 文件名变化（日期变了）→ 切到新文件
  ├── 当前文件 ≥100MB → 滚动序号 +1
  └── BufferedWriter.append("-- 时间戳\nSQL\n\n")
        ↓
保存文件 (.idea/.../sql-history/sql-history-2026-08-25.sql)
```


#### 2.2 addEntry() 淘汰时触发回调

当前实现（第 44-47 行）：

```kotlin
synchronized(entries) {
    entries.addLast(entry)
    while (entries.size > maxEntries) entries.removeFirst()
}
```

改为：

```kotlin
synchronized(entries) {
    entries.addLast(entry)
    while (entries.size > maxEntries) {
        val evicted = entries.removeFirst()
        onEvicted?.invoke(evicted)
    }
}
```

> **线程安全**：`onEvicted` 在 `synchronized` 块内调用，写入方（`SqlLogAutoSaver`）需自行保证文件 IO 的线程安全。

### 改动 ③：SqlLogAutoSaver.kt — 新建文件写入器

**新文件**：`src/main/kotlin/cn/song/mybatisplus/visualizer/log/SqlLogAutoSaver.kt`

```kotlin
package cn.song.mybatisplus.visualizer.log

import cn.song.mybatisplus.visualizer.config.PluginSettings
import com.intellij.openapi.diagnostic.Logger
import java.io.BufferedWriter
import java.io.File
import java.nio.charset.Charset
import java.nio.file.Files
import java.text.SimpleDateFormat
import java.util.Date

/**
 * 自动保存历史 SQL 到文件（F-43）：[SqlLogManager] 装配为 buffer 的 onEvicted 回调。
 *
 * 文件规则：
 *  - 默认路径：.idea/mybatis-plus-sql-visualizer/sql-history/
 *  - 文件名模板：sql-history-$yyyy-MM-dd$.sql（支持 $yyyy$ $MM$ $dd$ $HH$ $mm$ $ss$ 占位符）
 *  - 文件滚动：单文件 ≥100MB 时滚动（.2.sql、.3.sql…）
 *  - 格式：`-- 时间戳\nSQL\n\n`（纯文本，可直接在数据库工具中打开）
 *
 * 生命周期跟随 [SqlLogManager]：manager dispose 时 [close] 释放文件句柄。
 */
class SqlLogAutoSaver {

    private var writer: BufferedWriter? = null
    private var currentFile: File? = null
    private var saveDir: String = ""
    private var fileNamePattern: String = ""
    private var currentResolvedName: String = ""  // 当前解析后的文件名（不含滚动序号）
    private var currentIndex: Int = 1  // 当前滚动序号（1=无后缀）

    /** 单文件滚动阈值（100MB）。 */
    private val rollThresholdBytes = 100L * 1024 * 1024

    /**
     * 配置保存参数（设置变更时调用）。
     * @param customPath 用户自定义目录（空串 = 默认 .idea 路径）
     * @param pattern 文件名模板（空串 = 默认模板）
     * @param projectBasePath 项目基路径（默认路径计算用）
     */
    fun configure(customPath: String, pattern: String, projectBasePath: String?) {
        close()
        saveDir = resolveDir(customPath, projectBasePath)
        fileNamePattern = pattern.ifBlank { PluginSettings.DEFAULT_LOG_AUTO_SAVE_FILE_NAME_PATTERN }
        currentResolvedName = ""
        currentIndex = 1
    }

    /** 解析最终保存目录。 */
    private fun resolveDir(customPath: String, projectBasePath: String?): String {
        if (customPath.isNotBlank()) return customPath.trim()
        return if (projectBasePath != null) {
            "$projectBasePath${File.separator}.idea${File.separator}$DEFAULT_DIR"
        } else {
            "${System.getProperty("user.home")}${File.separator}.idea${File.separator}$DEFAULT_DIR"
        }
    }

    /**
     * 写入被淘汰的条目（buffer.onEvicted 回调）。
     * 首次写入时懒打开文件。
     */
    fun write(entry: LogSqlEntry) {
        val w = writer ?: run {
            openNewFile()
            writer ?: return
        }
        // 解析模板得到目标文件名
        val resolved = resolveFileName()
        // 文件名变化（日期/时间变了）→ 切到新文件
        if (resolved != currentResolvedName) {
            switchFile(resolved)
            return
        }
        // 文件超阈值 → 滚动
        if (currentFile?.length() ?: 0 >= rollThresholdBytes) {
            rollFile()
            return
        }
        runCatching {
            synchronized(w) {
                w.write("-- ${formatTimestamp(entry.timestamp)}\n")
                w.write(entry.restoredSql)
                w.write("\n\n")
                w.flush()
            }
        }.onFailure {
            LOG.warn("自动保存历史 SQL：写入失败", it)
        }
    }

    /** 解析文件名模板（替换 $变量$ 占位符）。 */
    fun resolveFileName(): String {
        val now = System.currentTimeMillis()
        return fileNamePattern.replace(PLACEHOLDER_REGEX) { mr ->
            val key = mr.groupValues[1]
            when (key) {
                "yyyy" -> SimpleDateFormat("yyyy").format(Date(now))
                "MM" -> SimpleDateFormat("MM").format(Date(now))
                "dd" -> SimpleDateFormat("dd").format(Date(now))
                "HH" -> SimpleDateFormat("HH").format(Date(now))
                "mm" -> SimpleDateFormat("mm").format(Date(now))
                "ss" -> SimpleDateFormat("ss").format(Date(now))
                else -> mr.value  // 未知占位符原样保留
            }
        }
    }

    /** 打开新文件。 */
    private fun openNewFile() {
        currentResolvedName = resolveFileName()
        currentIndex = 1
        openWriterForCurrent()
    }

    /** 切换到新文件（文件名变化时）。 */
    private fun switchFile(newResolvedName: String) {
        close()
        currentResolvedName = newResolvedName
        currentIndex = 1
        openWriterForCurrent()
    }

    /** 滚动到下一个文件（超阈值时）。 */
    private fun rollFile() {
        close()
        currentIndex++
        openWriterForCurrent()
    }

    /** 根据 currentResolvedName + currentIndex 打开文件。 */
    private fun openWriterForCurrent() {
        val file = File(currentFileName())
        runCatching {
            file.parentFile?.mkdirs()
            writer = Files.newBufferedWriter(file.toPath(), Charsets.UTF_8)
            currentFile = file
        }.onFailure {
            LOG.warn("自动保存历史 SQL：无法打开文件 ${file.absolutePath}", it)
            writer = null
            currentFile = null
        }
    }

    /** 当前应写入的完整文件名（含滚动序号后缀）。 */
    private fun currentFileName(): String {
        val name = currentResolvedName
        if (currentIndex <= 1) return name
        // 在扩展名前插入滚动序号：xxx.sql → xxx.2.sql
        val dotIdx = name.lastIndexOf('.')
        return if (dotIdx > 0) {
            "${name.substring(0, dotIdx)}.$currentIndex${name.substring(dotIdx)}"
        } else {
            "$name.$currentIndex"
        }
    }

    /** 当前打开的保存文件（测试访问 + 状态展示用）。 */
    fun currentFile(): File? = currentFile

    /** 关闭文件句柄（manager dispose 或路径变更时调用）。 */
    fun close() {
        writer?.let { w ->
            runCatching {
                synchronized(w) { w.close() }
            }.onFailure {
                LOG.debug("自动保存历史 SQL：关闭文件异常", it)
            }
        }
        writer = null
        currentFile = null
    }

    private fun formatTimestamp(timestamp: Long): String =
        SimpleDateFormat("yyyy-MM-dd HH:mm:ss").format(Date(timestamp))

    companion object {
        private val LOG = Logger.getInstance(SqlLogAutoSaver::class.java)
        private const val DEFAULT_DIR = "mybatis-plus-sql-visualizer${File.separator}sql-history"
        /** 匹配 $变量$ 占位符。 */
        private val PLACEHOLDER_REGEX = Regex("""\$([^$]+)\$""")
    }
}
```
