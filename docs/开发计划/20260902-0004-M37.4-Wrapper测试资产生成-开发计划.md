## 一、现状与目标

### 1.1 现状

- **入口模式**：`SqlPreviewPanel.toolbar()` 的 `smallButton(text){action}` 追加即可。
- **PSI 生成先例**：`ui/JavaCodeFormatter.kt` 已用 `PsiFileFactory.createFileFromText(JavaLanguage)` 包 `ReadAction.compute`（EDT 直调 262 硬抛）；`SqlPreviewPanel` 亦有 ReadAction 内建 PSI 与 `createPreviewPsiFile` 测试缝。
- **输出方式现状**：SQL→Java 走 `JavaCodePreviewDialog`（DialogWrapper + 只读 Java Editor + 复制按钮），**只复制不落盘**；全项目唯一落盘实现是 `log/SqlLogAutoSaver`（BufferedWriter 追加 + 滚动）。
- **测试资源**：`src/test/resources` 为空，无 .sql 资源约定。
- **静态信息可用**：`PreviewResult`（`model/PreviewResult.kt`）已含最终 SQL、perfWarnings；方言渲染链路完整；MP 批量模型（BatchModel）与逻辑删除/乐观锁注入均已落到最终 SQL。

### 1.2 目标

预览面板「生成测试」按钮，弹两种形态：

1. **SQL 回归脚本**：方言渲染后的目标 SQL + 断言查询骨架，落盘 `<project>/src/test/resources/sql-visualizer/`。
2. **JUnit 用例骨架**：可编译的 @Test 方法（内嵌 SQL 常量 + TODO 断言位），弹窗预览 + 复制（复用 JavaCodePreviewDialog）。

### 1.3 非目标

- 不自动推导 INSERT 前置依赖数据（列级外键推导复杂度高，记 TODO 后续版本）。
- 不生成业务 Java 代码、不引入任何运行时依赖、不做断言自动执行。

## 二、实现设计

### 2.1 生成器（新包 `testgen/TestAssetGenerator.kt`）

输入 `PreviewResult` + 方言 + 锚点信息（文件:行），输出 `TestAsset`（`type: SQL_SCRIPT | JUNIT`，`content: String`，`suggestedFileName: String`）。纯函数，不碰平台 API，便于单测。

### 2.2 SQL 回归脚本形态

```
-- 来源: UserController.java:87 (LambdaQueryWrapper)  方言: MySQL
-- 生成: SQL Visualizer v2026.9.x  参数已回填为示例值,按需修改
SELECT ...;                     -- 目标语句(现有预览 SQL 原样)
-- TODO: 补充前置数据后执行断言
SELECT COUNT(*) ...;            -- 断言查询骨架(同表 COUNT)
```

落盘：`project.getBasePath()/src/test/resources/sql-visualizer/{table}-{type}-{yyyyMMdd-HHmmss}.sql`；java.io 直写 + `VfsUtil.markDirtyAndRefresh`（参照 SqlLogAutoSaver 直写模式，避开 VFS 安全写入坑——此处是新建文件非跟踪文件，无 File Cache Conflict 风险）。写前 `VfsUtil.createDirectoryIfMissing`。多模块项目首版落主源根并在弹窗提示路径。

### 2.3 JUnit 骨架形态

- Java + JUnit5 模板字符串生成 → `JavaCodeFormatter`（ReadAction）重排缩进 → `JavaCodePreviewDialog` 复用展示 + 复制。
- 内容：类头 `// Generated by SQL Visualizer`、`@Test void xxx()`、SQL 文本块常量、`// TODO: assert` 占位。不含 MP/JUnit 以外依赖。

### 2.4 入口

toolbar 加「生成测试」按钮 → `JBPopupFactory.createListPopup(BaseListPopupStep)` 两项（SQL 脚本/JUnit 骨架）——单击即选必须走 createListPopup（PopupChooserBuilder 单击不触发老坑）。

## 四、验证

- 单测：单表查询/JOIN/批量 UPDATE 三类 PreviewResult 快照断言；文件名合法性（表名含特殊字符）。
- 真机沙盒：对 sample 项目三链生成资产；SQL 脚本手工在 H2 执行通过；JUnit 骨架粘贴进测试目录编译通过。
- 落盘路径在 VFS 中即时可见（不刷新不出现即踩坑）。

## 五、风险

1. **范围膨胀为代码生成器**——守住「测试资产」边界：无业务代码、无 Service/Mapper 生成（P-立项-06 不做清单）。
2. **多模块/多源根路径**——首版 basePath 直拼 + 弹窗明示落盘位置，源根推导留 TODO。
3. **EDT**：PSI 格式化包 ReadAction；文件写在后台线程。
