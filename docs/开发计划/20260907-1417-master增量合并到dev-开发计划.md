## 三、解决原则

1. **功能并集，禁丢边**：master 的 T-DaoSql（字符串 SQL 方法锚点）与 dev 的 T-J9/M54 治理语义互不冲突，全部保留。
2. **回落链顺序语义**：`tryJdbcTemplateFallback → tryJpaFallback → tryRepositoryCallSiteFallback(T-J9, dev) → tryMethodBodyStringSqlFallback(T-DaoSql, master) → 文件级注解候选`。依据：JPA 调用点（resolve 到接口声明）比方法体字符串扫描更精确优先；两者都先于文件级全局候选（master 注释原文语义）。
3. **测试定胜负**：合并后 `WrapperAnchorDetectorTest` 双侧用例必须全绿；`StringSqlMethodGutterLineMarkerProviderTest` 与 `WrapperAnchorDetectorTest` 交叉（让位守卫 vs 方法锚点）语义冲突时以 master 交付测试为准并同步 dev 侧行为。
4. **bundle 逐行并集**：`gutter.pages.accessible.name` 保持删除态（防重复 key 回归）；其余键全并。
