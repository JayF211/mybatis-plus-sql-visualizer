# 移除侧边工具栏面板（工具窗口）——开发计划（M11）

> 本文档是 **MyBatis-Plus SQL Visualizer** 的 M11 增量开发计划：**移除侧边工具栏面板（Tool Window）及其相关代码**，展示统一收敛到弹窗，只保留三个入口——右键菜单、快捷键、代码左侧预览 SQL 图标（gutter）。
> 配套文档：[主开发计划](../开发计划/20260812-1058-MP-SQL可视化-开发计划.md)（M10/v1.4 已交付，本文档为其增量 M11）、[M10 gutter 开发计划](../开发计划/20260812-1844-代码左侧预览SQL图标-开发计划.md)。
> 当前基线：Kotlin 2.3.20 + IntelliJ Platform Gradle Plugin 2.18.1 + IDEA 2025.3.5，v1.4（M10）已提交（commit b3ca952），154 测试全绿。

---

## 1. 概述与目标

**用户决策**：不再需要侧边工具窗口面板（`MP SQL Visualizer` Tool Window），其相关代码一并去除。**只保留三个触发入口**：
1. 右键菜单（EditorPopupMenu → Convert to SQL）
2. 快捷键（`Ctrl+Alt+S` / `Cmd+Option+S`）
3. 代码左侧 gutter 预览 SQL 图标（M10）

三者统一走现有 `SqlPreviewService.showResult`，展示方式收敛为**弹窗**（`SqlPreviewDialog`，含参数回填/编辑/补全的 `SqlPreviewPanel`）。

**为什么要移除**（现状）：
- 工具窗口与弹窗展示同一份 `SqlPreviewPanel`，功能重复；`displayMode`（DIALOG / TOOL_WINDOW / BOTH）三态配置徒增复杂度；
- `SqlPreviewEditorTracker`（编辑器跟随实时预览）仅服务于工具窗口，是常驻监听（Alarm + CaretListener），移除后可减少运行时开销与事件面；
- 用户明确不再使用该面板。

## 2. 现状与影响面（代码清单）

### 2.1 待移除组件

| 文件 / 配置 | 说明 |
|-------------|------|
| `ui/SqlToolWindow.kt` | 工具窗口桥接（ID、findPanel、showResult、isFollowEditor 开关）——**整个文件删除** |
| `ui/SqlPreviewToolWindowFactory.kt` | Tool Window Factory（含 `SqlPreviewToolWindowPanel` 工具栏：复制/清空/转换/跟随/粘贴输入）——**整个文件删除** |
| `ui/SqlPreviewEditorTracker.kt` | `EditorFactoryListener` 编辑器跟随（防抖转换推送工具窗口）——**整个文件删除** |
| `plugin.xml` `<toolWindow id="MP SQL Visualizer" .../>` | 工具窗口扩展——删除 |
| `plugin.xml` `<editorFactoryListener implementation="...SqlPreviewEditorTracker"/>` | 编辑器跟随监听——删除 |
| `PluginSettings.State.displayMode`（DIALOG/TOOL_WINDOW/BOTH） | 显示方式配置——**移除**（展示恒为弹窗） |
| `PluginSettingsPanel` 显示方式下拉 + `settings.displayMode.*` bundle 文案 | 配置 UI 与文案——移除 |
| bundle `toolwindow.*` 系列文案 | 工具窗口文案——移除（`toolwindow.convert`/`toolwindow.follow` 等） |

### 2.2 需同步修改（保留组件）

| 文件 | 改动 |
|------|------|
| `ui/SqlPreviewService.kt` | `showResult` 的 `displayMode()` 分支简化为恒弹窗；删除 `displayMode()` 方法 |
| `actions/ConvertToSqlAction.kt` | 无改动（已走 `showResult`） |
| `ui/gutter/SqlGutterLineMarkerProvider.kt` | 无改动（已走 `showResult`） |
| `config/PluginSettings.kt` | 移除 `displayMode` 字段与三个 `DISPLAY_*` 常量；`getState/loadState` 自动兼容（旧配置多余字段忽略） |
| `docs/开发计划/20260812-1058-MP-SQL可视化-开发计划.md` | 主计划功能概览中 F-07 描述、路线图、发布计划、跟进说明回写 M11/v1.5 |

### 2.3 依赖核验（已确认）

- **测试层无工具窗口依赖**：`src/test` 中无 `SqlToolWindow`/`SqlPreviewToolWindowFactory`/`SqlPreviewEditorTracker`/`displayMode` 引用（grep 核验），移除不影响任何现有测试。
- `SqlPreviewPanel`（弹窗核心，含 M8 高亮 / M9 参数回填与补全）**保留**，弹窗体验完整。
- 批量操作 / 删除消费 / count 消费等转换逻辑在 `SqlPreviewService`，与展示方式无关，不受影响。
