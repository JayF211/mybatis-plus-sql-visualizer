## 根因分析

### 失败 1：`testSettingsPanelSectionsTitles`

**断言**：设置页应有 6 个分组标题，按高频→低频顺序：
```
preview → tableMapping → codeGen → sqlLog → ui → updateDiagnostics
```

**实际**：当前面板只有 5 个分组：
```
preview → tableMapping → sqlLog → ui → about
```

**差异**：
- ❌ 缺失 `settings.section.codeGen`（代码生成）
- ❌ 缺失 `settings.section.updateDiagnostics`（更新与诊断）
- ⚠️ 多出 `settings.section.about`（关于）

**根因**：T-M31.8 分组重构时，`codeGen` 组合并到了 `preview` 组（`reverseFormatCombo` 等控件在 preview 内部），`updateDiagnostics` 组未创建，额外添加了 `about` 组。

### 失败 2：`testPanelTableConfigRowsOrderAndPlaceholderHint`

**断言**：placeholder 应设置于 6 个输入栏（+F-43 保存路径+文件名模板），其中 4 个为"多个时使用;来分隔"。

**实际**：搜索框 `searchField` 也有 placeholder（"Search settings…"），导致 `collectTextFieldEmptyTexts` 收集到 7 个而非 6 个。

**placeholder 字段清单**：
| 字段 | placeholder 文本 | 计入 |
|------|-----------------|------|
| `searchField` | "Search settings…" | ❌ 不应计入（搜索框非设置输入栏） |
| `removeTablePrefixField` | "多个时使用;来分隔" | ✅ 多值 |
| `removeTableSuffixField` | "多个时使用;来分隔" | ✅ 多值 |
| `ignoredFieldsField` | "多个时使用;来分隔" | ✅ 多值 |
| `logFilterKeywordsField` | "多个时使用;来分隔" | ✅ 多值 |
| `logAutoSavePathField` | "默认：.idea/..." | ✅ F-43 |
| `logAutoSavePatternField` | "sql-$yyyy$-$MM$..." | ✅ F-43 |

实际 7 个，期望 6 个。

## 修复方案

### 任务 1：修复分组标题（失败 1）

**文件**：`src/main/kotlin/cn/song/mybatisplus/visualizer/config/PluginSettingsPanel.kt`

**改动**：
1. 将 `reverseFormatCombo` / `manualEntityCheck`（反向转换/代码生成控件）从 `preview` 组移出
2. 新增独立的 `collapsiblePanel("settings.section.codeGen", ...)` 分组
3. 新增独立的 `collapsiblePanel("settings.section.updateDiagnostics", ...)` 分组（包含更新检查、内部构建号、复制按钮等）
4. `about` 组保留（测试未断言其存在/不存在，但资源 key 已定义）

**分组顺序**（对齐测试期望）：
```
1. preview            （SQL 预览 + 参数替换 + 格式化 + 逻辑删除 + 多租户 + 数据权限）
2. tableMapping       （表名映射：前缀/后缀/移除/忽略字段/推断策略）
3. codeGen            （代码生成：反向转换格式 + 手动选择实体）
4. sqlLog             （SQL 日志：过滤/前缀/自动保存）
5. ui                 （UI 与操作）
6. updateDiagnostics  （更新与诊断：构建号/复制/更新检查）
```

### 任务 2：修复 placeholder 计数（失败 2）

**方案 A**（推荐）：修改搜索框组件类型，避免被 `collectTextFieldEmptyTexts` 计入

将 `searchField` 从 `JBTextField` 改为 `SearchTextField`（IntelliJ 搜索框专用组件），或包装在 `com.intellij.ui.SearchField` 中。

**方案 B**：修改搜索框为空文本时不触发计数

将搜索框的 `emptyText` 改为通过 `SearchTextField` 的 API 设置（不使用 `JBTextField.emptyText`）。

**文件**：`src/main/kotlin/cn/song/mybatisplus/visualizer/config/PluginSettingsPanel.kt:234`

### 任务 3：对齐行标签（失败 2 附带）

测试期望行顺序：`添加表前缀 → 添加表后缀 → 移除表名前缀 → 移除表名后缀 → 忽略字段名 → 表名推断策略`

当前实际行顺序需验证，若不一致需调整 `tableMapping` 组内 `addRow` 调用顺序。
