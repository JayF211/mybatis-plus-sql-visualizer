## 1. 问题与动机（用户需求，证据驱动）

**用户需求**：复制/执行 SQL 成功后弹出的提示框只有 OK 按钮——用户希望**再多一个按钮，
点击后一键关闭背后的 SQL 预览面板**（`SqlPreviewDialog`），省去先点 OK 再手动关弹窗的两步操作。

**现状盘点**（M23.5 交付后）：
- 预览弹窗 `SqlPreviewDialog`（`ui/SqlPreviewDialog.kt`）底部按钮区含「执行 SQL / 复制 SQL / 关闭」
  （`createActions`，`SqlPreviewDialog.kt:43-58`）；
- **复制 SQL**（`SqlPreviewPanel.copySql`，`SqlPreviewPanel.kt:265-275`）：写剪贴板 →
  `Messages.showInfoMessage(project, dialog.copy.done, plugin.name)`——**单 OK 信息框**；
- **执行 SQL**（`SqlPreviewPanel.executeSql` → `ExecuteSqlSupport.execute(project, sql)`，
  `execute/ExecuteSqlSupport.kt:46-65`）：成功 → `Messages.showInfoMessage`（runCatching 包裹），
  失败 → `Messages.showErrorDialog`——同为**单按钮**；
- 「背后的 SQL 面板」= 预览弹窗 `SqlPreviewDialog`（复用 `SqlPreviewPanel`）；
- bundle 已有 `dialog.copy.done` / `panel.executeSql` / `panel.copySql` 等 key（中英双语，
  插件语言独立于 IDE——M6-03）；**无** `OK` / 关闭面板按钮文案 key。

**约束**：
- 提示按钮文案走**插件 bundle**（插件语言独立于 IDE——`project-i18n` 约定）；
- `copySql` 的 `project?.let` 保护测试环境（project null 跳过弹框——存量测试 `SqlPreviewPanelTest:103`
  依赖此行为）；`ExecuteSqlSupport` 成功提示已有 `runCatching` 兜底（测试环境不炸）；
- **失败提示**（`showErrorDialog`）**不加**关闭面板按钮——失败时用户需要留在面板修改 SQL
  （文档化边界）。

## 2. 设计方案（T-M23.6）

### 2.1 bundle 新增 key（`MpSqlVisualizerBundle.properties` + `_zh`）

| key | en | zh |
|-----|----|----|
| `dialog.ok` | OK | 确定 |
| `panel.closeSqlPanel` | Close SQL Panel | 关闭 SQL 面板 |

### 2.2 提示弹框改多按钮（`Messages.showDialog` 返回点击 index）

```kotlin
// 形态（复制 SQL，SqlPreviewPanel.copySql）：
val options = arrayOf(bundle("dialog.ok"), bundle("panel.closeSqlPanel"))
val choice = Messages.showDialog(project, bundle("dialog.copy.done"), bundle("plugin.name"), options, 0, Messages.getInformationIcon())
if (choice == 1) onClosePanelRequested?.invoke()   // 点「关闭 SQL 面板」→ 回调关闭预览弹窗
```

- 默认按钮 = 0（OK，Enter 行为不变）；第二按钮 = 关闭 SQL 面板；
- **执行 SQL 成功提示**（`ExecuteSqlSupport.execute`）：同形态；`execute` 加可选参数
  `onClosePanel: (() -> Unit)? = null`（唯一调用点 `SqlPreviewPanel.executeSql:137` 传回调；
  默认 null → 存量/其他入口零影响；保持 `runCatching` 兜底）；
- **失败提示**维持 `showErrorDialog`（单按钮，边界文档化）。

### 2.3 关闭链路（面板 → 弹窗）

- `SqlPreviewPanel` 加内部字段 `var onClosePanelRequested: (() -> Unit)? = null`；
  `executeSql()` 传 `onClosePanel = { onClosePanelRequested?.invoke() }`；`copySql()` 按
  `showDialog` 返回 index 调 `onClosePanelRequested?.invoke()`；
- `SqlPreviewDialog` init 赋值 `panel.onClosePanelRequested = { dispose() }`——
  `DialogWrapper.dispose()` 关闭预览弹窗。

### 2.4 边界（文档化）

- 执行 SQL **失败**提示不加关闭按钮（用户需留在面板修改 SQL）；
- `onClosePanel` 默认 null（非预览弹窗入口的 execute 调用不受影响）；
- 测试环境（project null / headless）行为不变：`copySql` 的 `project?.let` 保护保留、
  `ExecuteSqlSupport` 的 `runCatching` 保留。

## 4. 验收标准

1. 复制 SQL 成功提示：两个按钮（OK / 关闭 SQL 面板）——点「关闭 SQL 面板」预览弹窗直接关闭；
2. 执行 SQL 成功提示：同形态（两按钮）；失败提示维持单 OK（边界）；
3. 默认按钮仍为 OK（Enter 行为不变）；文案走 bundle（中英双语，插件语言独立于 IDE）；
4. 存量 490 + 新增测试全绿；文档三处同步（矩阵/清单 §8/本文档变更记录），提交分两步。
