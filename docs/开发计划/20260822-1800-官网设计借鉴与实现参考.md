## 2. 各站详细拆解

### 2.1 Memoryzy / WriterSide（插件文档站）

**技术栈**：JetBrains WriterSide 6.22.0 + Cloudflare Pages

#### 2.1.1 页面结构

```
[顶部标题栏]  "Json Assistant Help" — 品牌名固定
[面包屑]      data-breadcrumbs 自动追踪
[正文区]
  ├─ 产品名  + 描述段
  ├─ Badge 栏（Marketplace / Version / Downloads / GitHub Shields）
  ├─ 主要内容章节（h2 分区）
  ├─ 最后更新日期
  ├─ Disqus 评论区
  └─ 底栏导航（上一页 / 下一页）
[右侧大纲]   virtual-toc-data JSON → 自动生成
[通知系统]   右下角浮动通知（带链接 + 自动消失）
```

#### 2.1.2 精华组件

| 组件 | 实现方式 | 复用情况 |
|------|---------|---------|
| GIF 懒加载 | `js-gif` class + `data-gif-src` 按需加载（首帧占位 → 点击/滚动播放） | ✅ 自建 `GifPlayer.vue`（IntersectionObserver） |
| 暗色图片切换 | `data-dark-src` 属性，JS 自动根据主题切换 | ✅ 自建 `ThemedImage.vue` |
| Keystroke 样式 | `<kbd class="keystroke">` 特殊渲染风格 | ✅ CSS 美化 `<kbd>` 标签 |
| 步骤向导 | `<section class="procedure-steps">` 带序号的逐步向导 | ✅ 自建 `Steps.vue` |
| 代码水平对比 | `<div class="code-comparer">` 左右并排 Before/After | ✅ 自建 `CodeCompare.vue` |
| 提示框 | `<aside class="prompt" data-type="note/tip/warning">` 三色提示 | ✅ VitePress 内置自定义容器 |
| 浮动通知 | 自定义右下角通知系统（JS 注入） | ✅ 自建 `SiteNotice.vue` |
| Badge 实时数据 | Shields.io 动态徽章（版本/下载/Stars） | ✅ 自建 `BadgeBar.vue` |
| 底栏线性导航 | 底栏 `< 上一篇 / 下一篇 >` | ✅ VitePress 内置 `prev/next` |
| 兼容性清单 | 列出 19 款 JetBrains 产品的兼容版本 | ❌ 未采用 |
| 交叉推广 | "另请参阅"放关联工具/外部规范链接 | ❌ 未采用 |

#### 2.1.3 不足（我们改进的）

| 不足 | 我们的方案 |
|------|-----------|
| 无首页 | ✅ 首页 Hero 区 + 功能概览卡片矩阵 |
| 无搜索 | ✅ Tinysearch 内置全文搜索 |
| 版本号硬编码 URL | ✅ VitePress 目录结构天然版本无关 |
| 无独立博客/新闻区 | ❌ 暂不需要 |
| Disqus 国内不可用 | ❌ 暂不需要评论 |
| 纯英文 | ✅ 中英双语同时建设 |

### 2.2 Cool Request（插件官网）

**技术栈**：Next.js（React） + Tailwind CSS

#### 2.2.1 设计系统

| 设计要素 | 实现 | 我们的落地 |
|---------|------|-----------|
| 深色背景 | `#0d1117` 底色 + `#161b22` 卡片 | ✅ CSS 变量覆盖 |

| CTA 按钮 | 蓝色渐变实心 + 透明边框，hover 上浮 + 阴影扩散 | ✅ 完全复刻 |
| 毛玻璃导航栏 | `backdrop-filter: blur(12px)` + 半透明背景 | ✅ 完全复刻 |
| 特性卡片 | 深色卡片 + 圆角 16px，hover 上浮 + 蓝色边框发光 | ✅ 完全复刻 |
| 代码块 | 暗底 + 圆角边框 + 蓝色行内代码 | ✅ 完全复刻 |
| 表格 | 暗底分层 + hover 高亮 | ✅ 完全复刻 |

## 6. 更新日志动态获取方案对比

### 6.1 方案演进

| 阶段 | 方案 | 问题 |
|------|------|------|
| v1 | Build-time 脚本 fetch API → 生成静态 MD | 需要重新构建才能更新 |
| v2 | Client-side fetch API 直接请求 | 跨域被浏览器拦截 |
| v3 | Cloudflare Function 代理 | 依赖 Cloudflare 部署 |
| **v4（当前）** | **Vite dev proxy + Cloudflare Function** | **开发/生产双环境均可用** |

### 6.2 跨域解决方案

```
开发环境：Vite server.proxy → /api/changelog → JetBrains API
生产环境：Cloudflare Pages Function → /api/changelog → JetBrains API
```

### 6.3 API 数据注意事项

| 问题 | 说明 | 解决方案 |
|------|------|---------|
| 重复内容 | 每个版本的 `notes` 包含从该版本到最早版本的全部日志 | 只取最新版本（第一个）的完整 notes |
| 蓝色文字 | `<li>` 有 4 空格缩进 → `marked` 将列表项误判为代码块 → `<code>` 蓝色 | `parseNotes` 去掉每行行首缩进 |
