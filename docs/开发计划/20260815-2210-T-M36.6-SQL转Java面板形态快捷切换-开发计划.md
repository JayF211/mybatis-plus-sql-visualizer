# SQL→Java 面板生成类型快捷切换开发计划（T-M36.6）

- 日期：2026-08-15
- 状态：**实施中**
- 前置：T-M36.4 已交付（96e8452，「SQL → Java」tab 面板）；T-M36.5 已交付（f23cfd5，设置生效性审计修复）
- 背景来源：用户需求——「SQL→Java 面板上可以快速调整生成类型（MyBatis-Plus / MyBatis-Plus-Join / **Wrappers 工厂形式**），和设置中的同步」

## 1. 需求分析

现状：面板转换遵循设置页「SQL 转代码默认 Wrapper 形态」（reverseWrapperFormat），改形态必须进设置页。

目标：
1. **面板内快捷切换生成类型**——输入区工具栏加「生成形态」下拉，**切换即用当前 SQL 重新生成**；
2. **与设置双向同步**——面板切换写回设置（持久化）；设置页修改后面板跟随（初始化/tab 重选刷新）；
3. **支持 Wrappers 工厂形式**——形态枚举新增 `WRAPPERS`（MP 官方 `Wrappers` 静态工厂，jar 实证 `com.baomidou.mybatisplus.core.toolkit.Wrappers`）：
   - 有实体 → `Wrappers.<User>lambdaQuery()` + lambda 列（MP 官方推荐写法）；
   - 无实体 → `Wrappers.<User>query()` + 字符串列（泛型类名表名推断）；
   - MPJ 工厂（JoinWrappers/MPJWrappers，lambdaJoin/queryJoin）暂不纳入本形态——MPJ 形态保持 `new MPJLambdaWrapper`（T-M37 多表 JOIN 时再评估）。

## 2. 技术方案

### 2.1 形态下拉（输入区工具栏，与转换/格式化/清空并列）

```
[JComboBox: 自动 / QueryWrapper / LambdaQueryWrapper / Wrappers / MPJLambdaWrapper] [转换] [格式化] [清空]
```

- 选项 = `ReverseWrapperFormat` 枚举（AUTO/QUERY/LAMBDA/**WRAPPERS**/MPJ_LAMBDA）+ 设置页同款 i18n label；
- 初始化：读 `PluginSettings.state.reverseWrapperFormat` 选中；
- **写穿式持久化**（对齐语言下拉 M19.1 实证模式）：选中即写 `state.reverseWrapperFormat`；
- 切换动作：重跑生成（见 2.2），**QUERY 形态跳过实体查找**（T-M36.3 既有语义）。

### 2.2 切换即重生成 + 解析缓存

- 面板缓存上次成功解析：`lastText / lastResult / lastCandidates`（输入文本未变时切换形态不重新 parse/查实体，仅重生成代码——`SqlToJavaConverter.generateCode` 为纯函数，毫秒级）；
- QUERY ↔ 非 QUERY 切换且无候选缓存（QUERY 路径不查实体）→ 走完整流程（后台 ReadAction 查实体）；
- 输入文本变化 → 缓存失效（下次转换重 parse）。

### 2.3 设置页 ↔ 面板同步边界

- 面板 → 设置：写穿（面板是快捷入口，改动即持久化）；
- 设置页 → 面板：面板创建时读 + **tab 重新选中时刷新下拉**（JBTabbedPane ChangeListener）；不做实时监听。

### 2.4 Wrappers 形态生成（JavaCodeGenerator）

- `GeneratedWrapper` 新增 `WRAPPERS_QUERY` / `WRAPPERS_LAMBDA`（resolve 分发：WRAPPERS + 有实体 → LAMBDA 变体，无实体 → QUERY 变体）；
- 渲染：`Wrappers.<类名>query()` / `Wrappers.<类名>lambdaQuery()`（显式类型参数，独立语句可编译）；列渲染与 QUERY/LAMBDA 完全同构（字符串列/lambda 列）；
- 注释头标注 Wrappers 工厂形态。

## 3. 测试

- WrapperFormatTest：WRAPPERS 分发（有/无实体）；
- JavaCodeGeneratorTest：WRAPPERS 两变体生成文本（含 `Wrappers.<User>query()` 语法）；
- 面板测试（SqlToJavaPanelTest 扩展）：下拉初始值 = 设置值；切换下拉 → 状态写回设置 + 结果区重生成；QUERY 切换同步路径直测；tab 重选刷新；
- 设置面板测试（PluginSettingsPanelBindingTest 扩展）：Wrappers 项与 state 写穿一致性。

## 4. 边界

- 切换形态不改变已解析的 SQL 语义（同 SQL 换形态重生成，非重新解析）；
- 多表 JOIN SQL 的形态强制（见 T-M37 文档）：多表恒 MPJ 形态，面板下拉对多表 SQL 显示提示（不强制改下拉值）。
