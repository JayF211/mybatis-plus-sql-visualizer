## 4. 部署到 Cloudflare Pages

### 4.1 前置条件

- Cloudflare 账号
- 域名（可选，可用 `*.pages.dev` 默认域名）
- Gitee 仓库已推送

### 4.2 部署步骤

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com)
2. 进入 **Workers & Pages** → **Create application** → **Pages**
3. 选择 **Connect Git**，关联 Gitee 仓库（需配置 Cloudflare-Gitee 集成）
4. 构建设置：
   - Framework preset: `VitePress`
   - Build command: `npm run build`
   - Build output directory: `.vitepress/dist`
5. 环境变量：无需额外配置
6. 点击 **Save and Deploy**

### 4.3 自定义域名

1. Pages 项目 → **Custom domains** → **Set up a custom domain**
2. 输入域名（如 `docs.your-domain.com`）
3. 按提示配置 DNS CNAME 记录指向 `*.pages.dev`

> **注意**：使用 `.com` / `.dev` / `.io` 等境外后缀域名无需 ICP 备案。若使用 `.cn` 域名则需备案。

### 4.4 自动部署

配置 Git 连接后，每次推送到 `master` 分支会自动触发重新构建和部署。

## 5. 更新日志动态获取

### 5.1 架构

```
浏览器 → /api/changelog（同域）→ Cloudflare Pages Function → JetBrains Marketplace API
```

JetBrains Marketplace API 不支持 CORS，因此需要通过 Cloudflare Pages Function 做代理。

### 5.2 Cloudflare Pages Function

文件：`functions/api/changelog.js`

```javascript
export async function onRequest(context) {
  const apiUrl = 'https://plugins.jetbrains.com/api/plugins/33633/updates'
  const res = await fetch(apiUrl, {
    headers: {
      'User-Agent': 'MyBatis-Plus-SQL-Visualizer-Docs/1.0',
      'Accept': 'application/json',
    },
  })
  const data = await res.json()
  return new Response(JSON.stringify(data), {
    headers: {
      'Content-Type': 'application/json',
      'Access-Control-Allow-Origin': '*',
      'Cache-Control': 'public, max-age=3600',
    },
  })
}
```

### 5.3 运行时组件

`DynamicChangelog.vue` 在页面加载时：

1. `fetch('/api/changelog')` 获取 JSON 数据
2. 取最新版本的 `notes` 字段（包含完整更新日志）
3. `parseNotes()` 将 HTML 转换为 Markdown
4. `marked.parse()` 渲染为 HTML
5. 显示加载中/错误/内容三态

### 5.4 关键注意事项

- **API 返回结构**：每个版本的 `notes` 包含从该版本到最早版本的全部日志，因此只取最新版本即可
- **缩进问题**：API 返回的 `<li>` 有 4 空格缩进，`parseNotes` 必须去掉行首缩进，否则 `marked` 会将列表项误判为代码块（4 空格 = 代码块），导致文字显示为蓝色
- **缓存**：Function 响应头设置 `Cache-Control: public, max-age=3600`（1 小时缓存）

## 6. 本地开发

### 6.1 安装依赖

```bash
cd mybatis-plus-sql-visualizer-docs
npm install
```

### 6.2 本地预览（带 API 代理）

VitePress 开发服务器已配置代理，`/api/changelog` 会自动转发到 JetBrains API：

```bash
npm run dev
```

访问 http://localhost:5173/about/changelog 查看效果。

代理配置位于 `.vitepress/config.mts`：

```typescript
vite: {
  server: {
    proxy: {
      '/api/changelog': {
        target: 'https://plugins.jetbrains.com/api/plugins/33633/updates',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api\/changelog/, ''),
      }
    }
  }
}
```

### 6.3 构建

```bash
npm run build
```

构建产物输出到 `.vitepress/dist`。

### 6.4 本地预览构建产物

```bash
npm run preview
```

### 6.5 独立本地服务器（备选）

如果不用 VitePress dev，也可以用 Node.js 独立服务器：

```bash
node scripts/local-server.mjs
```

访问 http://localhost:3000

## 7. GIF 资源管理

功能详解页需要配 GIF 演示动图。当前使用占位图 `/public/demo/placeholder.svg`。

### 7.1 录制工具

- Windows: [ScreenToGif](https://www.screentogif.com/) 或 [Kap](https://getkap.co/)
- 推荐尺寸: 800×450 或 16:9 比例
- 文件大小: 单 GIF < 2MB

### 7.2 存放位置

```
public/demo/
├── wrapper-preview.gif
├── xml-preview.gif
├── annotation-preview.gif
├── sql-to-java.gif
├── sql-log.gif
```

### 7.3 替换占位图
