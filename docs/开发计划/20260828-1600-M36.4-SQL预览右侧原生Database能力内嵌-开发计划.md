## 一、需求概述

### 1.1 用户诉求

SQL 预览面板右侧的 SQL 显示栏，需要具备与 IDEA 原生 Database 完全一致的能力——包括编辑器上方的工具栏（数据源选择器 / Tx 下拉 / 执行按钮 / 提交按钮等），和 IDEA 中使用 SQL 文件或 Database Console 的体验完全相同。

### 1.2 当前状态

```
┌─────────────────────────────────────────────┐
│ 左侧参数区  │ 右侧：自研 SQL 编辑器          │  ← 无原生工具栏
│            │ （可编辑 + 补全 + 参数回填）    │
├────────────┴────────────────────────────────┤
│ 底部：完整原生 Database 控制台              │  ← 原生能力在底部
│ （编辑器 + 工具栏 + 结果 tabs）             │
└─────────────────────────────────────────────┘
```

### 1.3 目标状态

```
┌─────────────────────────────────────────────┐
│ 左侧参数区  │ 右侧：原生 Database 编辑器     │  ← 完整原生能力
│            │ （工具栏 + 编辑器 + 结果 tabs） │
├────────────┴────────────────────────────────┤
│ 底部：执行状态 / 摘要信息                   │  ← 仅状态栏
└─────────────────────────────────────────────┘
```

## 二、技术调研

### 2.1 核心问题

| 尝试 | 方案 | 结果 | 原因 |
|------|------|------|------|
| M36.2b | `getView→getContent→getComponent` 内嵌 | ❌ 组件=[0,0,0x0] | 内容延迟构建 |
| M36.2f | `editor.component` + 结果区 SplitPane 拼合 | ✅ 可行 | 编辑器在 SplitPane 中布局正常 |
| M36.2h | 完整控制台 `logView.getContent` 内嵌底部 | ✅ 可行 | 完整 UI 内嵌 |
| M36.3 | 编辑器单独右侧 + 结果区底部 | ❌ 右侧空白 | `editor.component` 为 0x0 且 hidden |

**关键发现**：原生编辑器组件（`editor.component`）从未显示的控制台提取时尺寸为 `0x0` 且 `hidden`，无法单独使用。完整控制台 UI 是唯一可靠方案。

### 2.2 IDEA Database 控制台结构

```
Database 工具窗口（或 SQL 文件编辑器）
├── FileEditor 区域（上方）
│   ├── 工具栏（数据源选择器 / Tx / 执行 / 提交）
│   └── 编辑器（EditorImpl）
└── RunnerLayoutUi 区域（下方）
    ├── Output tab
    └── Result tab（查询结果网格）
```

完整控制台组件 = `logView.getContent().getComponent()`，包含上述全部内容。

## 三、技术方案

### 3.1 方案：完整控制台内嵌右侧

将完整原生 Database 控制台（编辑器 + 工具栏 + 结果 tabs）整体内嵌到 SQL 预览面板的**右侧**，取代自研编辑器。

**原理**：完整控制台 UI 在 `logView.getContent().getComponent()` 返回时已完成布局（不再为 0x0），因为执行查询后 RunnerLayoutUi 已创建结果 Tab，触发了完整的 UI 构建。

### 3.2 布局调整

```
当前布局（M36.2h）：
┌─────────────────────────────────────────────┐
│  verticalSplit                              │
│  ├── top: horizontalSplit (params | editor)  │
│  └── bottom: consoleHolder (完整控制台)      │
└─────────────────────────────────────────────┘

目标布局（M36.4）：
┌─────────────────────────────────────────────┐
│  horizontalSplit                            │
│  ├── left: paramScroll (参数面板)            │
│  └── right: 完整原生控制台                   │
│       ├── 工具栏（数据源/Tx/执行）           │
│       ├── 编辑器                             │
│       └── 结果 tabs（Output/Result）         │
├─────────────────────────────────────────────┤
│ bottom: resultPanel（状态栏：耗时/行数）     │
└─────────────────────────────────────────────┘
```

### 3.3 实现要点

1. **移除 verticalSplit 的下半区**：不再需要底部的控制台区域
2. **完整控制台内嵌右侧 `editorHolder`**：`embedConsole` 将组件添加到 `editorHolder`
3. **自研编辑器释放**：执行后释放自研编辑器（`releaseEditor`）
4. **参数回填**：由于原生编辑器不支持 `#param → 值` 回填，保留左侧参数面板，但回填目标改为原生编辑器文档
