本轮新沉淀（翻译互操作铁律补充）：

- **Java record 不允许 `extends`**（只可 `implements`）——master 的 Kotlin sealed class 若以 record 承载子类，须把父级降为接口（VisibleDiff 案例）。
- **Kotlin 测试调用 Java 方法的命名实参被禁**（Named arguments are prohibited for non-Kotlin functions）——直取 .kt 测试须把命名实参机械化为位置实参。
- **Java 静态成员/嵌套类型在 Kotlin 侧无默认导入**——顶层函数/常量/嵌套类型的引用须补显式 import（SqlLogPanelKt.diffVisible/VisibleDiff 案例）。
- **非 getX/getIs 前缀的 Java 方法不合成 Kotlin 属性**——`currentPopup()` 须更名 `getCurrentPopup()` 才能支撑测试的属性语法。
- **工具调用层吃反斜杠再实证**：heredoc 内 `\\n` 经工具层转义后落盘成真实换行——Java 字符串字面量的转义序列改用 Write 工具写脚本文件或 Edit 工具直接落。
- **git merge-file --union 做行级并集**优于 difflib 手写 union（后者会因双侧同位插入对齐成 replace 误吞一侧行；merge-file 三方合并零冲突通过）。
