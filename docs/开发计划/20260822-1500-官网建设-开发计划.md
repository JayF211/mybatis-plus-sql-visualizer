## 1. 项目背景

当前插件的用户文档以 README.md 为唯一对外门面，缺乏独立的官网品牌展示和结构化文档站。随着插件功能趋近完善（v2026.8.21 已发行，610+ 测试全绿），需要建设一个专业的官网，承担品牌展示、功能推广、文档托管、用户引导四项职责。

### 1.1 调研范围

| 官网 | 类型 | 核心可借鉴点 |
|------|------|-------------|
| JetBrains IDEA | 商业 IDE | 吸顶导航 + Hero CTA + 多列页脚 |
| Vite | 开源工具 | Hero 居中大标题 + 安装命令 + 特性 grid |
| Tailwind CSS | CSS 框架 | 大标题排版 + 内联代码示例 + 暗色切换 |
| Prisma | 数据库 ORM | 三卡片概览 + 情境化文档链接 |
| VS Code | 编辑器 | 导航四分区 + 场景化分组 |
| Prettier | 代码格式化 | 极简 Hero + 双 CTA |
| **Memoryzy / WriterSide** | **插件文档站** | **GIF 懒加载 + 暗色图片切换 + Keystroke + 步骤向导 + 浮动通知 + 代码对比 + 线性导航 + Badge 实时数据** |

### 1.2 产品定位（一句话）

> Wrapper 链、XML/注解动态 SQL 实时预览（含 MPJ 联表 JOIN），控制台日志一键还原，SQL 反向转 Java 代码。

## 2. 决策记录

| 决策项 | 结论 | 理由 |
|--------|------|------|
| 框架选型 | **VitePress** | 开源、Markdown 优先、搜索内置、i18n 原生、可任意定制首页 |
| 部署位置 | 独立仓库 | 与源码解耦，独立发布节奏 |
| 中英双语 | 同时建设，中文默认 | VitePress i18n 路由原生支持 |
| 示例交互 | 简单 Tab 切换 | Vue SFC 轻量实现 |
| GIF/视频演示 | **每个功能页必配** | Memoryzy 已验证：图文对照是转化率核心 |
| 统计方式 | 轻量统计 | 初期观察访问量 |
| 首页优先级 | **P0（最高）** | 首次访客转化率决定官网价值 |

## 3. 技术选型

### 3.1 框架：VitePress

| 维度 | 评估 |
|------|------|
| 成熟度 | Vue 官方文档同款，生态成熟 |
| Markdown 优先 | 现有 README/CHANGELOG/开发计划可直接复用 |
| 搜索 | Tinysearch 内置全文搜索 / Algolia 可升级 |
| i18n | 内置 locale 路由，`/zh/` + `/en/` 分区 |
| 首页定制 | Vue SFC 任意定制，完全可控 |
| 暗色模式 | 内置 `darkModeSwitch` |
| 语法高亮 | Shiki 内置，SQL/Java/Kotlin 全支持 |
| 构建产物 | 纯静态文件，Gitee Pages 部署 |
| 评论 | Giscus（基于 Gitee Issues / GitHub Discussions） |

### 3.2 从 WriterSide 吸收的精华 → VitePress 实现方案

| WriterSide 精华 | 在 VitePress 中的实现方案 |
|-----------------|--------------------------|
| GIF 懒加载（`data-gif-src` 按需加载） | 自定义 Vue `<GifPlayer>` 组件：IntersectionObserver 监听可视区 → 按需加载，首帧占位图 |
| 暗色图片自动切换（`data-dark-src`） | 自定义 `<ThemedImage>` 组件：根据 `useDarkMode()` 状态切换 `src` |
| Keystroke 样式（`Settings > Plugins`） | CSS 美化 `<kbd>` 标签 + 多步骤快捷键一行展示 |
| 步骤向导（`procedure-steps`） | 自定义 Vue `<Steps>` 组件：有序列表 + 卡片式序号 |
| 浮动通知（右下角滑入） | 自定义 `<SiteNotice>` 组件：版本更新/公告时右下角滑入，10s 自动消失 |
| 代码水平对比（`code-comparer`） | 自定义 Vue `<CodeCompare>` 组件：左右并排 Before/After |
| 提示框（note/tip/warning） | VitePress 内置自定义容器 `:tip` `:warning` `:danger` |
| Badge 实时数据（版本/下载/Stars） | Shields.io 一行 Markdown |
| 底栏线性导航（< 上一篇 / 下一篇 >） | VitePress 内置 `prev/next` 配置 |

### 3.3 完整技术栈

| 层级 | 选型 |
|------|------|
| 静态站点生成 | VitePress (Vite + Vue 3) |
| 语言 | TypeScript（配置 + 组件）+ Markdown（内容） |
| 样式 | VitePress 默认主题 + CSS 变量覆盖 |
| 部署 | 独立仓库 + Gitee Pages |
| 搜索 | 内置 Tinysearch（离线全文搜索） |
| 统计 | 轻量统计 |
| GIF 录制 | ScreenToGif / Kap |
| 图标 | Iconify（VitePress 内置） |
| 评论 | Giscus（可选，后期接入） |

## 8. 实施计划

### Phase 1：基础框架搭建（1-2 天）

**目标**：VitePress 项目初始化，导航/侧边栏/暗色模式/双语/搜索全部就绪

- [ ] 创建独立仓库 `mybatis-plus-sql-visualizer-docs`
- [ ] 初始化 VitePress 项目（`npx vitepress init`）
- [ ] 配置 `config.mts`：标题、描述、head meta、暗色模式
- [ ] 配置 i18n 路由：`/zh/` 中文默认 + `/en/` 英文
- [ ] 配置顶部导航（Features / Docs / About / GitHub / 语言切换）
- [ ] 配置侧边栏分组（功能详解 / 使用指南 / 关于）
- [ ] 配置 Tinysearch 搜索
- [ ] 部署到 Gitee Pages 验证 CI 流程
- [ ] 编写自定义 CSS 变量（配色 / 字体 / 间距 / Keystroke 样式）

**验收标准**：仓库可访问，中文首页有基础框架，侧边栏可导航，暗色模式可切换，搜索可用

### Phase 2：首页开发 ⭐ P0（3-4 天）

**目标**：首页全部区块完成。首页是唯一高优先级，必须打磨到位。

- [ ] **Hero 区**：产品名 + 一句话定位 + 代码片段（Java Wrapper 示例）
- [ ] **Hero 区**：15-30 秒演示 GIF（Wrapper 右键 → 预览弹窗 → 勾选条件 → SQL 变化）
- [ ] **Hero 区**：GIF 用 `GifPlayer.vue` 懒加载 + 首帧占位
- [ ] **Hero 区**：CTA 按钮（Install 跳转 Marketplace / GitHub 跳转仓库）
- [ ] **Badge 数据栏**：版本号 / 下载量 / GitHub Stars / 测试覆盖（Shields.io）
- [ ] **特色功能**：6 张特性卡片 `FeatureCards.vue`（图标 + 短描述 + 截图预览 + hover 动效）
- [ ] **代码示例区**：多 Tab 交互 `CodeTabs.vue`（查询 / 更新 / 联表 / 批量 / 反向）
- [ ] **功能矩阵**：分组表格（SQL 预览 / SQL 日志 / SQL→Java / 其他能力）
- [ ] **版本亮点**：最新版本核心变更 + changelog 链接
- [ ] **页脚**：安装引导 + 多列链接
- [ ] 英文首页同步翻译
- [ ] 响应式适配（手机 / 平板 / 桌面）
- [ ] 暗色模式全面检查（所有组件 + 图片）

**验收标准**：首页完整展示所有区块，GIF 懒加载流畅，Tab 切换正常，Badge 实时数据正确，移动端响应式可用，暗色模式无异常

### Phase 3：文档站填充（3-4 天）

**目标**：全部功能详解页 + 指南页 + FAQ，每页必配 GIF/截图

- [ ] `/guide/getting-started.md`：安装步骤向导（`Steps.vue` + 截图）

- [ ] `/features/wrapper-preview.md`：功能详解 + 截图 + 示例代码 + GIF
- [ ] `/features/xml-preview.md`：XML 动态 SQL 预览详解 + GIF
- [ ] `/features/annotation-preview.md`：注解 SQL 预览详解 + GIF
- [ ] `/features/sql-to-java.md`：反向转换详解 + 四形态对比 + `CodeCompare` + GIF
- [ ] `/features/sql-log.md`：日志工具窗口详解 + 操作 GIF

**目标**：性能优化 + SEO + 统计 + 正式推广

- [ ] Lighthouse 评分检查

**验收标准**：Lighthouse 性能分 > 90，SEO 分 > 90，无 404 死链，GIF 懒加载无闪烁

## 10. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| GIF 文件过大 | 加载慢、LCP 超标 | 单 GIF < 2MB，WebP 动图优先，GifPlayer 懒加载 |
| 英文翻译质量差 | 英文用户体验差 | 先中文 + 机翻，后续社区贡献润色 |
| 暗色模式图片漏配 | 暗色下图片不协调 | 强制每张截图配 `data-dark-src` 暗色版 |
| 文档与插件版本脱节 | 用户困惑 | 每次发行同步更新文档（加入发行 checklist） |
| Gitee Pages 访问慢 | 国内用户可接受 | 后期可迁 CDN |
| 独立仓库维护成本 | 需同步两边 | 文档站设 CI 提醒，插件发行时触发 |
