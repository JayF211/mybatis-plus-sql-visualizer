## 1. 问题描述

SQL 预览弹窗左侧参数面板（`SqlPreviewPanel`）的「全选/全不选」按钮位于参数列表
流式布局内：

- Wrapper 动态条件场景：`conditionSectionHeader()`（FlowLayout RIGHT 按钮行，列表顶部）；
- 批量「参数列」场景：`batchSectionHeader()`（BorderLayout EAST 按钮，分区标题行右侧）；
- XML 预览条件开关复用 `conditionSectionHeader()`。

当参数名过长（如 `#productInfo.getDicProtocolType()`，标签宽度自适应上限 300px，
T-M19.4-01）+ 值输入框使参数行宽超过左面板视口宽度时，右上角按钮被推出视口
（需拉宽左面板或横向滚动才能看到）。

## 2. 根因（已定位确认）

`paramPanel` 为 `BoxLayout(Y_AXIS)`（SqlPreviewPanel.kt:71-73）。BoxLayout 会把
**每一行子组件拉伸到整个 Box 的宽度**，而 Box 宽度 = 最宽一行的 preferred 宽度：
参数行（FlowLayout LEFT）宽度由内容决定，长参数名行可达 400px+ → `paramPanel`
整体被撑宽到 400px+ → 顶部的全选/全不选按钮行被同步拉伸，右对齐的按钮被推到
视口（默认约 240px）之外 → 被隐藏。按钮行在滚动区内，受内容宽度连累。

## 3. 方案设计（用户指定：固定右上角 + 随分隔栏移动）

把全选/全不选按钮**移出滚动区**，固定到左面板顶部（NORTH 固定行）：

```
SqlPreviewPanel(BorderLayout)
└── CENTER: ThemedSplitPane
    ├── 左: leftPanel = JBPanel(BorderLayout)      ← 新外层容器
    │   ├── NORTH: 固定操作行（FlowLayout RIGHT）  ← 全选/全不选按钮组，右对齐
    │   └── CENTER: paramScroll（原滚动参数列表）
    └── 右: editorHolder
```

要点：

1. **按钮实例只创建一次**（面板 init 时），按场景切换可见性，不再每次 rebuild 重建：
   - 批量预览（`batchModel != null`）→ 显示批量组（`setAllBatchColumns`）；
   - 动态条件 / XML 条件（`conditionViews` 非空）→ 显示条件组（`setAllConditions`）；
   - 无参数内容 → 整行隐藏（与现状"无按钮"行为一致）。
2. 按钮行宽度 = 左面板宽度 = 分隔栏位置 → **右对齐即始终贴住分隔栏，拖拽分隔栏自动跟随**，
   且完全不受参数列表内容宽度影响（长参数名只影响滚动区内容）。
3. 滚动区内清理：`conditionSectionHeader()`（纯按钮行）删除；`batchSectionHeader()`
   简化为纯分区标签（按钮已上移）。
4. 顶部行仅两个紧凑按钮、高度与现状按钮行一致，**不增加面板空间占用**。
