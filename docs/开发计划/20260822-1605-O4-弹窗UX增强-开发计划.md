## 0. 目标

增强 SQL 预览弹窗的交互体验：差异高亮（本次 vs 上次预览）、SQL Diff（两个 Wrapper 对比）、一键复制可执行 SQL。

**用户价值**：调试过程中快速定位 SQL 变化、方便分享可执行 SQL 给同事或在其他工具中执行。

---

## 1. 功能设计

### 1.1 差异高亮（本次 vs 上次）

**场景**：用户修改 Wrapper 条件后重新预览，需要快速看出 SQL 哪里变了。

**方案**：
- 每次预览完成后缓存 SQL 文本（`PreviewResult.previousSql`）
- 新预览完成后与缓存对比，标注差异行（新增绿色 / 删除红色 / 变更黄色）
- 缓存生命周期：会话级（IDE 重启清空）

**实现**：
```kotlin
object SqlDiffer {
    fun computeDiff(oldSql: String?, newSql: String): List<DiffEntry> {
        // 使用 java-diff-utils (google diff-match-patch 或 Myers diff)
        // 返回行级差异列表
    }
}
```

### 1.2 SQL Diff（两个 Wrapper 对比）

**场景**：Code Review 时对比两个不同 Wrapper 链的 SQL 差异。

**方案**：
- 弹窗工具栏新增「对比」按钮
- 点击后弹出 Wrapper 选择器（当前文件内的其他 Wrapper 链）
- 选择后并排显示两个 SQL，差异行高亮
- 参考 Git diff 风格

**实现**：
```kotlin
// 复用 WrapperLocator 收集当前文件所有 Wrapper 链
val wrappers = WrapperChainCollector.collect(file)
// 选择后并排渲染
```

### 1.3 一键复制可执行 SQL

**场景**：将参数替换后的完整 SQL 复制到 DBeaver/DataGrip 中执行。

**方案**：
- 弹窗工具栏新增「复制可执行 SQL」按钮
- 将 `?` 替换为当前面板输入的参数值
- 按字段类型决定是否加引号（复用 `ParamQuote` 逻辑）
- 复制到系统剪贴板， toast 提示

**实现**：
```kotlin
// 复用 ParameterReplacer（已有）
val executableSql = ParameterReplacer.buildExecutableSql(
    sql = result.sql,
    paramValues = panel.getParamValues(),
    dialect = result.dialect
)
CopyPasteManager.getInstance().setContents(StringSelection(executableSql))
```

## 6. 边界与降级

- `previousSql` 为空（首次预览）：不显示差异
- Diff 算法性能：SQL < 1000 行应在 100ms 内完成
- 复制可执行 SQL 时参数未填写：跳过该参数保持 `?`
