## 1. 问题描述

SQL 预览面板右侧为 `EditorFactory.createEditor` 创建的嵌入式编辑器（非文件编辑器），
IDEA 全局 Reformat Code（Ctrl+Alt+L）对其不生效（预览语言无 formatter，全局动作
本就不可用）。当前格式化只能点面板顶部「格式化」按钮（`formatSql()` → `SqlFormatter`）。

## 2. 方案设计（用户已确认）

1. **快捷键来源**：跟随 IDE keymap——取当前激活 keymap 中 Reformat Code
   （`IdeActions.ACTION_REFORMAT`）的快捷键注册（用户自定义键位跟随）；
   keymap 无绑定时兜底 `Ctrl+Alt+L`（`CustomShortcutSet`）。
2. **注册目标**：面板整体（`AnAction.registerCustomShortcutSet(action, shortcutSet, this)`）——
   焦点在 SQL 编辑器或参数输入框时均可触发；组件级 custom shortcut 命中即消费按键，
   不与 IDE 全局 Reformat Code 双触发。
3. **触发逻辑**：`actionPerformed` → 复用现有 `formatSql()`（逻辑零改动）；
   Action 保存为具名字段（测试可引用触发）。
4. **生命周期**：面板 init 注册一次，无注销管理（action 每次取当前 editor）。
