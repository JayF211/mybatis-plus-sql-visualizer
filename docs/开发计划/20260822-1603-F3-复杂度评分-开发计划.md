## 0. 目标

对当前 Wrapper 链生成的 SQL 给出 0-100 的复杂度评分，帮助开发者快速识别高风险复杂查询，引导拆分优化。

**用户价值**：Code Review 时一眼看出这条 SQL 是不是过于复杂，是否需要拆分或优化。

## 1. 技术方案

### 1.1 评分模型（移植自 sql-visualizer 的 COMPLEXITY_WEIGHTS）

```kotlin
object ComplexityWeights {
    // 结构复杂度
    const val JOIN_PER_TABLE = 5       // 每个 JOIN +5
    const val SUBQUERY_DEPTH = 10      // 每层嵌套 +10
    const val TABLE_COUNT = 3          // 每张表 +3
    const val UNION = 6                // 每个 UNION +6
    const val CTE = 8                  // 每个 CTE +8
    
    // 条件复杂度
    const val OR_CONDITION = 2         // 每个 OR +2
    const val IN_ITEMS_OVER_100 = 10   // IN 超 100 项 +10
    const val NESTED_SUBQUERY = 12     // 嵌套子查询 +12
    
    // 风险因子
    const val SELECT_STAR = 10         // SELECT * +10
    const val LEADING_WILDCARD = 8     // LIKE '%x' +8
    const val MISSING_WHERE = 15       // 无 WHERE +15
    const val NO_LIMIT = 5             // 无 LIMIT +5
    const val FUNCTION_ON_COL = 7      // WHERE FUNC(col) +7
    const val ORDER_BY_RAND = 10       // ORDER BY RAND() +10
    const val DISTINCT = 3             // DISTINCT +3
    const val GROUP_BY = 2             // GROUP BY +2
    const val HAVING = 4               // HAVING +4
    
    const val MAX_SCORE = 100
}
```

### 1.2 评分公式

```kotlin
fun computeScore(stmt: Statement, warnings: List<PerfWarning>): Int {
    var score = 0
    
    // 从 SQL AST 提取结构信息
    val tableCount = TableExtractor.extract(stmt).size
    val joinCount = JoinExtractor.count(stmt)
    val maxSubqueryDepth = SubqueryExtractor.maxDepth(stmt)
    val hasSelectStar = SelectStarDetector.detect(stmt)
    // ... 其他维度
    
    // 加权求和
    score += joinCount * JOIN_PER_TABLE
    score += maxSubqueryDepth * SUBQUERY_DEPTH
    score += tableCount * TABLE_COUNT
    if (hasSelectStar) score += SELECT_STAR
    // ... 其他加权
    
    // 叠加 F-2 警告的严重度
    for (w in warnings) {
        score += when (w.severity) {
            Severity.ERROR -> 10
            Severity.WARNING -> 5
            Severity.INFO -> 1
        }
    }
    
    return min(score, MAX_SCORE)
}
```

### 1.3 评分等级

| 分数 | 等级 | 颜色 | 含义 |
|:----:|:----:|:----:|------|
| 0-20 | 简单 | 🟢 绿 | 单表简单查询 |
| 21-40 | 中等 | 🟡 黄 | 2-3 表 JOIN 或简单子查询 |
| 41-60 | 较复杂 | 🟠 橙 | 多 JOIN 或嵌套子查询 |
| 61-80 | 复杂 | 🔴 红 | 复杂联表，建议拆分 |
| 81-100 | 极高 | 🔴 深红 | 必须优化 |

## 4. 边界与降级

- JSqlParser 解析失败：返回分数 -1（未知），不阻塞预览
- 评分仅供参考：不阻塞任何操作，仅展示
- 评分缓存：与 WrapperCache 绑定，同一 Wrapper 不重复计算
