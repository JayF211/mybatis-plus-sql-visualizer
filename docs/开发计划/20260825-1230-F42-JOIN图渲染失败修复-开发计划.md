# F-42 JOIN 图渲染失败修复 — 开发计划

> **创建日期**：2026-08-25
> **状态**：沙盒已修复，主 IDE 待验证
> **优先级**：高

---

## 问题描述

JOIN 关系图（PlantUML 渲染）在主 IDE (2026.2.1) 中无法正常显示，标签页持续显示"关系图渲染中..."（进度条动画），永远不显示实际图像。

沙盒 IDE (2024.3.7.1 + `--add-opens`) 中 PNG 渲染成功，但主 IDE 中失败。

---

## 根因分析

### 问题 1：IllegalAccessError 未捕获

**现象**：PlantUML PNG 渲染抛出 `java.lang.IllegalAccessError`，`catch (e: Exception)` 无法捕获（`Error` 不是 `Exception` 子类）。

**根因**：`DiagramRenderTask.run()` 使用 `catch (e: Exception)`，无法捕获 `IllegalAccessError`（继承自 `Error`）。异常直接传播，`onDone` 回调永不执行，UI 卡在"渲染中"。

**修复**：`catch (e: Exception)` → `catch (e: Throwable)`

### 问题 2：PNG 渲染失败无降级

**现象**：主 IDE 中 `com.sun.imageio.plugins.png` 模块未开放，PNG 渲染失败。

**根因**：`runIde` 沙盒通过 `--add-opens` 参数开放模块，但主 IDE 无此参数。

**修复**：`renderWithFallback()` 方法捕获 `IllegalAccessError` 后自动降级为 SVG 渲染。

### 问题 3：SVG 无法预览

**现象**：降级为 SVG 后，`ImageIO.read()` 无法解码 SVG 格式（只支持 PNG/JPEG/GIF/BMP）。

**根因**：`applyZoom()` 使用 `ImageIO.read()` 解码字节，不支持 SVG。

**修复**：`applyZoom()` 检测 SVG 字节（`isSvgBytes()`），通过反射调用 JavaFX `WebView` 渲染 SVG。

### 问题 4：DiagramPanel 期龄检查失败（核心根因）

**现象**：PNG 渲染成功（6465 字节），`invokeLater` 执行了 `onDone`，但回调内 `println` 未输出。

**根因**：`DiagramPanel` 被反复 `dispose()` → `dispose()` 设置 `currentSource = null`、`currentBytes = null`、`taskId = null`。回调中期龄检查 `currentSource != plantUmlText` 失败（`null != plantUmlText`），回调提前返回，图像永不显示。

**诊断过程**：
```
[DIAG-PANEL] showDiagram: currentSource=null, currentBytes=null  ← 第一次
[DIAG] render succeeded, bytes=6465
[DIAG] invokeLater: executing onDone
[DIAG-PANEL] callback: taskId=null, match=false  ← taskId 被 dispose 置 null
```

**修复**：移除回调中的期龄检查，直接处理结果：有字节就显示，无字节就报错。

## 已实施修复

| 文件 | 改动 |
|------|------|
| `DiagramRenderTask.kt` | `catch(e: Exception)` → `catch(e: Throwable)` |
| `DiagramRenderTask.kt` | PNG 渲染使用 `renderWithFallback()` 自动降级 SVG |
| `DiagramPanel.kt` | `applyZoom()` 检测 SVG → 反射调用 JavaFX WebView |
| `DiagramPanel.kt` | 移除回调中期龄检查（`currentSource != plantUmlText`） |
| `build.gradle.kts` | `runIde` 添加 `--add-opens` JVM 参数 |
