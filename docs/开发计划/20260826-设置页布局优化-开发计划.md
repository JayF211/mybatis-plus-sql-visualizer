## 一、现状分析

### 1.1 当前结构

```
Settings → Tools → MyBatis-Plus SQL Visualizer
└── 单页滚动（6 组 TitledSeparator + ~44 行配置项）
    ├── SQL 预览（10 行）
    ├── 表名映射（6 行）
    ├── 代码生成（2 行）
    ├── SQL 日志（17行）  ← 过长
    ├── 界面与操作（4 行）
    └── 更新与诊断（4 行）
```

### 1.2 核心问题

| # | 问题 | 表现 |
|---|------|------|
| 1 | **单页信息密度过高** | 44 行平铺，滚动距离长，找不到目标配置 |
| 2 | **SQL 日志组过大** | 17 行混合了 MyBatis 核心、Hibernate、JdbcTemplate、自动保存、执行耗时，无二级分组 |
| 3 | **组间无层级** | 6 组平铺，无主次，视觉权重相同 |
| 4 | **缺少搜索** | 无快速定位入口，高频/低频混在一起 |
| 5 | **代码生成组过小** | 仅 2 行独占一组，浪费空间 |
| 6 | **复选框行与输入行混排** | 开关类和编辑类行交错，视觉节奏乱 |
| 7 | **底部工具区无分隔** | 缓存/更新/构建号/导入导出堆在一起，缺少视觉分区 |

## 二、设计原则（对标 IDEA 原生设置）

### 2.1 IDEA 原生风格要点

1. **左侧树 + 右侧内容**：顶层用树形导航分层，右侧只显示当前选中分类的内容
2. **分组折叠**：同一分类内的子组用可折叠面板（` JBCollapsiblePanel` 或 `TitledSeparator` + 折叠按钮）
3. **搜索框置顶**：过滤配置项，高亮匹配项
4. **Tab 子页**：子功能用 Tab 切换（如日志分 MyBatis/Hibernate/JdbcTemplate 三个 Tab）
5. **辅助说明灰色小字**：tooltip 或说明文字用小号灰色字体，不抢视觉
6. **高频前置、低频后置**：常用配置在前，高级/诊断在后
7. **一致的行距和标签宽度**：标签列等宽，输入列左对齐

### 2.2 本插件的适配策略

- **不引入左侧树**：单 Configurable 注册为页面级，不用 `ConfigurableProvider` 拆子节点（用户需在同一页面完成所有配置）
- **引入折叠分组**：将 6 个 TitledSeparator 组改为可折叠面板，默认展开第 1/5/6 组，其余折叠
- **SQL 日志组内分 Tab**：17 行拆成 3 个 Tab（MyBatis 核心 / ORM 框架 / 自动保存与执行）
- **代码生成并入 SQL 预览**：仅 2 行不值得独立成组
- **底部工具区分隔**：缓存/更新/构建号/导入导出用独立折叠面板「关于」

## 四、技术方案

### 4.1 折叠面板

使用 Swing 内置的 `JPanel` + `TitledBorder` 或自实现折叠按钮（`JButton` 切换图标 + `JPanel.setVisible`）。

- 折叠状态持久化到 `PluginSettings.State`（新增 `Set<String> collapsedGroups`）
- 折叠动画可选（先做无动画的显隐切换）

### 4.2 SQL 日志 Tab

使用 `JTabbedPane` 嵌套在 SQL 日志折叠面板内：

```kotlin
val logTabs = JTabbedPane()
logTabs.addTab("MyBatis 核心", buildMyBatisLogPanel())
logTabs.addTab("ORM 框架", buildOrmLogPanel())
logTabs.addTab("自动保存与执行", buildAutoSaveLogPanel())
```

### 4.3 代码生成并入 SQL 预览

- 删除 `settings.section.codeGen` 分隔线
- `reverseFormatCombo` + `manualEntityCheck` 移入 SQL 预览组末尾
- 两行之间加一个轻量分隔（`JSeparator` 或留空行）

### 4.4 搜索框（可选，P2 阶段）

- 在页面顶部添加 `JBTextField` 搜索框
- 实时过滤：遍历所有 `JLabel` / component，匹配文本则显示，不匹配则隐藏
- 匹配时自动展开父级折叠面板

## 七、风险与回滚

- **Phase 1 无配置模型变更**，不影响持久化格式，回滚只需还原 `PluginSettingsPanel.kt`
- 折叠状态用 `Set<String>` 存储，旧版插件读取时忽略未知字段（XML 反序列化天然向前兼容）
- Tab 切换不触发 `isModified`，无误报脏数据风险
