# 导入失败时弹框手动输入 + 灰色示例占位 + 驼峰/下划线自动匹配（P-05.1）开发计划

> 状态：🔧 开发中（2026-08-20）
> 需求来源：用户反馈「导入如果剪贴板没有识别到，可以出现一个弹框供粘贴输入，并且使用灰色字体提供示例格式」+「导入时自动匹配驼峰或下划线」。

## 1. 目标与范围

1. **按钮文案**：「导入」→「导入参数」。
2. **弹框手动输入**：剪贴板导入失败（无文本 / 解析无有效参数）时，弹出一个带多行输入框的对话框，让用户直接粘贴参数文本，并以**灰色占位文本**提示支持的格式示例（JSON / CSV / key=value）。
3. **驼峰/下划线自动匹配**：导入参数时，key 与 source 的匹配除了现有的精确匹配（`key ≡ source` 或 `key ≡ #source`），新增**驼峰 ↔ 下划线**互转匹配（`userName` ≡ `user_name`），解决数据库列名（下划线）与 Java 字段名（驼峰）命名风格不一致的问题。

**已确认决策**：
- 触发时机：剪贴板为空 **或** 剪贴板文本解析出 0 个有效参数时弹出。
- 对话框形态：`DialogWrapper` 子类，中心面板为 `JBTextArea`（多行）。
- 灰色示例：`JBTextArea.emptyText` 原生能力。
- 驼峰匹配策略：精确匹配优先 → 去 `#` 前缀精确匹配 → 驼峰/下划线互转匹配（三级 fallback）。
- 互转算法：`userName` ↔ `user_name`（纯字母数字，不含连续下划线/首尾下划线）。

## 3. 模块设计

### 3.1 CaseFormatUtil（驼峰/下划线互转，纯函数可单测）

新增 `src/main/kotlin/cn/song/mybatisplus/visualizer/util/CaseFormatUtil.kt`：

```kotlin
object CaseFormatUtil {
    /** camelCase → snake_case：userName → user_name */
    fun camelToSnake(input: String): String =
        input.replace(Regex("([a-z0-9])([A-Z])")) { "${it.groupValues[1]}_${it.groupValues[2].lowercase()}" }

    /** snake_case → camelCase：user_name → userName */
    fun snakeToCamel(input: String): String =
        input.replace(Regex("_([a-z0-9])")) { it.groupValues[1].uppercase() }

    /** 取 key 的所有匹配形态：[原文, 去#前缀, snake, camel] */
    fun variants(key: String): List<String> {
        val stripped = if (key.startsWith("#")) key.substring(1) else key
        val result = mutableListOf(key, stripped)
        // key 本身是 camel → 转 snake；key 本身是 snake → 转 camel
        result += camelToSnake(stripped)
        result += snakeToCamel(stripped)
        return result.distinct()
    }
}
```

### 3.2 resolveSource 改造（三级 fallback）

```kotlin
private fun resolveSource(key: String, sources: Set<String>): String? {
    // 1. 精确匹配
    if (sources.contains(key)) return key
    // 2. 去 # 前缀精确匹配
    val stripped = if (key.startsWith("#")) key.substring(1) else key
    if (sources.contains(stripped)) return stripped
    // 3. 驼峰/下划线互转匹配
    val snake = CaseFormatUtil.camelToSnake(stripped)
    if (sources.contains(snake)) return snake
    val camel = CaseFormatUtil.snakeToCamel(stripped)
    if (sources.contains(camel)) return camel
    return null
}
```

### 3.3 ParamImportDialog（UI 弹窗）

新增 `src/main/kotlin/cn/song/mybatisplus/visualizer/ui/ParamImportDialog.kt`：

```kotlin
class ParamImportDialog(
    private val project: Project,
    private val onConfirm: (String) -> Unit,
) : DialogWrapper(project, true) {

    private val textArea = JBTextArea(8, 48).apply {
        emptyText.text = MpSqlVisualizerBundle.message("panel.param.import.dialog.placeholder")
        lineWrap = true
        wrapStyleWord = true
    }

    init {
        title = MpSqlVisualizerBundle.message("panel.param.import.result.title")
        init()
    }

    override fun createCenterPanel(): JComponent = JBScrollPane(textArea).apply {
        preferredSize = Dimension(DIALOG_WIDTH, DIALOG_HEIGHT)
    }

    public override fun doOKAction() {
        val text = textArea.text
        super.doOKAction()
        if (text.isNotBlank()) onConfirm(text)
    }

    companion object {
        const val DIALOG_WIDTH = 480
        const val DIALOG_HEIGHT = 200
    }
}
```

### 3.4 入口改造（SqlPreviewPanel）

```kotlin
fun importParamsFromClipboard() {
    val text = runCatching {
        Toolkit.getDefaultToolkit().systemClipboard
            .getContents(null)?.getTransferData(DataFlavor.stringFlavor) as? String
    }.getOrNull()
    if (text.isNullOrBlank()) {
        ParamImportDialog(project ?: return) { input ->
            importParams(ParamImportParser.parse(input))
        }.show()
        return
    }
    val parsed = ParamImportParser.parse(text)
    if (parsed.isEmpty()) {
        ParamImportDialog(project ?: return) { input ->
            importParams(ParamImportParser.parse(input))
        }.show()
        return
    }
    importParams(parsed)
}
```
