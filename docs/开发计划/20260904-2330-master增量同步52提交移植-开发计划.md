## 五、风险与规避

- 原生图框架为 Diagrams 插件可选依赖：diagram-optional.xml 的 optional 语义与「降级自绘」路径必须原样保留，
  验证时覆盖无 Diagrams 插件环境（既有降级测试）。
- T-Embed B 路径大量反射（Database 组件、VIRTUAL_FOREIGN_KEYS Holder）：API 名以本地 jar 反编译为唯一权威，
  禁止凭记忆调用不存在的方法。
- ConvertToSqlAction / SqlPreviewService 是历史热点文件，增量合入时先读本分支 .java 现状再对位，
  防止把 master 侧 .kt 的中间态直接翻译进来（只认 origin/master 终态）。
- 公开 API 形态变化（新增类/方法）后必须 `--rerun-tasks` 重编译测试，避免假失败。
- push 已知 headless GCM 挂死问题：完成本地提交即可，推送留给用户 GUI 环境，不反复重试。
