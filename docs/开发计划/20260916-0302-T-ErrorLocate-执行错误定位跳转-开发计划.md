## 一、背景与依据

「SQL 调试」定位下，执行失败是高频场景，但当前失败信息是一条裸字符串：异常在反射链被退化为 `cause.message`，errorCode/SQLState 全 worktree 零消费，用户看到红字却不知道错在语句哪一行。DBX 的实践证明：把驱动错误位置结构化并映射回编辑器，是排错体验的最大单点提升。PG 驱动的错误消息自带 `Position: N`（1-based 字符游标）、MySQL 语法错误自带 `at line N`——message 文本里就有位置信息，不必动协议层。

边界先钉死：渲染后的 SQL 与 mapper 原文行不是一一对应（动态 SQL 拼接、参数注入），**列级精确定位只对单语句 mapper 片段承诺**，其余场景降级为「跳到语句起始行」并如实说明——诚实降级是人设红线。

## 三、方案

**T-EL-01（错误位置解析纯函数）**：新增 `execute/ExecutionErrorInfo.kt`：data class（message、sqlState?、errorCode?、positionChar?、lineInSql?）+ `ErrorPositionExtractor` 纯函数——从异常/消息文本提取 PG `Position: N` / `Line: N`、MySQL `at line N`；**marker 单一性门控**（多平台位置信号并存时放弃归属，回退无位置）；越界钳制；对齐 DBX「基建语句不带位置」——非 SQL 错误（驱动连接串错误等）不产出位置。

**T-EL-02（onError 通道富化）**：反射链 catch 处（`:2461,2496,2509`）解包后读 SQLException 的 SQLState/errorCode/next 异常链再退化为 message；onError(String) 旧消费者零改动，新增并行富通道（`onErrorRich: (ExecutionErrorInfo) -> Unit` 重载，默认空实现），SqlPreviewPanel 接富通道。

**T-EL-03（UI 定位动作）**：SqlResultPanel 错误态新增「定位到出错位置」动作——**仅错误时出现**（对齐预览窗口 errorCopyButton 显隐先例与报告反馈记忆：不做成常驻）；点击 → 预览上下文的源文件 + 语句起始行（McpSourceLocator 同源数据）+ 错误行偏移换算 → OpenFileDescriptor(file, line, column).navigate(true)；换算不可靠时降级跳语句起始行，tooltip 注明「定位到语句起始（错误行映射不可靠）」。

**T-EL-04（MCP errorPosition）**：CheckSqlTool findings 行（`CheckSqlTool.kt:59-64`）与 RenderLogsTool 输出（`:87-97`）在解析/执行类错误样例上附 `errorPosition: line N, col M` 文本行（维持纯文本输出形态，不引 JSON）。

**T-EL-05（i18n + 测试 + 文档）**：双语键 2~3 个；表驱动——PG Position/MySQL at line N 提取、多 marker 放弃、越界钳制、无位置降级、SQLState 08xxx 分类桩；CHANGELOG [Unreleased] Added、变更记录行、第五轮报告 N-18 状态回填。

## 四、验收标准

1. ErrorPositionExtractor 表驱动全绿；多 marker/越界/无位置三降级路径覆盖。
2. onError(String) 旧通道逐字节不变（防回归断言）；富通道只增不改。
3. 定位动作仅错误态可见；换算降级路径有 tooltip 如实说明，绝不虚标精确。
4. 全量 test 绿（合流基线 + 新增数），跑前按铁律并行登记。

## 五、真机走查清单（留人工）

1. PG 数据源执行带语法错误的语句：红字出现「定位到出错位置」，点击落点行正确（Position 游标换算）；MySQL 同测 `at line N`。
2. mapper XML 多语句片段触发错误：降级为语句起始行，tooltip 说明在场。
3. MCP render_logs 传错误样例：输出含 errorPosition 行。

## 六、风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| PG 消息内 Position 行格式随驱动版本漂移 | pgjdbc 把 server 错误的 Position 拼进 message，格式需实测 | 提取函数宽松匹配 + 真机走查；匹配不到即无位置（诚实降级） |
| 渲染后 SQL ↔ mapper 原文行映射不对齐 | 动态 SQL 拼接后行号错位 | v1 只承诺单语句片段列级 + 其余语句级降级；映射算法后续迭代 |
| 反射链多层 catch 丢类型 | InvocationTargetException 解包点分散 | 富化只在三个已知 catch 点做，登记注释防新增 catch 漏改 |
| 环境受限 | 真机无全部九方言环境 | PG/MySQL 真机走查为必测，其余方言走消息格式表驱动 + 「环境受限未验证」口径 |
