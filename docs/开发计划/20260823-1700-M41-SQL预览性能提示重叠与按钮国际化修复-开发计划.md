## 问题分析

### 问题一：性能提示与按钮重叠

**现象**：SQL 预览弹窗顶部，当存在性能警告（如"含前导通配符 —— 无法利用 B-Tree 索引"）时，提示文本与右侧工具栏按钮出现水平重叠。

**根因**：`SqlPreviewPanel.kt` 第 198-202 行的 `topRow` 采用 `BorderLayout`：

```kotlin
val topRow = JBPanel<JBPanel<*>>(BorderLayout()).apply {
    add(metaLabel, BorderLayout.WEST)
    add(toolbar(), BorderLayout.EAST)
}
```

`metaLabel`（WEST）与 `toolbar()`（EAST）**共享同一行水平空间**。`BorderLayout` 优先满足 WEST/EAST 的 preferredWidth，当 `metaLabel` 文本过长时，WEST 区域膨胀挤压 EAST 区域，导致按钮与文本重叠。

而 `updateMeta()`（第 1632 行）将元信息、警告、性能建议**全部拼接为单行文本**塞入 `metaLabel`：

```kotlin
metaLabel.text = meta + warningLine + perfLine
```

性能警告本身较长（如 `LIKE '%xxx' 含前导通配符 —— 无法利用 B-Tree 索引，建议改用全文搜索或后缀匹配`），多条时以分号拼接，极易超出可用宽度。

**解决方案**：将性能警告从 `topRow` 拆出，放入独立的**第二行**（`BorderLayout.SOUTH` 的专属警告栏），使 `topRow` 仅承载元信息 + 按钮，警告区域独占一行、不参与水平竞争。

### 问题二：Diff / Compare 按钮英文硬编码

**现象**：中文语言环境下，工具栏的 "Diff" 和 "Compare" 两个按钮显示英文，其余按钮均为中文。

**根因**：`SqlPreviewPanel.kt` 第 279、281 行直接使用硬编码英文字符串：

```kotlin
add(smallButton("Diff") { toggleDiffHighlight() })      // 第 279 行
add(smallButton("Compare") { showSqlDiff() })           // 第 281 行
```

而所有其他按钮均通过 `MpSqlVisualizerBundle.message(...)` 获取 i18n 文案。同时，两个 bundle 文件中缺少 `panel.diff` 和 `panel.compare` 对应的键值。

**解决方案**：
1. 在 `MpSqlVisualizerBundle.properties` 添加 `panel.diff` / `panel.compare` 英文键
2. 在 `MpSqlVisualizerBundle_zh.properties` 添加对应中文键
3. 修改 `SqlPreviewPanel.kt` 第 279、281 行使用 `MpSqlVisualizerBundle.message()`

#### 1.2 修改 updateMeta() — 警告文本分离

将第 1614-1641 行的 `updateMeta()` 方法中 `perfLine` 从 `metaLabel` 分离，写入独立的 `perfWarningLabel`：

```kotlin
private fun updateMeta(result: PreviewResult) {
    val meta = buildList {
        result.wrapperType?.let { add("${MpSqlVisualizerBundle.message("panel.meta.type")}: ${it.name}") }
        result.tableName?.let { add("${MpSqlVisualizerBundle.message("panel.meta.table")}: $it") }
        result.xmlModel?.let { xml ->
            add("XML ${xml.kind.name.lowercase()}: ${xml.statementId}")
            xml.parameterType?.let { add("parameterType: $it") }
        }
    }.joinToString("   ")

    val xmlWarning = result.xmlModel?.let { xml ->
        (xmlErrors).joinToString("；").ifEmpty { null }
    }
    currentWarning = xmlWarning ?: result.warning
    val warningLine = currentWarning?.let { "   ⚠ $it" } ?: ""

    // M41：元信息仅含基础信息 + 解析/渲染警告
    metaLabel.text = meta + warningLine
    metaLabel.foreground = if (currentWarning != null) {
        JBColor.namedColor("ErrorForeground", JBColor.RED)
    } else {
        JBUI.CurrentTheme.Label.foreground()
    }
    errorCopyButton?.isVisible = currentWarning != null

    // M41：性能警告写入独立标签（独占一行）
    val perfLine = buildPerfLine(result)
    if (perfLine.isNotEmpty()) {
        perfWarningLabel?.text = perfLine
        perfWarningLabel?.foreground = JBColor.namedColor("ErrorForeground", JBColor.RED)
        perfWarningLabel?.isVisible = true
    } else {
        perfWarningLabel?.text = ""
        perfWarningLabel?.isVisible = false
    }
}
```
