## §4 W2 体验打磨候选批次（待 D7 勾选）

- **R2 gutter 按来源分组显隐**（成本 S）：动机＝MyBatisX「图标太大太醒目」差评多轮。现状＝仅全局布尔 `showGutterIcon`（PluginSettings.kt:83），15 个 lineMarkerProvider 无分组。方案＝按 SQL 来源分组（mapper XML/注解/JPA·HQL/JdbcTemplate/内嵌兜底…）各设开关，设置页 UI 增加组，gutter 可用性判定接 settings。验收：关闭组后对应 gutter 消失，开回恢复；设置页检索可达。
- **R3 日期/时间类型参数还原强化**（成本 M，先验证后动码）：动机＝Log Free LocalDate→ORA-01722 差评。第一步先做**缺口矩阵验证**：我方类型感知回填对 LocalDate/LocalDateTime/OffsetDateTime/时区 × MySQL/PG/Oracle/SQL Server/达梦/H2 的字面量包装逐格实测（真引擎优先，dbx MCP 有 Oracle/达梦在册连接），产出缺口表；第二步按缺口补方言字面量包装。验收：矩阵表落 docs + 补齐项带定向测试。
- **R4 SQL 历史/日志导出**（成本 S~M）：现状＝导出仅设置项（O-5 SettingsIO），SQL 历史与日志面板无导出。方案＝日志面板与历史 tab 右键/工具栏「导出」（CSV/TSV/纯文本三选，行集口径与面板过滤一致）。验收：导出文件与面板当前可见行集一致；大集（万行）不卡 EDT（后台线程+进度）。
- **R5 小件包**（成本 S）：快捷模板 LIMIT 值配置化（现 grep 无配置点）；软换行**维持现状**（SqlClickPreview/SqlSuppressManagerDialog 已硬编码开启，用户开关属低价值不立项）。
