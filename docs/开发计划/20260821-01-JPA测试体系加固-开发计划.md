# JPA 测试体系加固开发计划

> 创建日期：2026-08-21
> 状态：**计划中**
> 优先级：**P1**（多轮修复暴露测试严重不足，同类 bug 反复出现）

## 背景

v2026.8.20 发行后，用户 demo 项目实测发现 JPA/Hibernate 识别存在多个严重缺陷。经三轮修复才勉强覆盖主要场景，但每次修复都暴露同一个根因：**测试没有防住回归**。

### 已交付三轮修复回顾

| 轮次 | 修复内容 | 测试漏网原因 |
|------|---------|-------------|
| P0 | gutter 图标去重 + 参数名实际化 | 只断言 marker 存在，未断言数量；只断言结果非空，未断言参数名内容 |
| P1 | HQL 支持 + JPQL 增强 + CriteriaQuery | 测试用例太简单，未覆盖真实复杂度 |
| P2 | DELETE JPQL + native SQL + 交互参数 | 不知道 `JpqlConverter` 内部算出了 SQL 但没用；未模拟面板回填 |

### 根本问题

| 问题 | 说明 |
|------|------|
| **测试按组件隔离写** | 每个测试只验证自己函数的输入输出，bug 全部出在组件接缝处 |
| **断言不充分** | `assertNotNull(result)` 通过就算完成，不验证下游真正读取的字段 |
| **没有端到端测试** | 不知道 `JpqlConverter` → `SqlGenerator` → 面板回填这条链路怎么走 |
| **测试用例太简单** | `SELECT NEW DTO(u.name, u.email)` 通过了，`NEW DTO(o.id, COUNT(o), SUM(...))` 没测 |
| **没有面板行为测试** | 真实 bug 发生在面板交互层，但测试从未实例化过 `SqlPreviewPanel` |

---

## 目标

建立三层测试体系，让每一层都能防住特定类型的回归：

1. **组件契约测试**（升级现有单测）：验证下游组件真正读取的所有字段
2. **端到端集成测试**（新建）：覆盖完整链路 PSI → 定位 → 转换 → SQL 生成 → 参数回填
3. **面板行为测试**（新建）：实例化真实面板，模拟用户交互

---

#### 2.1 JpqlConverter 端到端

从 JPQL 字符串到面板可回填的完整链路：

```kotlin
class JpqlConverterEndToEndTest : BasePlatformTestCase() {

    private val userTable = TableInfo(
        entityClassName = "UserEntity", tableName = "user",
        columns = listOf(
            ColumnInfo("id", "id", isId = true),
            ColumnInfo("username", "username"),
            ColumnInfo("email", "email"),
            ColumnInfo("age", "age"),
            ColumnInfo("status", "status"),
            ColumnInfo("departmentId", "department_id"),
            ColumnInfo("createTime", "create_time"),
        ),
    )

    private val orderTable = TableInfo(
        entityClassName = "OrderEntity", tableName = "t_order",
        columns = listOf(
            ColumnInfo("id", "id", isId = true),
            ColumnInfo("orderNo", "order_no"),
            ColumnInfo("customerId", "customer_id"),
            ColumnInfo("totalAmount", "total_amount"),
        ),
    )

    /**
     * 端到端：JPQL → 转换后 SQL → 模拟面板参数回填。
     * 验证 ? 占位符存在且可被回填。
     */
    @Test
    fun `e2e JPQL SQL placeholders match method params`() {
        data class Case(val jpql: String, val table: TableInfo, val expectedParamCount: Int)
        val cases = listOf(
            Case("SELECT u FROM UserEntity u WHERE u.username = :username", userTable, 1),
            Case("SELECT u FROM UserEntity u WHERE u.username = :username AND u.age BETWEEN :minAge AND :maxAge", userTable, 3),
            Case("DELETE FROM UserEntity u WHERE u.age < :maxAge", userTable, 1),
            Case("SELECT o FROM OrderEntity o WHERE o.totalAmount >= :minAmount", orderTable, 1),
            Case("SELECT NEW cn.song.jpademo.dto.OrderStatDTO(o.customerId, COUNT(o), SUM(o.totalAmount)) FROM OrderEntity o GROUP BY o.customerId HAVING COUNT(o) > 1", orderTable, 0),
            Case("SELECT * FROM user WHERE username LIKE CONCAT('%', :keyword, '%') AND status = :status", userTable, 2),
        )
        for (c in cases) {
            val result = JpqlConverter.convert(c.jpql, c.table)
            assertTrue("SQL 不应为空白: ${c.jpql}", result.sql.isNotBlank())
            assertEquals("占位符数量不匹配: ${c.jpql}",
                c.expectedParamCount, result.sql.count { it == '?' })
        }
    }

    /** 端到端：DELETE JPQL 不应返回 SelectStatement */
    @Test
    fun `e2e DELETE JPQL statement type is DeleteStatement`() {
        val result = JpqlConverter.convert("DELETE FROM UserEntity u WHERE u.age < :maxAge", userTable)
        assertTrue("DELETE 应返回 DeleteStatement: ${result.statement::class.simpleName}",
            result.statement is DeleteStatement)
    }
}
```

#### 2.2 SqlPreviewService 端到端

从 PSI 方法到完整 PreviewResult：

```kotlin
class SqlPreviewServiceEndToEndTest : BasePlatformTestCase() {

    private fun newService() = SqlPreviewService(project)

    private fun findMethod(file: PsiFile, name: String): PsiMethod =
        PsiTreeUtil.collectElementsOfType(file, PsiMethod::class.java).first { it.name == name }

    /**
     * 端到端：@Query 方法 → previewJpql → PreviewResult 各字段验证。
     * 覆盖 demo 项目所有 @Query 方法。
     */
    @Test
    fun `e2e JPQL method produces valid PreviewResult with backfillable params`() {
        myFixture.configureByText("OrderRepository.java", """
            public interface OrderRepository extends JpaRepository<OrderEntity, Long> {
                @Query("SELECT o FROM OrderEntity o WHERE o.totalAmount >= :minAmount ORDER BY o.totalAmount DESC")
                List<OrderEntity> findByMinAmount(@Param("minAmount") BigDecimal minAmount);
            }
            @interface Query { String value(); }
            class JpaRepository<T, ID> {}
            class OrderEntity { private Long id; private String orderNo; private Long customerId; private BigDecimal totalAmount; }
            class BigDecimal {}
        """.trimIndent())
        val method = findMethod(myFixture.file, "findByMinAmount")
        val result = newService().previewJpql(method)

        assertNotNull("previewJpql 不应返回 null", result)
        // SQL 含 ?（面板回填前提）
        assertTrue("SQL 应含 ?: ${result!!.sql}", result.sql.contains("?"))
        // 参数名 == @Param 值
        assertEquals("参数名应为 minAmount", listOf("minAmount"), result.unresolvedParams)
        // paramTable 非 null
        assertNotNull("paramTable 不应为 null", result.paramTable)
        // 列信息非空
        assertTrue("columns 不应为空", result.columns.isNotEmpty())
    }

    /** 端到端：DELETE @Query 方法 */
    @Test
    fun `e2e DELETE JPQL method produces DeleteStatement with warning`() {
        myFixture.configureByText("UserRepository.java", """
            public interface UserRepository extends JpaRepository<UserEntity, Long> {
                @Query("DELETE FROM UserEntity u WHERE u.age < :maxAge")
                int deleteByAgeLessThanJpql(@Param("maxAge") Integer maxAge);
            }
            @interface Query { String value(); }
            class JpaRepository<T, ID> {}
            class UserEntity { private Long id; private Integer age; }
        """.trimIndent())
        val method = findMethod(myFixture.file, "deleteByAgeLessThanJpql")
        val result = newService().previewJpql(method)

        assertNotNull(result)
        assertTrue("DELETE SQL 应含 DELETE: ${result!!.sql}", result.sql.contains("DELETE", ignoreCase = true))
        assertEquals("参数名应为 maxAge", listOf("maxAge"), result.unresolvedParams)
    }

    /** 端到端：原生 SQL @Query 方法 */
    @Test
    fun `e2e native SQL method converts named params to placeholders`() {
        myFixture.configureByText("UserRepository.java", """
            public interface UserRepository extends JpaRepository<UserEntity, Long> {
                @Query(value = "SELECT * FROM user WHERE username LIKE CONCAT('%', :keyword, '%') AND status = :status", nativeQuery = true)
                List<UserEntity> findByKeywordNative(@Param("keyword") String keyword, @Param("status") Integer status);
            }
            @interface Query { String value(); boolean nativeQuery() default false; }
            class JpaRepository<T, ID> {}
            class UserEntity { private Long id; private String username; private Integer status; }
        """.trimIndent())
        val method = findMethod(myFixture.file, "findByKeywordNative")
        val result = newService().previewJpql(method)

        assertNotNull(result)
        // 命名参数应被转换为 ?
        assertFalse("SQL 不应含 :keyword: ${result!!.sql}", result.sql.contains(":keyword"))
        assertFalse("SQL 不应含 :status: ${result.sql}", result.sql.contains(":status"))
        assertTrue("SQL 应含 ?: ${result.sql}", result.sql.contains("?"))
        assertEquals("? 数量应为 2", 2, result.sql.count { it == '?' })
        // 参数名应从 @Param 提取
        assertEquals("参数名应为 keyword, status", listOf("keyword", "status"), result.unresolvedParams)
    }
}
```

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 面板行为测试需要 EDT 环境 | 使用 `runInEdt {}` 块，继承 `BasePlatformTestCase` |
| 面板组件树遍历复杂 | 先用 `ComponentUtil.findComponentsOfType` 找输入框 |
| 测试用例太多导致构建变慢 | 端到端和面板测试标记 `@Tag("integration")`，日常只跑单元测试 |
