## 0. 目标

将当前预览的 SQL + 参数一键分享给团队成员，支持生成 Markdown/HTML 报告、复制为单行可执行 SQL。Code Review 时直接贴可执行 SQL，减少沟通成本。

**用户价值**：Code Review / 问题排查时，快速分享「这条 SQL 会查出什么」给同事。

---

## 1. 功能设计

### 1.1 一键分享

**方案**：
- 弹窗工具栏新增「分享」按钮
- 点击后弹出分享选项：
  - 📋 复制为 Markdown 代码块（含 SQL 高亮）
  - 📋 复制为单行可执行 SQL（含参数替换）
  - 📋 复制为 Markdown 表格（SQL + 参数 + 来源）
  - 🔗 生成分享链接（可选：上传到 Gist/ Pastebin，需网络）
  - 📄 导出为 HTML 文件（带语法高亮的完整报告）

### 1.2 Markdown 格式

````markdown
```sql
SELECT id, name, email
FROM user
WHERE name = 'zhangsan'
    AND email LIKE '%@gmail.com'
```
> 来源：UserService.java:42 | 方言：MySQL | 2026-08-22 15:30
````

### 1.3 HTML 报告

**方案**：
- 使用 SQL 高亮 HTML（复用现有 `highlight/` 包的逻辑）
- 模板包含：SQL、参数表、来源、时间、方言
- 保存为 `.html` 文件，浏览器打开查看

### 1.4 Code Review 集成

**方案**：
- 分享内容自动附加来源信息（文件名 + 行号）
- 支持自定义前缀（如 `[SQL Review]` 标题）
- 可选：直接复制为 MR/PR 评论格式

## 6. 边界与降级

- 无网络时（生成链接）：提示「网络不可用，已复制到剪贴板」
- SQL 过长（>10KB）：Markdown 截断 + 提示
- HTML 文件保存失败：提示错误
