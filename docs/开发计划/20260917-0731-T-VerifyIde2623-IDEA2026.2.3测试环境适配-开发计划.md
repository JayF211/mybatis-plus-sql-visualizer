## 一、背景与依据

本项目构建策略是「以最低支持版本为编译基准」（平台 2024.3.7.1 / since-build 243），对最新版本只做字节码级兼容校验——`pluginVerification.ides` 与 `verifyGate` 的目标集合里，「最新版本」长期锚在 2026.2.1。本机日常 IDE 已升级 2026.2.3，若不追目标，2026.2.3 独有的 API 变动将漏出三目标门禁视野（编译基准 243 不受影响，无需动）。
