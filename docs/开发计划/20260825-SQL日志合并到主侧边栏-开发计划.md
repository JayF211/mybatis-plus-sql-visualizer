# F-44：SQL 日志合并到主侧边栏 + 源码定位 — 开发计划

> **创建日期**：2026-08-25
> **优先级**：P1（架构调整 + 功能增强）
> **涉及文件**：~15 个文件，改动量 ~600 行
> **数据来源**：用户功能需求

---

## 需求描述

1. **去除**现有的独立侧边栏按钮【SQL日志】（`cn.song.mybatisplus.visualizer.log` 工具窗口）
2. **合并**到插件的主侧边栏中，新增一个 tab
3. SQL 日志内容**只读取 `.idea` 目录**中的历史文件（F-43 自动保存的数据）
4. 支持**定位之前的代码位置**（跳转到产生该 SQL 的源码处）
5. 支持显示**当时的耗时**（executionTimeMs）
6. 支持显示**当时的执行时间**（timestamp）

---

## 现状分析

### 现有架构

```
工具窗口（plugin.xml）:
  ├── cn.song.mybatisplus.visualizer.log (SQL日志侧边栏)
  │   └── SqlLogToolWindowFactory → SqlLogPanel (3 tabs)
  │       ├── Tab 0 "SQL 日志" — 实时捕获（控制台日志解析）
  │       ├── Tab 1 "日志转 SQL"
  │       └── Tab 2 "SQL → Java"
  │
  └── cn.song.mybatisplus.visualizer.history (SQL历史记录侧边栏)
      └── SqlHistoryToolWindowFactory → SqlHistoryPanel
```

### 关键约束

| 项目 | 现状 | 目标 |
|------|------|------|
| 数据来源 | 实时控制台日志解析（`SqlLogConsoleBridge` → `FilterProxyHandler` → 3 个 Parser → `SqlLogEntryBuffer`） | 只读 `.idea/mybatis-plus-sql-visualizer/sql-history/` 文件 |
| 源码定位 | 无（`LogSqlEntry` 无 PSI/VirtualFile/行号字段） | 支持跳转到产生 SQL 的代码位置 |
| 耗时显示 | 有 `executionTimeMs` 字段（O-1 Phase B 从日志解析） | 保留并显示 |
| 执行时间 | 有 `timestamp` 字段 | 保留并显示 |
| 捕获机制 | `SqlLogConsoleBridge` 反射挂载 `RunContentManager` | **不再需要实时捕获** |

### 核心问题

1. **LogSqlEntry 无源码位置字段**：当前从控制台文本解析 SQL，不关联 PSI 元素。要支持"跳转到代码位置"，必须在捕获时记录调用栈中的源码位置（`VirtualFile` + 行号）。
2. **F-43 自动保存格式不含源码位置**：当前格式 `-- 时间戳\nSQL\n\n` 只有时间和 SQL，需要扩展。
3. **实时捕获机制需要保留但改为记录源码位置**：SQL 仍然从控制台解析，但在创建 `LogSqlEntry` 时附加调用栈信息。

### 改动 ②：捕获时记录源码位置

**文件**：`src/main/kotlin/cn/song/mybatisplus/visualizer/log/SqlLogConsoleBridge.kt`

在 `LogFilterProxyHandler.onLine()` 或 `applyFilter()` 中，解析出 `LogSqlEntry` 后、进入 buffer 前，附加源码位置：

```kotlin
    sourceLine = extractSourceLine(),
)
buffer.addEntry(entryWithSource)
```

**源码位置提取逻辑**（新建内部工具方法）：

```kotlin
/**
 * 从当前线程调用栈中提取产生 SQL 的源码位置。
 * 原理：SQL 日志由应用代码打印 → 调用栈中第一个非 JDK/非本插件的帧即为产生者。
 * 返回：VirtualFile 的相对路径 + 行号（PSI 不可用，仅从 StackTraceElement 获取）。
 */
private fun extractSourceLocation(): Pair<String?, Int> {
    val stackTrace = Thread.currentThread().stackTrace
    // 跳过前几个帧（Thread.getStackTrace、本方法、LogFilterProxyHandler）
    for (i in 3 until stackTrace.size) {
        val frame = stackTrace[i]
        val className = frame.className
        // 跳过 JDK、IntelliJ 平台、本插件类
        if (className.startsWith("java.") || className.startsWith("javax.") ||
            className.startsWith("jdk.") || className.startsWith("sun.") ||
            className.startsWith("com.intellij.") || className.startsWith("org.jetbrains.") ||
            className.startsWith("cn.song.mybatisplus.visualizer.")) {
            continue
        }
        // 找到第一个应用代码帧
        val relativePath = classNameToRelativePath(className, frame.fileName)
        return relativePath to frame.lineNumber
    }
    return null to 0
}

/**
 * 将类名 + 文件名转换为相对项目根目录的路径。
 * 例如：com.example.mapper.UserMapper + UserMapper.java → src/main/java/com/example/mapper/UserMapper.java
 * 注意：无法精确还原源码路径（无 PSI 上下文），仅作最佳-effort 提示。
 */
private fun classNameToRelativePath(className: String, fileName: String): String? {
    // 将包名转换为路径：com.example.mapper → com/example/mapper
    val packagePath = className.substringBeforeLast('.', "").replace('.', File.separatorChar)
    return if (packagePath.isNotEmpty()) "$packagePath${File.separatorChar}$fileName" else fileName
}
```

> **注意**：从 `StackTraceElement` 只能获取文件名和行号，无法获取 `VirtualFile`。精确导航需要结合 PSI（在 UI 层通过文件名搜索）。

### 改动 ③：扩展 F-43 保存格式

**文件**：`src/main/kotlin/cn/song/mybatisplus/visualizer/log/SqlLogAutoSaver.kt`

当前格式：
```
-- 2026-08-25 10:00:00
SELECT * FROM user
```

扩展为：
```
--- source: src/main/java/com/example/mapper/UserMapper.java:42 | time: 5ms | 2026-08-25 10:00:00.123 ---
SELECT * FROM user
```

**writeEntry() 修改**：

```kotlin
private fun writeEntry(w: BufferedWriter, entry: LogSqlEntry) {
    runCatching {
        synchronized(w) {
            // 头部：源码位置 | 耗时 | 时间戳
            val source = entry.sourceFile?.let { file ->
                if (entry.sourceLine > 0 "$file:${entry.sourceLine}" else file
            } ?: "unknown"
            val duration = entry.executionTimeMs?.let { "${it}ms" } ?: "—"
            val timestamp = SimpleDateFormat("yyyy-MM-dd HH:mm:ss.SSS", Locale.ENGLISH).format(Date(entry.timestamp))
            w.write("--- source: $source | time: $duration | $timestamp ---\n")
            w.write(entry.restoredSql)
            w.write("\n\n")
            w.flush()
        }
    }.onFailure {
        LOG.warn("自动保存历史 SQL：写入失败", it)
    }
}
```

> **向后兼容**：旧版格式（`-- 时间戳\nSQL`）仍可被 `SqlLogFileReader` 解析（通过头部前缀区分）。

### 改动 ④：新建 SqlLogFileReader

**新文件**：`src/main/kotlin/cn/song/mybatisplus/visualizer/log/SqlLogFileReader.kt`

```kotlin
package cn.song.mybatisplus.visualizer.log

import java.io.File
import java.text.SimpleDateFormat
import java.util.Locale

/**
 * 从 .idea/mybatis-plus-sql-visualizer/sql-history/ 文件反解析为 LogSqlEntry。
 * 支持两种格式：
 *   - 新版：--- source: xxx | time: xxx | timestamp ---\nSQL\n
 *   - 旧版：--- timestamp ---\nSQL\n（F-43 初始格式）
 */
object SqlLogFileReader {

    private val NEW_HEADER_REGEX = Regex(
        """--- source: (.+?) \| time: (.+?) \| (\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d{3}) ---"""
    )
    private val OLD_HEADER_REGEX = Regex(
        """-- (\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})"""
    )

    /**
     * 读取目录下所有 .sql 文件，返回按时间戳排序的 LogSqlEntry 列表。
     */
    fun readAll(dir: String): List<LogSqlEntry> {
        val directory = File(dir)
        if (!directory.isDirectory) return emptyList()
        return directory.listFiles { f -> f.extension == "sql" }
            ?.flatMap { readFromFile(it) }
            ?.sortedBy { it.timestamp }
            ?: emptyList()
    }

    fun readFromFile(file: File): List<LogSqlEntry> {
        if (!file.exists()) return emptyList()
        val content = file.readText()
        return parseContent(content)
    }

    fun parseContent(content: String): List<LogSqlEntry> {
        val entries = mutableListOf<LogSqlEntry>()
        val blocks = content.split(Regex("""(?=^--- )""", RegexOption.MULTILINE))
        for (block in blocks) {
            val trimmed = block.trim()
            if (trimmed.isEmpty()) continue
            parseBlock(trimmed)?.let { entries.add(it) }
        }
        return entries
    }

    private fun parseBlock(block: String): LogSqlEntry? {
        val lines = block.lines()
        if (lines.isEmpty()) return null
        val header = lines.first()
        val sql = lines.drop(1).joinToString("\n").trim()
        if (sql.isEmpty()) return null

        // 尝试新版格式
        NEW_HEADER_REGEX.find(header)?.let { mr ->
            val sourceStr = mr.groupValues[1]
            val timeStr = mr.groupValues[2]
            val timestampStr = mr.groupValues[3]
            val timestamp = parseTimestamp(timestampStr) ?: return null
            val (sourceFile, sourceLine) = parseSource(sourceStr)
            val executionTimeMs = parseDuration(timeStr)
            return LogSqlEntry(
                rawSql = sql,
                restoredSql = sql,
                params = emptyList(),
                timestamp = timestamp,
                sourceFile = sourceFile,
                sourceLine = sourceLine,
                executionTimeMs = executionTimeMs,
            )
        }

        // 尝试旧版格式
        OLD_HEADER_REGEX.find(header)?.let { mr ->
            val timestampStr = mr.groupValues[1]
            val timestamp = parseTimestampOld(timestampStr) ?: return null
            return LogSqlEntry(
                rawSql = sql,
                restoredSql = sql,
                params = emptyList(),
                timestamp = timestamp,
            )
        }

        return null
    }

    private fun parseSource(sourceStr: String): Pair<String?, Int> {
        if (sourceStr == "unknown") return null to 0
        val colonIdx = sourceStr.lastIndexOf(':')
        return if (colonIdx > 0) {
            val file = sourceStr.substring(0, colonIdx)
            val line = sourceStr.substring(colonIdx + 1).toIntOrNull() ?: 0
            file to line
        } else {
            sourceStr to 0
        }
    }

    private fun parseDuration(timeStr: String): Long? {
        if (timeStr == "—" || timeStr == "-") return null
        return timeStr.removeSuffix("ms").toLongOrNull()
    }

    private fun parseTimestamp(ts: String): Long? = try {
        SimpleDateFormat("yyyy-MM-dd HH:mm:ss.SSS", Locale.ENGLISH).parse(ts)?.time
    } catch (_: Exception) { null }

    private fun parseTimestampOld(ts: String): Long? = try {
        SimpleDateFormat("yyyy-MM-dd HH:mm:ss", Locale.ENGLISH).parse(ts)?.time
    } catch (_: Exception) { null }
}
```

**关键 UI 设计**：

```kotlin
class HistorySqlLogPanel(private val project: Project) : JPanel(BorderLayout()), Disposable {

    private val listModel = DefaultListModel<LogSqlEntry>()
    private val list = object : JBList<LogSqlEntry>(listModel) {
        fun itemToText(): String = withTerminator(selectedValue?.restoredSql ?: "")
    }

    init {
        buildUI()
        refresh()
    }

    private fun buildUI() {
        // 工具栏
        val toolbar = JPanel(BorderLayout())
        toolbar.add(buildActionToolbar(), BorderLayout.WEST)
        toolbar.add(buildSearchBar(), BorderLayout.CENTER)
        add(toolbar, BorderLayout.NORTH)

        // 列表
        list.cellRenderer = HistoryCellRenderer()
        list.fixedCellHeight = -1
        list.addMouseListener(object : MouseAdapter() {
            override fun mouseClicked(e: MouseEvent) {
                if (e.clickCount == 2) openPreview()
            }
        })
        add(JBScrollPane(list), BorderLayout.CENTER)
    }

    fun refresh() {
        val dir = getHistoryDir()
        val entries = SqlLogFileReader.readAll(dir)
        listModel.clear()
        entries.forEach { listModel.addElement(it) }
    }

    private fun getHistoryDir(): String {
        val basePath = project.basePath ?: return ""
        return "$basePath${File.separator}.idea${File.separator}mybatis-plus-sql-visualizer${File.separator}sql-history"
    }

    private fun jumpToSource(entry: LogSqlEntry) {
        if (entry.sourceFile == null) {
            Messages.showInfoMessage("无法定位源码：该条目未记录源码位置", "跳转源码")
            return
        }
        // 通过文件名搜索 VirtualFile → 打开 → 定位行
        val fullPath = "${project.basePath}${File.separator}${entry.sourceFile}"
        val virtualFile = LocalFileSystem.getInstance().findFileByPath(fullPath)
        if (virtualFile != null) {
            OpenFileDescriptor(project, virtualFile, entry.sourceLine - 1, 0).navigate(true)
        } else {
            Messages.showInfoMessage("源文件不存在：${entry.sourceFile}", "跳转源码")
        }
    }

    override fun dispose() {}
}
```

**CellRenderer 展示格式**：

