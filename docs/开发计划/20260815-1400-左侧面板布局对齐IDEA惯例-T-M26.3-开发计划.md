# 左侧面板布局对齐 IDEA 原生惯例——开发计划（T-M26.3）

> 状态：✅ 已交付（2026-08-15，T-M26.3，662 测试全绿）。
> 需求来源：2026-08-15 用户反馈——T-M26.2 交付后左侧面板布局仍不理想，
> 要求参考 IDEA 官方 UI 文档与原生布局优化；用户选定方案 A（全选/全不选回挂
> 分区标题行右侧）。
> 当前基线：T-M26.2 已交付（662 测试全绿，commit 601f151）。
> 任务编号源：本文档（T-M26.3，延续 M26 系列；如与里程碑规划不符可改号）。
> 交付后按仓库约定同步 docs/变更记录.md 总册 + CHANGELOG [Unreleased]。

## 1. 目标（对照 IDEA 官方 UI 规范）

1. **P0-1 分区标题统一 TitledSeparator 风格**：四区（动态条件 / foreach 展开 / bind 变量 / 参数）
   用「短标题 + 分隔线」分组（参考官方 [Group Header](https://plugins.jetbrains.com/docs/intellij/group-header.html) 规范）；
   动态条件区补标题「动态条件」（i18n 新增 `panel.condition.section`，中英双语）。
2. **P0-2 全选/全不选回挂分区标题行右侧**（方案 A，用户选定）：动态条件区标题行右侧挂
   条件组按钮、批量「参数列」标题行右侧挂批量组按钮——回归 T-M23.2 原生形态；
   **拆除 T-M26.2 的固定右上角 actionBar**（按钮恢复每次 rebuild 重建 + clear 置 null）。
3. **P1-1 表单两列对齐**：参数行 / bind 行 / foreach 行标签列统一宽度（**按最长可见标签
   自适应，140~260px，用户确认**），输入框左缘对齐（参考官方
   [Layout](https://plugins.jetbrains.com/docs/intellij/layout.html) 规范：输入框左缘对齐、标签左对齐）。
4. **P1-2 长文本截断 + tooltip 全名**：bind 表达式标签、条件 test 表达式标签超宽截断
   （中段省略「…」，保留尾部字段名），tooltip 全文——根治「长内容撑宽面板」，保证
   P0-2 按钮不再被推出视口；`paramLabel` 宽度自适应逻辑保留（T-M19.4-01 诉求不回归）。
