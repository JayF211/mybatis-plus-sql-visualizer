# SQL 日志面板布局修复 + 列表多行预览 + 过滤条优化开发计划

> 状态：✅ 已完成（全量测试通过）
> 需求来源：用户反馈「SQL 列表靠下放贴了，正常应该是铺满的」+「顶部按钮考虑用分割线区分」+「SQL 全部变成一行，用户看起来区分不清」+「筛选按钮按下后没有高亮状态」+「筛选按钮当侧边栏收缩时候会展示不全」。

## 1. 目标与范围

**Bug 修复**：SQL 日志列表（`JBScrollPane`）当前被放在 `BorderLayout.SOUTH`，只拿到首选高度、贴底显示；应改为 `BorderLayout.CENTER` 铺满剩余空间。

**体验优化 1**：工具栏（捕捉/清空/设置/帮助）与过滤条（全部/SELECT/INSERT/UPDATE/DELETE/折叠/排序）之间加一条水平分割线，视觉分区更清晰。

**体验优化 2**：SQL 列表条目从"单行摘要"改为"多行预览"——时间戳独占一行、SQL 词法着色自动换行、行底 1px 分隔线 + 四周内边距，解决"区分不清"。

**体验优化 3**：筛选按钮（全部/SELECT/INSERT/UPDATE/DELETE）选中态高亮——`JToggleButton` 选中时浅蓝底 + 深蓝字（整体变色），未选中时恢复默认；通过 `ChangeListener` 监听 `model.selected` 变化同步外观。

**体验优化 4**：过滤条换行布局——`FlowLayout` 改为 `WrapLayout`（自定义换行布局），侧边栏收缩时按钮自动换行而非截断。

**体验优化 5**：筛选按钮图标化——文字标签改为图标（`AllIcons.Actions.Execute/Add/Refresh/GC` + `SelectAll`），配合 tooltip 提示按钮作用，节省侧边栏空间。

**已确认决策**：
- 列表铺满：列表放 `CENTER`，工具栏 + 过滤条包成竖向容器放 `NORTH`；
- 分割线：`JSeparator(HORIZONTAL)`，全宽，上下各 3px 留白；
- 竖向容器用 `BoxLayout(Y_AXIS)`，子组件 `alignmentX = LEFT_ALIGNMENT` 保持左对齐；
- 多行预览：`fixedCellHeight = -1` 启用可变行高，条目内 HTML `<br>` 分隔时间戳与 SQL，自然换行；
- 行间分隔：cell renderer 底部 `MatteBorder(0,0,1,0)` + `EmptyBorder(5,8,5,8)` 内边距；
- 筛选高亮：`JToggleButton` 选中时 `background = JBColor(0x4A88C7)` + `foreground = WHITE`，未选中时恢复默认；通过 `ChangeListener` 监听 `model.selected` 变化同步外观；
- 换行布局：新增 `WrapLayout`（extends `FlowLayout`，重写 `layoutContainer` + `preferredLayoutSize` 实现自动换行）；
- 仅改动 `SqlLogPanel.kt`：`init` 块 + 新增 `buildTopPanel()` + 改写 cell renderer + 新增 `WrapLayout` + 筛选按钮高亮逻辑 + import。

## 2. 现状分析

### 2.1 布局缺陷（SqlLogPanel.kt:173-178）

```kotlin
init {
    val logPanel = JPanel(BorderLayout())
    logPanel.add(buildToolbar(), BorderLayout.NORTH)   // ✅ 工具栏：首选高度
    logPanel.add(buildFilterBar(), BorderLayout.CENTER) // ⚠️ 过滤条：占中间剩余空间
    logPanel.add(buildListPane(), BorderLayout.SOUTH)   // ❌ 列表：首选高度贴底
```

BorderLayout：SOUTH 只拿首选高度贴底；CENTER 拿走全部剩余空间。列表在 SOUTH → 贴底；过滤条 FlowLayout 在 CENTER 只占首选高度 → 中间大片空白。工具栏与过滤条无分隔。

### 2.2 列表单行问题（SqlLogPanel.kt:405-443）

```kotlin
this.text = "<html>" + timestamp + "<br>" + sql + "<br></html>"
```

HTML 虽含 `<br>`，但 JBList 默认 `fixedCellHeight` 为固定值（首项高度），所有行等高超 16-20px。`<br>` 的第二行被裁剪；条目间无 border、无 margin，相邻 SQL 紧贴，边界模糊。

### 2.3 既有测试影响

`SqlLogPanelFilterTest.kt` 通过内部访问器断言（`visibleEntryCount`/`visibleEntries`/`currentFilter` 等），不依赖布局结构，布局 + 渲染改动不影响既有测试。

## 3. 技术方案

```
├── NORTH → topPanel (BoxLayout Y_AXIS)          ← 新增

│   └── filterBar (FlowLayout, LEFT_ALIGNMENT)
```

#### 3.3.2 新增 buildTopPanel()

```kotlin
private fun buildTopPanel(): JPanel {
    val panel = JPanel()
    panel.layout = BoxLayout(panel, BoxLayout.Y_AXIS)
    panel.alignmentX = Component.LEFT_ALIGNMENT
    val toolbar = buildToolbar().apply { alignmentX = Component.LEFT_ALIGNMENT }
    val separator = JSeparator(SwingConstants.HORIZONTAL).apply {
        alignmentX = Component.LEFT_ALIGNMENT
        border = JBUI.Borders.empty(3, 4)
        maximumSize = Dimension(Int.MAX_VALUE, preferredSize.height)
    }
    val filterBar = buildFilterBar().apply { alignmentX = Component.LEFT_ALIGNMENT }
    panel.add(toolbar)
    panel.add(separator)
    panel.add(filterBar)
    return panel
}
```

#### 3.3.3 cell renderer 改写 + fixedCellHeight

```kotlin
// buildListPane() 内：
list.fixedCellHeight = -1  // 启用可变行高（多行 SQL 自动撑高）

list.cellRenderer = object : DefaultListCellRenderer() {
    override fun getListCellRendererComponent(
        list: javax.swing.JList<*>?,
        value: Any?, index: Int, isSelected: Boolean, cellHasFocus: Boolean,
    ): Component {
        super.getListCellRendererComponent(list, value, index, isSelected, cellHasFocus)
        val entry = value as? LogSqlEntry
        text = null
        if (entry != null) {
            val timestamp = timestampHtml(entry.timestamp)
            val sql = SqlListHtmlRenderer.render(withTerminator(entry.summary))
            // 折叠态 badge 分支保留，同样多行化
            val foldedGroup = findFoldedGroup(entry)
            if (foldedGroup != null) {
                val badge = MpSqlVisualizerBundle.message("log.fold.badge", foldedGroup.count)
                val tooltip = MpSqlVisualizerBundle.message("log.fold.tooltip.folded", foldedGroup.count)
                this.text = "<html>" + timestamp + "<br>" + sql +
                    "&nbsp;<span style='color:#888888;background:#E8E8E8;'>$badge</span></html>"
                toolTipText = tooltip + "\n" + entry.restoredSql
            } else {
                this.text = "<html>" + timestamp + "<br>" + sql + "</html>"
                toolTipText = entry.restoredSql
            }
        }
        // 行底分隔线 + 四周内边距（最后一行也有底边，滚动时视觉分隔清晰）
        border = BorderFactory.createCompoundBorder(
            BorderFactory.createMatteBorder(0, 0, 1, 0, JBColor.border()),
            BorderFactory.createEmptyBorder(5, 8, 5, 8),
        )
        return this
    }
}
```

#### 3.3.4 WrapLayout（过滤条自动换行）

```kotlin
/** WrapLayout：FlowLayout 的换行变体——空间不足时组件自动折到下一行。 */
private class WrapLayout(align: Int, hgap: Int, vgap: Int) : FlowLayout(align, hgap, vgap) {
    constructor() : this(LEFT, 4, 2)

    override fun preferredLayoutSize(target: Container): Dimension = layoutSize(target, preferred = true)
    override fun minimumLayoutSize(target: Container): Dimension = layoutSize(target, preferred = false)

    private fun layoutSize(target: Container, preferred: Boolean): Dimension {
        synchronized(target.treeLock) {
            val maxWidth = target.parent?.width?.takeIf { it > 0 } ?: Int.MAX_VALUE
            var x = 0; var y = 0; var rowHeight = 0; var maxRowWidth = 0
            for (i in 0 until target.componentCount) {
                val m = target.getComponent(i)
                if (!m.isVisible) continue
                val d = (if (preferred) m.preferredSize else m.minimumSize)
                if (x + d.width > maxWidth && x > 0) {
                    maxRowWidth = maxOf(maxRowWidth, x - hgap); x = 0
                    y += rowHeight + vgap; rowHeight = 0
                }
                x += d.width + hgap; rowHeight = maxOf(rowHeight, d.height)
            }
            maxRowWidth = maxOf(maxRowWidth, x - hgap)
            return Dimension(maxRowWidth, y + rowHeight)
        }
    }

    override fun layoutContainer(target: Container) {
        synchronized(target.treeLock) {
            val maxWidth = target.width
            var x = insets.left; var y = insets.top; var rowHeight = 0
            for (i in 0 until target.componentCount) {
                val m = target.getComponent(i)
                if (!m.isVisible) continue
                val d = m.preferredSize
                if (x + d.width > maxWidth && x > insets.left) {
                    x = insets.left; y += rowHeight + vgap; rowHeight = 0
                }
                m.setBounds(x, y, d.width, d.height)
                x += d.width + hgap; rowHeight = maxOf(rowHeight, d.height)
            }
        }
    }
}
```

#### 3.3.5 筛选按钮高亮

为每个 `JToggleButton` 添加 `ChangeListener`，选中时设置蓝色背景 + 白色文字，未选中时恢复默认：

```kotlin
private fun styleToggleButton(button: JToggleButton) {
    button.model.addChangeListener { updateToggleAppearance(button) }
    updateToggleAppearance(button)
}

private fun updateToggleAppearance(button: JToggleButton) {
    if (button.isSelected) {
        button.background = JBColor.namedColor("ToggleButton.selectedBackground", Color(0x4A88C7))
        button.foreground = JBColor.namedColor("ToggleButton.selectedForeground", Color.WHITE)
    } else {
        button.background = JBColor.namedColor("ToggleButton.background", Color(0xF2F2F2))
        button.foreground = JBColor.namedColor("ToggleButton.foreground", Color(0x3C3F41))
    }
}
```

在 `buildFilterBar()` 中，为 `allButton` 和每个 `typeButton` 调用 `styleToggleButton()`。

## 6. 风险与回退

| 风险 | 影响 | 缓解 |
|------|------|------|
| BoxLayout 子组件对齐偏移 | 工具栏/过滤条可能居中 | 显式设 `alignmentX = LEFT_ALIGNMENT` |
| 分割线被拉伸 | 竖向高度异常 | `maximumSize` 限制 |
| fixedCellHeight=-1 性能 | 大量条目（数百+）时测量慢 | SQL 日志场景条目数通常 < 200，可接受；summary 限 160 字符控制单行长度 |
| WrapLayout 换行时机 | 容器宽度测量可能有 1-2px 误差 | 预留合理间隙，按钮间距 4px |
| JToggleButton 背景色不生效 | IntelliJ LaF 可能覆盖 background | 同时设置 `isContentAreaFilled = true` + `isOpaque = true` |
| 既有测试失败 | 回归 | 既有测试不依赖布局，预期全绿 |

**回退**：纯布局+渲染+样式、零逻辑，回退只需恢复相关代码块，无数据/状态风险。
