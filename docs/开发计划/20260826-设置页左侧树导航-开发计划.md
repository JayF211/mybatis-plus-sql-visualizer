# 设置页左侧树导航开发计划

> **状态**：待评审
> **日期**：2026-08-26
> **目标**：将当前单页滚动设置页改为 IDEA 原生风格的左侧树导航 + 右侧分页内容

---

## 一、现状与目标

### 当前结构
```
Settings → Tools → MyBatis-Plus SQL Visualizer
└── 单页滚动（5 个可折叠面板 + ~44 行配置项 + 搜索框）
    ├── SQL 预览 + 代码生成
    ├── 表名映射
    ├── SQL 日志（3 Tab）
    ├── 界面与操作
    └── 关于
```

### 目标结构（IDEA 原生风格）
```
Settings → Tools → MyBatis-Plus SQL Visualizer
└── 左侧树导航
    ├── SQL 预览        → 右侧页面
    ├── 表名映射        → 右侧页面
    ├── SQL 日志        → 右侧页面
    ├── 界面与操作      → 右侧页面
    └── 关于            → 右侧页面
```

点击左侧树节点，右侧只显示对应分区的配置项，无需滚动。

## 二、技术方案

### 2.1 IntelliJ Platform 机制

IDEA 设置树通过 `applicationConfigurable` 的 `parentId` 自动构建：
- 父 `Configurable` 注册为文件夹节点（不显示页面内容）
- 子 `Configurable` 注册 `parentId` 指向父 ID → 点击时显示子页面

当前已有：
```xml
<applicationConfigurable parentId="tools"
                         id="cn.song.plus.visualizer.settings"
                         instance="PluginSettingsConfigurable"/>
```

改为：
```xml
<!-- 父节点（文件夹，不显示页面） -->
<applicationConfigurable parentId="tools"
                         id="cn.song.plus.visualizer.settings"
                         instance="PluginSettingsFolderConfigurable"/>

<!-- 子节点（各自显示页面） -->
<applicationConfigurable parentId="cn.song.plus.visualizer.settings"
                         id="cn.song.plus.visualizer.settings.preview"
                         instance="SqlPreviewConfigurable"/>

<applicationConfigurable parentId="cn.song.plus.visualizer.settings"
                         id="cn.song.plus.visualizer.settings.tableMapping"
                         instance="TableMappingConfigurable"/>

<applicationConfigurable parentId="cn.song.plus.visualizer.settings"
                         id="cn.song.plus.visualizer.settings.sqlLog"
                         instance="SqlLogConfigurable"/>

<applicationConfigurable parentId="cn.song.plus.visualizer.settings"
                         id="cn.song.plus.visualizer.settings.ui"
                         instance="UiActionsConfigurable"/>

<applicationConfigurable parentId="cn.song.plus.visualizer.settings"
                         id="cn.song.plus.visualizer.settings.about"
                         instance="AboutConfigurable"/>
```

### 2.2 PluginSettingsPanel 改造

当前 `PluginSettingsPanel` 包含所有分区的控件和逻辑。改为支持「分区模式」：

```kotlin
class PluginSettingsPanel(
    private val settings: PluginSettings,
    private val sections: Set<String> = SECTION_ALL,  // 新增：只显示指定分区
)
```

新增常量：
```kotlin
companion object {
    const val SECTION_PREVIEW = "preview"
    const val SECTION_TABLE_MAPPING = "tableMapping"
    const val SECTION_SQL_LOG = "sqlLog"
    const val SECTION_UI = "ui"
    const val SECTION_ABOUT = "about"
    val SECTION_ALL = setOf(SECTION_PREVIEW, SECTION_TABLE_MAPPING, SECTION_SQL_LOG, SECTION_UI, SECTION_ABOUT)
}
```

`buildSections` 方法根据 `sections` 参数只构建启用的分区：
```kotlin
private fun buildSections(panel: JPanel) {
    // 搜索框仅在「全部」模式下显示（分区模式下不需要）
    if (sections == SECTION_ALL) { addSearchBox(panel) }

    if (SECTION_PREVIEW in sections) { buildPreviewSection(panel) }
    if (SECTION_TABLE_MAPPING in sections) { buildTableMappingSection(panel) }
    if (SECTION_SQL_LOG in sections) { buildSqlLogSection(panel) }
    if (SECTION_UI in sections) { buildUiSection(panel) }
    if (SECTION_ABOUT in sections) { buildAboutSection(panel) }
}
```

`isModified()` / `apply()` / `reset()` 中仅检查启用的分区对应字段。

### 2.3 子 Configurable 类设计

每个子 Configurable 创建一个只包含对应分区的 `PluginSettingsPanel`：

```kotlin
class SqlPreviewConfigurable : Configurable {
    private lateinit var panel: PluginSettingsPanel

    override fun getDisplayName() = MpSqlVisualizerBundle.message("settings.section.preview")
    override fun createComponent(): JComponent {
        panel = PluginSettingsPanel(PluginSettings.getInstance(), setOf(PluginSettingsPanel.SECTION_PREVIEW))
        return panel.getRoot()
    }
    override fun isModified() = panel.isModified()
    override fun apply() { if (panel.apply()) panel.rebuild() }
    override fun reset() = panel.reset()
}
```

其他 4 个同理，只是 `setOf(...)` 中的 section ID 不同。

### 2.4 父 Configurable（文件夹节点）

父节点只作为文件夹，不显示内容：

```kotlin
class PluginSettingsFolderConfigurable : Configurable {
    override fun getDisplayName() = MpSqlVisualizerBundle.message("plugin.name")
    override fun createComponent(): JComponent = JPanel() // 空页面
    override fun isModified() = false
    override fun apply() {}
    override fun reset() {}
}
```

## 三、实施步骤

### Phase 1：PluginSettingsPanel 支持分区模式

1. 新增 `sections` 构造参数（默认 `SECTION_ALL` 兼容现有调用）
2. 新增 section ID 常量
3. `buildSections` 拆分为 5 个独立 `buildXxxSection` 方法
4. `isModified()` / `apply()` / `reset()` 中按分区过滤字段
5. 搜索框仅在 `SECTION_ALL` 模式显示
6. 折叠面板代码保留但仅在 `SECTION_ALL` 模式生效

**验证**：现有功能不受影响（默认 `SECTION_ALL`），测试通过。

### Phase 2：创建子 Configurable 类

1. `SqlPreviewConfigurable` — `setOf(SECTION_PREVIEW)`
2. `TableMappingConfigurable` — `setOf(SECTION_TABLE_MAPPING)`
3. `SqlLogConfigurable` — `setOf(SECTION_SQL_LOG)`
4. `UiActionsConfigurable` — `setOf(SECTION_UI)`
5. `AboutConfigurable` — `setOf(SECTION_ABOUT)`
6. `PluginSettingsFolderConfigurable` — 文件夹节点（空页面）

**验证**：每个子页面只显示对应分区。

### Phase 3：plugin.xml 注册 + 清理

1. 修改 `PluginSettingsConfigurable` 注册 → `PluginSettingsFolderConfigurable`
2. 注册 5 个子 `applicationConfigurable`，`parentId="cn.song.plus.visualizer.settings"`
3. 搜索框只在 `SECTION_ALL` 显示（分区模式下无搜索框）

**验证**：IDE 设置树显示左侧导航，点击子节点切换右侧页面。

## 四、风险评估

| 风险 | 影响 | 缓解 |
|------|------|------|
| `isModified()` 字段过滤遗漏 | Apply 按钮不启用 | 逐一核对每个分区的字段 |
| 父文件夹节点显示空页面 | 用户困惑 | 父 Configurable 返回空 JPanel |
| 快捷键录制（ShortcutEditor）跨页面共享状态 | 修改不生效 | ShortcutEditor 写入 Keymap 是即时生效，不受影响 |
| `languageCombo` 语言切换在子页面触发 `rebuild()` | 仅重建当前页面 | 语言切换后需重新打开设置才能看到新语言 |
| 折叠状态持久化 `collapsedGroups` 仍全局生效 | 分区模式下无折叠面板 | 分区模式下不创建折叠面板，自然不涉及 |
