# SQL 转 Java 工具窗口 Tab 开发计划（T-M36.4）

- 日期：2026-08-15
- 状态：**立项（需求收集完成，排期待实施）**
- 前置：T-M36.3 已交付（d948f2b，946 全绿）；T-M31 日志工具窗口已交付（SqlLogPanel 双标签页范式）
- 背景来源：用户需求——在侧边栏 MyBatis SQL 日志工具窗口（T-M31 交付）新加一个 tab：粘贴 SQL → 格式化 → 转换 → 展示 Java 代码（含基础代码补全与 Java 语法高亮）

## 1. 需求分析（用户视角）

在现有侧边栏工具窗口（`cn.song.mybatisplus.visualizer.log`，右侧，当前含「SQL 日志 / SQL 预览」两个标签页）新增第三个标签页 **「SQL → Java」**：

1. **SQL 输入区**：粘贴 SQL 文本，可编辑；
2. **SQL 格式化**：输入区工具栏「格式化」按钮——粘贴的乱格式 SQL 一键整理（复用 `SqlFormatter`，幂等）；
3. **代码提示自动弹出**：输入区**打字即自动弹出 SQL 补全（无需快捷键）**，Ctrl+Space 手动触发仍可用——复用 T-M27.2 自建 autopopup 先例（平台 autopopup 对非项目文件编辑器不生效，实证空弹窗）；
4. **转换**：点击「转换」按钮 → 生成 MyBatis-Plus Java 代码（复用 T-M36 系列转换链路：`SqlReverseParser` + `EntityClassFinder` + `JavaCodeGenerator`，遵循设置页「默认 Wrapper 形态」配置）；
5. **Java 代码可编辑 + 语法高亮**：结果区**可编辑**（非只读）——用户可改实体类名/参数/方法名后复制；Java 关键字/字符串/注释实时着色（`JavaSyntaxHighlighterFactory`，com.intellij.java 依赖已有）；
6. 结果可**复制**（一键复制到剪贴板，对齐现有弹窗复制交互）。

与现有 ConvertSqlToJavaAction（编辑器选中转换）的关系：**同一转换链路、不同入口**——Action 面向编辑器选中文本，Tab 面向工具窗口内粘贴文本。两者共享编排逻辑（见 §3）。

## 2. 技术方案

### 2.1 面板结构（复用 SqlLogPanel 范式）

```
JBTabbedPane（现有实例，第三 tab）
└──「SQL → Java」JPanel(BorderLayout)
    ├── 上部：SQL 输入区（可编辑 Editor，SqlPreviewLanguage 高亮 + **打字自动弹补全**）
    │     └── 行内 ActionToolbar：格式化 / 清空
    ├── 中部：转换按钮（醒目，BorderLayout.NORTH 之下）
    ├── 下部：Java 结果区（**可编辑** Editor，Java 高亮）
    │     └── 行内 ActionToolbar：复制代码 / 清空
    └── 底部：状态行（JLabel：错误红字 / 提示灰字，如「未找到实体，已回落字符串列名」）
```

### 2.2 关键复用点（全部有现成先例）

| 能力 | 复用来源 | 实现方式 |
|------|---------|---------|
| SQL 高亮 | SqlLogPanel.createPreviewEditor / SqlPreviewPanel.createEditor | `EditorFactory.createEditor` + `LexerEditorHighlighter(SqlSyntaxHighlighter())` |
| SQL 补全（打字自动弹） | SqlPreviewPanel（M16.2/M27.1/M27.2 实证） | `PsiFileFactory.createFileFromText("...mpsql", SqlPreviewLanguage, sql)` → PSI 文档 → Editor；**DataProvider 包装补 EDITOR**（2025.3 UiCompatibleDataProvider 坑，M27.1 已修）；**自建 autopopup**（M27.2：DocumentListener + commitDocument + explicit=true 调度，平台 autopopup 对非文件编辑器空弹窗；格式化 setText 期间 suppressAutoPopup 防误触发）；Editor+PSI 双载体 userData 挂 SqlCompletionContext |
| SQL 格式化 | SqlFormatter.format（纯函数） | 工具栏按钮 → 文本替换回输入区（suppressAutoPopup 包裹） |
| 转换链路 | T-M36 系列（SqlReverseParser/JavaCodeGenerator/EntityClassFinder） | 抽取共享编排（§3） |
| Java 高亮 + 可编辑 | 平台 JavaSyntaxHighlighterFactory（com.intellij.java 依赖已有） | 可编辑 Editor（不 setReadOnly）+ `LexerEditorHighlighter(JavaSyntaxHighlighterFactory.getSyntaxHighlighter(JavaLanguage.INSTANCE, project, null))`（词法级，无需 PSI 文件；编辑实时高亮） |
| 编辑器生命周期 | SqlLogPanel.dispose | Disposable + `EditorFactory.releaseEditor`（输入/结果两个 Editor） |
| 多实体候选 | ConvertSqlToJavaAction（T-M36.2） | 多候选弹 SqlSelectionDialog（工具窗口内可弹） |

### 2.3 转换流程（对齐 Action，后台 ReadAction）

```
点击转换
→ EDT 取输入区文本
→ 纯函数 parse（SqlReverseParser，EDT 安全；失败 → 底部红字错误 + 行号）
→ 后台 ReadAction：EntityClassFinder.find（跳过 QUERY 形态，T-M36.3）
→ EDT 分发：0 实体 → 回落 QueryWrapper；1 实体 → 生成（按设置 reverseWrapperFormat）；
  多候选 → SqlSelectionDialog 选择
→ 结果写入 Java 结果区（只读）+ 状态行提示（未映射列/降级 warning 汇总）
```

## 3. 共享编排抽取（重要设计）

当前 `ConvertSqlToJavaAction` 内联了「parse → finder → resolve → generate」编排，Tab 需要同一逻辑。抽取公共组件：

```
reverse/SqlToJavaConverter.kt（或 ConvertSqlToJavaService，project 级）
  fun convert(project, sqlText, onResult: (ConvertOutcome) -> Unit)
  ConvertOutcome = Success(code, warnings) | ParseError(message, line) | ...
```

Action 与 Tab 均调用它（Action 保留选择区交互，Tab 保留面板交互）；避免两处复制导致行为漂移（M29 教训：三套渲染路径审计）。

## 5. 边界与风险

- **补全上下文**：工具窗口无实体上下文（M27 面板补全的实体上下文来自 SQL 所在文件）——P0 补全为 SQL 关键字/语法级（SqlCompletionProvider 默认路径）；表/列候选属 P1；
- **自动弹补全的触发边界**：自建 autopopup 仅在**用户输入**时调度（DocumentListener 内 suppressAutoPopup=false 路径）；「格式化」「清空」「转换回填」等程序性 setText 全部 suppressAutoPopup 包裹（对齐 T-M27.2/27.4 实证，防误弹）；
- **结果区可编辑的边界**：单向编辑（改 Java 代码不回写 SQL）；结果区不挂 Java 补全（完整 Java PSI 解析成本高，P0 不做——语法高亮是词法级，编辑实时生效）；
- **慢操作守卫**：实体查找（PSI 索引）必须在后台 ReadAction（2025.3+ EDT 禁止），复用 previewAsync 模式；
- **Editor 泄漏**：两个 Editor 必须在面板 dispose 时 release（对齐 SqlLogPanel.dispose）；
- **内嵌编辑器补全失效**（2025.3+ UiCompatibleDataProvider）：照抄 SqlPreviewPanel 的 DataProvider 包装先例（pitfall-uicompatible-dataprovider）；
- **设置遵循**：转换形态跟随设置页 reverseWrapperFormat（T-M36.3），不做面板内独立开关（避免两套配置）。
