# SQL 日志筛选项精简 开发计划

- 日期：2026-08-27（二次修订：去重计数改为条目旁重复次数、耗时排序保留、新增 Ctrl+F 搜索、类型下拉改多选）
- 状态：待开发
- 关联：P-06（日志智能分组/高频折叠）、T-M31.5（去重勾选开关）

## 一、需求

SQL 日志 tab 筛选区精简为四个能力，全部收纳进工具栏一行：

1. **SQL类型多选下拉**：替代原「全部/查询/插入/更新/删除」按钮组（占两行），放在「移除重复的sql」旁边；支持多选。
2. **高频折叠删除**：按钮去掉，折叠功能整体下线。
3. **去重重复次数**：开启「移除重复的sql」后，被去重的 SQL 在**列表条目旁累加显示重复次数**（⨉N 徽章），不是在勾选框旁计数。
4. **Ctrl+F 搜索**：sql 列表支持快捷键唤起搜索框过滤，注意 mac（⌘F）与 win/linux（Ctrl+F）差异。

**耗时排序按钮保留**（仅检测到耗时信息时出现，不占常驻空间）。

### API 可用性核实（本地 jar 反编译，2024.1 ideaIC 缓存）

- `com.intellij.ui.SearchTextField`：存在于 `lib/app-client.jar`（源码已解包核对，含 `addDocumentListener`/`getText`/history popup）。与当前已在编译使用的 `com.intellij.openapi.ui.Messages`、`com.intellij.openapi.actionSystem.CommonShortcuts` 同 jar——**app-client.jar 在编译 classpath 上，可直接使用**。
- `CommonShortcuts.getFind()`：app-client.jar 已核实，返回平台自适应查找快捷键（win/linux = Ctrl+F，mac = ⌘F）——快捷键差异由平台 keymap 处理，无需手写 `SystemInfo.isMac` 分支。
- 平台**不存在**多选 ComboBox（`ComboBoxMultiSelection` 等类名 grep 无果）→ 类型多选须自建「按钮 + 可勾选弹窗」。

## 三、方案决策

| 决策点 | 结论 | 理由 |
|--------|------|------|
| 类型筛选形态 | 自建 `TypeFilterButton`：按钮显示当前选中摘要（如「SQL类型: 全部」/「查询, 更新」），点击弹 `JPopupMenu` 内嵌 4 个 `JCheckBoxMenuItem` + 「全选/全不选」 | 平台无多选 ComboBox；对齐用户既有偏好（可选参数面板全选/全不选）；底层沿用 `activeFilter` Set，管线零改动 |
| OTHER 归属 | 「全部」（4 类型全选）额外包含 OTHER；弹窗不单列 OTHER | 修正隐性过滤；OTHER 极低频 |
| 高频折叠 | 整体删除（按钮 + LogFrequencyGrouper + GroupedEntry + 死配置 + 相关测试） | 无入口即无功能；其「识别重复 SQL」价值由去重徽章承接 |
| 去重计数口径 | buffer 内 `Map<指纹, 次数>`：去重开启期间每丢弃一条，对应 SQL 的计数 +1；指纹 = `restoredSql` 全等（与 isDuplicate 匹配同源） | 徽章语义 = 「该 SQL 在窗口内被去掉过 N 次」；与去重判定完全一致，不引入第二套归一化规则 |
| 徽章渲染 | cellRenderer 纯文本尾部追加 ` ⨉N`（N≥1 才显示；取条目 restoredSql 查 map） | 复用 M46 纯文本渲染路径，无 HTML 开销 |
| 计数生命周期 | `clear()` 归零；去重关闭期间不累计也不清零（徽章保留既有值）；首次开启时归零 | 与用户对「移除重复的sql」开关的直觉一致：勾上从零数起 |
| 搜索框形态 | 默认隐藏的 `SearchTextField`（无 history popup），Ctrl+F/⌘F 唤起并聚焦，Esc 清空后自动收起；实时过滤（DocumentListener → refreshList） | 用户抱怨占位——按需显示最省空间；SearchTextField 自带空态提示/清除按钮，观感原生 |
| 搜索快捷键 | `CustomShortcutSet(CommonShortcuts.getFind())` 注册到列表组件；Esc 用 `KEY_ESCAPE` 注册收起动作 | 平台 keymap 自适应 mac/win；显式提及差异但代码不写平台分支 |
| 搜索匹配范围 | `restoredSql`（含参数值）+ `summary`，忽略大小写 contains | 参数值常是检索目标（如按订单号找 SQL） |
| 耗时排序 | 保留，挪到工具栏行（勾选框之后） | 用户确认需要；原逻辑不动 |
| 设置页「显示类型筛选条」 | 删除（状态字段 + 面板行 + bundle 键）；三个死配置字段一并删 | 下拉/搜索常驻按需显示，无需开关；清理无 UI 配置 |

## 四、改动清单

### 4.1 SqlLogEntryBuffer.kt — 去重重复次数

```kotlin
/** 去重丢弃计数（指纹 = restoredSql 原文；仅 dedupeEnabled 期间累计）。 */
private val dedupeCounts = java.util.concurrent.ConcurrentHashMap<String, Int>()
fun dedupeCount(sql: String): Int
fun resetDedupeCounts()          // clear() 内部调用；首次开启去重时由面板调用
```

- `addEntry()`：`dedupeEnabled && isDuplicate(entry)` 命中时 `dedupeCounts.merge(entry.restoredSql, 1, Int::plus)` 后再返回 false。
- `dedupeEnabled` 改为带副作用不可行（普通 `@Volatile var`）→ 面板在勾选监听里处理「从关到开 → `resetDedupeCounts()`」。
- `snapshot()` 不变；新增 `dedupeCountsSnapshot(): Map<String, Int>` 供面板渲染徽章。
- 计数变更不触发 `notifyChanged()`（丢弃本就不通知，维持现状；徽章在下一次列表刷新时自然出现）。

### 4.2 SqlLogPanel.kt — 主要改造

**删除**：

- `typeButtons`/`allButton`/`foldButton` 字段及测试访问器；`buildFilterBar()`/`updateFilterBar()`/`syncTypeButtonSelection()`/`syncAllButtonSelection()`；`WrapLayout` 内部类。
- `filterBarPanel`/`filterSeparator`/`refreshFilterBarVisibility()` 及 init 中三处调用（`SettingsChangeListener` 保留 `updateHistoryTabVisibility()`）。
- 折叠链路：`frequencyFoldEnabled`/`groupedEntries`/`findFoldedGroup`/`applyFrequencyFold`/`rebuildListModel` 折叠分支/cellRenderer 折叠徽章/`mouseClicked` 单击展开分支/`isFoldEnabled`/`currentGroupedEntries`。
- `labelForType` 移入新组件。

**新增**：

1. `TypeFilterButton`（内部类或独立文件）：`JButton` + 下拉箭头图标（`AllIcons.General.ArrowDown`），文案动态 = 「SQL类型: 全部」/「SQL类型: 查询, 更新」；点击弹 `JPopupMenu`：
   - 4 个 `JCheckBoxMenuItem`（查询/插入/更新/删除，选中态绑 `activeFilter`）；
   - 分隔线 + 「全选」「全不选」两项（`activeFilter` 全 4 类型时「全部」语义，含 OTHER 透传）；
   - 任一勾选变化 → 更新按钮文案 + `refreshList()`。
2. 搜索条：`SearchTextField(false)`（禁 history popup），置于 `JBPanel` 薄条（工具栏行与列表之间），默认 `visible=false`；
   - 注册 `CustomShortcutSet(CommonShortcuts.getFind())` 到 `list`（`registerCustomShortcutSet`，面板 dispose 自动注销）；
   - 唤起动作：显示搜索条 + `requestFocus`；
   - `addDocumentListener` → `searchText = text` + `refreshList()`；
   - Esc（`KEY_ESCAPE` 注册到搜索条）：文本非空先清空；已空则隐藏搜索条 + 清过滤 + 焦点还给列表。
3. `refreshList()` 管线改为：类型过滤（`activeFilter` Set，语义不变；全部时含 OTHER）→ 搜索过滤 → 排序 → 直接 `listModel.addAll`（无分组）。
4. 去重徽章：cellRenderer 中 `dedupeCountsSnapshot()[entry.restoredSql]?.takeIf { it > 0 }?.let { " ⨉$it " } ?: ""`；`dedupeCheckBox` 监听中开启时调 `resetDedupeCounts()`。
5. 工具栏行最终布局（FlowLayout.LEFT 一行）：`ActionToolbar(捕捉/清空/设置/帮助)` + `dedupeCheckBox` + `TypeFilterButton` + `sortButton`（耗时排序，原 toggle 逻辑不变）+ 慢查询计数 label。
6. 测试访问器：新增 `searchField`/`typeFilterButton`；删除折叠相关。

## 七、风险与回滚

- 老用户 `mp-sql-visualizer.xml` 中被删字段的残留键被 PersistentState 忽略，天然兼容。
- 折叠功能为删除性变更，发行说明标注「功能移除」；回滚 revert 提交。
- 多选交互收窄反面：原按钮组可一眼看到各类型计数，新方案不保留类型计数（占位主因）；如有反馈可后续在按钮 tooltip 补计数。
- `SearchTextField` 虽已核实 classpath，但 262 沙盒若出现非预期行为（history popup 被裁剪等），降级方案 = `JBTextField` + 自绘空态提示，接口保持 `getText/addDocumentListener` 不变。
