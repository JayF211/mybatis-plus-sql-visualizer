## 0. 目标

支持插件设置的导入/导出（团队统一配置分发），以及按项目覆盖全局设置（如不同项目用不同方言）。

**用户价值**：团队统一配置标准，新项目快速应用已有配置。

---

## 1. 功能设计

### 1.1 设置导入/导出

**方案**：
- 设置页底部新增「导入」/「导出」按钮
- 导出：将当前 `PluginSettings` 序列化为 JSON 文件
- 导入：从 JSON 文件读取并覆盖当前设置
- 格式：JSON（人类可读，便于版本控制）

```json
{
  "version": 1,
  "dialect": "MySQL",
  "replaceParams": true,
  "formatOutput": true,
  "injectLogicDelete": true,
  "logicDeleteValue": "0",
  "tablePrefix": "",
  "tableSuffix": "",
  "ignoreFields": "",
  "tableNamingStrategy": "SNAKE"
}
```

### 1.2 按项目覆盖全局设置

**方案**：
- 新增 `ProjectPluginSettings`（`@Service(Service.Level.PROJECT)` + `PersistentStateComponent`）
- 设置页新增「使用项目设置」开关
- 开启后，项目级设置覆盖全局设置
- 项目设置存储在 `.idea/mp-sql-visualizer-project.xml`

**可覆盖项**：
- 数据库方言
- 替换参数开关
- 逻辑删除注入
- 表前缀/后缀
- 忽略字段名

**不可覆盖项**（全局统一）：
- 界面语言
- 快捷键
- 更新通道

### 1.3 设置页 UI 调整

```
┌─ SQL 预览 ─────────────────────────────┐
│ 数据库方言: [MySQL ▼]                   │
│ 替换 ? 占位符: [✓]                      │
│ ...                                     │
├─────────────────────────────────────────┤
│ [使用项目设置] ← 新增开关               │
│   ↳ 项目方言: [PostgreSQL ▼]  ← 展开    │
├─────────────────────────────────────────┤
│ [导入] [导出]  ← 新增按钮               │
└─────────────────────────────────────────┘
```

## 6. 边界与降级

- 导入文件格式错误：toast 提示「配置文件格式错误」
- 导入版本不兼容：提示「配置文件版本不匹配，已忽略不兼容字段」
- 项目设置文件损坏：降级到全局设置
- 多模块项目：项目设置对同一 Project 下所有模块生效
