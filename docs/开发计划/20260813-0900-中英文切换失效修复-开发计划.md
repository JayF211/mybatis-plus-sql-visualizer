# 设置中英文切换失效——问题分析与修复计划（M16.1）

> 本文档是 **MyBatis-Plus SQL Visualizer** 的 M16.1 增量计划：修复用户报告的**设置中英文切换失效**——「切换为英文后设置页即时变英文（说明切换链路生效），但点击确定后再次打开设置仍是中文，且弹窗等其他界面也保持中文」。
>
> 当前基线：v1.10（M16 已提交，237 测试全绿）。

---

## 1. 问题复现与证据（2026-08-13）

**用户症状**：
1. 设置页语言下拉切换为 English → 设置页文案变英文（**切换链路生效**）；
2. 点击「确定」→ 再次打开设置 → **仍是中文**；
3. 弹窗等其他界面 → **仍中文**。

**测试实证（fixture 环境，全部通过）**：

| 验证项 | 结果 | 结论 |
|--------|:----:|------|
| `getState → loadState` 往返保留 `language="en"`（模拟 IDE 保存/重启加载） | ✅ | 持久化契约本身无 bug |
| Configurable `apply()` 写回 state → 新 panel `reset()` 读取 en（表单与 state 一致） | ✅ | 设置页读写链路无 bug |
| bundle `currentLocale()` 切换即时生效（M14.7 已修复的回归用例） | ✅ | 文案读取链无 bug |

> **结论**：代码逻辑链路在测试环境全部正常——问题**不在业务代码**，而在**真实 IDE 的 service 注册/持久化机制**。

**根因定位（高置信）**：**`PluginSettings` 双重注册**——

```xml
<!-- plugin.xml:56（模板遗留） -->
<applicationService serviceImplementation="cn.song.mybatisplus.visualizer.config.PluginSettings"/>
```

```kotlin
// PluginSettings.kt:15-16（M14.7 加入注解式注册，但未移除 XML 注册）
@State(name = "MpSqlVisualizerSettings", storages = [Storage("mp-sql-visualizer.xml")])
@Service(Service.Level.APP)
class PluginSettings : PersistentStateComponent<...>
```

**IntelliJ Platform 官方规则**：使用 `@Service` 注解注册的服务**不应再在 plugin.xml 注册**（注解式注册是唯一推荐方式）。双注册的后果（社区已知问题）：
- `getService()` 与持久化机制可能绑定**不同的实例**——`apply()` 写入实例 A 的 state（内存 en，设置页即时变英文 ✓），而 IDE 的 `PersistentStateComponent` 保存/加载绑定实例 B（旧 state zh）→ **重启/重开读回 zh**；
- 或 IDE 检测重复注册产生未定义行为（日志可见 "duplicate registration"）。

**辅助因素**：应用级配置的持久化时机——点击「确定」**不会立即写盘**（IDE 定期/退出时保存）；叠加双注册的保存错实例，用户感知为"保存不生效"。

**附带问题（并行改动引入）**：`applicationConfigurable` 的 `key="configurable.settings.displayName"`（M16 提交中的并行改动）由 **IDE 默认 locale** 解析 displayName——**不跟随插件语言切换**（设置页标题 Tools 下的显示名固定中文/英文取决于 IDE 语言），与插件内文案切换不一致。

---

## 2. 方案设计

### 2.1 移除双注册（T-M16.1-01）

- 删除 `plugin.xml` 的 `<applicationService serviceImplementation="cn.song.mybatisplus.visualizer.config.PluginSettings"/>`——保留 `@Service(Service.Level.APP)` 注解，IDE 自动发现（M14.7 动态插件支持已确认注解式注册兼容）；
- 验证：`PluginSettings.getInstance()`（`ApplicationManager.getApplication().getService(...)`）在真实 IDE 中正常返回单例；构建自检测试断言 plugin.xml 无重复注册。

### 2.2 持久化链路回归测试（T-M16.1-02）

- 保留并完善 `PluginSettingsPersistenceTest`：`getState→loadState` 往返、Configurable apply/reset 链路、bundle 即时切换（已存在 3 个用例，M16.1 验收基线）；
- 新增构建自检：plugin.xml 中 `PluginSettings` 类仅出现一次（防双注册回归）。

### 2.3 设置页标题跟随语言（T-M16.1-03）

- `applicationConfigurable` 移除 `bundle`/`key` 属性（或保留但以 `getDisplayName()` 动态覆盖）——`PluginSettingsConfigurable.getDisplayName()` 改为返回 `MpSqlVisualizerBundle.message("plugin.name")`（走插件 currentLocale，切换即生效）；
- 验证：IDE 对 `applicationConfigurable` 同时声明 `key` 与覆写 `getDisplayName()` 时以代码为准（官方行为：displayName 由 getDisplayName() 优先）。

### 2.4 验收（T-M16.1-04）

- `./gradlew clean test` 全绿 + `buildPlugin`；
- 手动验收清单（真实 IDE）：切 en → 确定 → 重开设置（英文）→ 弹窗文案（英文）→ **重启 IDE** → 设置仍英文（持久化生效）。
