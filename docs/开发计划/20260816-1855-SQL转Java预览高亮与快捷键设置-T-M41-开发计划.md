## 2. 现状代码分析（已逐行核实）

### 2.1 弹窗无高亮（需求 1）

`ui/JavaCodePreviewDialog.kt`：`JTextArea(code)` + `isEditable=false` + MONOSPACED 13px（27-32 行）——纯文本，无词法着色、无行号。

参照实现（侧边栏面板）`log/SqlToJavaPanel.kt:896 createJavaEditor()`：

```kotlin
val editor = EditorFactory.getInstance().createEditor(EditorFactory.getInstance().createDocument(""), project)
(editor as EditorEx).apply {
    highlighter = LexerEditorHighlighter(
        JavaSyntaxHighlighterFactory.getSyntaxHighlighter(JavaLanguage.INSTANCE, project, null),
        EditorColorsManager.getInstance().globalScheme,
    )
    settings.isLineNumbersShown = true
    settings.isFoldingOutlineShown = true
    ...
}
```

差异点：面板编辑器**可编辑**（用户改完复制）；弹窗是**只读预览**（复制按钮），应设 `settings.isReadOnly = true`（保留行号/选中/复制，不引入编辑）。

### 2.2 快捷键无设置入口（需求 2）

- plugin.xml:186-187 已注册标准快捷键：`$default` → `alt shift J`、`Mac OS X` → `meta shift J`（标准注册，IDE Keymap 设置页理论上可改；用户指的实际是**插件设置页**无编辑行）。
- `config/PluginSettingsPanel.kt`：组 5「界面与操作」第 3 行（380 行）`settings.shortcut` → `shortcutEditor`，仅绑定 `ConvertToSqlAction.ACTION_ID`。
  - `currentShortcut()`（565 行）硬编码 ConvertToSql 的 actionId；
  - `applyShortcut()`（580 行）硬编码 `ConvertToSqlAction.ACTION_ID`；
  - `isModified()` 含 `shortcutEditor.shortcut != currentShortcut()`（689 行）；
  - `apply()` 末尾 `if (shortcutEditor.shortcut != currentShortcut()) applyShortcut()`（726 行）；
  - `reset()` 末尾 `shortcutEditor.shortcut = currentShortcut()`（767 行）。
- `ShortcutEditor`（442 行，内部类）：录制对话框 + 冲突检测 `conflictActionName`（与 actionId 无关，可复用）。组件本身无 actionId 依赖，可多实例化。

## 3. 方案设计

### 3.1 需求 1：JavaCodePreviewDialog 改 Editor + Java 高亮

`ui/JavaCodePreviewDialog.kt` 改造：

1. 字段 `textArea` → `editor: Editor`，创建方式仿 `SqlToJavaPanel.createJavaEditor`（`EditorFactory.createEditor` + `EditorEx.highlighter = LexerEditorHighlighter(JavaSyntaxHighlighterFactory...)`），差异：
   - `settings.isReadOnly = true`（只读预览，复制/选中不受影响）；
   - 行号开启、折叠开启（对齐面板观感）；`caretPosition = 0`。
2. `createCenterPanel()` 返回 `JScrollPane` 包 `editor.component`（尺寸常量沿用）。
3. **释放**：override `dispose()` → `EditorFactory.releaseEditor(editor)` + `super.dispose()`（DialogWrapper.dispose() 为 protected，Kotlin 覆写须显式 public——EntitySelectionDialog doOKAction 实证同款）。
4. 测试访问器 `textAreaForTest()` → `editorForTest(): Editor`（现有测试无引用，grep 已核实，可直接改）。
5. 复制逻辑不变（copyCode 读构造参数 `code`，不依赖组件）。

### 3.2 需求 2：设置页加「SQL→Java 快捷键」行

`config/PluginSettingsPanel.kt` 改造：

1. `ShortcutEditor` 增加构造参数 `private val actionId: String`（默认值给现有 `ConvertToSqlAction.ACTION_ID`，少改调用点）：
   - `currentShortcut()` → `currentShortcut(actionId: String)`（读该 action 在 activeKeymap 的第一个 KeyboardShortcut）；
   - `applyShortcut()` → `applyShortcut(editor: ShortcutEditor, actionId: String)`（清理旧绑定 → 冲突检测/强制抢占 → addShortcut，逻辑不变）。
2. 新增字段 `private val reverseShortcutEditor = ShortcutEditor(ConvertSqlToJavaAction.ACTION_ID)`。
3. 组 5「界面与操作」在现有快捷键行（380 行）下加一行：`addRow(p, g, MpSqlVisualizerBundle.message("settings.shortcut.sqlToJava"), reverseShortcutEditor.apply { updateTexts() })`。
4. 接线三处：
   - `isModified()`：`|| reverseShortcutEditor.shortcut != currentShortcut(ConvertSqlToJavaAction.ACTION_ID)`；
   - `apply()`：`if (reverseShortcutEditor.shortcut != currentShortcut(...)) applyShortcut(reverseShortcutEditor, ConvertSqlToJavaAction.ACTION_ID)`；
   - `reset()`：`reverseShortcutEditor.shortcut = currentShortcut(ConvertSqlToJavaAction.ACTION_ID)`。
5. bundle 新键（en/zh 两个文件）：`settings.shortcut.sqlToJava` = "SQL→Java Shortcut" / "SQL→Java 快捷键"；录制/冲突/提示文案复用现有 `settings.shortcut.*` 键。
6. 帮助弹窗文案（`help.content.shortcuts`）顺带补一句「可在插件设置页修改」（可选，低成本同步点）。
