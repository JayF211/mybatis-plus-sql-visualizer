# XML 动态 SQL 预览（M24）开发计划

> 状态：✅ 已交付（2026-08-14，610 测试全绿）
> 需求来源：用户新需求「支持 MyBatis XML 中的 SQL 预览，留意各种动态标签解析，完全兼容大部分常见情况」。

## 1. 目标与范围

在 XML mapper 文件的 `<select|insert|update|delete>` 语句上提供 SQL 预览（gutter 图标 + 右键菜单），
引擎**忠实复刻 MyBatis 3.5.19 的 XMLLanguageDriver 渲染算法**，动态标签全兼容：
if / choose(when/otherwise) / trim / where / set / foreach / bind / sql+include（同文件）。

**已确认决策**：
- 求值引擎：**自研受限 OGNL 子集**（递归下降）——覆盖常用表达式（判空/比较/逻辑/算术/成员方法/in/列表字面量）；
  无法解析的表达式 → 面板手动开关兜底。保持插件运行时零第三方依赖。
- **不含** `${ew.customSqlSegment}`（MP 特有，需 Java↔XML 跨文件关联）——引擎产出后作为 P-立项-03 复用基础，后续单独立项。

## 2. 架构与数据流

新增 `src/main/kotlin/cn/song/mybatisplus/visualizer/xml/`（纯逻辑，无 PSI 依赖，可独立单测）：

```
编辑器 XML PSI（XmlTag 定位语句文本范围）
 → XmlMapperParser（JDK DOM 解析，secure-processing 防 XXE）
     → XmlIncludeExpander（同文件 include 展开 + property 静态替换）
     → XmlScriptBuilder.parseDynamicTags → SqlNode 树
 → XmlSqlRenderer.render(node, bindings, conditionOverrides, protectedNames)
     → 第一遍 SqlNode.apply()：分支判定（开关优先）+ ${} 替换 + bindings 累积
     → 第二遍 #{} → ? + ParameterMapping 清单（含 foreach __frch_ 重写名）
 → XmlPreviewModel（renderSql 唯一渲染源 + 条件/foreach/bind 视图 + 变量收集）
 → PreviewResult.xmlModel → 复用 SqlPreviewDialog / SqlPreviewPanel（xmlModel 分支）
```

## 3. 引擎要点（对照 mybatis-3.5.19 源码逐条复刻）

| 模块 | 复刻要点 |
|------|----------|
| OgnlEvaluator | 判真规则（Boolean/Number≠0/其他非 null，**空串为真、0 为假**）；属性链/getX·isX getter 推断/方法白名单（size/length/isEmpty/contains/startsWith/endsWith/containsKey/toString，**白名单优先于 getter 推断**——`isEmpty()` 不被 is 前缀误捕）；`in`/`not in`/列表字面量/下标/转义字符串；解析失败 → Err（面板开关兜底） |
| DynamicContext | bindings 含 `_parameter`/`_databaseId`；appendSql 段间单空格（3.5.13+ StringJoiner 行为）；getUniqueNumber（foreach 用）；conditionOverrides（开关）/protectedBindNames（bind 覆盖）为预览引擎扩展 |
| TextSqlNode | isDynamic 只认 `${}`（`\${` 转义）；null 求值 → 空串（issue #274）；简单类型 `value` 便捷绑定；未解析变量（根变量不在 bindings）→ 错误记录 |
| TrimSqlNode | 内容整体 trim → 空则全不输出；override 用**大写副本**匹配、`\|` 分隔**只删第一个**、按 `toRemove.trim().length()` 删（**匹配空格保留** → `WHERE  id = ?` 双空格为真实行为）；prefix 插入 = `prefix + " " + 内容`；suffix 由 `endsWith \|\| endsWith(trim)` 双条件匹配 |
| WhereSqlNode/SetSqlNode | where = Trim("WHERE", [AND/OR + 空格/换行/回车/制表符 8 变体])；set = Trim("SET", [","]) |
| ForeachSqlNode | `__frch_<名>_<唯一编号>` 双写；`#{item.x}` 逐 token 重写（正则 `^\s*item(?![^.,:\s])`，itemName 不误伤）；Map → entrySet（index=键/item=值）；separator 由 PrefixedContext 惰性插入（首项无内容顺延）；空集合整段无输出（open/close 也不出）；null 非 nullable → 错误记录；嵌套同名 item 遮蔽；collection 表达式全文 mock 命中优先（预览适配） |
| VarDeclSqlNode | 执行期求值 + 绑定；覆盖名跳过（面板覆盖优先）；表达式解析失败 → 错误记录 + bind null |
| XmlScriptBuilder | 标签 → 节点映射；choose 内 when/otherwise 专门处理（多 otherwise 报错）；未知元素报错；CDATA 按纯文本 |
| XmlIncludeExpander | 同文件 refid；property 静态替换只作用于 `${}`（`#{}` 不替换）；嵌套 include 继承/覆盖；refid 动态 `${}`；**循环链检测**（同一 refid 在链上重复 → 截断移除 + 错误）；深度保护；跨命名空间 → 移除 + 错误提示 |
| XmlSqlRenderer | 第二遍 `#{}` → `?` + ParameterMapping（jdbcType 等属性提取）；`\#\{` 转义；无 `}` 原样保留 |

## 4. 模拟参数与默认展开策略（M24 版，文档化）

- **顶层变量**（bind/`${}` 表达式引用的根标识符 + `_parameter` 直接属性）统一占位字符串 `"1"`
  （非 null 非空，使 `x != null`、`x != ''`、`'%' + x + '%'` 等常见形态可求值）；
- **if/when 真假由面板开关直接决定**（启发式默认：含 `== null` → false，其余 true——保守展开），
  开关缺席 = false；表达式求值仅在无开关覆盖时发生（API 直接渲染路径）；
- **foreach 展开次数**由面板输入（默认 2，0 = 空集合 → 整段空输出），null 勾选 → 错误提示/nullable 跳过；
- **bind 覆盖值**优先于表达式求值；
- `#{}` 参数值由面板回填（foreach 的 `__frch_` 重写名不提供输入框，值空保留 `?`）。

## 5. UI 集成

- `PreviewResult.xmlModel`（batchModel 先例，与 previewModel/batchModel 互斥）；
- `SqlPreviewPanel`：renderSql 第四分支（xmlModel 优先）+ rebuildLeftPanel XML 控件区
  （条件开关复用 enabledIds/全选全不选；foreach 次数+null；bind 覆盖值；`#{}` 参数行过滤 `__frch_`）；
  渲染错误并入 metaLabel 红色警示；紧凑模式对 XML 渲染结果做空白归一化；
- `XmlSqlGutterLineMarkerProvider`（plugin.xml `lineMarkerProvider language="XML"`）：
  **leaf 锚点 = 标签名 XML_NAME token**（LineMarker 必须注册在 leaf 元素），O(1) 判定（token 类型 + 父级 `mapper` 守卫）；
- `ConvertToSqlAction` 放行 XmlFile：光标所在语句优先，否则文件首个语句（多语句候选选择留后续迭代）；
- 构建依赖：`bundledModule("intellij.xml.psi")`（IPGP DSL，`com.intellij.modules.xml` 是插件依赖标记而非模块 id）；
  plugin.xml `<depends>com.intellij.modules.xml</depends>`。

## 6. 边界与已知限制（文档明示）

- include 仅同文件（含 property 静态替换）；跨命名空间 refid → 移除 + 错误提示；
- 根节点非 `<mapper>` / 无语句元素 → 预览提示；非良构 XML / 未知标签 → warning 展示（不抛异常）；
- MP 占位 `${ew.customSqlSegment}` 按普通 `${}` 求值（无模拟值 → 空串 + 「未解析变量」提示）——P-立项-03 后续立项；
- 注解 `@Select` 的 `<script>` 不支持（引擎解析路径通用，入口后续）；
- XML 预览不做方言化（SQL 为原生文本）；foreach `nullable` 属性（3.5.9+）支持。
