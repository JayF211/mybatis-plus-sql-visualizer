## 需求描述

「复制为 MD 表格」功能生成的 Markdown 表格无法正常渲染。根本原因是多行 SQL 中的换行符 `\n` 直接嵌入表格单元格，破坏了 Markdown 表格结构。

### 当前错误输出

用户复制后得到：

```
| SQL | 参数 | 来源 |
| --- | --- | --- |
| `SELECT
    t.id,
    ...
    AND t.tel LIKE '%1%'` | - | 表：user 方言：MySQL 2026-08-26 09:46 |
```

表格行被 SQL 中的换行符截断，Markdown 渲染器无法识别为合法表格。

### 期望输出

SQL 中的换行应替换为 `<br>`，使表格行保持单行：

```
| SQL | 参数 | 来源 |
| --- | --- | --- |
| `SELECT<br>    t.id,<br>    ...<br>    AND t.tel LIKE '%1%'` | - | 表：user 方言：MySQL 2026-08-26 09:46 |
```

## 根因分析

**文件**：`src/main/kotlin/cn/song/mybatisplus/visualizer/share/format/MarkdownFormatter.kt`
**方法**：`formatAsTable()`（第 85-111 行）
**问题行**：第 106 行

```kotlin
sb.append("| `").append(sql.trim().replace("`", "\\`")).append("` | ")
```

### 三个缺陷

| # | 问题 | 影响 | 严重度 |
|---|------|------|--------|
| 1 | SQL 中的 `\n` 未处理，直接嵌入表格单元格 | 表格行被截断，渲染失败 | **P0** |
| 2 | SQL 中的 `\|` 管道符未转义 | 若 SQL 含 `|`（如 `WHERE a \| b`），列对齐错位 | P1 |
| 3 | params 中的 `\|` 管道符未转义 | 同上 | P1 |

> 注：`meta` 字段在第 108 行已有 `.replace("|", "\\|")` 转义，但 SQL 和 params 字段遗漏。

## 修复方案

### 修改文件

`src/main/kotlin/cn/song/mybatisplus/visualizer/share/format/MarkdownFormatter.kt`

### 修改内容

在 `formatAsTable()` 方法中，对 SQL 和 params 做表格安全转义：

```kotlin
fun formatAsTable(...): String {
    val sb = StringBuilder(256)
    val params = if (sources.isNotEmpty()) {
        sources.joinToString(", ") { src ->
            val v = paramValues[src]
            if (v.isNullOrEmpty()) "$src=?" else "$src=$v"
        }
    } else {
        "-"
    }
    val meta = buildMeta(tableName, dialect, source).joinToString(" ")

    sb.append("| SQL | 参数 | 来源 |\n")
    sb.append("| --- | --- | --- |\n")
    sb.append("| `").append(escapeForMdTable(sql.trim())).append("` | ")
    sb.append(escapeForMdTable(params)).append(" | ")
    sb.append(escapeForMdTable(meta)).append(" |")

    return sb.toString()
}
```

新增私有方法：

```kotlin
/**
 * 转义 Markdown 表格单元格内容：
 * - 换行符 → <br>（保持可读性同时不破坏表格结构）
 * - ` → \`（避免提前关闭 code span）
 * - | → \|（避免被误认为列分隔符）
 */
private fun escapeForMdTable(text: String): String {
    return text
        .replace("\\", "\\\\")   // 反斜杠最先处理，避免重复转义
        .replace("`", "\\`")
        .replace("|", "\\|")
        .replace("\r\n", "<br>")
        .replace("\n", "<br>")
        .replace("\r", "<br>")
}
```

> **注意**：反斜杠优先转义是关键——否则后续替换产生的 `\` 会被再次转义。

### 新增测试用例

```kotlin
@Test
fun `formatAsTable_多行SQL_换行替换为br`() {
    val sql = "SELECT\n    t.id,\n    t.name\nFROM user"
    val md = MarkdownFormatter.formatAsTable(
        sql = sql,
        tableName = "user",
        dialect = "MySQL",
    )
    // 换行应替换为 <br>，不应保留原 \n
    assertTrue(md.contains("<br>"))
    assertTrue(!md.contains("\n    t.id"))  // 原始缩进换行不应存在
    // 表格行数：表头1 + 分隔符1 + 数据行1 = 3 行（不含末尾换行）
    val lines = md.split("\n")
    assertEquals(3, lines.size)
}

@Test
fun `formatAsTable_SQL含管道符_转义为竖线`() {
    val sql = "SELECT id FROM user WHERE a = 1 | b = 2"
    val md = MarkdownFormatter.formatAsTable(
        sql = sql,
        tableName = "user",
        dialect = "MySQL",
    )
    // | 应被转义为 \|
    assertTrue(md.contains("\\|"))
}

@Test
fun `formatAsTable_参数含管道符_转义为竖线`() {
    val sql = "SELECT id FROM user WHERE name = ?"
    val md = MarkdownFormatter.formatAsTable(
        sql = sql,
        sources = listOf("name"),
        paramValues = mapOf("name" to "a|b"),
        tableName = "user",
        dialect = "MySQL",
    )
    assertTrue(md.contains("a\\|b"))
}

@Test
fun `formatAsTable_多行SQL_表格结构完整`() {
    val sql = "SELECT\n    t.id,\n    t.name\nFROM `user` t\nWHERE t.id = 1"
    val md = MarkdownFormatter.formatAsTable(
        sql = sql,
        sources = emptyList(),
        paramValues = emptyMap(),
        tableName = "user",
        dialect = "MySQL",
        source = "UserService.java:42",
    )
    val lines = md.split("\n")
    // 3 行结构
    assertEquals(3, lines.size)
    // 每行都以 | 开头和结尾
    lines.forEach {
        assertTrue(it.trim().startsWith("|"))
        assertTrue(it.trim().endsWith("|"))
    }
    // 分隔符行
    assertTrue(lines[1].contains("---"))
}
```
