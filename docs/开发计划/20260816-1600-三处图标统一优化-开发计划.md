## 3. 目标设计：三处统一为「MP 蓝圆角底 + 白色 </> + 右下角白色放大镜」

统一视觉语言：`#1E9FFF` 圆角矩形底、白色 `</>`（完全对称）、右下角白色放大镜角标。16×16 与 40×40 同构（40 版 = 16 版 ×2.5 的等比例布局，y 中心分别 8 / 20）。

### 3.1 基准 16×16 布局（sqlLog.svg 与 sqlGutter.svg 同款）

```xml
<svg width="16" height="16" viewBox="0 0 16 16" fill="none" xmlns="http://www.w3.org/2000/svg">
  <!-- 底：MP 蓝圆角矩形 -->
  <rect x="0.5" y="0.5" width="15" height="15" rx="3.5" fill="#1E9FFF"/>
  <!-- <  左右尖关于 x=6.5 对称（尖 2.6 / 10.4，肩 4.8 / 8.2，距尖 2.2、距中心 1.7） -->
  <path d="M4.8 5.6 L2.6 8 L4.8 10.4" stroke="#FFFFFF" stroke-width="1.3" stroke-linecap="round" stroke-linejoin="round"/>
  <!-- /  中竖 x 5.5~7.5（中心 6.5 = 左右尖中点） -->
  <line x1="5.5" y1="10.6" x2="7.5" y2="5.4" stroke="#FFFFFF" stroke-width="1.3" stroke-linecap="round"/>
  <!-- >  与 < 完全镜像 -->
  <path d="M8.2 5.6 L10.4 8 L8.2 10.4" stroke="#FFFFFF" stroke-width="1.3" stroke-linecap="round" stroke-linejoin="round"/>
  <!-- 放大镜：右下角，与字符区不重叠（字符最低点 y=10.4 < 镜片上缘 9.8） -->
  <circle cx="12.1" cy="12.1" r="2.3" stroke="#FFFFFF" stroke-width="1.2"/>
  <line x1="13.7" y1="13.7" x2="14.6" y2="14.6" stroke="#FFFFFF" stroke-width="1.2" stroke-linecap="round"/>
</svg>
```

布局推导：字符区 x 2.6~10.4（中心 6.5），占 49%；放大镜圆心 (12.1,12.1) r2.3，占 34%——与 40×40 logo 的字符/放大镜占比（62%/37.5%）同数量级，16px 下互不重叠、整体居中。三笔完全对称（左右尖/左右肩均关于 x=6.5 镜像）。放大镜为简洁几何（圆 + 45° 柄），13px 工具窗口尺寸下仍可辨。

## 8. 边界与权衡

- **13px 可辨性**：16px 放大镜 r2.3 缩至 13px 约 r1.9——为简洁几何（圆 + 45° 柄），可辨但细节有限；若实测发糊，降级方案为放大镜贴角加大至 r2.6（与 `>` 轻微重叠，如旧 40 版「轻微重叠」观感），实施时在沙盒目检定夺；
- gutter 图标改为蓝底：IDEA gutter 区域蓝底方块为常见插件观感，可接受；如用户偏好透明底，仅去掉底 rect 保留白字（蓝底上的白字在任意编辑器底色下仍清晰）；
- `icons/candidates/` 历史稿目录保留不动（含旧 pluginIcon_dark.svg），不清理；
- 不涉及 Marketplace 重新发布（用户此前明确不发布市场；本任务为源码级优化，随下次发版生效）。

## 3.4 定稿设计（2026-08-16 用户多轮预览确认，最终坐标）

多轮迭代教训：① 放大镜圆环带宽覆盖 `>` 线距范围会使其完全消失（"不对称"假象）；② 字符间距 < 笔画圆帽半径和 → 三笔粘连；③ 字符区中心须与方块中心重合（16px x=8.0 / 40px x=20.0），否则整体偏置；④ "放大镜在代码图标的上方"指**层级（前景层）**而非位置——放大镜保持在右下角，玻璃盘+圆环+柄绘制在代码之上（盘半透明，代码线透过可见；16px 环与代码同色融合无断点，40px 仅尖端 ~1.6px 微叠）；⑤ dark 版为**备用**，置于 `icons/pluginIcon_dark.svg` 而非 META-INF——与 pluginIcon.svg 同目录会触发暗色主题自动切换，用户要求 logo 一直显示亮色版。
