### 1.3 关键设计

#### 编辑器创建

```kotlin
// 原生 SQL FileType 创建 PSI 文件
val sqlFileType = FileTypeManager.getInstance().getStdFileType("SQL")
val psi = PsiFileFactory.getInstance(project)
    .createFileFromText("preview.sql", sqlFileType, sql)
val doc = PsiDocumentManager.getInstance(project).getDocument(psi)
val editor = EditorFactory.getInstance().createEditor(doc, project)

// 手动关联原生高亮器（内存 PSI 文件不自动关联）
val sqlHighlighter = SyntaxHighlighterFactory
    .getSyntaxHighlighter(sqlFileType, project, null)
editor.highlighter = LexerEditorHighlighter(sqlHighlighter, colorsScheme)
```

#### 补全守卫（三级回退 + Document 映射）

```
SqlCompletionContributor.addCompletions():
  1. parameters.editor.getUserData(SqlCompletionContext.KEY)  ← 编辑器实例未变
  2. position.containingFile.getUserData(SqlCompletionContext.KEY)  ← PSI 未重建
  3. documentContexts[document]  ← PSI commitDocument 重建后兜底
     ↑ WeakHashMap<Document, SqlCompletionContext>

registerContext() 调用时机：
  - createEditor：首次创建编辑器时登记
  - refreshCompletionContext：每次新预览刷新上下文时同步更新
```

### 2.2 P5 根因深度分析

#### H6（createEditor 缺少 sqlFileType）— 主因

`EditorFactory.createEditor(doc, proj)` 的 2 参数版本不传入文件类型，编辑器默认 `PlainTextFileType`。
平台补全框架按 `editor.getFileType().language` 匹配贡献者——PlainText → 无 SQL 贡献者被调度。

对比 `SqlInputEditor`（正常工作）使用 4 参数版本：
```kotlin
EditorFactory.getInstance().createEditor(doc, project, sqlFileType, false)
```

`SqlPreviewPanel` 原版使用 2 参数版本：
```kotlin
EditorFactory.getInstance().createEditor(doc, proj)  // ← 缺少 sqlFileType
```

**修复**：`createEditor` 改为传入 `sqlFileType` 参数，与 `SqlInputEditor` 对齐。

#### H5（registerContext 从未调用）— 辅因

`SqlCompletionContributor.registerContext()` 定义了 `documentContexts` WeakHashMap 的写入方法，但 **从未被任何代码调用**。导致三级回退的 level 3（Document→Context 映射）始终为空映射——死路径。

**影响**：即使 H6 已修复（贡献者被调度），PSI commitDocument 重建后 userData 丢失时，level 3 兜底失效，表/列补全丢失。Editor userData 在正常编辑期间稳定（level 1），因此首次补全可工作，但 PSI rebuild 后可能降级。

**修复位置**：
- `createEditor`：首次创建编辑器时写入映射
- `refreshCompletionContext`：每次新预览刷新上下文时同步更新映射

#### 测试夹具局限说明

`BasePlatformTestCase` 未加载 IDEA SQL 插件 → `getStdFileType("SQL")` 回退 `PlainTextFileType`（language = TEXT）。`CompletionContributor.forLanguage(TEXT)` 不包含全局注册的贡献者，因此 `testCompletionContributorRegistered` 改为验证类可实例化。运行时行为需在 runIde 沙盒验证。
