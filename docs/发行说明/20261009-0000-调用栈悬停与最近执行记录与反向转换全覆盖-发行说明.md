# 🎉 SQL Visualizer v2026.10.9

> 发行说明留档：对应 Gitee 发行版 **v2026.10.9**（标签 `2026.10.9`），附件 `mybatis-plus-sql-visualizer-2026.10.9.zip`。
> 范围＝自 v2026.10.7 发行包之后的全部用户可见增量。

自 v2026.10.7 后的正式版。本版主题是 **调用栈悬停 UI + 最近执行记录弹框 + SQL → Java 反向转换全覆盖**：预览面板调用栈区域悬停弹出调试器风格弹层，结构化解析帧、帧数可配置、精确跳转源码；gutter 图标右键菜单「最近执行记录」由二级列表换代为浏览对话框，复用日志列表渲染器，支持多选批量复制与右侧面板可编辑；SQL → Java 反向转换支持 groupBy/having/UNION 等子句，Beta 转正；Map 响应形态支持与 VO 列别名驱动；返回类型自由输入与选类按钮；编辑器与 SQL 列表的 Ctrl+C 复制语义按界面统一；SQL 历史标签页改为常驻并修正自定义保存目录下的可见性；修一批真机反馈缺陷（单条错误上报点「提交」无反应、MP 链假 HQL 锚点重复图标与点击后弹框卡住）。

## ✨ 新增

**预览面板调用栈悬停调试器风格弹层（T-StackHoverUi）**
- 预览面板的调用栈区域悬停时弹出调试器风格弹层——结构化解析调用栈帧（`StackDigestFrames`），跳过尾部基础设施帧（Tomcat/线程池尾巴），锚定最深业务帧（Controller→Service 链）
- 帧数可配置：设置页「调用栈快照帧数」+ agent 侧双通道下发，默认 24 帧，范围 [12,64]
- 尾部穿透补 spring web/boot 前缀
- 验收阻塞修复：日志预览识别/字面量恢复分支丢调用栈快照

**最近执行记录弹框化（T-RecentExecDialog）**
- gutter 图标右键菜单「最近执行记录」由二级列表换代为浏览对话框——左侧列表直接复用 SQL 日志面板的条目渲染器（两行形态/类型色条/耗时与来源角标与日志页完全一致），右侧高亮编辑器展示参数还原后的可执行 SQL（后由 T-RecentEditable 由只读改为可编辑），选中切换/双击打开预览（预览后对话框保持在场，便于连续对比多条）
- 交互对齐「SQL 屏蔽规则管理」对话框（非模态/可拖拽/尺寸位置记忆）
- 空命中也弹对话框（状态行显示空态文案，原一闪而过的轻通知退役）
- 右侧编辑器恒为格式化 SQL（D91，取代 D88 的「切换原文」）：编辑器显示只剩格式化一种形态（与预览「格式化还原 SQL」同源 formatter，主子句各占一行），长 SQL 不再挤成软换行长条；「查看原文」切换已按用户要求移除；编辑器上方两枚按钮改为图标按钮（图标取「日志转 SQL」结果区同款：格式化 `ReformatCode`、复制 `Copy`，文案走悬停），格式化按钮=幂等重排（格式化降级原文后可手动重试），复制取当前显示文本（经平台复制通道进 IDE 复制历史）

**弹框右键菜单与编辑器按钮图标化（T-RecentExecMenu）**
- 与 SQL 日志页右键同源六件——复制时间戳（受「显示时间戳」开关门禁，关闭时置灰）、屏蔽此 SQL（规则入库后该行即刻从弹框移除，气泡附「管理屏蔽规则…」直达）、发送到 SQL → Java、发送到日志转 SQL（工具窗口未创建时状态行提示）、跳转到 Java、跳转到 Mapper XML（定位不到即隐藏）
- 不含删除（弹框是浏览视图，不越权改全局日志缓冲）、方法级聚焦（锚点本身就是那个方法）、按请求聚焦、复制 SQL（按钮已有）
- 跳转/屏蔽/复制/送页签一律走日志页同一套实现（新增 `LogEntryJumpOps` 共享跳转原语，顺带消除实时页与历史页既有的一份重复实现）

**「最近执行记录」弹框多选与批量复制（T-RecentMulti）**
- 与 SQL 日志页同一套语义——Ctrl / Shift 多选、Ctrl+C 批量复制（逐行拼接纯 SQL）、多选时右侧编辑器按行序拼接显示（所见即复制）、状态行显示「已选 N 条」；「打开预览」取最后交互行，右键「复制时间戳」在多选下批量复制；单选行为不变

**「最近执行记录」右侧面板可编辑（T-RecentEditable）**
- 与「SQL 日志单击弹出的预览浮窗」同效果——右侧 SQL 面板由只读改为可编辑，可临时改字段值再复制（复制按钮与 Ctrl+C 都取改动后的文本）；自动折叠跟随设置。行号保持开启、内容恒为格式化（沿用既定口径）

**SQL 历史标签页常驻（T-HistoryTabAlways）**
- 历史标签页由「条件页签」改为常驻：此前只有开启自动保存、或默认历史目录下已有 `.sql` 文件才挂载，且设置变更时会把已挂载的页签摘掉——未开启自动保存的干净项目里用户根本看不到历史入口；现构造期无条件挂载，空态沿用既有文案（提示在设置页开启自动保存）
- 顺带修一处既有缺陷：历史文件读端此前只认默认 `.idea` 目录，而写端认自定义「保存目录」——改过保存目录后写进去的历史文件在历史页里看不到；现目录解析上收单点、读写同源，且保存目录变更即触发重扫，不必手动刷新

**SQL → Java 反向转换全覆盖（T-SqlToJavaPromote）**
- `GROUP BY` 建模 `.groupBy(...)`；`HAVING` 建模 `.having("...")`（聚合表达式原样透传）；`SELECT DISTINCT` 建模 `.select("DISTINCT ...")`；`FOR UPDATE` 建模 `.last("FOR UPDATE")`（与 LIMIT 并存合并单 last）
- 聚合/函数列（`COUNT(*) AS cnt`、`MAX(price)` 等）收集原文回落 `.select("expr AS alias")`（此前整体放弃致往返语义丢失）
- `INSERT ... NULL` 值建模生成 Java `null`（此前报错）
- `UNION / UNION ALL` 子查询解析（SQL 层往返经渲染还原，Java 生成层因 MP core 无 union() 方法降级为原文注释提示）
- 条件值参数化——`DATE_FORMAT(...) = '2024'` 形态生成 `apply("... = {0}", "2024")`（值/表达式分离）
- 方言宽容：双引号标识符、`0x` 十六进制字面量、反斜杠字符串转义、`DATE / TIMESTAMP '...'` ANSI 类型字面量；算术表达式 / `<=>` 空安全比较 / `ILIKE` 等无法静态映射的形态一律降级 `apply()` 透传
- Beta 转正：工具窗页签「SQL → Java (Beta)」→「SQL → Java」；覆盖四语句型 + 分组/聚合/联合/方言宽容，全语料往返门禁（52 条 ROUND_TRIP + 13 条降级/结构断言）在册

**Map 响应形态支持与 VO 列别名驱动（T-MapResultVo）**
- 「返回类型」字段（原「返回 VO」）改为可编辑组合框——自由键入任意返回声明（`List<Map<String, Object>>` / `List<HashMap<...>>` / `List<Object>` / VO 类名），一个控件承载全部返回形态语义
- 生成器按声明派生调用族：含 Map → `selectJoinMaps(wrapper)`/分页 `selectJoinMapsPage(page, wrapper)`（JOIN，MPJ）/`selectMaps`·`listMaps`（单表）族；含 Object → `selectObjs`/`listObjs` 族（单表；JOIN 场景无 `selectJoinObjs` 报错指路）；类名 → VO 语义（`selectJoinList(Vo.class, wrapper)` + `selectAs` 别名驱动）
- Maps/Objs 族不带 Class 参数（1.5.8/MP 3.5.17 javap 实证）
- 正向识别 `selectJoinMaps` 调用与分页 Page 实参
- MCP `sqlv_reverse_sql` 加可选 `maps`+`mapperVariable` 参数（默认不传零回归）
- 返回类型选择器补 Maps 分页声明 `Page<Map<String, Object>>`；返回类型声明项补类图标；返回类型固定候选并入「选择类」弹框前插；返回类型字段改照「调用类」同款形态（灰字占位标签＋点击弹选择）；返回类型字段去下拉（纯输入框＋选类按钮）

## 🛠 修复

**SQL 复制快捷键按界面统一（T-SqlCopyShortcuts）**
- 此前只有单击预览浮层的 Ctrl+C 能复制，其余带 SQL 编辑器的界面（主预览面板、最近执行记录、屏蔽规则、回滚 SQL、SQL → Java 输入区、参数导入）以及「最近执行记录」的列表都无法用键盘复制——编辑器上按 Ctrl+C 走不到平台的复制动作、列表复制出的是渲染文本
- 现按同一套语义统一接线：编辑器内无选中复制全文、圈选后只复制片段（Ctrl+C 与 Ctrl+Insert 同义键）；「最近执行记录」列表的 Ctrl+C 改为复制纯 SQL（与 SQL 日志列表一致）。各界面原有的复制按钮 / 菜单不变

**SQL 日志单击预览浮层 Ctrl+C 复制失效修复（T-ClickPreviewCopyRestore）**
- 单击 SQL 条目弹出预览浮层后按 Ctrl+C 复制不到 SQL、多选批量复制也被浮层打断。根因两条：①浮层为「弹出即可编辑」需抢键盘焦点；②焦点落到浮层编辑器后，平台的复制动作在编辑器上取不到复制能力提供者，按键事件落回编辑器默认复制——无选中时是空操作，表现为「按了 Ctrl+C 毫无反应」（列表自身的复制链路正常，只是焦点已不在列表）
- 修复：带 Ctrl / Shift 修饰键的单击从第一击起不再弹预览（多选全程焦点不离列表，批量复制恢复）；浮层内 Ctrl+C / Ctrl+Insert 改为在编辑器自身的按键绑定层接管——无选中复制整条 SQL（与头部复制按钮同源同反馈），圈选片段时只复制片段

**单条错误上报「提交」没反应（T-ErrReportSubmitNoOp）**
- 从 IDE 的错误 / 冻结通知进入「报告到需求池」对话框后点「提交」没有反应：按钮不转「提交中…」、状态行空白、窗也不关（用户连点五次，每次同栈）。缺陷自 2026-09-15 的缺陷笔起，存在于其后的全部发行版
- 根因：单条事件按设计不出批次分节，收集批次条目时对空容器做了裸索引（容器里没有复选框），越界异常被点击处理器外层吞掉，只在 IDE 日志里留一条 SEVERE——与「失败必须可见」的定论冲突
- 现容器访问全部带界（单条落到文档化的「单帖」路径），且请求组装环节整体纳入兜底：万一组装失败，原因显示在对话框状态行，可原地重试或转浏览器填写

**MP 链假 HQL 锚点重复图标与点击后弹框卡住（T-GutterDupFreeze）**
- MP 链上出现假 HQL 锚点，同一行挂两枚预览图标（demo 实测：三条 `selectList` 行各 2 枚，全方法体 10 枚、应为 4 枚）；点开后弹框卡住、关不掉
- 根因两条：①链内嵌 `.exists("select 1 from ...")` 令整条 wrapper 链源码被兜底当作 HQL 文本、被 `SELECT ... FROM` 正则命中（缺「首参须是字符串」门控）；②批量注册路径与链首 mapper 变量两条收录路径在同一行各挂一枚
- 修复三件：字符串首参门控 + 源码文本兜底改空；批量注册路径让位；把「按实体名找类」的全项目短名扫描改为索引构建期降级 + 有界扫描（上限 5000、可取消、命中即止）——后者消除了点击时持读锁连续 70 秒把 EDT 卡住、覆盖层窗口关不掉的机制
- 说明：截图里 21 枚按行标记中仅 10 枚属本插件（按配色判定），其余是第三方插件的标记，不计入本插件缺陷面

**exists 双语义撞名修复（T-ExistsChainTerminal）**
- 工厂链裸实参下带参 `exists` 被误判为链终结点，`EXISTS` 子查询条件整条丢失——`exists` 在 MP 里同时是条件方法（`Join.exists(String, Object...)`）与链终结点（`ChainQuery.exists()` 无参），PSI 定位层的终结点判定只按方法名匹配，二者又落在链尾时结构完全同形
- 现按实参个数区分（javap 实证 3.5.7/3.5.15/3.5.17 的 core 侧只有带参形态、extension 的 `ChainQuery.exists()` 才无参）：无参 `exists()` 仍是链终结点，带参一律作条件解析（布尔前缀照旧剥离为动态条件开关）
- 同一判据以 `isExistsConditionCall` 单点收口，供终结点筛选与 wrapper 变量接受门共用

**SqlToJavaPanel 两处 Throwable 捕获补 fatal 透传**
- `SqlToJavaPanel` 两处 `catch (Throwable)` 未透传 `Error` 子类，守卫由红转绿（整段收口）

**调用类 MPJ 能力误报「无 MPJ 能力」**
- 真机实证：`DeviceInfoMapper extends MPJBaseMapper` 仍被误判——「先贴 SQL 后选调用类」路径拿 stale 的能力判定（此前仅 SQL 解析链反查、选类回调不刷新）——现选类后后台重查 MPJ 能力与方法集再重生成

**列名→字段映射驼峰归一 + 多候选实体静默取首明示**
- 真机实证：`role_id` 等列大列表回落字符串——列名查询双向归一（snake_case↔camelCase，含 `@TableField` 显式驼峰列）；同表匹配到多个实体时静默取首个现于状态栏列出全部候选与已选项（如不符可开启「手动选择实体」切换）
