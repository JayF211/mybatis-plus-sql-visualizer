# 🎉 SQL Visualizer v2026.10.7

> 发行说明留档：对应 Gitee 发行版 **v2026.10.7**（标签 `2026.10.7`），附件 `mybatis-plus-sql-visualizer-2026.10.7.zip`。
> 范围＝自 v2026.10.6 发行包之后的全部用户可见增量。

自 v2026.10.6 后的正式版。本版主题是 **JPA 链式参数预览错位修复 + SQL 日志滚动与性能优化**：链式 `setParameter` 写法下预览参数值整体串位的双根因根治；SQL 日志工具栏新增「滚动到底部」动作与尾部跟随；并发大量 SQL 灌入下监听与历史加载性能修缮；参数字面量与枚举常量自动预填参数框。

## 🛠 修复

**JPA 链式 setParameter 参数预览错位（T-JpaParamOrder）**
- 链式 `em.createQuery(...).setParameter(a).setParameter(b)...` 写法下预览渲染的参数值整体串位——用户实测 `setParameter("locationStatus",…)` 写重后五个条件值全部错位、尾参被丢弃，出现 `warehouse_id='TC'` 这类张冠李戴，参数面板行值却显示正确
- 双根因：①链式调用的 PSI 是嵌套结构，参数收集按前序遍历先外后内，收集顺序＝书写顺序的逆序；②渲染/复制时第 i 个 `?` 配第 i 个参数名的纯位置配对，重复参数名把参数序列撑到多于 SQL 占位符数，错切后尾参直接落空
- 修复三刀：收集后按参数表偏移归位为文档序（非链式分语句写法本就文档序，零影响）；同名命名参数去重保首现序（JPA 覆盖语义）；渲染与「复制可执行 SQL」改按名回填（HQL `:name` 占位符名序，同名占位复用同值），与 setParameter 书写顺序彻底解耦——位置参数混入时保守回退按序回填
- 附带修复「表： long」：`createQuery(hql, Long.class)` 的结果类型 Class 此前被当实体解析、面板表名误显 `long`，现非 `@Entity` 的结果类型回落语句头实体名解析真表
- 同名写重时参数区尾部新增灰字提示（运行时以最后一次为准）

**参数占位启发式复合词误报修复（O-111 用户 demo 实测跟进）**
- `locationStatus` 这类复合词此前被参数占位启发式误配为集合占位，现不再误配

## ✨ 新增

**参数字面量与枚举常量自动预填（T-JpaParamOrder F6）**
- `setParameter("status", OrderStatus.PAID)` 这类字面量/枚举常量调用自动预填参数框，用户追问「为什么这些常量没有回显」后补齐

**SQL 日志「滚动到底部」+ 尾部跟随（T-SqlLogPerf）**
- SQL 日志工具栏新增「滚动到底部」动作——一键跳列表底并恢复跟随；跟随态下新 SQL 到达自动贴底，向上滚动阅读即自动停跟随（滚回底部/点动作恢复，IDE 控制台同款习惯）
- 此前 log 包无任何滚动控制，并发灌入时新条目只进模型、视口原地不动（用户体感「监听加载有延迟」的主形态）

## 🔧 改进

**并发大量 SQL 日志下监听与历史加载性能修缮（T-SqlLogPerf）**
- 日常 IDE 实测并发压测约 65 条/秒持续灌入、8708 条/19MB 历史文件加载 15~16.6s（超线性劣化）后的五处修复：
- 历史二级列表改滚动追加（首屏 30 条 + 滚动逼近底部才续写；原 invokeLater 链对 8708 条排 290 个 EDT 脉冲全量排空，无论看多少全部进模型）
- 历史页浏览态 refresh 不再每次全量重读当前文件（(lastModified,length) 快照判定，未变直接复用已解析条目——实测同一浏览窗口 19MB 被解析 3 遍）
- 历史解析单遍化（每块 joinToString→lines()→joinToString 三份拷贝砍到一份，解析语义逐字一致）
- 去重判定锁内 O(n) 全表扫描改 dedupeKey→最近时间戳 O(1) 索引（并发下三通道写线程与 EDT snapshot 抢锁的大头；入队/淘汰/裁剪/开关/清空/删单六维护面等价性守卫钉死，摘修复必红）
- 实时列表全量重建链防抢占——风暴期 200ms 一次的新刷新此前反复重启重建链致列表卡首屏 30 条，现进差分前同步补完在途链
- 另热路径新增阈值触发耗时探针（idea.log 检索 `[T-SqlLogPerf]`，单次 >100ms 才打，常态零噪音）供真机对账

**帮助页 / Marketplace 自定义页文案精简**
- 功能矩阵 27 个「说明」单元格压缩到一行级，可见文字 5005 → 3973 字符（-21%）；全部功能名、New / Ultimate 标签、触发方式、FAQ 八条、快捷键与链接零删减
- 新增 Markdown 版 `docs/发行说明/marketplace-custom-page.md`（整页复制进 Marketplace → Documentation 自定义页编辑器直接使用）
- 两版各内联三张演示动图（Wrapper 静态预览 / SQL 日志 / MCP agent 调用）
