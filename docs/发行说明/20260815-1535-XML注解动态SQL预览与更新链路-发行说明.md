# 🎉 MyBatis-Plus SQL Visualizer v2026.8.15

> 发行说明留档：对应 Gitee 发行版 **v2026.8.15**（标签 `v2026.8.15`），附件 `mybatis-plus-sql-visualizer-2026.8.15.zip`。

自 v2026.8.14 后的第三个版本。本版完成**XML/注解动态 SQL 预览引擎**（M24~M26，复刻 MyBatis 3.5.19 渲染算法）、**XML/注解 SQL 代码补全**（M27）、**设置页检查更新与自动安装**（M28）三大能力，并交付**预览一致性修复**（M29 系列，用户实测驱动）；测试 507 → 805 全绿。

## ✨ 本版新增（相对 v2026.8.14）

**XML 动态 SQL 预览（M24）**
- mapper XML `<select|insert|update|delete>` 语句上 gutter 图标或右键预览动态 SQL——引擎忠实复刻 MyBatis 3.5.19 渲染算法
- 动态标签全兼容：`if` / `choose(when/otherwise)` / `trim` / `where` / `set` / `foreach`（含 `__frch_` 参数重写、Map 迭代、空集合语义）/ `bind` / `sql`+`include`
- 受限 OGNL 求值（判空/比较/逻辑/算术/成员方法/列表字面量），表达式无法解析时面板提供手动开关兜底
- 预览面板：动态条件勾选（启发式默认）、foreach 展开次数与 null、bind 覆盖值、`#{}` 参数回填；SQL 高亮/格式化/执行/复制全部复用

**注解 SQL 预览（M25）**
- Java Mapper 方法上的 `@Select/@Insert/@Update/@Delete`（含 `<script>` 动态标签）与 `@SelectProvider` 等 Provider 注解（L1 常量折叠）——注解行 gutter 图标 + 右键预览，与 XML 引擎同一解析路径
- `@Param` 参数名 mock（`param1..N` 注入）；Provider 常量折叠（字面量/文本块/`+` 拼接/静态 final 引用）
- XML 多语句候选：光标不在语句内时列出全部语句（行号 + 摘要）供选择预览
- 实测修复（T-M25.2~25.5）：OGNL 静态常量引用 `@类全名@字段名`、`||表达式||` 非标准包裹兼容、OGNL 两套判真语义对齐、预览弹窗「复制错误信息」按钮、foreach 集合值输入（`2,3` → `IN ( 2 , 3 )`）、bind 自动求值回显参数行

**MP 占位展开与多候选（M26）**
- `${ew.customSqlSegment}` / `${ew.sqlSelect}` / `${ew.sqlSet}` 占位展开（M26-B）：经 namespace → Mapper 方法 → 调用处 wrapper 实参全链路回填（`customSqlSegment` = `WHERE (条件)` 对齐 MP `SqlHelper`），降级链逐级提示
- 文件级多注解候选（M26-A）：Wrapper 预览未命中时回落文件内全部 SQL 注解——单个直接预览、多个弹候选对话框（注解行号 + SQL 摘要）

**面板与预览体验（T-M26.x）**
- 左右分栏分隔条深色主题白竖条修复；左栏布局对齐 IDEA 原生惯例（TitledSeparator 分区、全选/全不选按钮回挂标题行、两列对齐、长文本中段省略 + tooltip 全名）
- 删除 bind 变量分区（与参数区重复展示，收敛单一来源）；foreach 行精简 + LIKE 参数恒引号（`#keyword="111"` → `LIKE CONCAT('%', '111', '%')`）
- SQL 面板 Ctrl+Alt+L 格式化快捷键（跟随 IDE keymap）

**XML/注解 SQL 代码补全（M27）**
- mapper XML 语句与 Java SQL 注解字符串内 Ctrl+Space 补全：SQL 关键字、表名/列名（FROM/JOIN/WHERE 等子句位置感知）、`别名.` 前缀列（联表别名绑定）、`#{}` 参数名（@Param 感知）、XML 动态标签与 test/collection 属性 OGNL
- 列注释 tailText 展示与中文关键词检索；Community 兼容（自研贡献器、零数据源依赖、实体注解即 schema）
- 预览面板输入自动弹出补全（平台 autopopup 对非文件编辑器弹空窗——面板自建监听 + 手动补全处理器接管）；注解 `<script>` 内动态标签补全；表名全位置提示（含 @TableName 联表候选）+ SQL 渲染自动格式化

**设置页检查更新与自动安装（M28）**
- 设置页新增「更新」分区：当前版本展示、「检查更新」按钮（已最新/发现新版/失败原因状态反馈）、新版变更日志展示、「下载并安装」一键完成（下载进度条）→ 安装后提示「重启 IDE 生效」+ 重启按钮
- 「启动时自动检查更新」开关（默认开）：启动静默检查，发现新版弹通知可「立即更新」后台下载安装；更新源 = 仓库 `update/update.json` 清单 + Gitee Release 附件
- 修复与配套（T-M28.1/28.2）：「检查更新」按钮此前未绑定事件点击无反应；内部构建号 (MPV-Build) 在 2026.2.1 上恒为 — 的显示修复；更新链路跨平台加固（Win/Mac 目录差异不影响判定）；构建号行「复制」按钮一键复制

**预览 SQL 修复（M29 系列，用户实测驱动）**
- 分组方法布尔条件重载不再静默丢弃：`.and(condition, w -> ...)` 等 and/or/nested/not/func 布尔首参剥离为动态条件开关（`and(false, ...)` 默认不渲染），组内 OR 条件正常渲染（`AND (code LIKE ? OR user_phone LIKE ?)`）
- 分页 LIMIT 渲染：`service.page(new Page<>(...), wrapper)` / `selectPage` / 链式 `page()` 识别为分页消费——字面量直接计算 `LIMIT 0, 10`，运行时变量渲染 `LIMIT ?, ?`（参数区回填，offset 标注 `(pageNum - 1) * pageSize` 公式），全 9 方言适配
- SQL 格式化逗号丢失修复：列清单逗号保留行尾换行、`LIMIT ?, ?` / `GROUP BY a, b` 逗号保持同行；格式化幂等——默认显示与点击格式化结果不再漂移
- XML 预览格式化空格修复：函数名与括号紧贴（`CONCAT (` → `CONCAT(`）、双引号字符串不再被拆成 `" 1 "`
- 动态条件面板组行合并：布尔组开关行与组内子条件重复展示修复（HAVING 子条件恒丢失预存缺陷一并修复）
- XML 参数回填默认引号：Map 等无类型信息入参 `2025` → `'2025'`——LocalDate/字符串列比较不再被数字启发式误判（数值列隐式转换语义不变）
