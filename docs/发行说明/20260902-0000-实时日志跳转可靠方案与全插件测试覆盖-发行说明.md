# 🎉 SQL Visualizer v2026.9.2

> 发行说明留档：对应 Gitee 发行版 **v2026.9.2**（标签 `v2026.9.2`），附件 `mybatis-plus-sql-visualizer-2026.9.2.zip`。

自 v2026.8.21 后的第十个版本（含原计划 8.22 未发行的更新机制改进）。本版是迄今最大更新——**190 个提交、20+ 功能模块、232 类 2860 用例全绿**。核心主题是 **SQL 预览面板原生 Database 控制台内嵌**（M36 系列——从拼合方案到整控台嵌入，执行/Tx/会话/数据源选择工具栏全保留）与 **全插件 UI / 集成测试覆盖**（50+ 测试文件 200+ 用例）——同时完成 **实时日志精确跳转源码**（F-44-6）、**SQL 日志合并主侧边栏**（F-44）、**自动保存历史 SQL**（F-43）、**JOIN 关系图自绘 Swing 引擎**（F-42）、**原生语法高亮 + 智能补全**（M34）、**数据源 schema 字段注释补全**（M35）、**HQL 关联字段解析 + Hibernate XML 映射**（F-45）、**Spring JdbcTemplate 日志捕获**（M47）、**SQL 日志 EDT 冻结修复**（M46）、**日志捕捉性能优化**（T-LogPerf）、**设置页左侧树导航 + 布局优化**、**插件更名 SQL Visualizer**、**Gitee 抢先体验更新通道**，以及 **帮助按钮本地 HTML 定稿**。

## ✨ 本版新增（相对 v2026.8.21）

**SQL 预览面板原生 Database 控制台内嵌（M36 系列）**
- **M36 内嵌完整原生控制台**：执行链改为 `getConsoleView()` 提取 JdbcConsole 原生 UI 组件（编辑器 + 结果区），不再打开主编辑器窗口——执行/Tx/会话/数据源选择工具栏全保留，SQL 预览面板下半区 `consoleHolder` 状态行 + 内嵌控制台，内嵌后分割线展开到 55%
- **M36.2 默认结果 Tab + 编辑器融合**：默认打开查询结果 Tab，控制台编辑器融合插件补全；弹窗改非模态（`IdeModalityType.MODELESS`）让密码框正常置顶
- **M36.3 错误回调链路**：执行失败提取真实错误（`extractConsoleError` 读 console history + `ERROR_SIGNATURES` 防误判），`SqlResultPanel` 状态机（EMPTY/LOADING/ERROR/SUCCESS）+ 复制按钮 + `showIdle` 保留 ERROR
- **M36.4 拼合方案**：编辑器 + 结果区内嵌右侧，拼合编辑器 + 结果区布局
- **M36.5 原生融合优化**：去空白（删除冗余 `verticalSplit`/`consoleHolder`）、去白边（`JBScrollPane` viewport 描边 + `ThemedSplitPane` border 清零）、控制台默认展示（唯一数据源/last-used 静默复用，多数据源弹一次选择，无数据源静默打开 Database 工具窗口）
- **M36.5.5-5.76 布局全链修复**：持久 SplitPane 强制换底 + 结果区隔离 + 真实错误展示；分隔条保险条件修正（布局漂移根因闭环）；▶灰探针假阴性修复；Output 控制台 44px 塌缩根因修复（布局替换替代 `setSize`）；OUTFILL 搜索范围收紧到结果区 bottom
- **M36.6.1 EDT SlowOperations 治理**：面板打开期 EDT SlowOperations 治理 + 版本戳修复
- **M36.7 HQL SELECT 实体别名展开**：修复 `SELECT u` 在 MySQL 报 `[1054] Unknown column 'u'`——裸别名且登记在 FROM/JOIN 才展开，无 SELECT 子句自动补列清单，JOIN 副表/元数据缺失降级 `alias.*`

**SQL 预览原生语法高亮 + 智能补全（M34）**
- 编辑器从自研 `SqlPreviewLanguage` 切换为 IDEA 原生 SQL FileType——`SqlPreviewPanel` / `SqlInputEditor` / `LogToSqlPanel` 三处统一升级
- 原生 SQL 高亮器通过 `SyntaxHighlighterFactory` 手动关联，补全贡献者注册改为全语言 + `Document WeakHashMap` 守卫
- 差异对比改用 IDEA 原生 Diff（`SqlDiffDialog` 废弃删除），按钮名「并排对比」→「差异对比」
- 删除 4 个废弃文件：`SqlPreviewFileType` / `SqlParserDefinition` / `SqlPsiFile` / `SqlSyntaxHighlighter`
- 修复预览编辑器 PSI 解析 EDT SlowOperations 硬抛（临时文件创建 + `findFile` 整体包 `ReadAction.compute`）

**数据源 schema 字段注释补全（M35）**
- `DatabaseSchemaResolver`：全反射访问 `com.intellij.database`（`DataSourceManager` → `DbDataSource` → `DasModel.traverser` → `DasTable` → `DasColumn`），按实体表名匹配取 DB COMMENT 作为列注释
- 列注释合并策略——数据源 schema 注释优先于实体注释（DB COMMENT 更权威），同名列覆盖，新增列保留实体注释
- Community 无 database 插件时空转（`Class.forName` 探测），零编译期依赖

**HQL 关联字段解析 + Hibernate XML 映射（F-45）**
- `HqlConverter` 新增 `mapAssociationPath`：`alias.field.id` → 外键列名
- 新增 `HbmXmlEntityResolver` 解析 `.hbm.xml` 映射文件，`SqlPreviewService` 实体解析降级链增加 `.hbm.xml` 路径
- 新增 `HbmXmlMapping` 数据模型 + 12 个单元测试

**maintainPage XML SQL 预览（F-45）**
- 支持 vTradex Forest 框架 `<pages>` XML 格式中 `<maintainPage>` 的 `<datasource>` CDATA SQL 预览
- `PagesXmlParser` 独立 DOM 解析器 + `PagesXmlPreviewService` 纯 SQL 路径 + `PagesXmlGutterLineMarkerProvider` gutter 图标
- `SqlPreviewPanel` 列信息 tab（列标识/标题/类型/可见性）+ 实体类推断
- 25 个新增测试

**SQL 日志合并主侧边栏 + 源码定位 + 历史读取（F-44）**
- 去除独立 SQL 日志工具窗口，合并到主侧边栏新增「历史」tab
- `LogSqlEntry` 增加 `sourceFile/sourceLine` 字段，`SqlLogConsoleBridge` 捕获时从调用栈提取源码位置
- `SqlLogAutoSaver` 保存格式扩展为 `-- source | time | timestamp --`
- 新建 `SqlLogFileReader` 反解析 `.idea` 历史文件（兼容新旧格式）+ `HistorySqlLogPanel`（列表 + 搜索 + 双击预览 + 右键跳转源码）

**自动保存历史 SQL（F-43）**
- 设置页新增「自动保存历史 SQL」配置组：开关 + 保存目录 + 文件名模板（支持 `$yyyy$ $MM$ $dd$ $HH$ $mm$ $ss$` 占位符）
- 默认路径 `.idea/sql-visualizer/sql-history/`，单文件 ≥100MB 自动滚动（`.2.sql`、`.3.sql`…）
- `SqlLogAutoSaver` 文件写入器（模板解析 + 日期切换 + 大小滚动）+ 12 个 i18n 键

**JOIN 关系图自绘 Swing 引擎（F-42）**
- 移除 plantuml:1.2024.8 (21.9MB) + batik (~8MB) 依赖，改用纯 Java Graphics2D 自绘 ER 关系图——插件体积从 42MB 降至 5.3MB，渲染延迟从 2-6s 降至 <50ms
- 新增 `DiagramModel` 结构化中间模型（`EntityNode` + `RelationshipLine`）+ `DiagramRenderer` Swing 自绘引擎（PNG + SVG 导出）
- 三层渲染架构：卡片 → 标签(顶层) → 线条(分段，跳过标签区域)；动态间距根据 ON 条件文字宽度自动扩展；UML cardinality 基数标签垂直错开防重叠
- F-1.1 UI 优化：主表居中上方 + JOIN 表水平排列下方（梳状拓扑）+ 正交路由 T 型折线 + 箭头指向子表

**实时日志精确跳转源码可靠方案（F-44-6）**
- **根因**：旧 `extractSourceLocation` 在 IDE 控制台线程取栈恒失败，退化为按表名猜实体
- **新方案**：运行期用 MyBatis-Plus `InnerInterceptor` 在 SQL 执行线程捕获真实调用点，向 stdout 打印标记行 `SQLVIS-SOURCE|<相对路径>|<行号>`；`SqlLogConsoleBridge.processConsoleLine` 解析写入 `LogSqlEntry.sourceFile/sourceLine`，实时日志复用与历史面板一致的精确 `OpenFileDescriptor` file:line 跳转
- 新增 `SqlSourceMarker`（标记格式/解析）、`CallerSourceLocator`（调用栈→用户代码帧纯函数）
- 运行期拦截器自包含示例 `docs/instrumentation/SqlSourceInterceptor.kt`

**Spring JdbcTemplate SQL 日志捕获（M47）**
- 新增 `JdbcTemplateLogParser` 解析 Spring JdbcTemplate 控制台日志（DEBUG SQL 行 + TRACE 参数行），与 MyBatis/Hibernate 三解析器并列
- `PluginSettings` 新增 `logJdbcEnabled` 开关（默认开）+ 设置页 JdbcTemplate 复选框
- 23 个单元测试全绿

**SQL 日志筛选项精简**
- SQL 类型多选：工具栏「SQL 类型：[状态]」标签 + 按钮，弹窗勾选即时过滤（查询/插入/更新/删除 + 全选/全不选）
- 高频折叠整体移除（按钮 + `LogFrequencyGrouper` + P-06 死配置字段）
- 去重徽章：`SqlLogEntryBuffer` 丢弃计数，列表条目尾部 `⨉N` 累加显示
- Ctrl+F/⌘F 搜索：`CommonShortcuts.getFind()` 唤起 `SearchTextField` 实时过滤（匹配还原 SQL 与摘要，参数值可搜）
- 工具栏布局：左侧动作图标 + 筛选区（`WrapLayout` 折行），右侧「移除重复的sql」勾选

**设置页左侧树导航 + 布局优化**
- 设置页改为左侧树导航 + 5 个独立子页面（SQL 预览 / 表名映射 / SQL 日志 / 界面与操作 / 关于）
- 主页面：子页面列表（图标 + 名称粗体 + 描述灰色小字）+ 顶部搜索栏（实时过滤字段 + 所属页面路径）
- 折叠面板 + Tab 拆分：6 个 TitledSeparator → 5 个可折叠面板，SQL 日志 17 行拆为 3 Tab（MyBatis 核心 / ORM 框架 / 自动保存）
- 搜索过滤：实时过滤行（标签文本 + tooltip + checkbox 文本），递归扫描嵌套容器
- 搜索跳转同对话框内定位并高亮目标控件（`Settings.KEY.select()`）
- 消除 `SettingsEditor(@ApiStatus.Internal)` 编译期依赖（`Class.forName` 反射）
- `JBColor` 替换硬编码颜色值支持主题切换

**插件显示名更名 SQL Visualizer**
- `plugin.xml` `<name>` 与全部用户可见文案（设置页/弹窗标题/gutter tooltip/通知/工具窗口标题，中英双语）同步更名——插件 ID、构建产物 zip 顶层短名、仓库与 Marketplace 页地址均不变，已安装用户正常升级

## 🔧 修复（相对 v2026.8.21）

**SQL 日志面板四项缺陷终局修复（F-44-2）**
- **列表 SQL 词法高亮恢复**：SQL 摘要走 `SqlListHtmlRenderer`（关键字/表名/字符串/数字/注释分色），时间戳与耗时走灰色 `#9E9E9E`
- **耗时字段接入控制台链路（root fix）**：`ExecutionTimeParser` 接通，`LogSqlEntry.executionTimeMs` 写入真实值，阈值色（<100ms 灰 / ≥100ms 橙 / ≥`slowQueryThresholdMs` 红）
- **「移除重复的sql」已存在条目同步去重**：`SqlLogEntryBuffer.dedupeExisting()` 立即按窗口裁剪
- **去重计数即时刷新**：去重分支也调用 `notifyChanged()`，`⨉N` 徽章一帧同步

**SQL 日志 EDT 冻结修复（M46）**
- 根因：`rebuildListModel` 逐条 `addElement` 触发 O(N²) 事件风暴，cell renderer 在 EDT 执行 SQL 词法分析 + Swing HTML 渲染，导致 20-30 秒 EDT 冻结
- 修复：`addAll` 批量更新（O(N²)→O(N)）+ cell renderer 纯文本化 + 新增 `logMaxCount` 设置项（默认 200）

**日志捕捉性能优化（T-LogPerf-01~05）**
- 快速轮询 100ms→500ms 起步指数退避至常规 2s 封顶
- 反射 Method 缓存（含 null 负缓存）——热路径零重复查找
- descriptor→console 身份缓存短路（已挂载 console 跳过组件树遍历）
- 逐行配置同步改事件驱动（订阅 `SETTINGS_CHANGE_TOPIC`）

**历史面板高亮 + 耗时 + 注释格式（F-44-2）**
- 历史列表 SQL 高亮 + 耗时显示
- 历史文件注释回归标准 `--` 注释，`NEW_HEADER_REGEX` 兼容 2/3 个 `-` 起结

**SQL 历史面板两级导航（F-44-3）**
- 一级文件列表（文件名/大小/条数）→ 二级逐条 SQL（高亮/耗时/源码）→ 双击预览
- 刷新语义：保持二级视图 / 文件删除回一级

**多行拼接 HQL gutter 漏检（M36.5.79）**
- 修复 gutter 漏检 `PsiPolyadicExpression`，`findAssignedVariable` 沿引用链上溯

**复制为 MD 表格格式修复（F-46）**
- `MarkdownFormatter`：多行 SQL 换行→`<br>`，列序调整为来源|SQL|参数|表|方言|时间
- `ShareDialog` 来源字段预填充当前文件名:行号

**弃用 API 清理（M36.5.78）**
- `HttpConfigurable`/`USE_HTTP_PROXY` → `ProxySettings.getProxyConfiguration()`
- `isUnderDarcula()` → `StartupUiUtil.isDarkTheme()`

**数据源选择器 NPE 修复**
- `DataSourceSelector.prepareConsole` 在平台 runner 列表为空时返回降级路径
