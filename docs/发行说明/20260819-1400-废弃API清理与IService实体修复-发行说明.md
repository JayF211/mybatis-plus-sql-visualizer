# 🎉 MyBatis-Plus SQL Visualizer v2026.8.19

> 发行说明留档：对应 Gitee 发行版 **v2026.8.19**（标签 `v2026.8.19`），附件 `mybatis-plus-sql-visualizer-2026.8.19.zip`。

自 v2026.8.18 后的第七个版本。本版核心主题是 **Marketplace 审核阻断级废弃 API 全量清理**（T-M51 + T-M52）与 **IService 内置 CRUD 方法实体解析修复**——三版本（243/253/262）达成 0 Internal + 0 Scheduled-for-removal；同时完成功能截图替换 + Marketplace Custom Page + plugin.xml 清理；测试 1227 全绿。

## ✨ 本版新增（相对 v2026.8.18）

**废弃 API 全量清理（T-M51 + T-M52，Marketplace 审核阻断级）**
- **三版本 0 Internal + 0 Scheduled-for-removal**：verifyPlugin 实证 243/253/262 全部达标；Deprecated 由 9/11/27 降至 3/4/20（剩余 5 类无跨版本非废弃替代，保留 @Suppress）
- **ToolWindowFactory synthetic bridge 消除**：`SqlLogToolWindowFactory.kt` 删除 → 改写为 Java（`SqlLogToolWindowFactory.java`），消除 Kotlin 生成的 `properties` synthetic bridge（262 标记 Internal）；新建 `ToolWindowVisibilityListener.java`（两参版 `stateChanged`）；`SqlLogPanel.kt` 新建迁移面板逻辑
- **PluginManager.getPlugin() 完全消除**：用标准 Java `ProtectionDomain.codeSource.location` 获取当前类所在 jar/目录路径；用 `DeleteCommand` 替代 `PluginManager.uninstallAfterRestart()`——两者皆为公开 API，三平台可用；verifyPlugin 实证：243 Internal 1→0, 262 Internal 2→0
- **ProjectListenerRegistrar 删除**：`projectOpened()` 无公开替代方案——整个文件删除（`LogStartupCapture.kt` 移除调用 + 更新 KDoc）；verifyPlugin 实证：三版本 Scheduled-removal 1→0
- **跨版本 Deprecated 替代**（T-M52）：`LineMarkerInfo` 六参→七参构造（+accessibleNameProvider）；`DaemonCodeAnalyzer.restart()`→`restart(psiFile)`；`JavaAnnotationIndex.get()`→`getAnnotations()`；`ChooseByNameModel.getCheckBoxMnemonic()` 删除覆写；`Document.addDocumentListener` 单参→双参 + Disposable 生命周期管理；`Notification.setListener` 移入 `createNotification` 3 参数

**IService 内置 CRUD 方法预览修复**
- **无 Entity 后缀实体类支持**：`BatchOperationConverter.resolveServiceEntityClass()` 步骤 3b 原硬限定实体类名以 "Entity" 结尾——`User`/`Order` 等不含后缀的真实实体类解析失败（gutter 图标点击报"未找到 Wrapper"）；修复：去掉 `endsWith("Entity")` 限定，在 service 上下文 + 白名单方法名双重约束下仅排除 `java./javax.` 包前缀（防基础类型误判）；同步更新中英文错误提示文案为泛化描述；新增 3 个测试用例

**UI 打磨与文档升级**
- **功能截图 5 张替换真实截图**：`docs/images/screenshot-01~05` 替换占位图（覆盖预览弹窗/日志面板/SQL→Java/XML·注解预览）
- **Marketplace Custom Page**：`docs/发行说明/marketplace-custom-page.html`——Feature Matrix + 11 条 FAQ（纯 CSS checkbox hack 折叠）
- **plugin.xml description 清理内嵌图**：移除 5 张截图 + 2 张二维码（Gitee 防盗链 302 拦截），改为指向 Marketplace 详情页截图区

## 🔧 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；执行 SQL 需 Ultimate）
- Plugin Verifier 已验证 2024.3 / 2025.3 / 2026.2 三版本 0 Internal + 0 Scheduled-for-removal

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.8.19.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装旧版：设置页「更新」分区可直接检查更新下载安装（Gitee 渠道），或按上法手动安装覆盖
