# 🎉 MyBatis-Plus SQL Visualizer v2026.8.17

> 发行说明留档：对应 Gitee 发行版 **v2026.8.17**（标签 `v2026.8.17`），附件 `mybatis-plus-sql-visualizer-2026.8.17.zip`。

自 v2026.8.16 后的第五个版本。本版围绕**SQL→Java 反向转换链路质量大修**（T-M41~M45，用户实测驱动——调用 API 真实性/复制纯净/占位符 round-trip/性能）、**方言 UPSERT 全兼容**（T-M43）、**日志体验五项修复**（T-M42）与**三处图标统一 + 功能截图入库**（T-M40）；测试 1063 → 1210 全绿。

## ✨ 本版新增（相对 v2026.8.16）

**SQL→Java 反向转换链路质量大修（T-M44 / T-M45，用户实测驱动）**
- **调用方法按调用类真实 API 选择**：生成调用前反查调用类继承链方法集——`selectPage`/`selectList`/`page`/`list` 等普通方法不存在时自动回落 MPJ join 方法族（`selectJoinPage(page, Class, wrapper)` / `selectJoinList(Class, wrapper)` / `selectJoinListPage` / `updateJoin(null, wrapper)` / `deleteJoin(wrapper)`，签名经 MPJ 1.4.13/1.5.6 双版本 jar 实证）——兼容 MPJBaseMapper 与 BaseMapper API 不同的项目（用户实证：部分 MPJ 依赖的 mapper 无 selectPage）
- **复制只复制 Java 代码**：预览弹窗与「SQL → Java」tab 的「复制代码」自动剥离说明注释（头注释/占位提示等）——粘贴即用纯代码，行尾说明注释改独立行注释
- **结果区「格式化代码」按钮**：用 IDE Java 格式化器归一空格/缩进，长链按用户代码风格折行
- **`?` 参数占位符 round-trip 修复**：正向 Java→SQL 产生的 `?` 参数反向转换不再降级 `apply()`——`= ?` 转 `.eq`、`IN (?, ?)` 转 `.in`、`BETWEEN ? AND ?` 转 `.between`、`LIMIT ?, ?` 转 `.last(...)` 等全形态，生成代码头部注释提示替换占位
- **手动选择实体类**（可选开关）：自动推断不好推断时弹窗手动指定（多表 JOIN 一次多选主/副表，Goto Class 手动挑选、自动候选预选、可清除；设置页「自动推断失败时允许手动选择实体类」默认开）
- **AUTO 形态优先对象引用**：实体类名与表名驼峰不一致时（`AccountRoleRelEntity` ↔ `sys_account_role_rel`）经 `@TableName` 反查自动找到实体，生成 `LambdaQueryWrapper` + 方法引用形态
- **调用形态按 MPJ 1.5.6 实证重写**：移除不存在的 `listVo/pageVo/selectVoList` 等，改用真实方法（`selectJoinList(Vo.class, wrapper)` / `selectJoinListPage(page, Vo.class, wrapper)`）；调用类改驼峰实例变量调用（`bannerService.page(...)`），复制即可编译
- **性能修复**：实体反查全量扫描结果项目级缓存（PsiModificationTracker 失效）+ 类名「去首段」启发式 + 跳过接口/枚举——无实体场景不再每次转换全量扫描；设置页「更新与诊断」分区统一缓存管理（大小显示 + 清除反馈）

**方言全兼容：UPSERT 与分页宽容（T-M43）**
- **UPSERT 按方言渲染**：`saveOrUpdate` / `insertOrUpdate` 冲突子句按当前方言生成——MySQL/MariaDB 渲染 `ON DUPLICATE KEY UPDATE 列 = VALUES(列)`，PostgreSQL/H2/SQLite/KingBase 渲染 `ON CONFLICT (主键) DO UPDATE SET 列 = EXCLUDED.列`，Oracle/SQL Server/DM 降级纯 INSERT——保证「设置里出现 = 承诺可用」：任何可选方言下预览 SQL 均可在该数据库执行
- **反向分页解析方言宽容**：粘贴 SQL 分页子句支持全部主流形态——`LIMIT n OFFSET m`、`OFFSET n ROWS FETCH NEXT m ROWS ONLY`、`FETCH FIRST n ROWS ONLY`，值可为数字或 `?` 占位符；列名 `offset`/`fetch` 不误判
- **达梦方言实证化**：DM8 官方支持 `LIMIT M, N` 写法（4 种之一），「假设性标注」更新为官方实证依据

**日志体验修复五项（T-M42，用户反馈）**
- 双击日志 SQL 弹窗**自动识别参数**：左侧参数区显示 `#param1…` 行并预填日志参数值（类型感知引号），修改实时回填 SQL
- 日志列表 **Ctrl+C 复制纯 SQL**（不再复制列表渲染 HTML 源码，多选逐条换行拼接）
- 预览弹窗 **EDT read access 报错修复**（PSI 文件创建包读操作，全部预览弹窗入口统一受益）
- 调用类支持 **`this` / `baseMapper`** 固定候选（service 内 `this.list(...)`、ServiceImpl 字段 `baseMapper.selectList(...)`）
- **serialVersionUID 默认忽略**：不再生成 `User::getSerialVersionUID` 这类编译不过的引用（全形态列名跳过）

**预览高亮与快捷键（T-M41）**
- 右键「Convert SQL to MP Java Code」结果弹窗升级为 IDEA 只读编辑器——生成代码带完整 **Java 词法高亮 + 行号**
- 设置页新增「**SQL→Java 快捷键**」行——录制式修改 Alt+Shift+J（与 Convert to SQL 同款交互，冲突检测保留）

**图标统一与功能截图（T-M40）**
- 侧边栏 SQL 日志 / gutter 预览 / 插件 logo 三处图标统一——MP 蓝圆角底 + `</>` 代码 + 右下角放大镜前景层；gutter 预览图标放大 1.25 倍加粗更醒目
- **功能截图 5 张真实截图入库**（预览弹窗 / 日志面板 / SQL→Java / XML 预览 / 注解预览），插件详情页与 README 同步展示

## 🔧 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；执行 SQL 需 Ultimate）
- Plugin Verifier 已验证 2024.3 / 2025.3 / 2026.2 三版本 0 问题

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.8.17.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装旧版：设置页「更新」分区可直接检查更新下载安装（Gitee 渠道），或按上法手动安装覆盖
