# 🎉 SQL Visualizer v2026.9.18-beta.4（内测版）

> 内测版留档：Gitee 抢先体验通道发行版，标签 `2026.9.18-beta.4`，附件 `mybatis-plus-sql-visualizer-2026.9.18-beta.4.zip`。
> 基线为内测版 v2026.9.18-beta.3，本内测版承载其后的全部增量；对外更新清单只保留最新一个 beta 版。

自 v2026.9.18-beta.3 后的同日内测第四轮。本版以 **界面组件全面原生化（T-UiNative）首轮落地** 为主线——日志/历史列表接入原生 SpeedSearch 搜索，模态轻提示换平台通知，右键菜单与弹层改用原生组件，JOIN 图与历史导航按钮行迁原生工具栏，加载态与占位符接原生件，配色统一跟随平台主题；同时完成 **增删改（CUD）语句源码位置捕获修复**、**IN 字面量参数识别**、**IN 列表全量竖向排列** 三处预览链路修复。

## ✨ 新增

- **界面组件全面原生化首轮（T-UiNative）**：本版起将大量自绘/自定义组件替换为 IDEA 平台原生组件。主日志与历史二级列表接原生 SpeedSearch（快速过滤、匹配高亮与平台一致）、19 处模态轻提示改平台通知、右键菜单与类型过滤弹层换原生组件、JOIN 图与历史导航按钮行迁原生工具栏、加载态与占位符接原生件、33 项写死颜色统一跟随平台主题，设置落地页行渲染器与项目级设置页同步归一

## 🐛 修复

- **增删改（CUD）语句源码位置捕获修复（T-AgentCudSource）**：增强捕获下只有 SELECT 捕获到源码位置，INSERT/UPDATE/DELETE 捕获不到。根因=`StackLocator` 调用方缓存把「无调试信息的 null 位置」也缓存（缓存键=首个非框架帧 `class#method`，主位置为 null 时候选首位顶上且可能仍为 null）——某调用方一旦解析出 null（CUD 常走的 MP 默认方法/代理中间帧），该名名下所有后续语句恒无源码位置且不再自愈。修复=仅缓存有效位置：主位置为 null 时候选挑非 null 顶上、候选全 null 则本次不产出不缓存（下次重试）。新增 `StatementSourceLocationTest` 2 例经真实 CUD 执行把「CUD 事件 sourceFile 必指向用户栈帧」锁进绿灯；顺带盘清方言与增强的关系（采集面为 JDBC 接口级、对全部方言一视同仁）
- **IN 字面量 SQL 预览参数未识别修复（T-InParamRec）**：上游把值直接内联进 SQL（非 `?` 绑定参数）时，源码跳转反查入口打开的预览不出现参数行、值不可编辑——该入口是 M37.1 时代独立实现，漏接字面量恢复能力。现与日志 tab / 历史 tab 收编同一识别通道，字面量（含 IN 列表）原位改写为可编辑参数行，改值即时生效
- **IN 列表全量竖向排列（T-VStack·InAll）**：预览「竖向排列」对 IN 列表不再按元素数分级——含逗号即 ≥2 元素一律 `(` 自占一行逐元素竖排；单元素形态（`IN (1)` / `IN (?)`）仍同行，子查询 IN 与 LIMIT 分页参数照旧不展开
- **增强捕获确认弹窗标题与取消按钮文案**：标题补插件名前缀，Cancel 按钮走 plugin bundle，消除中英混排

## 🔧 内部

- **构建脚本拆分分治（T-BuildScriptSplit）**：`build.gradle.kts`（1073 行）拆为 buildSrc 四个 convention 插件的块级搬运零逻辑改写；changeNotes 数据外置，发版只编辑数据文件
- **兼容校验目标追平 IDEA 2026.2.3（T-VerifyIde2623）**、**verifyPlugin 提取失败 home 隔离修复（T-VerifierHomeIso）**

## 🧪 测试

- **T-UiNative 全链**：SpeedSearch 安装/匹配高亮、右键菜单迁 ActionPopupMenu、加载态/占位符、namedColor 配色、Kul UI DSL 落地页渲染器等用例随各批次落地，全量门禁 4147 绿基线
- **CUD 源码位置**：`StatementSourceLocationTest` 2 例（真实 executeUpdate/execute 触发、断言 sourceFile 指向用户栈帧）
- **IN 字面量**：`InLiteralRecoveryRegressionTest` 4 例（用户实录多行 SQL 喂真实解析器：零占位符零绑定行事实钉死 / 统一通道字面量恢复产出参数行 / 开关关闭维持现状 / 按 paramHints 回填往返）
- **IN 竖向排列**：SqlFormatterTest 反转 6 例 + 新增 2 例 + SqlPreviewPanelTest 补面板级断言
- 本版全量 test + agent 子项目 test 绿（testShards 全量，6 跳过为 Docker），`verifyGate` 三目标（IU-243/253/262）Compatible

## 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；EXPLAIN、执行 SQL、表右键入口与 Database 原生图需 Ultimate）
- 增强捕获为默认通道：**首次运行项目会弹一次注入确认**，同意后生效并持久记忆；拒绝则本次不注入、下次运行再询问，控制台捕获照常回落零劣化
- 脱敏默认关闭（默认采集真实参数值），设置页「增强捕获」分组仍可开启打码
- 插件 ID 与升级链路不变，v2026.9.18-beta.3 用户可直接覆盖升级

## 📦 安装（内测通道）

1. 下载附件 `mybatis-plus-sql-visualizer-2026.9.18-beta.4.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装 v2026.9.11+ 用户：设置页「更新」分区检查更新即自动收到本内测版（Gitee 抢先体验通道），经该通道更新免重启即时生效
