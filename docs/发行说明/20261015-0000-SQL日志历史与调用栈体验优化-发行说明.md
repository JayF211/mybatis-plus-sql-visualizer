# SQL Visualizer v2026.10.16

> 本地发行准备完成，尚未创建标签、Gitee 发行版或 Marketplace 上传记录。范围以 master `fea2640a` 加本次发行增量为准；`preview.update.json` 是更新清单草稿，不代表下载地址已经生效。

本版集中改进 SQL 日志、历史浏览与调用栈阅读体验。列表默认保留关键字换行与 SQL 的大致形态；单击改为选择条目，按需打开底部快速预览后可连续查看，双击仍打开完整预览。

## 新增与改进

- **日志与历史更易读**：SQL 高亮跟随 IDEA 编辑器配色，长来源与 SQL 随侧栏宽度省略，列表不再横向滚动；格式化显示、复制与完整预览不受省略影响。工具栏动作由平台处理窄栏溢出，排序入口与左侧动作同组。
- **快速预览**：日志列表与历史二级列表的普通单击只选中，不再弹出遮挡列表的轻预览；工具栏「快速预览」打开默认收起的底部预览区，随后切换选中条目即可连续查看。编辑 SQL 时保留当前草稿，恢复原文后继续跟随；首次使用会给出一次不抢焦点的入口提示。双击完整预览与多选复制保持原样。
- **尾部跟随、排序与筛选**：默认跟随最新 SQL；手动滚轮、拖动滚动条或键盘浏览会暂停自动滚底，点击「滚动到底部」恢复。排序新增「同结构聚类」与「按目标库分组」，类型过滤增加「只看慢查询」（耗时未知的条目不算慢查询）。
- **调用栈业务帧优先**：静态调用栈优先显示已经采集到的业务帧，相邻内部帧折为可展开段；采集时已经省略的帧明确标示，不伪装为可展开内容。深栈采样改善部分业务入口帧的保留，摘要也可单击打开弹层，原文复制与逐帧跳转仍可用。跨线程或原始快照没有采集到的帧无法靠展示恢复。
- **交流群入口**：SQL 日志工具栏可打开原生弹框，分别说明作者微信和交流群。二维码在打开时从官网异步加载；加载失败时可转到官网交流页。二维码能否扫码入群取决于官网当前图片及群码有效期。

## 修复

- SQL 日志与历史列表中正常耗时不再被展示层覆盖为灰色：低于半阈值为绿色、达到半阈值为橙色、达到慢查询阈值为红色；未知耗时灰色、选中白色。此修复已随 `fea2640a` 纳入本版。
- 后台预热执行临时文件时不再持写意向锁同步等待 VFS 刷新会话，修复预览停在「正在准备预览...」并导致 IDE 无响应的问题；投机性预热增加 30 秒预算，超时放弃且释放在途标记。EDT 冷路径的读写保护不变。262 真机冷启动复验仍待完成。
- 移除 SQL 日志面板里打入生产包的三处测试专用 override-only API 直接调用；排序 tooltip 的断言留在测试侧，正常工具栏分派不变。修复后 IDEA 243 / 253 / 262 的离线及在线报告均为零项 override-only 用法。
- 首次真正进入「SQL 历史」页时补幂等扫描，已有历史文件不再需要手动刷新才显示。
- 日志工具窗四个页签改用平台 JBTabs，窄侧栏保持单行；空间不足时由平台压缩或提供溢出入口。
- 底部快速预览的分隔条跟随 IDE 主题，避免深色主题出现白边。

### 验证过程中的失败记录

前期主工作树与 JDK 24 录制任务共用编译输出，出现 Java 21 测试进程加载 class version 68 的失败；转入独立工作树后消除。隔离工作树首次因缺少 demo 路径在端到端前置检查退出，改显式参数后通过。早期 7170 / 7177 测试读数及中间包哈希均不代表最终包。

一次端到端运行因 8082 被其他应用占用而误读旧服务的 HTTP 200，随后 11 项断言失败，旧清理逻辑还可能按端口误杀占用者。脚本现从指定应用端口起搜索连续 11 个候选，向 Spring Boot 显式传入端口，并生成同端口的探针请求脚本；Windows PID 清理须匹配本轮 agent HELLO。受控占用 19080 的实测自动切到 19081，**26 PASS / 0 FAIL**，占用者仍在，直到测试方主动停止。该脚本修复已用于最终成功门禁，不改变插件功能。
