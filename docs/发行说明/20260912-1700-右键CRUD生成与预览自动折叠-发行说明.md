# 🎉 SQL Visualizer v2026.9.14-beta.1（内测版）

> 内测版留档：Gitee 抢先体验通道发行版，标签 `2026.9.14-beta.1`，附件 `mybatis-plus-sql-visualizer-2026.9.14-beta.1.zip`。
> 本内测系列（beta.1 起）的全部更新内容将在正式版 `2026.9.14` 发行时统一并入正式版更新日志；对外更新清单只保留最新一个 beta 版。

自 v2026.9.11 后的内测首发（34 个提交，代码交付 3 项新功能 + 3 项修复）。本版主题是**右键直出 CRUD SQL**：实体类、数据库表右键一步生成四类语句；同时上线宽表预览的字段列表自动折叠，并把三处「全选/全不选」双按钮合一为状态切换按钮。

## ✨ 新增

**实体类与数据库表右键生成 CRUD SQL（T-CrudSql）**
- 双入口：实体类右键（编辑器 + 项目视图，自动识别 MyBatis-Plus 注解实体）与 Database 工具窗表节点右键，一键产出 INSERT / UPDATE / SELECT / DELETE
- 候选选择为原生浮层（Recent Files 式）：打字按摘要过滤、Enter/双击选定、ESC 关闭，主题色双行渲染（加粗摘要 + 等宽代码行详情），明暗主题自适应；选中后进入既有 SQL 预览窗口，不新增弹窗
- INSERT / UPDATE 复用批量列勾选模型：自增主键默认不勾，`@Version` 乐观锁列 SET 尾 `= version + 1` 并追加 WHERE 条件；实体含 `@TableLogic` 时自动给出逻辑删除变体
- 无主键表降级 `WHERE 1 = 0` 占位提示；Database 为可选依赖，Community 版仅实体侧入口，优雅降级

**SQL 预览字段列表自动折叠（T-AutoFold）**
- 宽表 SQL 列清单逐行展开、定位 FROM/WHERE 困难——新增「SQL 预览字段较多时自动折叠」配置项（默认关）：列清单 / VALUES 组 / UPDATE SET 顶层元素数达到阈值（默认 10）且跨多行时折叠为占位行，点击即展开，阈值可配
- 覆盖全部六处预览编辑器（主预览、原生 Database 控制台、日志单击预览、SQL→Java 结果区、SQL 输入编辑器）；关闭开关时渲染行为与旧版逐字节一致

**全选/全不选按钮合一（T-SelToggle）**
- 预览「动态条件」「批量列」两分区与日志「类型过滤」弹窗三处并排的「全选」「全不选」按钮各合并为一个随勾选态切换文案的单按钮：全勾显示「全不选」点击清空，其余状态显示「全选」点击补满；点击行为与 SQL 产物零变更

## 🐛 修复

- **SQL 转 Java 选类重渲染异常逃逸 EDT（T-PickMpjErr）**：SQL→Java 弹窗选定目标类后重渲染时，设计内的 MPJ 业务异常从鼠标回调逃逸为未处理异常——收口为单点拦截，转状态栏提示并保留上次渲染结果
- **MPJ 括号条件反向转换退化 + 262 预览控制台静默挂载失败（T-ReverseParenWira）**：两项修复于 v2026.9.11 打标签后交付、未入该版发行包，随本内测版发出——① ON/WHERE 括号单条件被解析成条件组致 MPJLambdaWrapper 退化字符串形态，解析器单条件括号直接解包；② 262 平台 attachConsole 裸 EDT 读权限硬抛致原生控制台从未挂载，包 WriteIntentReadAction 修复
- **定时回归测试弹用户系统浏览器（HelpAction 回退守卫）**：自动化任务跑全量测试期间宿主机默认浏览器被反复拉起——测试沙盒降级分支不经隔离直接拉起真机浏览器，三处降级出口收敛为单点并在单测模式短路

## 🧪 测试

- **CRUD SQL**：`CrudSqlGeneratorTest` 11 例 + `DbTypeQuoteHintTest` 3 例 + `CrudSqlPreviewFlowTest` 3 例，真机反馈轮补弹窗回调/双击直开/六语句喂真实面板防回归 6 例
- **自动折叠**：`SqlAutoFoldPlannerTest` 12 例（纯逻辑零平台依赖）+ `SqlAutoFoldingTest` 5 例（含只摘本方折叠区域守卫）+ 六点位行为 5 例 + 设置台账/导入导出断言
- **按钮合一**：新建 `SqlLogPanelTypePopupToggleTest` 6 例（文案随勾选态翻转/部分勾选回填/重建初始化），既有用例迁移单按钮
- 本版全量 **3353/0/0/6 绿**，与基线一致零回归

## 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；执行 SQL、表右键入口与 Database 原生图需 Ultimate）
- 表右键 CRUD 入口注册于 Database 视图弹出菜单，可选依赖缺席时不出现该入口，插件功能不受影响
- 自动折叠为纯程序化 FoldingModel，绝不触碰平台 ConsoleFolding 既有折叠区；默认关闭零影响

## 📦 安装（内测通道）

1. 下载附件 `mybatis-plus-sql-visualizer-2026.9.14-beta.1.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装 v2026.9.11+ 用户：设置页「更新」分区检查更新即自动收到本内测版（Gitee 抢先体验通道），自 v2026.9.11 起经该通道更新免重启即时生效
