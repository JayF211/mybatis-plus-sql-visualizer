# MyBatis-Plus SQL Visualizer v2026.8.20

> 发行说明留档：对应 Gitee 发行版 **v2026.8.20**（标签 `v2026.8.20`），附件 `mybatis-plus-sql-visualizer-2026.8.20.zip`。

自 v2026.8.19 后的第八个版本。本版核心主题是 **参数导入交互体验升级**（P-05.1：手动输入弹窗 + 驼峰/下划线自动匹配 + 清除按钮）与 **内存泄漏修复**（面板 Disposer 树注册 + 历史召回弹窗移除）——同时完成 SQL 监听手动启动无需等待项目运行（armed 态）+ 解析兼容性提升（前缀与 SQL 分行形态）。

## ✨ 本版新增（相对 v2026.8.19）

**参数导入交互体验升级（P-05.1）**
- **手动输入弹窗**：`ParamImportDialog` 取代直接读取剪贴板——点击「导入参数」按钮弹输入框，顶部工具栏含「格式化」（JSON 美化 / 非 JSON 归一）+「清除」图标按钮；多行输入框带灰色占位示例（支持 JSON / CSV / key=value 格式提示）；剪贴板有合适参数时预填原文，用户可在此基础上修改后确认导入
- **驼峰/下划线自动匹配**：`CaseFormatUtil` 工具类实现 camelCase ↔ snake_case 双向互转；`resolveSource` 三级 fallback（精确命中 → 去 `#` 前缀精确命中 → 驼峰/下划线互转命中），解决数据库列名（snake_case）与 Java 字段名（camelCase）命名风格不一致导致导入参数无法匹配的问题
- **清除按钮**：动态条件分区和批量参数列分区标题行新增「清除」按钮——一键清空该分区所有参数值（不影响勾选态），清空后 SQL 立即恢复 `?` 占位形态
- **参数面板顶部对齐**：参数行由垂直居中改为顶部对齐（`BorderLayout.NORTH` 包裹），参数少时不再悬在面板中央

**内存泄漏修复**
- **SqlPreviewDialog Disposer 注册**：预览弹窗的 `SqlPreviewPanel` 注册到弹窗 `disposable` 树，弹窗关闭时级联释放面板及其 messageBus 连接，避免 IDE 退出时 ObjectTree 报 "Memory leak detected"
- **SqlLogPanel / SqlToJavaPanel Disposer 注册**：子面板（`logToSqlPanel` / `sqlToJavaPanel` / `inputEditor`）注册到父面板 Disposer 树，父面板 dispose 时级联释放子面板及其 DocumentListener

**SQL 监听行为完善**
- **手动启动无需等待项目运行（armed 态）**：点击捕捉按钮立即进入 capturing 态（⏸），项目启动后自动捕 SQL——无需等待项目完全启动后再点捕捉
- **启动行为区分（manual/auto）**：`userArmed` + `logAutoCaptureSuppressed` 持久标志——手动停止后重启不再自动开启；设置优先（autoStart=true 时项目启动始终自动捕捉）
- **解析兼容性提升**：SQL 日志解析兼容前缀（如框架附加的时间/线程前缀）与 SQL 分行形态（多行 SQL 正确合并解析）

**测试调整**
- **移除历史召回弹窗**：`showRecalledHint` 移除（仅在非 unitTestMode 弹 info，测试缝绕过导致该提示从未在测试中被验证；弹窗交互也由新弹窗取代）
- **新增测试**：驼峰/下划线互转 4 例（camel→snake / snake→camel / `#`前缀+驼峰 / 精确优先）+ 清除按钮 2 例（动态条件 / 批量参数列）+ 弹窗态端到端 1 例

## 🔧 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；执行 SQL 需 Ultimate）
- Plugin Verifier 已验证 2024.3 / 2025.3 / 2026.2 三版本 0 Internal + 0 Scheduled-for-removal

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.8.20.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装旧版：设置页「更新」分区可直接检查更新下载安装（Gitee 渠道），或按上法手动安装覆盖
