自 v2026.9.14 后的正式版。本版主题是 **回滚链打通 + 增强捕获可靠性大修 + 错误定位全链修复 + MCP 能力上线**：预览面板一键生成回滚 SQL 并打通 SQL Server / 达梦的自增列包装；增强捕获的控制通道解析错位、30 秒必掉线、停采后无法恢复三项顽疾根治；错误定位按钮、Oracle 报错位置、执行计划索引建议等一批「看得见但不工作」的缺陷逐项收口；面向 AI agent 的 MCP 能力全新上线（十个确定性只读工具 + 设置页门控）。内测系列内容（界面原生化首轮、并发日志分桶、历史全量化、设置真实性收敛）全部随本版转正。

## ✨ 新增

**一键生成回滚 SQL**
- 预览面板「更多」菜单首项「回滚 SQL」：对当前预览的 INSERT 推导逆向 SQL（整行等值谓词 DELETE，NULL 走 `IS NULL`），弹窗展示并一键复制；UPDATE / DELETE 无 before-image，改走快照查询 + 粘贴回填的人工恢复路径
- 回滚链与 CRUD 链的 INSERT 打通**自增列包装**：SQL Server 与达梦对「显式给自增列赋值」的拒绝同形，现统一产出 `SET IDENTITY_INSERT … ON/OFF` 包裹；取不到自增列（如表尚未内省）时明确告警，不再静默产出必失败的 INSERT
- 执行 UPDATE / DELETE 前的确认浮层对批量等值删除给出「可合并为 `DELETE … WHERE id IN (…)`」单行参考（仅预览参考，执行仍逐条原样）

**新增 MCP 能力：十个面向 AI agent 的确定性只读工具**
- 接入平台 MCP Server，外部 agent（Claude Code / Cursor / AI Assistant / Junie 等）可直接调用：`sqlv_render_sql`（源码 / mapper 片段渲染真实可执行 SQL）、`sqlv_schema_context`（表列注释上下文）、`sqlv_explain`（七方言执行计划）、`sqlv_render_logs`（日志还原可执行 SQL）、`sqlv_check_sql`（写风险与类型核查）、`sqlv_rollback_plan`（回滚预案，只产出不执行）、`sqlv_perf_advice`（性能建议）、`sqlv_crud_sql`（实体生成 CRUD 四件套）、`sqlv_reverse_sql`（SQL 转 MyBatis-Plus 代码）、`sqlv_mapper_check`（mapper 契约核查 + 渲染产物分析）
- 全部只读、每次调用落审计，执行结果进 SQL 历史；设置页「MCP 工具」子页支持总开关与逐项启用/禁用，即时生效。MCP 能力需 IDEA 2025.2+（内置 MCP Server）

**执行安全**
- 执行 UPDATE / DELETE 前的确认框在命中无界写特征时列出发现（无 WHERE 全表、恒真条件、`LIKE '%'` 纯通配等），无发现时零打扰
- 含 `${}` 直接替换的预览在「执行 SQL」与「EXPLAIN」前弹确认框；预览面板对含 `${}` 的产物显示非模态提示横幅；复制产物头部带 `-- contains ${} raw segments` 注释让风险随产物走

**数据库方言智能推断**
- 方言默认改为「智能推断（跟随数据源）」：增强捕获连接的 JDBC URL 优先，IDE 数据源配置次之；设置页全局与项目级各有哨兵项与推断结果状态行（含依据），手动选定后按手动值生效。升级后未动过方言设置的老用户自动进入推断模式（原默认 MySQL）

**实体列名数据源校正**
- 实体字段名与数据库真实列名不一致时（库 `order_id` / 实体 `orderID`），按「精确命中 → 归一化唯一命中 → 否则原样保留」的保守口径，用数据源真实列集合校正实体列名，覆盖列清单、逻辑删除列、乐观锁列、复合主键列与 JOIN ON 外键列；默认开启，无可用数据源时行为与改造前完全一致

**预览可读性**
- **空白符可视化开关**：插件自建的全部 9 处编辑器用 `·`/`→`/`↵` 标出空格、Tab 与行尾，排查动态拼接 SQL 里的多余空格一眼可见；默认关闭（跟随 IDE 全局偏好）
- **INSERT 目标列提示**：多列动态 INSERT 的每个 VALUES 表达式旁标出目标列名，「列-值错位」一眼可见；静态不可判时不提示
- **foreach 集合快捷别名**：`<foreach collection="list">` / `"collection"` / `"array"` 按 MyBatis 参数命名语义补齐，未写 `@Param` 的集合参数不再静默少展开
- **跨命名空间 include**：`refid="其它命名空间.片段id"` 在项目内定位目标片段合并展开，`${}` 动态 refid 与动态标签照常渲染，失败给出具体原因
- **动态条件预检标注**：超出受限表达式支持面的 test 条件（三元、静态方法、`new` 等）带淡色标注说明原因，不再「看起来展开了、其实没算」
- **参数面板类型契约**：按方法签名给数字/日期/集合/对象占位提示与行尾校验警示；设置页新增「空参数填充策略」（NULL 字面量 / 空字符串）

**捕获与诊断**
- **启动即捕获**：增强捕获经 `-javaagent` 在目标 JVM 的 premain 阶段完成织入，应用启动阶段（框架初始化、数据源探活、迁移脚本）发出的 SQL 直接进增强通道，不再依赖挂载后补捞；未同意注入时零注入，任一步失败只回落既有 attach 与桥捕获
- **执行错误同列展示**：控制台的 SQL 执行异常行（MyBatis `###` 错误块、Spring DAO、JDBC 异常家族、参数绑定报错）不再被静默丢弃，反向绑定到时间窗内最近条目，预览详情含报错全文与复制按钮
- **日志条目直跳 Mapper XML**：携带 mapper 语句信息的条目右键直达 XML 语句节点，失败回退跳 Java
- **方法级 / 请求级聚焦页签**：右键「聚焦调用方方法」或「按请求聚焦」，只看该方法区间 / 该请求内发出的 SQL，与类型过滤、搜索正确叠加
- **执行链超时护栏**：新增「执行超时」设置（默认 30 秒，0=不限），挂死查询不再永远停在 loading
- **错误定位跳转**：执行报错富化 SQLState / 驱动错误码与驱动报告的出错位置，结果面板一键跳到出错语句；MCP 侧错误附 `errorPosition` 行供外部 agent 自修复
- **错误上报分级脱敏**：默认只预填异常类名、栈帧摘要与指纹，异常消息全文与完整堆栈降为可勾选附加
- **断连后 DDL 生效性探测**：执行 CREATE 类 DDL 时连接断开，后台自动探测对象是否已建出并如实警示，绝不把「没查到」包装成「没生效」
- **驱动 notices 通道**：PostgreSQL `NOTICE`/`WARNING` 等驱动消息随 MCP 输出透出，外部 agent 不再盲飞
- **执行计划索引建议**：识别全表扫描等低效模式后在输出尾附索引建议（MySQL 与 PostgreSQL 两方言先行，只提示不执行）
- **首用引导**：首次打开 MyBatis-Plus 代码弹一次指路通知（可关）、面板空态补引导文案、首次捕获成功直达工具窗
- **缺源码跳转引导优先增强捕获**：SQL 条目无源码位置时的「无法跳转到源码」引导弹框按全局增强捕获状态分支——未开启 / 未授权时默认按钮让位「开启增强捕获」，一键置总开关并复用既有授权确认流（同意后提示重启应用生效）；已开启已授权时维持原出口并附一行实时状态
- MySQL 客户端习惯的 `\G` 后缀粘进预览 / 控制台不再报语法错；`DELIMITER $$` 自定义界符脚本不再被切碎；XML 内联 DTD 增实体声明数 / 展开深度 / 字符数三道防护

## 🔧 改进

- **性能收敛**：点击预览后控制台 SQL 区固定等待约 2 秒的阻塞消除（连续预览同一 SQL 的主路径不再白付落盘与等待）；捕捉开启时控制台日志不再双路解析（解析成本减半）；inlay 规划、schema 上下文、负命中元数据查询等高频路径补进程级缓存；历史文件裁剪、设置变更落盘加节流与限批
- **设置导入不再静默重置未导出的配置**：改为「以现值为底逐键覆盖」，参数历史、增强捕获授权记忆、保存路径等 56 个未导出字段不再被悄悄清空
- **项目级设置完善**：总开关关闭时 9 行置灰并显示全局生效值（所见即所用），新增「重置为跟随全局」一键清空覆盖；项目级设置页 10 项进设置搜索索引，同一关键词同时列出全局与项目两个作用域
- **EXPLAIN 包装链硬化（行为变更）**：点「执行计划」不再对任意文本加 EXPLAIN 前缀——DML/DDL 与标识符一律明确拒绝，只放行只读查询表达式
- **三套语句切分收敛为单一状态机**：字符串 / 注释 / 存储过程块内的分号不再误切，`BEGIN…END` 块与 `CASE…END` 计数感知，T-SQL 裸 `IF…; ELSE…;` 控制流批整批不拆
- **JOIN 图与补全**：JOIN 表改整表列口径（与主表同待遇，>50 列只留主键）；数据源字段补全恢复（此前 schema 读取链从未成功执行过一次）且数据库列进补全候选；JOIN 图字段注释按库 COMMENT 回填
- **更新包解压有界化**：自更新 zip 过条目数 / 单条目 / 累计三重上限守卫后才进平台解压器，zip 炸弹拦在安装前
- **注入确认不再反复打扰**：拒绝记忆 24 小时冷却、非主配置进程静默跳过、新增「关闭增强捕获并不再询问」一键持久化关闭（内测系列反馈收口）
- 语句注释命名标注（`-- Name: x`）、多语句 MCP 输出按名分节、错误报告去抖上限、日志时间格式化复用等长尾收敛

## 🛠 修复

**增强捕获（本版重点）**
- **控制通道 CONFIG 帧解析错位（P0）**：应用侧读帧先读命令后读长度，与 IDE 侧写序相反——停采 / 脱敏 / 帧过滤三条指令从未生效，开关是「未捕获」列表却在进条目。现统一「先长度后命令」，畸形帧告警后重连不再静默吞
- **会话建立后 30 秒必掉线**：心跳计时假定每轮 200ms 而实际约 1.2s，首条心跳永远赶不上 30 秒在线窗口。现按墙钟差判定、连上即补发心跳，实测稳定约 10.7s 一发
- **掉线后无法恢复**：监听 socket 只 `accept()` 一次，应用已在运行时重挂载永不触发，一次摘除即终局。现改循环 accept，通道寿命绑定本次运行
- **停采 → 恢复后永久零事件（P0）**：连接出口判停采直接返回原连接，停采期间建立的连接永远不被包装，连接池复用放大为整条链失效。现连接级一律包装、停采只做逐调用短路
- **捕获源码位置被首个查询钉死**：调用方缓存把共享库帧（如 MPJ 拦截器）的首个行号永久服务给后续所有语句。现判定缓存按当前栈现算行号，共享键被改写即自愈
- **子类加载器下织入静默失效**：Spring Boot fat jar / devtools 的驱动加载器看不见代理类，异常被吞、零事件零日志。现逐个加载器实测校验、失败给一次性告警并返回原对象不再向宿主抛
- **增删改语句捕获不到源码位置**：调用方缓存把 null 位置也缓存且不自愈，现仅缓存有效位置
- 控制通道新增回执确认（5 秒未收到 ACK 告警）与 fail-open 看门狗（15 秒未收到任何配置即主动停采，损害从无界压到 15 秒）；监听关闭时入站事件丢弃并计数，面板不再「说谎」；空态诊断行超宽截断修复（提示语现在完整可见）；状态行把「等待首条心跳」与「心跳停摆」分开叙述，不再断言它不知道的原因

**错误定位与执行计划**
- 「定位到出错语句」按钮在无项目上下文 / 锚点未登记 / 源文件失效时不再「可见但点了没反应」——先解析锚点再决定给不给按钮
- Oracle 报错位置此前被 PG 正则顺带命中、挂着错误标签且恒差一位，现按 Oracle 专属形态归一；只有行号的报错（MySQL 语法错）如实显示驱动行号
- 位置越界钳制在四处生产投递点全部接线（此前只在单测生效）
- PostgreSQL / KingBase 的执行计划索引建议实际永不触发（`FORMAT JSON` 输出与文本树正则错配），现按输出格式分派解析器，真库实测生效

**回滚链与方言**
- 带引用符的表名（`[user]` / `"user"` / `` `user` ``）原样送进解析器致表结构取不到，现剥引用符；SQL Server 方括号语句在回滚弹窗直接解析崩溃，现统一走带方括号支持的解析入口
- Oracle 目录来源含小写的标识符加双引号（裸写必报 ORA-00942），实体来源逐字节不变；H2 裸标识符实测折为大写、归属订正；PG 族目录来源含大写名按族加引号
- 达梦与 SQL Server 同用自增列包装（此前仅 SQL Server 产出，达梦上勾回自增列的 INSERT 必失败）

**HQL / JPA**
- 显式实体 JOIN 的副表别名属性不再原样透传（`detail.pickTicketId` 正确映射为 `pick_ticket_id`）；`@Embedded` 嵌入对象路径展平（`pickTicket.updateInfo.createdTime` → `pickTicket.created_time`，此前产出无效 SQL）；实体继承 / 抽象类「列信息未解析」降级修复（内测系列）

**预览与执行链**
- 服务端 SQL 报错不进预览面板错误条：判据升级为「`[SQLSTATE][错误码]` 结构性前缀 + 厂商报文短语族 + 未知形态兜底呈现」，MySQL 语法错不再被归因成密码 / 驱动问题
- 预览会话库上下文对齐（执行文件被 DBN 映射到另一个库时如实标注并自动对齐 URL 库）；预览控制台格式化显示回归修复；执行文件「文件缓冲区冲突」连环根治（五轮：同临界区落盘、控制台侧窗口清零、裸写兜底退役）；`Write-unsafe context!` 报错根治（写入上下文闸门 + 动态热更新派发改判）
- 冷启首开降级后预热成功可原地恢复，硬失败给「重试」动作；JOIN 图连线丢失修复（旧图释放整表清空虚拟外键注册表）；JOIN 图默认自适应居中与加载态接线；预览参数区背景丢失修复
- 占位符回填与「复制可执行 SQL」改串感知位点，字符串与注释里的 `?` 不再被误换；多项目同开时表配置按实体所属项目取；共享控制台复用与数据源记忆升级为 UUID 身份 fail-closed，同名多条数据源不再静默取首条
- T-SQL 裸控制流批、`SELECT INTO OUTFILE` / `EXPLAIN ANALYZE` 等只读豁免盲区收窄（fail-closed）

**设置与界面**
- 增强捕获确认框「同意」曾被记成「拒绝」——经界面完全无法授权的根因修复；确认框第三个按钮从未渲染（属性声明顺序）修复；未授权后设置页新增「重新授权」入口
- 设置页双击跳转不再把整棵设置树实例化（EDT 慢操作卡顿根治）；捕捉开关回归面板工具栏（新 UI 标题栏悬停才渲染致入口「消失」）；右键菜单「SQL 快捷模板」显示原始键修复；帧过滤前缀输入框压扁不可见修复；定时回归任务不再弹出真机浏览器；设置页打开多次泄漏面板修复
- 批量错误报告合并为单个弹窗；历史裁剪只认插件命名文件族，自定义目录用户脚本永不删除；SQL 历史全量化与打开防卡顿；日志 / 历史时间来源切换、行号时间搜索与排序选择器（内测系列）
- 界面组件全面原生化首轮：原生 SpeedSearch、平台通知、原生右键菜单与工具栏、加载态与占位符、配色跟随主题（内测系列）

## 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；EXPLAIN、执行 SQL、表右键入口与 Database 原生图需 Ultimate）；MCP 能力需 **2025.2+**
- **增强捕获默认开启**：首次运行项目会弹一次注入确认，同意后生效并持久记忆；拒绝则 24 小时内不再询问，控制台捕获照常回落零劣化。脱敏默认关闭，设置页可开启打码
- **方言智能推断成为默认**：升级后未手动选过方言的老用户自动进入推断模式（原默认 MySQL），手动值原样保留
- **EXPLAIN 硬化**：此前「任意文本都能点执行计划」的场景现在会被明确拒绝（只放行只读查询）
- 标识符引号行为变化：Oracle / H2 / PG 族目录来源标识符按大小写与折叠方向加引号，达梦勾回自增列的 INSERT 自此带成对包装
- 历史文件与回滚快照格式向后兼容（新增字段缺失即按旧行为处理）；插件 ID 与升级链路不变，v2026.9.14 及 beta 系列用户可直接覆盖升级

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.9.23.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. Marketplace 用户：市场页直接更新；Gitee 通道用户：设置页「更新」分区检查更新即自动收到本版，自 v2026.9.11 起经该通道更新免重启即时生效
