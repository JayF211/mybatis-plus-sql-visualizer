# 🎉 MyBatis-Plus SQL Visualizer v2026.8.14

> 发行说明留档：对应 Gitee 发行版 **v2026.8.14**（标签 `v2026.8.14`），附件 `mybatis-plus-sql-visualizer-2026.8.14.zip`。

自 v2026.8.13 首发版后的第二个版本。本版完成**官方 API 覆盖差距清零**（MP 3.5.17 / MPJ 1.5.9，P0~P2 全量）与**批量操作路径增强**（用户实测驱动），并新增**多 SQL 选择定位**、**SQL 关键字方言化引用**、**9 种数据库方言**；测试 282 → 507 全绿。

## ✨ 本版新增（相对 v2026.8.13）

**官方 API 覆盖差距清零（M19.5 ~ M22）**
- 实体单条 CRUD：`save` / `getById` / `listByIds` / `selectByIds` / `deleteByIds`
- 工厂与链式：`JoinWrappers` / `MPJWrappers` / `ChainWrappers`；服务链赋值形态（实体/boolean/long 三形态）gutter 锚点修复；`service.query()/update()` 字符串链
- 消费方法全集：`selectCount` / `getObj` / `selectJoinMaps` / `selectJoinPage`；Map 条件消费（`selectByMap` / `listByMap` / `removeByMap` / `deleteByMap`）；BaseMapper 批量族（`insert` / `insertOrUpdate`）；`getOptById` / `removeBatchByIds` / `saveOrUpdate(entity, wrapper)`
- 逻辑删除精确化：六方法主/副表独立开关 + ON/WHERE 位置；`enableLogicDel` / `logicDelToWhere` / `logicDelToOn` / `disableLogicDel` 四形态
- 联表扩展：join 4/5 参（rightAlias / 子表 MConsumer / ext MFunction）、`selectCollection` prefix/free 形态、`selectFunc` 枚举映射、`from` 子查询主表、`union` / `unionAll` 子查询、`selectSub` 子查询列、**UpdateJoinWrapper / DeleteJoinWrapper 全链路**（多表 UPDATE/DELETE 渲染）；on 双字符串列对列比较
- 条件与语句补全：`allEq` 6 重载、`eqOrIsNull`、`setEntity`、`select(Class, Predicate)` / `selectFilter`、`nested` / `not` / `func`、`inSql` / `notInSql`、`eqSql` ~ `leSql`、`notLikeLeft/Right`、`setIncrBy` / `setDecrBy`、`having`、`comment` / `first` / `setAlias`

**多数据库方言（M22）**：新增 6 种——SQL Server（OFFSET..FETCH）/ H2 / SQLite（LIMIT..OFFSET）/ MariaDB / DM 达梦 / KingBase 人大金仓（共 9 方言，设置下拉自动同步）；`@Version` 乐观锁注入；Db / SimpleQuery / ActiveRecord 识别

**SQL 关键字方言化引用（M23.4 ~ M23.5）**：按方言判定保留字并引用（反引号 / 双引号 / 方括号），`table` 等关键字字段不再裸奔——覆盖 SELECT 全列 / WHERE / 批量模板 / 解析期拼接（查询路径六处）；`apply` / 原生字面量维持不处理

**批量操作增强（M23 系列，用户实测驱动）**
- 批量逻辑删除/软删除对齐：`@TableLogic` 批量 SELECT 自动追加 `deleted = 0`；有 `@TableLogic` 时 `removeById` 等自动转 `UPDATE ... SET deleted = 1` 软删除
- 批量参数面板：`save(entity)` 每个 `?` 登记参数行、实参字面量内联、按列类型回填引号（数值类型白名单外一律加引号）
- 参数列级勾选：`save` 自增主键（IdType.AUTO）默认不勾选、`updateById` SET 可按需取消、**全选/全不选**、`saveOrUpdate` 主键可选（取消 → 纯 INSERT）
- 字段顺序角色分组：主键置顶、自动填充审计字段沉底（BaseEntity 继承场景）

**触发与选择体验（M23.6 ~ M23.8）**
- 任意位置触发：光标在 `eq` 调用处 / `.list()` 链尾也可触发预览
- 多 SQL 选择：选择代码块右键 → 自动扫描候选 → 多个时弹选择框（摘要 + 代码行预览 + 定位跳转，IDEA Find 风格）
- 选择区候选扩展至批量方法调用
- 复制 / 执行 SQL 成功提示新增「关闭 SQL 面板」一键按钮
- 多 SQL 弹窗 EDT 慢操作修复（候选预计算，不再在 UI 线程解析 PSI）

**修复与质量**：弹窗关闭按钮文案走插件自身语言包（不再随 IDE 语言显示英文 Cancel）；打包编译警告清零；jar manifest 保留 MPV-Build 内部构建号（每次构建唯一）；**本版另含三项用户实测修复（T-M23.10~12，507 测试全绿）**——① **MPJ 联表主表逻辑删除条件补主表别名**（`AND deleted = 0` → `AND t.deleted = 0`，多表 JOIN 下裸列名与副表 deleted 歧义；DeleteJoin 多表删除、UpdateJoin + @Version 乐观锁同病同治，单表输出不变）；② **gutter 预览图标去重**（`selectAll` 批量注册表与 MPJ 链方法撞名导致双图标、嵌套条件 lambda 参数被误标导致三图标——均已修复，每链恒一个图标）；③ **服务链/工厂形态 SELECT 展开列对齐实体全列**（与真实 IDE 一致）。

## 🔧 兼容性

- 支持 IntelliJ IDEA **2025.3+**（Ultimate / Community；执行 SQL 需 Ultimate）
- Plugin Verifier 已验证 2025.3.1 / 2025.3.5 / 2026.2.1 三版本 0 问题

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.8.14.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
