# 🎉 SQL Visualizer v2026.9.9

> 发行说明留档：对应 Gitee 发行版 **v2026.9.9**（标签 `2026.9.9`），附件 `mybatis-plus-sql-visualizer-2026.9.9.zip`。

自 v2026.9.8 后的下一个版本（13 个提交）。本版主题是 **发行后一日内的集中修复、功能转正与发行前插件校验常态化**：单击预览两轮打磨（编辑器高亮与列表同色 + 可编辑焦点修复、复制按钮对号反馈）、双击预览无数据源时 Database 工具窗抢占侧边栏修复、2026.2 平台 verifyPlugin 字节码级兼容问题修复（市场发布受阻解除）、发现 SQL 自动打开日志窗口假开关复活（dev 全量移植）、dev 已修缺陷与假开关批量移植处置（转换语义六处 / 定位误报两处 / 导入导出行内反馈 / INSERT 租户开关接线）、启动项目清除自动展开抑制与「关闭工具窗口时停止监听」开关转正恢复；发行当日又追补四项——SQL 日志列表行号（会话内捕获序号）、预览刷新后内嵌 Database 丢失根治（多弹窗僵尸监听）、执行临时文件失败可见化与复制错误反馈、预览点击侧边栏闪烁根治，并将三处弃用 API 换现代等价物使三平台兼容性报告再收敛。

## 🔧 修复（相对 v2026.9.8）

**单击预览四轮优化：编辑器高亮与列表同色 + 可编辑修复（T-ClickPreview-04）**
- ① 预览编辑器高亮改与 SQL 日志列表**同源同色**——新增 `SqlListSyntaxHighlighter`（SqlLexer 分词 + SqlHighlightColors 配色），token→配色键映射收敛为唯一权威 `ATTR_BY_TYPE`，列表片段渲染与预览编辑器高亮共用（改色只动一处）；不再依赖 Database 插件与平台 SQL FileType，无 Database 插件环境同样有高亮
- ② 修复「还是不能编辑」——根因=弹窗不抢焦点导致键盘输入全落在列表上；现弹出即聚焦编辑器可直接打字（复制/关闭按钮不抢焦点不变）

**单击预览五轮优化：复制按钮对号反馈（T-ClickPreview-05）**
- 复制按钮点击后图标即时闪变为**对号**，1500ms 后自动恢复——复制成功即时可见（此前点击无任何视觉反馈）

**双击预览无数据源时 Database 工具窗抢占侧边栏（T-DsCover）**
- IDE 未配置数据源（或驱动未下载）时每次双击开预览，Database 工具窗都被拉起覆盖插件侧边栏——根因=预览总入口末尾无条件 `prepareDefaultConsole()`，无数据源分支每次调 Database 工具窗 `show()`；现改为仅显式执行 SQL 才引导开窗，预览路径失败静默且清损坏数据源的 last-used 记忆；成功路径（有数据源预览内嵌 DBN 原生工具栏）零改动

**IDE 2026.2.1 双击预览潜在必崩修复 + 插件市场发布受阻解除（T-Wia262）**
- 三版本官方兼容性校验（verifyPlugin）在 2026.2 平台报字节码级问题：上版双击预览崩溃修复所用的 `WriteIntentReadAction.compute(ThrowableComputable)` 重载在 262 平台已移除，真机会 `NoSuchMethodError`——改用三版本交集重载 `compute(Computable)`（锁语义与执行路径零变化），复跑三版本校验 0 兼容性问题

**发现 SQL 自动打开日志窗口失效（T-AutoShowMaster）**
- 「发现 SQL 自动打开日志窗口」设置自 F-44 删独立窗口起为**纯假开关**（设置项/勾选框残留、生产代码零读取点）——自 dev 全量移植复活实现：无条件 buffer 监听（首条捕获即触发）+ 60s 防抖 + 主工具窗 show 不抢编辑器焦点 + 用户手动关窗本会话抑制 + 设置重新开启解除抑制；默认值改为**开启**（已持久化关闭的用户不受影响）
- 平台实证：监听器须 `com.intellij.openapi.wm.ex` 包——非 ex 包不在裁剪发行版（243 平台 599 jar 全量扫描实证）

**dev 已修缺陷批量移植（T-PortLossBatch1 A~C 组）**
- 转换语义六处：`ne` 渲染 `<>` 对齐 MP 语义（三转换器）、`or(Consumer)` 外层 OR 组内 AND 组合修正、`condition=false` 前缀子句整体跳过、having 字符串版透传、`last(...)` OFFSET 回填、负数字面量静态求值
- 定位误报守卫两处：非 MP 服务链 `new Helper().lambdaQuery()` 不再误识别为锚点；PartTree 方法仅 Repository 接口产出 gutter 标记
- 设置导入导出改**行内提示**（原模态弹窗叠在 Settings 对话框下不可见），IO 移后台线程 + 模态存续期照常回调

**假开关批量处置（T-PortLossBatch1 D 组）**
- 「INSERT 时追加租户列」子开关接线生效（对齐 MP `TenantLineInnerInterceptor` INSERT 语义；UPDATE SET 走主开关）；「自动注入 SQL 拦截器」tooltip 改为描述实际行为（勾选时立即生成一次）
- 设置页复选框计数 22→21

**启动项目清除自动展开抑制 + 「关闭工具窗口时停止监听」开关转正（T-AutoShowRecover）**
- 真机复测实证「手动关窗抑制置位后，启动项目仍不自动展开」与用户预期相悖——项目进程启动同样视为对自动展开的再次确认，启动时同步清除关窗抑制（autoStart 关闭时不动）
- 「关闭工具窗口时自动停止监听」开关**转正恢复**：该功能在 master 曾为真实现，此前以「master 无读者」的错误前提被整体下线用力过猛；现按基点原文选择性恢复 7 文件，恢复面与基点零内容差异

## ✨ 发行当日追补

**SQL 日志列表行号（T-LogRowNumber）**
- 列表条目元信息行最前显示 `#N` 会话内捕获序号（第 N 条捕获的 SQL），每次启动项目从 1 重新计数（手动清空列表同样归零）；去重丢弃/暂停/过滤命中的 SQL 不占号，列表不跳号；耗时排序下行号保持可辨认原始捕获顺序
- 序号在入队临界区分配，历史文件读回与 round-trip 条目不带行号；渲染走片段管线零结构变更，固定行高不受影响

**预览刷新后内嵌 Database 丢失根治（T-RefreshDbSteal）**
- 刷新后 DBN 工具栏消失/参数不再同步右侧 SQL/执行 SQL 跑到 IDEA 控制台三症状同根——每次预览 new 一个 MODELESS 弹窗且从不关闭，旧弹窗的 rehost 监听残活把插件级共享控制台抢回废弃面板（真机日志 6 连抢实锤）
- 四组修复：弹窗单例化（关旧开新）；监听引用入字段随 dispose 显式移除（僵尸监听根治），去抖跳过改单发延迟复查幂等重挂；所有权卫队——写 SQL/执行/回退建编辑器三处失联先重嵌恢复，执行侧恢复未落地时放弃执行防打在别人的控制台上；关键路径带栈埋点
- 新增 `RefreshDbStealTest` 8 用例；真机复验清单留人工

**执行临时文件失败可见化 + 复制错误反馈（T-ExecCopyFix）**
- 两处「复制错误信息」按钮点击无反馈——对号闪变反馈（图标换对号 + 文案短暂换「已复制」）
- 执行失败 Failed to create temporary SQL file 此前整段吞异常零日志——现分级记录每个失败站点与阶段原因，错误文案本地化并携带阶段原因；冷路径 VFS 刷新包 `WriteIntentReadAction`（262 平台 EDT-ReadAction 硬抛陷阱）；预览切换不再清临时文件缓存（消除每次执行必落冷路径）

**预览点击侧边栏闪烁根治（T-PreviewFlash）**
- 点击预览图标侧边栏列表闪一次像被刷新、idea.log 刷慢操作告警——根因：预览链覆盖写临时 SQL 文件 + VFS refresh 制造索引 dumb 窗口，dumb 退出时平台对控制台全文档重跑日志 filter，插件 filter 不幂等导致历史行被重放入库
- 修复：新增四态重放守卫（区分流式/重放/重置/混合，反射解析失败降级直连）；预览临时文件创建/刷新/查找全移后台线程有界等待（消除两处 EDT 慢操作热点）

**三处弃用 API 换现代等价物（T-DepApi）**
- `StdLanguages.JAVA` → `JavaLanguage.INSTANCE`、`FilenameIndex.getFilesByName` → `getVirtualFilesByName`、`Notification.setListener` → `BrowseNotificationAction`——三平台兼容性报告弃用 40→38、experimental 10→8，剩余四项经 javap 三平台核实无等价替换保留

## 🔧 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；执行 SQL 与 Database 原生图需 Ultimate）
- 三版本（2024.3 / 2025.1 / 2026.2）verifyPlugin 全绿——2026.2 平台字节码级兼容问题清零，弃用告警 40→38
- 行为默认值变更：发现 SQL 自动打开日志窗口默认**开启**（已手动关闭过的用户保持关闭）；预览不再拉起 Database 工具窗（仅显式执行引导开窗）
- 新增展示元素：SQL 日志列表条目带 `#N` 会话内捕获序号，每次启动项目重新计数

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.9.9.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装旧版：设置页「更新」分区可直接检查更新下载安装（Gitee 渠道），或按上法手动安装覆盖
