# 🎉 SQL Visualizer v2026.9.14

> 发行说明留档：对应 Gitee 发行版 **v2026.9.14**（标签 `2026.9.14`），附件 `mybatis-plus-sql-visualizer-2026.9.14.zip`。
> 本版为内测系列（beta.1 已发行 / beta.2 未发行）内容的正式版：beta.2 最终未在抢先体验通道放出，内容直接并入本版。

自 v2026.9.11 后的正式版。本版主题是 **dev 分支整体回合 + 合并反馈一日修复链**：SQL 列表 CRUD 类型颜色标记、日志与源码双向深链（gutter 左右键 + 最近执行反查）、真实 EXPLAIN 执行计划、错误一键上报、三种列表显示模式、更多 ORM 预览支持与全链路性能优化；随后一天内根据真机反馈连环修复十五项（合并语义丢失、显示模式切换错乱、多模块跳转与注入、执行计划重复前缀、预览数据源跨项目错乱、EDT 慢操作刷屏等）。

## ✨ 新增

**SQL 列表 CRUD 类型颜色标记（T-CrudColor）**
- SQL 日志页与「SQL 历史」页二级列表按语句类型着色：SELECT 蓝 / INSERT 绿 / UPDATE 橙 / DELETE 红（OTHER 不标记），类型判定与类型过滤弹窗同源
- 标记形态三选一：左侧 3px 色条（默认）/ 整行淡背景 / 关闭（关闭与改造前逐字节一致）；四色均可在设置页自定义，类型过滤弹窗同步显示色块图例
- 整行淡背景样式的选中态为「保留类型色调 + 2px 选中描边」而非平台填充——键盘上下浏览时颜色不丢失，耗时快/慢着色不再被选中态抹白

**日志与源码双向深链（M37 竞品融合）**
- Wrapper 链锚点 gutter 图标**左键单击直接预览**，**右键弹菜单**（「预览 SQL」/「最近执行记录」）
- 「最近执行记录」从源码反查：开启日志捕获后，右键即从本会话捕获记录里反查该位置附近的执行（同文件优先、行号 ±30 行内排前），选中打开带参数完整 SQL
- 多模块项目源码跳转容错（按模块 content root 逐个匹配）

**真实 EXPLAIN 执行计划（M37.2）**
- 预览面板「执行计划」按钮：按当前方言把 SQL 包装成 EXPLAIN 提交原生数据库控制台，真实执行计划与静态性能规则标注同屏对照
- MySQL / PostgreSQL / 人大金仓 / 达梦真机验证，H2 / SQLite 引擎级支持；Oracle / SQL Server 提示降级
- 依赖数据源（Ultimate Database 工具窗）

**错误与反馈一键上报（T-ErrReport）**
- IDE 内部错误对话框一键报告官网需求池（异常预填 + 堆栈附件 + IDE/插件版本自动携带 + 24 小时去重）
- 帮助菜单与设置页手动反馈入口；手动形态支持自主粘贴堆栈与「从错误池导入」

**SQL 列表三种显示模式（T-ListMode）**
- SQL 日志与 SQL 历史列表支持单行 / 关键字换行 / 格式化三种显示（工具栏下拉即时切换，默认关键字换行）；模式跨会话保留、两列表共享，Ctrl+C 复制仍为纯 SQL

**更多 ORM 预览支持（M39/M44）**
- Querydsl / EasyQuery / Xbatis / MDS 链式查询识别与预览
- Spring Data JPA 增强：Specification / QueryByExample 形态；JPA 元数据（`@Embedded` 嵌入列展开、`@Convert` 转换标记、`insertable`/`updatable` 不可插入/更新列跳过）

**实体类与数据库表右键生成 CRUD SQL（T-CrudSql，beta.1 起）**
- 实体类右键（编辑器 / 项目树，MP 注解实体）+ Database 工具窗表节点右键，一键产出 INSERT / UPDATE / SELECT / DELETE；候选浮层 Recent Files 式打字过滤，选中进既有预览窗口
- INSERT/UPDATE 列勾选重建：自增主键默认不勾、`@Version` 列自动 `= version + 1` 并追加 WHERE、逻辑删除变体；无主键降级 `WHERE 1 = 0` 占位提示

**SQL 预览字段列表自动折叠（T-AutoFold，beta.1 起）**
- 宽表 SQL 列清单逐行展开定位困难（官网需求池 FR-0017）——新增「SQL 预览字段较多时自动折叠」配置项（默认关）：SELECT/INSERT 列清单、VALUES 每组、UPDATE SET 四类顶层列表元素数达阈值（默认 10）且跨多行时自动折叠

**多选批量复制与历史行号（T-ListPreviewCopy / T-LogHistoryRowNo）**
- 两页列表 Ctrl/Shift 多选后右键一次性复制全部选中 SQL（逐条分号收尾、换行拼接，与 Ctrl+C 产物一致）；多选期间单击不再误弹预览浮层
- 单击预览默认跟随「预览时格式化还原 SQL」开关（默认开启），长 SQL 点开即多行缩进展示
- 「SQL 历史」二级列表按文件内条目顺序显示 #N 行号，搜索过滤下稳定不变

**多模块注入勾选选择（T-ModPick）**
- 多模块项目注入拦截器不再一律全模块生成：逐模块勾选弹窗（默认全选 + 全选/全不选，旧版待更新标注），单模块不打扰直注，取消即回滚

## 🔧 改进

- **自动监听被动模式**：开启「自动开始监听」设置后不再立即进入预捕捉状态，项目 Run 时才自动开始捕捉
- **性能系列（T-Perf）**：SQL 历史目录扫描与文件读取全部移后台（大文件不再冻结界面）；日志列表增量刷新（可见区差分）；渲染热路径零分配治理
- **全选/全不选双按钮合一（T-SelToggle）**：预览两分区与类型过滤弹窗三处并排按钮合并为一个随勾选态切换文案的单按钮

## 🛠 修复（09-14 一日修复链）

- **预览「执行计划」按钮合并丢失补回**：dev 合并中按钮行被 master 重构删除无冲突标记，补回内联高频位
- **gutter 右键菜单无反应根治**：243 平台 gutter renderer 基类不接右键，改走平台右键正解 API
- **显示模式切换后列表重叠错乱根治**：多次切换单行/换行/格式化后行高布局缓存不失效致内容挤压——强制重装列表 UI 使布局状态失效；下拉按钮与「SQL类型」单元完全同构
- **日志跳转仅信捕获位置**：移除 Wrapper 表名反查回退链（会把跳转指到同名表任意文件），缺位置时给出开设置/立即注入引导
- **多模块源码跳转三缺陷**：拦截器自位污染（改运行时实际比对）、包式/项目根式路径解析缺失（三级解析补 sourceRoots）、最近执行反查恒空（段对齐比较）
- **重复点击执行计划 EXPLAIN 前缀双加致 1064**：方言侧幂等包装单点收口
- **MPJ 联表列错归主表别名致 1054**：委托前按 join 映射重写列归属；**MPJ 括号条件反向转换退化**：单条件括号组直接解包，MPJLambdaWrapper 不再退化字符串形态
- **报告对话框真机反馈三波**：宽度/灰提示/可拖拽、堆栈勾选显隐窗口跳动、手动形态堆栈自主输入（粘贴 + 错误池按包名过滤导入）
- **报告需求池文案语言跟随 IDE**：AUTO 语言落点修正；嵌入平台 UI 的文案恒跟 IDE 语言走
- **旧拦截器自位污染残留自动升级**：手工拷贝的旧版拦截器位置恒显拦截器自身——解析防线丢弃污染标记 + 注入时自动识别并升级旧形态文件（用户自写文件永不覆盖）
- **预览执行链 EDT 慢操作刷屏**：方言映射两段式（后台探测 + EDT 落位），预热全离 EDT，idea.log 双 SEVERE 消除
- **预览补全缺失与执行数据源跨项目错乱**：临时文件缓存绑定项目、共享控制台被平台清扫后自动感知重挂、预览文件迁项目内 + 三级降级链
- **262 预览控制台静默挂载失败**：挂载调用链读权限断言硬抛被吞——按锁语义分包裹；**SQL转Java 选类重渲染业务异常逃逸**：收口转状态栏提示
- **定时回归测试弹系统浏览器**：帮助动作降级出口加单测模式守卫

## 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；EXPLAIN、执行 SQL、表右键入口与 Database 原生图需 Ultimate）
- 颜色标记默认「色条」形态文本位置零位移；「关闭」形态与改造前逐字节一致
- 显示模式默认「关键字换行」与既有版本一致；自动折叠默认关闭
- 插件 ID 与升级链路不变，内测版可直接覆盖升级

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.9.14.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装 v2026.9.11+ 用户：设置页「更新」分区检查更新即自动收到本版（Gitee 渠道），自 v2026.9.11 起经该通道更新免重启即时生效
