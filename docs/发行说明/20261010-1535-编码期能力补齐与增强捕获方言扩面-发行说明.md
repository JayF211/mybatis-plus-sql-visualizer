# 🎉 SQL Visualizer v2026.10.13

> 发行说明留档：对应 Gitee 发行版 **v2026.10.13**（标签 `2026.10.13`），附件 `mybatis-plus-sql-visualizer-2026.10.13.zip`。
> 范围＝自 v2026.10.9 发行包之后的全部用户可见增量。

自 v2026.10.9 后的正式版。本版把此前在开发线上累积的一批编码期与工作流能力补齐交付，并扩大运行期增强捕获的覆盖：**mapper XML 语法高亮与补全**、**SQL 历史工作流**（钉住 / 正则检索 / 多格式导出 / 版本对比）、**预览参数预设**、**分页拦截器模拟**、**EXPLAIN 结构化渲染与 Oracle / SQL Server 模板**、**MCP 第十一枚工具**，以及增强捕获对运行中 **PostgreSQL / Oracle / SQL Server / 达梦 DM8** 应用的 attach 织入扩面。

## ✨ 新增

**编码期：mapper XML 语法高亮与补全（T-XmlSynHi）**
- mapper XML 内语句文本按 SQL 语法着色（关键字 / 字符串 / 注释），`#{}` / `${}` 参数占位加底色，`test` / `value` 属性里的表达式同样着色
- 输入 `#` / `$` 自动补全 `{}`；resultMap 的 `column` 属性补全列名
- 让位改为「宿主级探测」：只有确实有别的注入器会给该宿主上色时才让位（在位 ≠ 覆盖），与本机其他 SQL 插件共存不打架
- 设置页「界面与操作」可按来源分组控制 gutter SQL 图标显隐（mapper XML / 注解 SQL / JPA·HQL / JdbcTemplate / 通用 XML 内嵌 / Wrapper 链及其它，默认全开＝现行为不变）（R2）

**SQL 历史工作流（R15/R16 · R4 · T-ExportSqlFormat · T-HistorySearchToggles · T-SearchToggleNativeLook · R31）**
- 历史条目可**钉住**防淘汰；二级搜索支持 `regex:` 前缀正则匹配（SQL / 摘要 / 源文件三目标，非法正则回退子串）（R15/R16）
- 历史面板与日志面板右键「导出」CSV / TSV / 纯文本；并新增**导出 SQL 文件格式**——参数已回填、带分号终止的可执行 `.sql` 脚本，可直接在数据库客户端执行（T-ExportSqlFormat）
- 搜索框旁新增 **Regex / Aa** 两枚开关（与 IDE 原生查找同图标同语义，会话级、默认均关）；日志页 Ctrl+F 搜索条同步新增 Aa 开关；搜索框整体迁平台原生 `SearchTextArea`（原生框体、状态区命中数读数、Cc / .* 开关钮）（T-HistorySearchToggles / T-SearchToggleNativeLook）
- 历史面板二级右键「对比选中两条」——LCS 逐行 diff 走 IDEA 原生 Diff 视图，同结构指纹时标题直接给「结构等价，仅参数不同」（R31）

**预览参数预设（R22 T-04）**
- 参数区新增「预设」行：当前填好的参数可另存为预设，下拉一键切换（参数值 / OGNL 勾选态 / foreach 权威值随预设整组还原），「管理预设…」对话框支持另存为 / 重命名 / 删除（默认预设受保护，删除带知情确认）
- 命名预设＝**快照语义**：日常编辑只更新工作区（默认预设），命名预设只在「另存为 / 管理预设」时写入；预设**按语句隔离**（同名预设可在不同语句下各自存值，重命名 / 删除作用于同名预设的全部语句）
- 预设行可折叠收起，缺省折叠（折叠状态跨语句 / 跨弹窗保留，重启复位）

**分页拦截器模拟（R12 · T-CountSimToggle）**
- mapper 方法 / XML / 注解路径带 `IPage` 形参的查询此前预览不分页——现按方言在 SELECT 尾追 LIMIT（参数取 `(当前页-1)×页大小`，手写 LIMIT 不重复追加），并并列产出 COUNT 包裹语句（`SELECT COUNT(*) FROM (…) TOTAL`）
- 新增**分页 COUNT 独立开关**：COUNT 与 LIMIT 解耦——父开关（模拟分页拦截器）关＝全无；子开关只关 COUNT、不影响 LIMIT

**EXPLAIN 结构化渲染与方言扩展（R33 · R23）**
- EXPLAIN 结果新增结构化视图：TABLE 形态只读表格、JSON 形态可折叠树，附方言 / 数据源 / 耗时与索引建议条，可一键「回到原生控制台」
- Oracle 与 SQL Server 的 EXPLAIN 模板接入，支持面 11/11 收口

**MCP 第十一枚工具 sqlv_history_search（R14）**
- AI agent 可检索本地 SQL 历史落盘——关键词 / 正则 / 时间范围 / 来源文件四维过滤，默认只查当天（`allDates` 跨全量），返回条目摘要，只读不执行；设置页逐项门控

**增强捕获：语句级织入 attach 即生效（T-StatementWeave）**
- 向运行中的应用挂载增强捕获时，对连接池里**已存在的**连接同样生效（此前 attach 路径下存量连接无法回溯 connect 包装，只能捕获新连接）；能力边界通知文案同步升级
- 语句面 / prepare 面登记扩面至 PostgreSQL、Oracle、SQL Server 与达梦 DM8（T-PgWeave / T-DmWeave，详见「修复」节）

**其它新增**
- 数据源上下文角标：条目元信息行显示「库名@host:port」（Oracle service_name / SID、SQL Server 分号参数等形态解析），并可切换为**默认只显示数据库类型**（R32 / T-DataSourceBadgeMode）
- 原生 MyBatis（非 Spring Boot）拦截器自动注入补完——装配点落在 `mybatis-config.xml`（R24）
- 动态 SQL 条件求值探镜：预览里 `if` / `choose` 条件行尾标注求值结果（真 / 假 / 未求值三态），OGNL 判真语义不变（R30）
- N+1 同模板计数徽章：同结构指纹条目聚合出「×N 同模板」，可右键聚焦同模板条目（O-90）
- CRUD / 回滚 SQL 可移植导出：当前预览 CRUD 行与回滚链产物逐条导出，每条语句前带方言形态注释头（O-91）
- 「日志转 SQL」输入工具栏新增「从剪贴板读取」——一键读系统剪贴板文本并立即转换（O-92）
- ShardingSphere 双段日志捕获兼容解析：5.x `sql-show` 的 Logic SQL 与 Actual SQL 双段形态（R10）
- 抽样快捷模板的 LIMIT 行数设置页可配（默认 10，钳制 1..10000）（R5）
- 预览列信息表恢复 Ctrl+A 全选（O-85）
- 设置落地页新增能力矩阵与官网链接（R20）；首次引导通知新增「立即试用」按钮，一键直达预览（R21）
- 「日志 → SQL」页恒显灰字提示；搜索历史接管为面板自有会话历史（T-LogToSqlHint）
- 空态 / 引导链接点击自动定位并高亮目标设置项（T-SettingsFocusFromLink）

## 🛠 修复

**增强捕获对运行中的非 MySQL 应用 attach 后零条目（T-PgWeave / T-DmWeave）**
- PostgreSQL：语句级织入登记名单原只有 MySQL 与 H2，attach 路径下连接池的存量连接无法回溯 connect 包装、语句面又没有 PG 实现类可 retransform ⇒ 零钩子零事件（premain 路径因连接建立时已被包装，此前掩盖了该缺陷）。现按 javap 实测 + 真实驱动类字节织入 / JVM 校验扩面 PG 语句面 / prepare 面；同批评估后一并登记 Oracle 与 SQL Server；openGauss 2.x 走 PG 驱动同享
- 达梦 DM8：现场应用实跑 dm profile，`StatementWeaver` 语句面 / prepare 面一个达梦类都没有 ⇒ 零事件。补登时暴露织入器一处硬约束——达梦 javac 在出口对已死局部发 `chop_frame`，旧织入形态读原局部触发 `VerifyError: Bad local variable type`；改「入口捕获、出口读自有槽」后通过 JVM 校验并落钩，真库 E2E 由 `matched=1 wove=0 failed=1` 零事件变为 `matched=4 wove=3` 且首条事件到达
- 同批加固：语句面 / prepare 面字节级回归守卫扩达梦三面 + 新增**厂商对齐守卫**（连接面已登记的每个厂商，要么有语句面 / prepare 面条目，要么在显式「已知不覆盖」白名单带原因），把「看着支持、attach 后一条不出」的静默缺口钉成红灯

**attach 跨通道去重吞掉 agent 首批事件（T-AttachZeroEvent）**
- 增强通道与控制台通道的去重索引未随通道切换重置，agent 挂载后的首批事件被跨通道去重吞掉；现接管时按通道纪元重置去重索引

**mapper XML 补全两处失效（T-XmlCmpl2 / T-XmlCmpl3）**
- dumb 态整体丢弃：`XmlSqlCompletionContributor` 未实现 `DumbAware`，索引期（数据库方言 push / 项目初扫等 dumb 窗口）平台把一切非 DumbAware 贡献器整体丢弃，按补全零响应——现实现 DumbAware（索引不可用时降级为「只补关键字」）；另修一处沙盒失效双根因（派发劫持双语言注册 + 宿主还原生产形态）
- `where` 内裸列补全零候选（动态标签语义替身）；别名.列名补全插入重复别名（`o.o.user_id`）

**预览首次点「执行 SQL」结果区空白、二击正常（T-FirstExecResultInvisible）**
- 准备链（远程数据源需数秒）未落地时点执行，旧代码会再建第二条临时文件 / 会话 / 控制台链，两条链的代际与提交 / 取消判定交错，用户见「无 loading 无报错下方空白」。现准备链单飞：在飞时执行意图只排队（不再建第二链），准备完成即自动消费执行；控制台折叠语义由布尔归口为显式模式（执行恒展开）

**个别增强捕获条目源码位置显示 `[<generated>]`（T-SrcGenFrame）**
- 经 Spring 代理调用 MP `ServiceImpl` 继承方法时，栈上最深非框架帧是 CGLIB 增强类帧（SourceFile 硬编码为 `<generated>`、行号恒 -1），被当业务帧选中。现主位置选择一律要求真实源文件，生成类帧让位给真实业务帧（触发本次调用的调用方行）；仅池内无真实源文件帧时保留作「真无主」信号

**预览编辑器行注释前缀统一为 `--`（T-PreviewLineCommentDash）**
- 预览编辑器 Ctrl+/ 此前插入 `#` 前缀，对 PostgreSQL 执行报语法错误。现接管行注释快捷键：插入一律 `-- `、再按一次剥除，修复前残留的 `#` 行同样可剥（缩进保留、多行选区整段切换、一步撤销）；未打标编辑器直通平台原行为

**增强捕获织入改写致宿主应用启动失败（P0）**
- 织入器写入器原先用 ASM 默认 `COMPUTE_FRAMES`，其帧合并类型解析会在被织类自身 `defineClass` 进行中触发重入类加载，宿主启动即抛 `attempted duplicate class definition`（SpringBoot 2.6.3 / JDK8u181 / mysql-connector 8.0.28 现场实录）。现改 `COMPUTE_MAXS` + 零类加载兜底，帧语义经全套回归实测定形

**日志 DDL 预览两缺陷（T-DdlLogPreview）**
- 字面量恢复此前对零 `?` 的 DDL 也全量改写单引号、占位符化致 DDL 不可执行——现加语句类型门禁（DDL / UNKNOWN fail-closed）
- DDL 预览排版分派（DML 逐字节不变）；格式化零变化时给轻提示

**其它修复**
- 描述与文案口径统一为「运行期以增强捕获为主、控制台为回落」（`plugin.xml` 描述、README、Marketplace 自定义页三处同步）；README 与文档站的 EXPLAIN 方言计数由 9 勘正为 11
- 沙盒验收批缺陷修复：分页 LIMIT 面板丢失、MCP 就绪横幅、空态引导链接、历史徽章渲染（`ExpandedItemListCellRendererWrapper` 包装渲染器）、settings-rescan 补能力、注入器模板 javac8 编译
- 空态引导英文链接文案大小写回归修复（`log.panel.empty.link` 回归 `Enhanced Capture`，与同 bundle 其余 EN 文案一致）
- SQL 日志 / 历史搜索框行高三处返工（历史钮尺寸对齐平台基线、历史钮不再常灰、进条目卡清搜索框、灰字提示位置统一）

## 🔧 改进

- 增强捕获织入通道补全链路取证打点（transform 四计数、retransform 汇总行、织入通道首条事件到达打点），排障可直接从 `idea.log` 读到「命中几条、织入几条、失败几条」
- 预览重渲染链 EDT 慢操作定性治理（折叠同文本短路）；预览面板绑定数据源常驻灰字指示行，执行路径不再停留在「关联（上次使用）」态
- 语句面 / prepare 面名单单源化（登记表 + 形态标注统一到一处，防两份名单漂移）

- 增强捕获织入扩面：达梦 / PG / Oracle / SQL Server 驱动类字节级回归守卫（登记谓词命中 + 织入 changed + 产物过 JVM 校验，含非法帧负向自证）；真库 E2E 红 → 绿对照；`ZeroLoadClassWriterWeaveTest` 五例（首织零类加载增量为主红信号，含 `TEMP-RED` 反向读数）
