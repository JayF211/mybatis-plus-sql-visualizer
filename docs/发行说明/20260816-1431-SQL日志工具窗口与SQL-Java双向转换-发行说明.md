# 🎉 MyBatis-Plus SQL Visualizer v2026.8.16

> 发行说明留档：对应 Gitee 发行版 **v2026.8.16**（标签 `v2026.8.16`），附件 `mybatis-plus-sql-visualizer-2026.8.16.zip`。

自 v2026.8.15 后的第四个版本。本版完成**SQL 日志工具窗口**（T-M31，运行控制台 SQL 自动捕获还原）、**SQL 反向转 MP Java 代码**（T-M36/T-M37，含多表 JOIN）、**日志转 SQL 工具**（T-M38）、**侧边栏帮助入口**（T-M39）四大能力，并将**兼容下限降至 IDEA 2024.3**（T-M30）；测试 830 → 1063 全绿。

## ✨ 本版新增（相对 v2026.8.15）

**SQL 日志工具窗口（T-M31）**
- 侧边栏新增「MyBatis SQL Log」工具窗口：运行控制台 SQL 自动捕获——`Preparing:`/`Parameters:` 解析还原为可执行 SQL（时间戳 + SQL 词法着色列表、双击弹窗、右键复制/删除、去重窗口、捕捉开关、格式化/清空工具栏、侧边栏图标）
- 设置页新增「SQL 日志」组 11 项：SQL/参数前缀、混合前缀开关、自动监听、时间戳开关与格式、发现 SQL 自动打开窗口、格式化开关、移除包含关键字、去重窗口等
- 「逻辑删除值」可配置（注入 `deleted = 值`）；设置生效性全量审计（29 项全部有读取点，修复 5 个真实缺陷：保存链路断/监听耦合/静默失败状态机/自动监听不传播/参数缓存旧值）
- 挂载链路兼容 IDEA 2026.2（execution 包移动/接口变化反射桥）并真机验证通过（用户实测正常识别 SQL）

**SQL 反向转 MP Java 代码（T-M36）**
- 选中 SQL 文本右键 / Alt+Shift+J 一键生成 MyBatis-Plus Java 代码：SELECT/UPDATE/DELETE/INSERT 全语句支持——QueryWrapper / LambdaQueryWrapper / Wrappers 工厂 / MPJLambdaWrapper 四种形态（设置页可配默认形态）
- 嵌套括号组与顶层 OR 递归还原（nested/not lambda、.or() 分隔）；复杂表达式（函数/子查询/列对列/占位符）降级 apply() 透传并注释警告；实体列自动映射 lambda（未映射回落字符串列名）；全表更新警告
- 可指定调用类与返回 VO：生成 Service/Mapper 调用形态（list/selectList/update/remove/save/insert 等）
- 侧边栏工具窗口「SQL → Java」tab：粘贴 SQL 即转（形态快捷切换下拉、SQL 输入补全/高亮、结果格式化/复制/清空）

**多表 JOIN 与增删补全（T-M37）**
- JOIN 链解析：LEFT/RIGHT/INNER/FULL [OUTER] JOIN 副表[别名] ON 等值列对 → 生成 MPJLambdaWrapper + selectAll + leftJoin 链（ON 多条件回落字符串形态；主实体缺失回落 MPJQueryWrapper）
- INSERT 多行 VALUES 生成实体 setter 链（Service saveBatch / Mapper 逐条 insert）；DELETE 多表目标生成 MPJ DeleteJoinWrapper + join 链
- 副表多候选逐个弹选择框（按 JOIN 顺序选择实体，选择结果缓存复用）

**日志转 SQL Tab（T-M38）**
- 侧边栏「SQL 预览」tab 改造为「日志转 SQL」输入转换工具：粘贴 MyBatis 日志（`Preparing:`/`Parameters:` 行）批量还原为可执行 SQL——多组语句 `-- SQL #N` 分隔、默认多行格式化 + 单行切换、参数不足红字警告、SQL 高亮 + 一键复制
- 日志列表右键「发送到日志转 SQL」联动（条目渲染回日志文本自动填入并转换）

**侧边栏帮助入口（T-M39）**
- 工具窗口工具栏「?」按钮 → 帮助弹窗：核心功能（Wrapper 预览 / 日志捕获还原 / SQL→Java 反向转换 / XML·注解动态 SQL 预览 / 代码补全 / 执行与更新）、使用方法与默认快捷键（Alt+Shift+Q / Alt+Shift+J，可在 Keymap 修改）；i18n 双语、主题化渲染、离线可用
- 体验修复（用户实测驱动）：工具窗口标题栏插件名/包名显示修复、调用类/VO 字段改类选择器（Goto Class 弹窗 + 类图标 + 类名 + ✕ 清除）、截断文案 hover 完整提示、帮助弹窗样式对齐 IDE 观感

**兼容下限降至 IDEA 2024.3（T-M30）**
- 构建基准 2024.3.7.1、since-build=243——支持范围由 2025.3+ 扩展至 **2024.3 ~ 2026.2**
- Plugin Verifier 三版本（2024.3 / 2025.3 / 2026.2）全 Compatible

**更新链路修复与预览增强（T-M28.3~28.6、T-M29.5/29.6）**
- 更新安装修复：更新后插件消失（解压目标改为插件目录根）、「current installation is not under the IDE plugins directory」误拒（守卫路径归一化 + 黑名单式判定）、下载包权限加固（POSIX 644）
- 更新通知优化：每行一个版本标题 + 自动编号有序列表、可点击跳转 Gitee 发布页、失败通知「更新失败」标题
- XML 参数回填类型感知：按 mapper 方法签名解析参数 Java 类型（LocalDate → `'2025-08-01'`、Integer → `2`），Map/无类型信息参数兜底引号
- 选择区多 SQL 选择栏覆盖 XML 与注解：XML 选中段落与 Java 选择区（无 Wrapper 候选时回落注解候选）均可弹选择栏（行号 + 摘要 + 定位跳转）

## 🔧 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；执行 SQL 需 Ultimate）——本版由 2025.3+ 扩展而来
- Plugin Verifier 已验证 2024.3 / 2025.3 / 2026.2 三版本 0 问题

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.8.16.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装旧版：设置页「更新」分区可直接检查更新下载安装（Gitee 渠道），或按上法手动安装覆盖
