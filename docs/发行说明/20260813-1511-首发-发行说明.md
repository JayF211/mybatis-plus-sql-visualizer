# 🎉 MyBatis-Plus SQL Visualizer v2026.8.13 首发版

> 发行说明留档：对应 Gitee 发行版 **v2026.8.13**（标签 `v2026.8.13`），附件 `mybatis-plus-sql-visualizer-2026.8.13.zip`。

一个 IntelliJ IDEA 插件，将 MyBatis-Plus（含 MyBatis-Plus-Join）的 Wrapper 构造链**实时转换为
可读、可复制、参数已替换的 SQL**——告别「开启日志看控制台、手工拼参数」的调试方式。

## ✨ 核心功能

**Wrapper 全覆盖**
- LambdaQueryWrapper / LambdaUpdateWrapper / LambdaDeleteWrapper / 字符串版 QueryWrapper / UpdateWrapper
- MPJLambdaWrapper / MPJQueryWrapper：联表 JOIN、selectCollection 子查询、selectFunc 聚合、exists 三形态、apply/last 原生片段
- 服务链 `lambdaQuery().one()/list()/count()/exists()/page()` 与 `lambdaUpdate().update()/remove()`

**参数替换**
- `?` 占位符替换为实际值（基本类型 / 对象 / 集合，同文件变量赋值自动追踪）
- LIKE 自动拼百分号；字段类型推断引号（String 列恒加引号、数值列恒原样）

**动态条件**：布尔重载 `.eq(true, ...)` 在预览面板复选框手动开关，拼接/移除即时可见

**SQL 格式化**：关键字大写、子句换行缩进，格式化 / 单行两种视图

**字段补全 + 注释提示**：位置感知（FROM/JOIN 后提示表名，WHERE/ON/GROUP BY 等后提示列名）、
父类继承字段参与补全、@Schema/@ApiModelProperty 注释展示（输入注释关键词也能检索到字段）

**表名配置**：表前缀/后缀、推断策略（SNAKE/CAMEL）、忽略字段、移除前缀后缀，@TableName 显式表名最高优先级

**CRUD 全覆盖**：SELECT / UPDATE / DELETE / 联表 JOIN 预览；无 WHERE 条件时红色警示全表操作风险

**逻辑删除注入**：@TableLogic 自动追加 `deleted = 0`（设置页可关闭，父类继承字段同样识别）

**执行 SQL**（Ultimate + Database 插件）：选择数据源 → 自动创建临时 .sql 文件 → Ctrl+Enter 执行；Community 版自动隐藏

**多数据库方言**：MySQL / PostgreSQL / Oracle 分页子句差异化渲染

**多种触发方式**：右键菜单 / 快捷键（默认 Alt+Shift+Q，设置页可录制）/ 代码左侧 gutter 图标

**中英文界面**：设置页语言即时切换，无需重启

## 🔧 兼容性

- 支持 IntelliJ IDEA **2025.3+**（Ultimate / Community；执行 SQL 需 Ultimate）
- Plugin Verifier 已验证 2025.3.1 / 2025.3.5 / 2026.2.1 三版本 0 问题

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.8.13.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
