# 🎉 SQL Visualizer v2026.9.14-beta.2（内测版）

> 内测版留档：Gitee 抢先体验通道发行版，标签 `2026.9.14-beta.2`，附件 `mybatis-plus-sql-visualizer-2026.9.14-beta.2.zip`。
> 本内测系列（beta.1 起）的全部更新内容将在正式版 `2026.9.14` 发行时统一并入正式版更新日志；对外更新清单只保留最新一个 beta 版。

自 beta.1 后的第二发（合并 dev 分支 119 提交与 t-crudcolor 分支 7 提交）。本版主题是**dev 分支整体回合**：SQL 列表 CRUD 类型颜色标记、日志与源码双向深链（gutter 左右键 + 最近执行反查）、真实 EXPLAIN 执行计划、错误一键上报、三种列表显示模式、更多 ORM 预览支持与全链路性能优化，自此进入正式发行渠道。

## ✨ 新增

**SQL 列表 CRUD 类型颜色标记（T-CrudColor）**
- SQL 日志页与「SQL 历史」页二级列表按语句类型着色：SELECT 蓝 / INSERT 绿 / UPDATE 橙 / DELETE 红（OTHER 不标记），类型判定与类型过滤弹窗同源
- 标记形态三选一：左侧 3px 色条（默认）/ 整行淡背景 / 关闭（关闭与改造前逐字节一致）；四色均可在设置页自定义，类型过滤弹窗同步显示色块图例
- 整行淡背景样式的选中态为「保留类型色调 + 2px 选中描边」而非平台填充——键盘上下浏览时颜色不丢失，耗时快/慢着色不再被选中态抹白

**日志与源码双向深链（M37 竞品融合）**
- Wrapper 链锚点 gutter 图标**左键单击直接预览**，**右键弹菜单**（「预览 SQL」/「最近执行记录」）
- 「最近执行记录」从源码反查：开启日志捕获后，右键即从本会话捕获记录里反查该位置附近的执行（同文件优先、行号 ±30 行内排前），选中打开带参数完整 SQL——调试时看着代码想知道"它最近一次实际执行长什么样"的反向诉求一步到位
- 多模块项目源码跳转容错（按模块 content root 逐个匹配）

**真实 EXPLAIN 执行计划（M37.2）**
- 预览面板「执行计划」按钮：按当前方言把 SQL 包装成 EXPLAIN 提交原生数据库控制台，真实执行计划与静态性能规则标注同屏对照
- MySQL / PostgreSQL / 人大金仓 / 达梦真机验证，H2 / SQLite 引擎级支持；Oracle / SQL Server 提示降级
- 依赖数据源（Ultimate Database 工具窗）

**错误与反馈一键上报（T-ErrReport）**
- IDE 内部错误对话框一键报告官网需求池（异常预填 + 堆栈附件 + IDE/插件版本自动携带 + 24 小时去重）
- 帮助菜单与设置页手动反馈入口

**SQL 列表三种显示模式（T-ListMode）**
- SQL 日志与 SQL 历史列表支持单行 / 关键字换行 / 格式化三种显示（工具栏下拉即时切换，默认关键字换行）；模式跨会话保留、两列表共享，Ctrl+C 复制仍为纯 SQL

**更多 ORM 预览支持（M39/M44）**
- Querydsl / EasyQuery / Xbatis / MDS 链式查询识别与预览
- Spring Data JPA 增强：Specification / QueryByExample 形态；JPA 元数据（`@Embedded` 嵌入列展开、`@Convert` 转换标记、`insertable`/`updatable` 不可插入/更新列跳过）

## 🔧 改进

- **自动监听被动模式**：开启「自动开始监听」设置后不再立即进入预捕捉状态（此前"还没启动项目就自动开启"），项目 Run 时才自动开始捕捉
- **性能系列（T-Perf）**：SQL 历史目录扫描与文件读取全部移后台（大文件不再冻结界面）；日志列表增量刷新（可见区差分，全量重建成为历史）；渲染热路径零分配治理
- **列表条目元信息两行结构延续**：元信息行在上、SQL 高亮行在下（2026.9.10 已交付），本版在此基础上叠加颜色标记与三显示模式

## 🧪 测试

- **颜色标记**：`SqlListTypeColorTest` 18 + `SqlListSelectionOutlineTest` 10 + 分类器/两渲染器/设置绑定共 44 例（含选中态 insets 逐边相等防抖动参数化与实例同一性防回退）
- **合并门禁**：全量 **3880/0/6 绿**（303 测试类），`verifyPlugin` 三目标（IU-243/253/262）Compatible，`buildPlugin` 产出发行包
- 功能入口与逐项验收步骤：[docs/验收文档/20260913-1225](https://gitee.com/songrenshuo/mybatis-plus-sql-visualizer/blob/master/docs/验收文档/20260913-1225-dev与CrudColor合并master-新增功能验收文档.md)

## 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；EXPLAIN、执行 SQL、表右键入口与 Database 原生图需 Ultimate）
- 颜色标记默认「色条」形态文本位置零位移；「关闭」形态与改造前逐字节一致
- T-ListMode 默认「关键字换行」与既有版本一致；T-CrudColor 默认色条形态视觉变化最小
- 插件 ID 与升级链路不变，beta 系列可直接覆盖升级

## 📦 安装（内测通道）

1. 下载附件 `mybatis-plus-sql-visualizer-2026.9.14-beta.2.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装 v2026.9.11+ 用户：设置页「更新」分区检查更新即自动收到本内测版（Gitee 抢先体验通道），自 v2026.9.11 起经该通道更新免重启即时生效
