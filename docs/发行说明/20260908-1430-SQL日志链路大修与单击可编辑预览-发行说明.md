# 🎉 SQL Visualizer v2026.9.8

> 发行说明留档：对应 Gitee 发行版 **v2026.9.8**（标签 `2026.9.8`），附件 `mybatis-plus-sql-visualizer-2026.9.8.zip`。

自 v2026.9.4 后的下一个版本（30 个提交）。本版核心主题是 **SQL 日志链路一次大修**——日志列表 EDT 冻结 16 秒根治（渲染器弃 HTML 通道 + 刷新管线增量化）、SQL 列表悬停卡顿改单击预览（三轮优化后升级为 SQL 高亮可编辑编辑器）、多行 JdbcTemplate 日志漏捕获与日志去重失效双根因修复、双击预览平台断言硬抛修复、「自动开始监听」联动失效与手动停止后永不自动捕捉修复——同时交付自研 DAO 字符串 SQL 预览与方法定义锚点贯通、设置页缓存信息修复，并完成 MyBatisCodeHelper-Pro 反编译调研精华取舍。

## ✨ 本版新增（相对 v2026.9.4）

**自研 DAO 字符串 SQL 预览与方法定义锚点贯通（T-DaoSql）**
- 用户反馈 `beanCruder.selectList(ScheduleVO.class, sql拼接变量, "CUR_USER", userId)` 调用行无预览图标、`selectListPagination` 等分层方法定义处快捷键失效——四处根因一次修复
- 方法名白名单扩展 select 族（`DAO_STRING_SQL_METHODS` 统一入口）；SQL 实参定位泛化为扫描实参列表取第一个字符串形态实参，兼容自研框架 `(Class, sql, ...)` 形态
- JDBC gutter 家族守卫改排除制（UNKNOWN 家族兜底，CUSTOM_DAO/HIBERNATE/JPA 各归专属 provider），批量锚点对字符串 SQL 形态让位去重
- 新增**方法定义锚点**：方法体内存在字符串 SQL 调用时方法名行显示预览图标（daemon 快速路径限单方法体遍历 + 200K 文本护栏）；`ConvertToSqlAction` 方法定义 fallback（光标在方法定义名/方法体内任意处均可触发，方法体候选 0/1/多分发）
- 已知边界：SQL 以对象字段/方法返回值形态运行时构造（`query.getQuery()`）静态不可还原，仅提供图标入口不预览文本

## 🔧 修复（相对 v2026.9.4）

**SQL 日志列表 EDT 冻结 16 秒根治（T-LogListFreeze-04）**
- 用户真机 Freeze 报告（采样 11.4s 全落 Swing BasicHTML 解析）——三层根因一次根治：
- ① 列表渲染器弃 JLabel-HTML 通道（每次 setText 触发 BasicHTML 完整解析排版，长 SQL 数十个着色 span 逐条放大），改双 `SimpleColoredComponent` 两行片段渲染（元信息行在上、SQL 分词高亮在下；配色体系与关键字加粗保留；摘要文本原样绘制，HTML 注入转义面消失）
- ② 列表固定行高（可变行高使每次布局逐条测量；固定行高下走 O(1) 快路径）——条目恒定两行不再按 SQL 内容自动折行，全文查看走单击预览/双击弹窗
- ③ 刷新管线增量化（差分增量刷新 + 代际守卫、搜索 200ms 防抖、UI 通知置脏合并、去重计数键指纹化、dispose 精确注销监听、去重判定入临界区防 CME）；SQL 历史面板两个渲染器同型改造

**SQL 列表悬停预览卡顿改单击预览、双击开完整弹窗（T-ClickPreview，三轮优化）**
- 条目多后鼠标悬停整列表卡顿——根因为渲染器 `toolTipText` 设完整 SQL，悬停逐行弹气泡且连动可变行高重排；移除悬停 tooltip（悬停零成本），单击条目延迟 300ms 弹轻量预览，双击仍开完整预览弹窗（定时器区分单击/双击，第一击不闪预览）
- 二轮：预览排程严格绑定「点到真实行」（空白区/行下留白点击立即停表关预览，杜绝预览自行复活）；仅左键触发；弹窗锚点改被点行下缘 2px 缝不遮被点行
- 三轮：预览内容升级为 **SQL 高亮可编辑编辑器**（SQL FileType 驱动词法高亮，无 Database 插件时降级纯文本）——可临时改一个字段值后点头部**复制**按钮取编辑后文本（软换行免横向滚动，编辑器随弹窗关闭自动释放），头部另有**关闭**按钮

**多行 JdbcTemplate 日志漏捕获（T-JdbcMultiline）**
- SQL 跨行的 `Executing prepared SQL statement [...]` 控制台日志（含 TLog 等自定义日志前缀）此前一条不进 SQL 日志列表——现按 string-aware 括号配对跨行收集完整语句（字符串内方括号、标识符 `[列]` 不误判闭合），参数还原与 MP 分页计数标记链路不受影响；「日志 → SQL」手动粘贴面板同步受益

**SQL 日志去重失效与 MP 分页计数误标（T-LogDedupeMpMark）**
- 开启「移除重复的sql」后列表仍成对重复——根因一：JdbcTemplate 双路日志（仓储层 TRACE 行与 Spring DEBUG 行）对同一语句产出两条副本，还原文本仅差首尾空白而去重判定按原文精确相等永不命中，现按空白规范化指纹判重（trim + 连续空白折叠；参数不同仍不合并，60s 窗口语义不变）
- 根因二：MP 分页 COUNT 标记按「同一行产出的全部条目」批级判定，与 COUNT 副本同批闭合的数据查询被一并误标（且丢失源码跳转）——现改逐条判定，[MP 分页计数] 标记只落在真正的 COUNT 语句上

**SQL 日志双击预览崩溃（T-PreviewWiLock）**
- 双击 SQL 日志条目预览恒抛 `Access is allowed from write thread only`，弹窗打不开——同步 VFS refresh 被包在 EDT 的 `ReadAction` 内触发 2024.2+ 平台 write-intent lock 断言（IDE 2026.2 硬抛）；修复改用 `WriteIntentReadAction`（write-intent 隐含读权限），该入口每次必走的主路径恢复可用

**设置页缓存信息恒 0 B（T-CacheInfo）**
- 「插件缓存」一直显示 0 B——统计口径只含实体反查兜底缓存（主流命名快路径恒命中、该缓存恒空）；现扩展为三类缓存全量口径（实体反查 + 实体解析 + Wrapper 预览缓存），「清除缓存」同步清空全部三类，展示增条目数

**「自动开始监听」修复链（20260907-1617 计划）**
- 用户反馈开启「项目启动时自动开始监听」后运行项目不自动捕捉、手动停止后再 Run 永不自动捕捉、开启设置瞬间就进入监听态——会话日志逐段复盘定位三个独立缺陷一次修复
- ① 边沿联动挂在未注册进 plugin.xml 的死类上（设置页「文件夹+分区子页」重构后实际走 `SectionConfigurable.apply()` 基类透传，无边沿检测）——迁入基类：设置「关→开」清 suppressed 并对已打开项目调 startCapture
- ② 手动停止面板捕捉会持久化 suppressed 并拆除全部检测链，此后再 Run 项目三条自动入口（启动捕获单次/设置边沿/控制台出现守卫）全部失效——补进程级入口 `onProjectProcessStarted`（autoStart 优先清 suppressed + 幂等启动）+ `RunConfigurationProcessListener` 订阅进程启动事件（订阅异常自动降级轮询兜底）
- ③ 被动模式：开启设置不再立即进入 armed 监听态（此前「还没启动项目却自动开启」），恢复链由 Run 事件自洽；④ 订阅失败修复——反射拿到的泛型擦除桥方法序不定致 argument type mismatch，改编译期直调 `MessageBusConnection.subscribe`

## 🔧 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；执行 SQL 与 Database 原生图需 Ultimate）
- 单击预览的 SQL 语法高亮依赖 SQL FileType：无 Database 插件环境（含 Community）自动降级纯文本，功能不丢失
- 行为变更提示：日志列表条目恒定两行不再按 SQL 内容自动折行，查看全文请单击预览（可编辑）或双击开完整弹窗

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.9.8.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装旧版：设置页「更新」分区可直接检查更新下载安装（Gitee 渠道），或按上法手动安装覆盖
