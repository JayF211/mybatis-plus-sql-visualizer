# 🎉 MyBatis-Plus SQL Visualizer v2026.8.20

> 发行说明留档：对应 Gitee 发行版 **v2026.8.20**（标签 `v2026.8.20`），附件 `mybatis-plus-sql-visualizer-2026.8.20.zip`。

自 v2026.8.19 后的第八个版本。本版核心主题是 **参数导入交互体验升级**（P-05.1：手动输入弹窗 + 驼峰/下划线自动匹配 + 清除按钮）与 **内存泄漏修复**（面板 Disposer 树注册 + 历史召回弹窗移除）——同时完成 SQL 监听手动启动无需等待项目运行（armed 态）+ 解析兼容性提升（前缀与 SQL 分行形态）+ 调用类校验与智能识别 + MPJ 工厂链双图标修复 + IN 子句多值回填与关键字换行格式化 + 测试覆盖缺口体系化修复。

## ✨ 本版新增（相对 v2026.8.19）

**参数导入交互体验升级（P-05.1）**
- **手动输入弹窗**：`ParamImportDialog` 取代直接读取剪贴板——点击「导入参数」按钮弹输入框，顶部工具栏含「格式化」（JSON 美化 / 非 JSON 归一）+「清除」图标按钮；多行输入框带灰色占位示例（支持 JSON / CSV / key=value 格式提示）；剪贴板有合适参数时预填原文，用户可在此基础上修改后确认导入
- **驼峰/下划线自动匹配**：`CaseFormatUtil` 工具类实现 camelCase ↔ snake_case 双向互转；`resolveSource` 三级 fallback（精确命中 → 去 `#` 前缀精确命中 → 驼峰/下划线互转命中），解决数据库列名（snake_case）与 Java 字段名（camelCase）命名风格不一致导致导入参数无法匹配的问题
- **清除按钮**：动态条件分区和批量参数列分区标题行新增「清除」按钮——一键清空该分区所有参数值（不影响勾选态），清空后 SQL 立即恢复 `?` 占位形态
- **参数面板顶部对齐**：参数行由垂直居中改为顶部对齐（`BorderLayout.NORTH` 包裹），参数少时不再悬在面板中央

**内存泄漏修复**
- **SqlPreviewDialog Disposer 注册**：预览弹窗的 `SqlPreviewPanel` 注册到弹窗 `disposable` 树，弹窗关闭时级联释放面板及其 messageBus 连接，避免 IDE 退出时 ObjectTree 报 "Memory leak detected"
- **SqlLogPanel / SqlToJavaPanel Disposer 注册**：子面板（`logToSqlPanel` / `sqlToJavaPanel` / `inputEditor`）注册到父面板 Disposer 树，父面板 dispose 时级联释放子面板及其 DocumentListener

**SQL 监听行为完善**
- **手动启动无需等待项目运行（armed 态）**：点击捕捉按钮立即进入 capturing 态（⏸），项目启动后自动捕 SQL——无需等待项目完全启动后再点捕捉
- **启动行为区分（manual/auto）**：`userArmed` + `logAutoCaptureSuppressed` 持久标志——手动停止后重启不再自动开启；设置优先（autoStart=true 时项目启动始终自动捕捉）
- **解析兼容性提升**：SQL 日志解析兼容前缀（如框架附加的时间/线程前缀）与 SQL 分行形态（多行 SQL 正确合并解析）

**测试调整**
- **移除历史召回弹窗**：`showRecalledHint` 移除（仅在非 unitTestMode 弹 info，测试缝绕过导致该提示从未在测试中被验证；弹窗交互也由新弹窗取代）
- **新增测试**：驼峰/下划线互转 4 例（camel→snake / snake→camel / `#`前缀+驼峰 / 精确优先）+ 清除按钮 2 例（动态条件 / 批量参数列）+ 弹窗态端到端 1 例

**插件自更新静默失败修复（本次重点，用户实测定位）**
- **症状**：已装 2026.8.18，内置更新下载 2026.8.19「更新成功」并重启，但版本仍是 2026.8.18——`lib/` 下新旧两版本 JAR 共存、旧 JAR 未删除
- **三处叠加断点彻底修复**：
  1. `PlatformPluginInstaller` 改用 `PathManager.getPluginsDir()` 定位插件目录——IDEA 2026.2 实证 `protectionDomain.codeSource.location` 返回 `null`，原 `getPath` 类工具对 null 无能为力
  2. 目录名用 zip 顶层短名 `mybatis-plus-sql-visualizer`（新增 `UpdateSource.INSTALL_DIR_NAME`）而非 `<id>` FQN——安装目录名与插件 ID 不同名，此前删除扑空
  3. 删除整个插件目录（递归）而非单个 JAR + 全程诊断日志（真实 IDE 断点定位）
- **平台兼容**：`INSTALL_DIR_NAME` 取自 zip 布局，与 OS 无关，三平台（Win/Mac/Linux）通用

**SQL→Java 调用类校验与智能识别**
- **调用类校验**：选中 VO/DTO/BO/PO/Utils/Controller 等不合法类时拒绝选中 + 状态行友好提示（3 条 bundle 文案），不再等到生成阶段才报错；白名单（Mapper/Service/ServiceImpl/Impl）直接放行
- **智能识别当前编辑器打开类**：选中 `this`/`baseMapper` 时 tooltip 追加当前类上下文，兼顾 PM 与 MPJ 两种依赖（ServiceImpl 取第 2 泛型参数，BaseMapper/MPJBaseMapper 取第 1 个）
- 新增 16 个测试用例（SqlToJavaPanelTest 37→53，全绿）

**MPJ 工厂链 selectAll 双图标修复**
- **症状**：`MPJLambdaWrapper wrapper = JoinWrappers.lambda(...).selectAll(...)` 出现双 gutter 图标
- **根因**：场景 D（批量操作）的 `selectAll` 去重靠 `initializerHeadIsWrapper` 回溯链首，但工厂链 `JoinWrappers.lambda(...)` 的 qualifier 是引用（非 new/工厂调用）→ 回溯停在 `PsiReferenceExpression` 返回 false → `selectAll` 未去重 → 第二个图标
- **修复**：`initializerHeadIsWrapper` 先识别调用自身即工厂方法名（链头=工厂调用，无需沿 qualifier 回溯）；`isInsideWrapperVariableInitializer` 改用 `getParentOfType` 定位变量祖先，健壮处理跨行链/方法引用/类字面量实参

**IN 子句参数多值回填（XML/MP/MPJ）**
- **inList 标记**：新增 `detectInClauseParams` 检测 SQL 中 `IN (?, ?, ...)` 模式的参数索引，面板回填时这些参数标记 `inList=true`
- **逗号分割多值渲染**：导入参数或手动输入 `1,2,3` 时，IN 子句参数自动按逗号分割渲染为 `IN (1, 2, 3)`（`renderParamValue` 分支处理）
- **关键字换行格式化**：新增 `SqlFormatter.formatClauseLine` + 工具栏「关键字换行」按钮——只在主子句关键字处换行（SELECT/FROM/WHERE/GROUP/ORDER/HAVING/LIMIT/JOIN/UPDATE/SET/DELETE），列清单与 WHERE 条件压一行；与「全展开」格式化互补（前者快速总览，后者阅读细节）

**废弃 API 修复（T-M52 补充）**
- `ReadAction.compute(ThrowableComputable)` 在 262 平台报 deprecated，但 243 编译目标仅此重载可用（javap 实证）——保留显式 `<T, Throwable>` 类型参数 + `@Suppress("DEPRECATION")` 抑制 262 告警；涉及 8 个文件 17 处调用点

**测试覆盖缺口体系化修复（T0045，四类缺口分 4 波修复）**
- **波次一（测试缝抽取）**：从 EDT/UI 回调中抽取 6 个测试缝方法（`SqlPreviewPanel.createPreviewFileForTest` / `EntitySelectionDialog.resolveQualifiedNameForTest` / `DatabaseConsoleLauncher` 拆分 / `LogStartupCapture.shouldStartCapture` 纯函数）
- **波次二（无测试文件补全）**：新增 5 个测试文件——`NamedQueryLocatorTest`（@NamedQuery 定位）/ `DatabaseConsoleLauncherTest` / `PluginCacheManagerTest` / `LogStartupCaptureTest` / `PluginSettingsConfigurableTest`
- **波次三（接缝测试）**：新增 3 个接缝测试文件（共 22 个用例）——`SqlPreviewServiceRoutingTest`（WrapperLocator→ConverterRegistry 分派接缝）/ `GutterPreviewConsistencyTest`（gutter 标记=预览可用接缝）/ `EntityClassFinderIntegrationTest`（反查命中→下游传递接缝）
- **波次四（沙盒验证清单）**：新增 `docs/测试沙盒验证清单.md`，列出必须在沙盒/真机验证的行为

## 🔧 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；执行 SQL 需 Ultimate）
- Plugin Verifier 已验证 2024.3 / 2025.3 / 2026.2 三版本 0 Internal + 0 Scheduled-for-removal

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.8.20.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装旧版：设置页「更新」分区可直接检查更新下载安装（Gitee 渠道），或按上法手动安装覆盖
