# 🎉 SQL Visualizer v2026.9.11

> 发行说明留档：对应 Gitee 发行版 **v2026.9.11**（标签 `2026.9.11`），附件 `mybatis-plus-sql-visualizer-2026.9.11.zip`。

自 v2026.9.10 后的下一个版本（17 个提交，其中代码交付 6 项）。本版主题是**自更新免重启**：插件检查更新后默认**动态热替换、立即生效、不再需要重启 IDE**；同时根治「SQL 历史」页参数识别丢失与零占位符 SQL 的字面量参数恢复。

## ✨ 新增

**自更新免重启动态安装（T-DynUpdate）**
- 检查更新点击「立即安装」后，新版直接在运行中的 IDE 内**热替换生效**，不再弹出「重启后生效」——插件全部扩展点早已合规声明动态加载（262 平台逐条实证 9/9 `dynamic="true"`），旧版走「下次启动脚本替换」路径从未尝试平台动态安装，本次改为按平台动态链路手工编排：zip 前置校验 → 能力探测 → 卸载预检 → 卸载旧版 + 装载新版
- 任一环节失败自动回退原「脚本路径重启生效」兜底，无中间态；安装成功分叉提示「已更新并立即生效」/「需重启生效」
- 262 平台热替换探测失效修复：平台 `unloadPlugin` 首参类型在 2026.2 漂移为其子类，精确签名匹配扑空导致真实 IDE 上探测失败回退重启——改弹性首参匹配后归零
- 更新通知「查看 Gitee 发布页」入口去重（正文内嵌链接与动作行按钮重复，收敛为按钮一个）；「立即安装」点击先过期源通知，缓解动态卸载后平台「插件未完全卸载」信息级警告（经 1GB hprof 堆转储实证为结构性互引非泄漏，新实例完整接管、旧类加载器一过性驻留重启即清，无功能影响）
- 跨版本平台签名回归护栏：新增 243/253/262 三平台本地核验用例，动态安装反射入口的签名漂移本地即暴露，不再依赖真实用户升级才暴露

**历史页参数识别与字面量参数恢复（T-HistParam）**
- 「SQL 历史」页打开历史条目参数识别丢失根治——历史文件此前不持久化参数，本次升级为 v2 格式在语句旁以 `-- pd:` 注释行保存参数，读取自动剥离展示行；实时日志面板与历史面板的参数识别统一走同一通道，消除双面板行为分叉
- 零占位符 SQL 的参数恢复：无 `?` 占位符的字面量 SQL 也能识别出参数行——字符串字面量全量识别；数值常量限定在比较运算符 / `IN` / `BETWEEN` / `VALUES` 谓词语境才识别，`LIMIT` 与投影列常量不识别（避免分页 LIMIT 数字被误认成参数）

## 🧪 测试加固

- **动态安装**：新增 `DynamicInstallSupportTest`（184 行，zip 校验/弹性首参匹配/探测降级）、`PlatformSignatureCrossVersionTest`（97 行，跨 243/253/262 发行版签名护栏，缺失版本自动跳过不阻塞）；`PluginUpdateRunnerTest`/`StartupUpdateCheckTest`/`UpdateSectionTest` 改判三分支安装结果
- **历史参数**：新增 `LiteralParamRecoveryTest`（264 行）、`SqlLogParamCodecTest`（77 行）；`SqlLogFileReaderTest`/`SqlLogAutoSaverTest`/`SqlLogHistoryRoundTripTest`/`HistorySqlLogPanelPreviewTest`/`LogEntryPreviewRecognizerTest` 补 v2 格式与识别通道用例
- 本版全量 **3305/0/0/6 绿**，与基线一致零回归；免重启热替换经本地离线全链沙盒实测通过（清单 → 下载 → 校验 → 卸载 → 动态装载）

## 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；执行 SQL 与 Database 原生图需 Ultimate）
- 三版本（2024.3 / 2025.3 / 2026.2）verifyPlugin 全绿；本版未引入新的弃用/内部 API 使用
- 动态热替换依赖平台动态卸载链路：探测失败自动回退「重启生效」，行为与旧版一致（最坏 = 现状）
- 历史文件 v2 格式向下兼容：旧版插件忽略 `-- pd:` 参数行照常打开；新版可读全部旧历史文件

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.9.11.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装旧版：设置页「更新」分区可直接检查更新下载安装（Gitee 渠道）——本版起旧版用户经 Gitee 通道更新仍需重启一次，**自本版起**后续版本的更新将免重启即时生效；或按上法手动安装覆盖
