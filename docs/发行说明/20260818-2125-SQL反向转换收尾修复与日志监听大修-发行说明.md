# 🎉 MyBatis-Plus SQL Visualizer v2026.8.18

> 发行说明留档：对应 Gitee 发行版 **v2026.8.18**（标签 `v2026.8.18`），附件 `mybatis-plus-sql-visualizer-2026.8.18.zip`。

自 v2026.8.17 后的第六个版本。本版围绕 **SQL→Java 反向转换链路收尾修复**（T-M48~M50，用户实测驱动——selectAs 形态/MPJ 能力识别/实体选择弹窗）、**日志监听生命周期五项修复**（用户反馈驱动——启动时机/窗口关闭停止/日志顺序/第一条丢失/工具栏刷新）与 **UI 打磨 + 文档升级**；测试 1221 → 1221 全绿。

## ✨ 本版新增（相对 v2026.8.17）

**SQL→Java 反向转换收尾修复（T-M48 / T-M49 / T-M50，用户实测驱动）**
- **selectAs 字符串联接形态修复**：MPJQueryWrapper（字符串联接）无 `selectAs(String, SFunction)` 重载——ON 含额外条件（无法 lambda 化）回落字符串联接时，别名列改渲染为 `.select("t.name AS productName")`（lambda 形态保持 `.selectAs(Entity::getX, VO::getY)`）；同时 `isSubLogicalDelete` 过滤 `deleted = 0` 后若可 lambda 化则生成更优的 lambda 形态
- **invocationHasMpj 接口继承误判修复**：jar-loaded 泛型超类型（`MPJBaseService<BikeDeviceInfoEntity>`）在 `getInterfaces()` 因泛型实参解析失败返回空数组 → 继承链第一层断裂 → 误判无 MPJ 能力 → 多表 JOIN 报错；新增 superTypes + PsiClassType.resolve() 回退路径
- **SQL→Java 反向 selectAs 选中 VO 时引用 VO 属性方法**：选了调用类 + VO 后生成 `.selectAs(BikeDeviceInfoEntity::getName, BikeDeviceInfoVO::getProductName)`（不再字符串别名）；消除 `t.model` 未映射误报（提取 `resolveColumn` 共享归属解析）
- **VO-only selectAs 引用 VO 方法**：只选 VO 不选调用类时，selectAs 用 `Vo::getXxx`，不生成调用行
- **实体选择弹窗优化**：多表联查唯一可推断（主表 1 候选 + 每个副表各 1 候选）时跳过弹窗直接自动渲染；任一表 0/多候选仍有歧义时保留弹窗手动选择
- **SQL→Java 联表反向转换修复**：① 反引号列紧跟表别名不吞列（`t.`signal`` 分词器修复）；② raw join 字符串换行未转义不编译（`joinString()` 空白归一 + `javaEscape`）；③ 开启三参 lambda 联表（容忍 ON 副表逻辑删除条件——`isSubLogicalDelete` 仅放行逻辑删除列名集合）；④ SELECT 别名保留 → selectAs（新增 `SelectColumn(expr, alias)` 模型）；⑤ 主表别名下副表列归属推断
- **invocationHasMpj jar-loaded 泛型超类型解析失败修复**：CarDeviceInfoService 误判无 MPJ 能力（getInterfaces() 返回空数组因泛型实参解析失败）

**日志监听生命周期大修（用户反馈驱动）**
- **监听启动时机修正**：自动监听增加主运行控制台守卫——打开项目（未启动运行）不再自动进入监听；项目真正启动运行（主运行控制台出现）时才自动开始，停止运行自动停止
- **「关闭工具窗口时停止监听」设置生效**：此前只监听 content 移除（新 UI 关闭/折叠面板只是隐藏 ToolWindow，content 仍在，事件不触发），改为监听 ToolWindow 可见性变化（沿「可见 → 不可见」转换沿按设置停止）
- **SQL 日志列表改为正序**：最早在前、最新在底部（此前最新在前为倒序）
- **工具栏「捕捉/停止」按钮状态实时刷新**：根因是此前用反射调 `ActionToolbarImpl.updateActionsAll()`/`updateActions()` 不存在于此平台（恒抛 `NoSuchMethodException`，刷新从未执行）；改为直接调用 `ActionToolbar` 接口公开方法 `updateActionsImmediately()`
- **项目停止后监听不关闭修复**：scanAll 主控制台进程存活检查（`ProcessHandler.isProcessTerminated()`——getAllDescriptors 进程死后仍返回旧 tab，须额外检查进程状态）；移除 processTerminated 监听（误触发：HTTP 请求/profiler 等短命进程致 stopCapture 反复调用 + filter 重复挂载 + 图标不同步）
- **第一条 SQL 丢失修复**：MyBatisLogParser.feed() 在 Parameters 行后立即闭合（原等下一句 Preparing 才闭合，致第一条 SQL 延迟显示 + 同 SQL 去重时序错乱）
- **手动停止监听后重启 IDEA 不再自动开启**：CaptureAction 手动停止时同步将 `logAutoCaptureOnStart` 设为 false
- **设置生效性机制重写**：ProjectListenerRegistrar 改 object + registerIfNeeded（`@Service(APP)` 懒加载致 listener 永不注册）；`apply()` 仅「关→开」且项目有控制台时启动；SqlLogManager.dispose 重置 capturing

**UI 打磨与 notificationGroup 修复**
- **ClassPickerField ✕/… 按钮贴右边框**：actionButtonHost 补右侧 4px 边距
- **notificationGroup schema 报错修复**：243 平台 `NotificationGroupEP` 属性集为 `id/displayType/icon/toolWindowId/isLogByDefault/hideFromSettings/bundle/key`，无 `displayName`；分组显示名改用 `bundle + key` 本地化

**文档与描述升级**
- **插件描述中文段补宣传导语**：「MyBatis-Plus / MyBatis-Plus-Join 的 SQL 调试利器——Wrapper 链、XML/注解动态 SQL 实时预览（含 MPJ 联表 JOIN），控制台日志一键还原，SQL 反向转 Java 代码。告别翻日志、手拼参数。」
- **插件描述与最新变化优化**：英文段改综合描述（保留 ≥40 字符拉丁开头约束）；中文段精简为 7 条；changeNotes 精简为「标题 + 里程碑」纯列表
- **README 简介段升级定位**：从「Wrapper 构造链实时转换」升级为「MyBatis-Plus / MPJ 的 SQL 调试利器」
- **README 配置节补全**：按设置页 6 个分区组织配置表
- **README 重写去 AI 味 + 补新版本内容**：功能特性重组为 5 组自然段落；补齐新版本功能；新增 MPJ 联表示例
- **项目介绍.md 合并入 README**：痛点分析表 + 已知差异表并入 README

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；执行 SQL 需 Ultimate）
- Plugin Verifier 已验证 2024.3 / 2025.3 / 2026.2 三版本 0 问题

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.8.18.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装旧版：设置页「更新」分区可直接检查更新下载安装（Gitee 渠道），或按上法手动安装覆盖
