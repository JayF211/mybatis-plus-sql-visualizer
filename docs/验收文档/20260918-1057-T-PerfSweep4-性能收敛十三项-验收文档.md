## 三、分项验收步骤（真机走查，留人工）

### 3.1 注入确认三态（核心新增，T-PS4-01）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 删 `mp-sql-visualizer.xml` 全新配置，Run 一个主配置（Application） | 弹「是否注入」确认框，动作栏**三个按钮**：同意（原 OK 文案）/「关闭增强捕获并不再询问」/取消 |
| 2 | 点「关闭增强捕获并不再询问」 | 框关、不挂载；设置页打开可见增强捕获总开关已**置为关闭**（已持久化，重启仍在） |
| 3 | 重开总开关 Apply，再 Run 主配置 | 再次弹确认框（重开上升沿重置了拒绝冷却，保留改主意入口） |
| 4 | 本步点「取消」后，24h 冷却内连续 Run 主配置 / 跑测试 / 发 HTTP 请求 | **零弹窗**（冷却只管弹窗频率）；idea.log 有「拒绝冷却期内」一行 |
| 5 | 未确认态直接跑测试 / HTTP 请求（未点过任何按钮的全新配置亦可） | **不弹窗**（非主配置静默跳过）；随后 Run 主配置仍正常弹 |
| 6 | 弹窗点右上角 X | 按拒绝处理（进冷却，语义同取消） |

### 3.2 历史裁剪安全门（T-PS4-10，数据安全门禁）

| 步骤 | 操作 | 预期 |
|------|------|------|

| 2 | 让插件名族文件超过保留上限（默认 30 组） | 最旧名族组被删（裁剪功能本身正常） |
| 3 | 混放一个形如 `sql-history-backup.sql` 的用户文件 | 会被计入名族（与渲染形状同构）——固有取舍已注释固化，验收知悉即可 |
