## 三、缺陷清单与处置

### KW-1（SEVERE，已修复闭环，提交 8dd6d23 + 77f19f4）

- **现象**：跨工程切换（Open This Window）后预览弹窗残留（SQL 编辑器区渲染整块绿、可交互）；关闭残留弹窗时 idea.log 双发 `SEVERE DisposalException: Double release of editor`（Plugin to blame: SQL Visualizer），用户侧「IDE error occurred」红通知。
- **根因两面**：①showSql 双走 createEditor 后编辑器字段被覆盖转移，两个面板实例先后持有同一编辑器，后到方 releaseEditor 触发平台 TraceableDisposable 断言（DisposalException 为 package-private 不可 catch——javap 亲证）；②弹窗仅弱引用登记，工程关闭无人收口。
- **修复**：①`SqlPreviewPanel.disposeCurrentEditorOnly` 加 `Editor.isDisposed()` 前置幂等跳过；②收口注册挂 `SqlPreviewDialog` 构造器（弹窗自挂 project Disposer 树；首版挂 SqlPreviewService 构造器被真机复测证伪——gutter 的 XML 链在 `getService` 之前 return，服务整个会话可零实例化）。
- **验证**：守卫测试 `SqlPreviewPanelDoubleReleaseGuardTest` 三读数（在场绿 1/0/0 → 摘守卫红 `DisposalException: Double release of editor` 实锤 → 恢复绿）；同族 SqlPreviewDialogTest 6/0 + SqlPreviewDialogSizeTest 3/0；runIde 活体复验两条日志（`[KW-1] editor already disposed, skip release` / `[KW-1] project closing: dispose leftover preview dialog`）+ 切换后零残留 + 退出零 leak 零 SEVERE。
