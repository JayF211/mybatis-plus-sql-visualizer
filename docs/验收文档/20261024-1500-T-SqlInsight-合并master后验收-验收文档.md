## 二、准备

1. **装包**：`mpsv-sql-insight-gate/build/distributions/mybatis-plus-sql-visualizer-2026.10.23.zip`。
   Settings → Plugins → 齿轮 → Install Plugin from Disk → 重启 IDE。
   注意版本号已从 `2026.10.23-beta.2` 转正为 `2026.10.23`；distributions 目录里可能同时躺着旧的 beta 包和 `2026.10.16` 包，装错就验的是旧树。
2. **核对版本**：Settings → SQL Visualizer → About 显示 `2026.10.23`。
3. **演示工程**：`mybatis-plus-sql-visualizer-demo`，从 IDE 内 Run 启动 `MybatisPlusDemoApplication`（8081）。
   运行分析（功能 3）与请求观测的前提是应用**从 IDE 内启动**——外部命令行启动的进程不会被 agent 挂载。
4. **数据库**：`mpj_demo`（root/root），demo 的 `.idea/dataSources.xml` 已配好。若数据源未绑定，先在 Database 工具窗口执行一次查询完成绑定。
5. **打开预览**：SQL 日志工具窗双击任一条目，或编辑器 gutter 图标，或 `Alt+Shift+Q`。
6. **打开洞察入口**：预览面板工具栏最右侧「更多」菜单。九项洞察插在「回滚 SQL」之后，实际顺序：
   `分析SQL / 参数场景 / 渲染解释 / 运行SQL分析 / 导入离线Trace / 对象使用与影响 / 比较本地Schema快照 / 优化候选 / 比较SELECT结果`，之后才是导入参数、差异对比、分享等原有项。

## 三、十分钟冒烟路径

九项全过且不抛异常，即冒烟通过；细节走第四节。

1. 双击一条 SELECT 日志 → 更多 → 分析SQL。面板内出现「SQL分析」页签，含结构与来源树、读写关系有向图、分析质量三块。
2. 点树里任一节点 → 预览编辑器对应语句被选中。
3. 打开一个 Mapper XML 的动态 SQL 预览 → 更多 → 参数场景。出现「场景与渲染解释」，列出当前输入与已存预设。
4. 同一预览 → 更多 → 运行SQL分析。勾「启用所有会话的分析」→ 让 demo 跑几个请求 → 点「刷新快照」，工作负载表出现形状指纹、执行数、累计 JDBC 纳秒。
5. 更多 → 对象使用与影响。先在 IDE 里选中一个源文件 → 填表名 → 「扫描所选范围」→ 出现引用清单，点「打开选中引用」能跳回源码。
6. 更多 → 优化候选。对 `WHERE DATE(created_at) = ?` 这类 SQL，应出现带规则 ID 与 AST 证据的候选。
7. 更多 → 比较SELECT结果。不选目标时应提示「请先明确选择目标」，不默认使用任何数据源。
8. 更多 → 比较本地Schema快照。左右各粘一份 `sql-visualizer-schema-v1` JSON → 出现增删改差异表。
9. 更多 → 导入离线Trace。粘贴一段 OTLP JSON（≤1 MiB）→ 出现 span 投影列表。
10. **本轮新增**：看预览参数区下方的「数据源：」指示行是否在、三态文案是否正确，右侧是否有「切换数据源」链接（§4.10）。
11. **本轮新增**：点「切换数据源」→ 必须弹出 IDE 原生数据源列表；选一条后不自动执行（§4.10）。
12. **本轮新增**：把数据源故意绑错库，点「执行计划」→ 应就地出横幅而不是弹模态框（§4.11）。

## 四、逐项功能验收

每项表格三列：**功能点 / 路径与操作 / 预期**。「路径」一律从打开预览开始写，可直接照做。

### 4.1 分析 SQL（结构与来源）

入口：更多 → 分析SQL。面板内新增「SQL分析」页签，**不弹独立窗口**。

| 功能点 | 路径与操作 | 预期 |
|---|---|---|
| 结构树 | 更多 → 分析SQL → 看「结构与来源树」 | 分「语句结构与表读写角色」「结果字段与已证实来源」「值来源与行选择依赖」「诊断与覆盖范围」四块；未解析处显示局部原因而不是留白 |
| 读写图 | 切到「读写关系有向图」 | 只画读写关系边；JOIN 不会被画成写。节点可点，点后定位 SQL |
| 分析质量 | 看「分析质量」区 | 显示 CERTAIN / PARTIAL / AMBIGUOUS / UNKNOWN / CONDITIONAL 之一并给出依据；另显示「源码区间质量」与「已验证方言」 |
| 节点定位 | 点树节点或图节点 | 有已验证精确区间时选中该区间（提示「已定位到经过验证的源码区间」）；没有时选中整条 SQL（提示「没有经过验证的精确区间，已选择全语句；未猜测同名片段位置」）——后者是正常现象 |
| 复制摘要 | 点「复制分析摘要」 | 剪贴板得到文本摘要；超预算时明确写 omitted，不静默截断 |
| 离线声明 | 读面板顶部提示 | 明说「仅离线分析，不执行SQL，不读取数据库元数据。JOIN和筛选依赖不等于值血缘」 |
| 空文档 | 清空 SQL 后打开 | 显示「当前SQL文档为空，不会分析上一次SQL」 |
| 编辑失效 | 打开分析后改 SQL 文本 | 提示「SQL或预览已变化，旧分析已清除，请重新分析」；旧分析不复活 |
| 老结果不串页签 | 关闭预览再开另一条 SQL | 不显示上一条 SQL 的分析结果 |
| 显示预算 | 对超大语句（>200 节点）打开 | 提示「已达显示预算（200节点／400边／1000条详情），当前展示的是不完整子集」 |
| 输入超限 | 粘贴 >65,536 字符 | 提示「输入超过65,536字符，请缩小为单条语句后分析」 |
| 取消 | 分析中点点「取消」 | 提示「已取消分析，不会回填结果」 |
| 重新分析 | 改 SQL 后点「重新分析」 | 按新文本重跑，结果与新版一致 |

### 4.2 参数场景 / 渲染解释

入口：更多 → 参数场景，或 更多 → 渲染解释。**两个菜单项打开同一个面板**（同一能力的两种叫法，不是两个功能）。

| 功能点 | 路径与操作 | 预期 |
|---|---|---|
| 场景列表 | 打开 XML 预览 → 更多 → 参数场景 | 出现「场景与渲染解释」，列表含「当前输入」与已存命名预设；列显示场景名、参数数、关系数／失败 |
| 上限 | 预设多于 19 个 | 提示「展示当前输入及前19个已存场景，其余预设未分析」 |
| 只读性 | 选中另一个场景看详情 | 只读快照，不切换、不改写命名预设，参数面板不变 |
| 条件说明 | 读面板提示 | 明说「条件遵循预览开关，不代表真实运行路径覆盖」；trace 定位是展开节点路径，不是原 XML 偏移 |
| 非 XML 预览 | 对普通 Java Wrapper 预览打开 | 提示「参数场景需要XML预览模型；当前SQL和预设未改变」 |
| 脱敏导出 | 点「预览脱敏回归JSON」→「复制已审阅JSON」 | 参数值、标识符、预设名已移除；无网络请求；提示「此包不得作为SQL执行」 |
| 期望校验 | 「保存本页期望」→「验证当前场景」 | 仅确定语义可保存；无期望时显示 INCONCLUSIVE 而不是 PASS |
| 存储清理 | 参数存储被清后打开 | 提示「参数存储已清理，请重新打开预览后生成场景」 |

### 4.3 运行 SQL 分析

入口：更多 → 运行SQL分析。**默认不开启分析**。

| 功能点 | 路径与操作 | 预期 |
|---|---|---|
| 总开关 | 勾「启用所有会话的分析」 | 显式提示影响所有已连接 agent 会话；关闭本页即停用所有会话的分析 |
| 手动刷新 | 点「刷新快照」 | 只在点击时刷新，不常驻轮询 |
| 工作负载表 | 看「工作负载」页签 | 列含：会话、形状指纹、执行数、累计JDBC纳秒、错误／未知、预算判定 |
| 目标身份 | 看目标列 | 显示「已解析目标身份（不是数据库显示名）」；无法解析时显示「未知连接目标」「未知执行目标」「未验证目标身份」三档之一 |
| 预算判定 | 填「最大执行数」「最大累计毫秒」→「按当前预算判定」 | 按当前阈值判定，结果回写判定列 |
| 请求时间轴 | 切「请求与时间轴」页签，展开请求 | 显示 requestId（来自请求控制事件）与 requestTag（仅为标签）的区别；区间并集纳秒；只代表请求线程内观测 |
| 事务视图 | 切「事务」页签 | 仅展示已观测 JDBC 边界事件；CLOSE 不等于 COMMIT，未知保持 UNKNOWN |
| 重复候选 | 切「标签、重复与时间轴」→ 看「重复查询候选」 | 只显示「候选」，不宣称已证实 N+1 |
| 预览执行候选 | 看「预览执行候选」 | 只列最近 24 小时候选；同形状不证明同次执行；不猜数据库或调用点；未保留 SQL 原文，不提供全文 Diff |
| 基线 | 点「保存本页基线」→「对比本页基线」 | 提示「已保存本页内存基线；缺少生产端总量或质量证据时仍为INCONCLUSIVE」；未保存就对比时提示「请先保存本页基线」 |
| 隐私 | 读面板提示 | 「仅在本机内存保留参数化形状指纹与元数据，不上传；不会替你开启JDBC捕获」 |

### 4.4 离线 Trace 导入

入口：更多 → 导入离线Trace。面板名「离线Trace投影」。

| 功能点 | 路径与操作 | 预期 |
|---|---|---|
| 粘贴导入 | 粘贴 OTLP JSON → 点「导入粘贴的JSON」 | 出现 span 列表；**不自动读剪贴板** |
| 文件导入 | 点「选择本地Trace JSON文件」 | 弹文件选择器；读取有界（≤1 MiB） |
| 超限 | 粘贴 >1 MiB | 提示「导入已拒绝」，不部分导入 |
| 非法 JSON | 粘贴非法内容或重复键 | 同上，整体拒绝 |
| 外部覆盖 | 看 span 的覆盖标记 | 外部覆盖保持 UNKNOWN，不猜 |
| 链接模板 | 填含 `{traceId}` 的 HTTPS 模板 → 「打开选中Trace链接」 | 校验：只含一个 `{traceId}`、禁凭据、非 443 拒绝；错误时提示「请选择span并配置只含一个{traceId}的有效HTTPS模板，不允许凭据或非443端口」 |
| 不点不发 | 全程观察 | 不点击「打开选中Trace链接」就不发任何网络请求 |

### 4.6 本地 Schema 比较

入口：更多 → 比较本地Schema快照。面板名「Schema快照比较」。

| 功能点 | 路径与操作 | 预期 |
|---|---|---|
| 比较 | 左粘旧 JSON、右粘新 JSON（`sql-visualizer-schema-v1`）→「比较粘贴的快照」 | 出现表／列／变化清单，含可空性前后值 |
| 身份校验 | 两份数据库身份相同或版本相同 | 拒绝比较并说明原因（必须含数据库身份、方言和不同版本） |
| 超限 | 单份 >1 MiB | 拒绝，不部分读取 |
| 无查询 | 全程观察 | 不查询、不自动绑定生产数据源 |
| 影响范围 | 缺少源码使用证据 | 明确标注影响范围不完整，不当作完整清单 |
| 关联使用 | 勾「关联本次已收集的使用快照」 | 有使用快照时把影响范围并入 |

### 4.7 优化候选

入口：更多 → 优化候选。面板名「静态优化候选」。列：规则、AST证据。

| 功能点 | 路径与操作 | 预期 |
|---|---|---|
| 函数包裹列 | 对 `WHERE DATE(created_at) = ?` 打开 | 出现 `SI.NON_SARG_COLUMN_FUNCTION`，附 AST 证据与「普通索引可能不适用」前提 |
| 宽投影 | `SELECT *` 或投影列很多的语句 | 出现 `SI.WIDE_STAR_PROJECTION`，说明列随 schema 增长的成本 |
| 笛卡尔风险 | 多表 FROM 但无 ON／USING／NATURAL 且无 WHERE 连接谓词 | 出现 `SI.CARTESIAN_JOIN` |
| 只读 | 全程观察 | 不改写 SQL、不建索引、不执行 EXPLAIN 或查询 |
| 无候选 | 单表简单等值查询 | 空态说明无命中，**不编造建议** |
| 位置 | 缺精确区间时 | 不猜位置，退回整语句 |
| 性质声明 | 读提示 | 明说「仅带前置条件的静态候选，不是实测性能结论」 |

### 4.8 SELECT 结果比较

入口：更多 → 比较SELECT结果。面板名「显式SELECT结果比较」。**仅打开不执行**。

| 功能点 | 路径与操作 | 预期 |
|---|---|---|
| 目标选择 | 「发现目标」→ 明确选一个 →「使用明确选中的目标」 | 不默认选任何数据源；未选时提示「请先明确选择目标，不默认选取任何数据源」 |
| 审阅 | 点「审阅准确SQL对」 | 显示两段完整 SQL 与行数上限；未回填参数时提示「不接受未回填的位置／命名／模板参数，请提供完整字面SELECT」 |

## 六、正常现象（先排除，再报缺陷）

- 点树节点后选中整条 SQL：未证明精确源码区间时按设计选全语句，不是定位失败。
- 「分析质量」显示 PARTIAL／AMBIGUOUS／UNKNOWN：解析器只对已验证子集给 CERTAIN，带星号、未绑定元数据、方言不支持等都会降级，属正常披露。
- 运行分析里大量「未知连接目标」：多主机／非标准 URL 或无连接事件时按未知隔离，不会合并成同一目标。
- 请求时间轴出现 INCONCLUSIVE：跨线程、终态缺失或采集不完整时按设计不判 PASS。
- 事务视图显示 UNKNOWN：只有 JDBC 边界事件被观测，CLOSE 不等于 COMMIT。
- 优化候选为空：没有命中已实现的三条规则时不编造建议。
- 结果比较拒绝执行：未选目标、未勾三项批准、参数未回填、方言未确认，任一不满足都会拒绝，属安全设计。
- 离线 Trace 导入被拒绝：超 1 MiB、字段非法、重复键或非 OTLP JSON 都拒绝。
- 对象使用提示「未使用陈旧偏移定位」：源文件已变化，按设计不跳旧位置。
- 编辑 SQL 后分析页签消失或变空：文档版本变化使旧结果失效，重新打开即可。
- **数据源指示行显示「未绑定数据源」**：预览从未在控制台执行过查询，属正常初态，执行一次查询即绑定。
- **点「切换数据源」后没有自动执行**：W6 已取消自动重试，选中源后需自己再点执行计划，属设计而非失灵。

## 七、不覆盖范围（不要按缺陷报）

- 未实现的语法形态：递归 CTE、存储过程内部、任意动态脚本、跨过程血缘。
- 请求观测仅限 Servlet 线程内（`SERVLET_THREAD_ONLY`）；异步、线程池、响应式、虚拟线程未承诺。
- 事务仅为代理连接／wrapper 生命周期证据（`PROXIED_CONNECTION_ONLY`），不认证真实池租借、XA 或跨线程传播。
- 结果比较是两次顺序读取，不是数据库原子快照。
- **性能**：新增请求追踪的延迟与 CPU 超出初始目标（P95 +27.17%、CPU +14.28pp），因此请求／事务追踪默认关闭，只在显式开启时承担成本。这是已披露的取舍，不是缺陷。
- 本机 Docker 不可用，5 个真实数据库方言用例在门禁中跳过；H2／SQLite 嵌入式验证覆盖语法形态，不等于方言运行时全覆盖。
- 结果比较、Schema 比较、影响面等仍只有合成 H2／SQLite 证据，未做真实业务库端到端。

## 十、本轮合并对功能的影响
