O-52（T-IdentityInsertWrap，`docs/开发计划/20260921-2330`）把「可回放 INSERT 的 identity 包装」从**生成物缺陷**升级为**执行缺陷**——SQL Server 上把带 identity 列的整行 INSERT 直接提交会报 **544**，须 `SET IDENTITY_INSERT <表> ON/OFF` 成对包裹。

包装成立要**两个输入同时到位**：`active` 里有列带 `autoGenerated=true`，且 `model.dialect` 是需要包装的方言。判定落在共用渲染点 `BatchModel.renderSql` 的 INSERT 分支（`model/BatchModel.kt:128-133`）：`if (active.none { it.autoGenerated }) base else dialect.renderInsertWrapper(...) ?: base`。

**回滚链上这两个输入都是空的**（2026-09-22 独立复核 blocker②，逐条实测）：

| 环节 | 实测事实 |
|---|---|
| 唯一生产登记点 | `ui/SqlPreviewPanel.kt:1079`（回滚SQL 按钮）与 `:1291`（执行链）调 `RollbackSnapshotStore.register(...)`——第 6/7 参 `dialect` / `identityColumns` **都有默认值**（`null` / `emptyList()`），**两处都没传** |
| 消费侧 | `ui/RollbackSqlDialog.kt:269-270` 只从 `snapshotEntry` 取这两项 → 恒 null/empty |
| 判定侧 | `sql/rollback/RollbackSqlGenerator.kt:413-415` 的 `backfillInsert`：`wrapIdentity = identityColumns.any {...}` → 空清单恒 false → `wrapper` 恒 null |
| 现状被钉成断言 | `ui/RollbackSqlPanelTest.kt:174-180` 的 `testExecuteAdhocSqlRegistrationCarriesNoIdentityInfoYet` 把该缺口写成契约，**修复须同步反转，否则一改就红** |

**为什么单测全绿而产品不可用**：单测**直接构造 `SnapshotEntry`**（自带 dialect/identityColumns），**绕过了登记点**——这正是缺陷漏到生产的原因，也是验收只能靠真机的原因。

**同族另两条链已收口，只剩回滚链**：CRUD 链由 O-52 本体接线（`CrudSqlGenerator`）；**PSI/实体批量链**（MP `saveBatch`/`insertBatch`，`psi/BatchOperationConverter`）由 T-Round10 的复核订正 `751fc82` 补齐（`batchColumns` 补 `autoGenerated = col.idTypeAuto`，口径与 `GenerateCrudSqlFromEntityAction` 同源）——即**实体/批量路径在 SQL Server 上已能出带包装 INSERT，回滚链（DELETE 后粘贴快照回填）仍报 544**。两者缺口不同：前者缺标记接线（已补），后者缺登记点的表结构来源（未补）。

**处置＝已立项 T-IdentityInsertRollback（O-59）**，计划 `docs/开发计划/20260922-2045-T-IdentityInsertRollback-回滚链identity包装接线与表结构来源-开发计划.md`（用户 2026-09-22 定案「单独立项」）。计划含三条口径修正与四条待验证前提，**前提 1 已于 2026-09-22 实测**：DELETE 路径**确实**不持有表结构（两个登记点如上，得靠自省）；**可复用面确实存在**（`DatabaseSchemaResolver.columnMeta`，符合计划说的「复用不新造」）**但 `ColumnMeta(comment, typeSpec, notNull)` 没有自增标记** → T-IIR-02 须扩该字段；且 `resolveFromSources` 在**无数据源时直接返回空**（本环境正是如此，`roots=0`）。

**环境依赖（验收硬约束）**：本机 DBX 在册连接**无 `sqlserver` 类型**（50~53 条实测）→ SQL Server 端到端**不可执行**，只能登记「环境受限未验证」，**不得以单测读数替代**。
