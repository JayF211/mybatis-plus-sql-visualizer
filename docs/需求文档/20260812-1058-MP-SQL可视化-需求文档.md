# 功能概览

> 本文档是 **MyBatis-Plus SQL Visualizer** 的功能规格书，用于指导开发与验收。
> 配套文档：[README](../README.md)（产品背景与初稿）、[开发计划](../开发计划/20260812-1058-MP-SQL可视化-开发计划.md)（分阶段实施计划）。
> 功能编号（`F-xx`）为稳定标识，开发计划中的任务会引用它们，后续跟进请以编号为准。

---

## 1. 产品定位

在 IntelliJ IDEA 中，将 MyBatis-Plus（含 MyBatis-Plus-Join）的 Wrapper 构造链**实时转换为可读、可复制、参数已替换的 SQL**，解决"调试困难、SQL 优化不便、联表查询复杂、参数不可见、CRUD 覆盖不全"等痛点，降低 MP 学习与排查成本。

## 3. 功能详细规格

### 3.1 支持的类型与操作矩阵

**Wrapper 类型（输入）**

| Wrapper | SELECT | UPDATE | DELETE | JOIN | 状态 |
|---------|:------:|:------:|:------:|:----:|------|
| `LambdaQueryWrapper` | ✅ F-01 | – | – | – | P0 |
| `LambdaUpdateWrapper` | – | ✅ F-09 | – | – | P1 |
| `LambdaDeleteWrapper` | – | – | ✅ F-10 | – | P1 |
| `MPJLambdaWrapper` | ✅ F-11 | – | – | ✅ | P1 |
| `MPJQueryWrapper` | ✅ F-12 | – | – | ✅ | P1 |
| `QueryWrapper` / `UpdateWrapper`（字符串） | ✅ F-17 | ✅ F-17 | – | – | P2 |

**条件操作（WHERE 片段，query 类通用）**

| 操作 | 示例 | 优先级 |
|------|------|--------|
| 等值/不等 | `eq` `ne` | P0 |
| 比较 | `gt` `ge` `lt` `le` | P0 |
| 模糊 | `like` `notLike` `likeLeft` `likeRight` | P0 |
| 范围 | `in` `notIn` `between` `notBetween` | P0 |
| 空值 | `isNull` `isNotNull` | P0 |
| 逻辑 | `and` `or`（含嵌套 lambda） | P0 |
| 分组/排序/分页 | `groupBy` `having` `orderByAsc/Desc` `orderBy` `last` `limit/page` | P0 |
| 自定义片段 | `apply` `last` | P2 |

**列与表操作**

| 操作 | 说明 | 优先级 |
|------|------|--------|
| `select` / `selectAs` | SELECT 列（含别名） | P0 |
| `from` | 表（MPJ 联表场景） | P1 |
| `join` / `leftJoin` / `rightJoin` | 联表（MPJ） | P1 |
| `set` / `setSql` | UPDATE 赋值 | P1 |

### 3.2 转换流程（核心链路）

```
编辑器 PSI 源码
   │  ① 定位 Wrapper 变量/调用链（PSI 解析）
   ▼
Wrapper 调用链模型（内部 AST：类型、字段、操作、参数）
   │  ② 语义映射（Lambda → 列名、实体 → 表名）
   ▼
SQL 语句模型（SELECT/UPDATE/DELETE 结构化表示）
   │  ③ SQL 生成（含方言差异、格式美化）
   ▼
最终 SQL 文本 + 参数绑定表
   │  ④ 展示（悬停 / 弹窗 / 工具窗口）与复制
```

### 3.3 各功能详细说明

#### F-01 LambdaQueryWrapper → SELECT（P0）
- **输入**：代码中 `LambdaQueryWrapper<Entity>` 或 `new LambdaQueryWrapper<>().eq(...)...` 调用链。
- **输出**：完整 `SELECT` SQL：`SELECT 列 FROM 表 WHERE ... GROUP BY ... ORDER BY ... LIMIT ...`。
- **要点**：
  - 解析方法调用链（支持链式与分步变量引用：`wrapper.eq(...)` 后赋给新变量再继续）。
  - `select()` 未显式指定时，默认取实体类全部字段（按实体解析）。
  - Lambda 形如 `Entity::getXxx`，需将 getter 反解为列名（`getCarId` → `car_id`，遵循命名策略）。
  - 未知/无法解析的调用应降级为可读的占位提示，而不是崩溃或静默丢弃。

#### F-02 参数替换（P0）
- `?` 占位符替换为真实值：
  - **基本类型**：数值原样；字符串加引号 `'xxx'`；布尔、日期按方言格式化。
  - **对象**：调用其 `toString()`（常见 VO/DTO）。
  - **集合**：`in` 场景展开为 `(1, 2, 3)`。
  - **null**：`IS NULL` 语义或 `= NULL` 保留原样并标注。
- 提供"替换/不替换"开关（F-16 配置联动）。
- 输出 SQL 时附参数对照表（如 `[stationId=101, schemeId=5, id=1]`），便于核对。

#### F-03 SQL 格式化（P0）
- 关键字大写、子句换行缩进（`SELECT` / `FROM` / `WHERE` / `GROUP BY` / `ORDER BY` / `LIMIT`）。
- 逗号分隔列、条件缩进。
- 提供"格式化 / 单行"两种视图切换（UI 层）。

#### F-04 / F-05 / F-06 触发方式（P0）
| 触发方式 | 实现 | 优先级 |
|----------|------|--------|
| 右键菜单 | `AnAction`，注册到编辑器弹出菜单，分组名 "MP-SQL-Preview" → "Convert to SQL" | P0 |
| 快捷键 | `AnAction` + `Keymap` 注册，默认 `Ctrl+Alt+S`（Mac `Cmd+Option+S`），可配置（F-16） | P0 |
| 悬停 | 编辑器 `DaemonCodeAnalyzer` + `DocumentationProvider` 或 `EditorMouseMotionListener`，光标停留显示 SQL 弹层 | P0 |
- 三者共用同一套转换引擎与结果面板，避免重复实现。

#### F-07 / F-08 工具窗口与复制（P0）
- 工具窗口（`ToolWindow`，ID 建议 `MyBatis-Plus SQL Visualizer`）：
  - 上方：SQL 展示区（带语法高亮的只读编辑器，或 `JBTextArea` + 高亮器）。
  - 下方：参数对照表、方言选择、格式化开关（快捷操作，与 Settings 联动）。
  - 工具栏：复制、刷新、定位到代码（`Show Source`）、清空。
- 复制按钮一键复制当前 SQL 到剪贴板，复制成功后提示。

#### F-09 / F-10 UPDATE / DELETE（P1）
- `LambdaUpdateWrapper`：`set(Entity::getX, v)` / `setSql(...)` → `UPDATE 表 SET col = ? ... WHERE ...`。
- `LambdaDeleteWrapper`：`DELETE FROM 表 WHERE ...`。
- 复用 F-01 的条件解析与参数替换；若无 WHERE，明确提示"全表更新/删除"风险（红色警示）。

#### F-11 / F-12 MPJ 联表（P1）
- `MPJLambdaWrapper`：解析 `selectAs`、`join/leftJoin`、`on` 条件、`from` 主表。
- 输出完整联表 SQL（参考 README 中的示例）。
- 表别名规则与 MPJ 一致（主表 `t`、关联表按类名小写首字母等），需在实现时对齐 MPJ 实际行为并写入测试。

#### F-13 表名 / 列名解析（P0，贯穿所有转换）
- 从实体类 PSI 读取 `@TableName(value)`、`@TableField(value)`；无注解时按命名策略推断。
- 支持全局命名策略配置（下划线转驼峰/原样），映射到 F-16 配置项。
- 字段继承、`@TableId` 主键识别。

#### F-14 多数据库方言（P1）
- 影响：占位符风格（`?` / `:name`）、分页（`LIMIT` / `OFFSET ... FETCH` / `ROWNUM`）、字符串与日期字面量、标识符引用（反引号/双引号）。
- 方言来源：Settings 手动选择（优先实现）→ 后续可探测项目数据库连接（P2 增强）。

#### F-15 批量操作预览（P2）
- 识别 `updateBatchById` / `insertBatchSomeColumn` 等批量调用，展开为批量 SQL 或循环 SQL + 参数组列表。

#### F-16 配置页面（P1）
- 入口：Settings → Tools → MyBatis-Plus SQL Visualizer。
- 配置项（默认值）：
  | 配置项 | 默认值 |
  |--------|--------|
  | 数据库方言 | MySQL |
  | 是否替换参数 | 是 |
  | SQL 格式化 | 是 |
  | 显示方式（弹窗/工具窗口/两者） | 两者 |
  | 触发快捷键 | Ctrl+Alt+S |
  | 自动预览（悬停） | 开启 |
  | 表名/列名策略 | 自动识别（下划线转驼峰） |
  | 悬停延迟 | 500ms |
- 使用 `PersistentStateComponent` 持久化。

#### F-20 缓存与性能（P0 贯穿）
- PSI 解析结果按 `PsiFile` + 版本号缓存，文件变更时失效。
- 转换引擎纯函数化，便于单测与复用；悬停路径不得执行重量级操作（如项目模型刷新）。

## 4. 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 悬停/快捷键触发响应 < 200ms；解析缓存命中时 < 50ms；不阻塞 EDT |
| 兼容性 | 基于 IDEA 2025.3.5 编译，目标兼容 2024.x ~ 2025.x；`verifyPlugin` 通过 |
| 健壮性 | 遇到无法解析的代码（语法错误、未知 API）给出可读提示，不抛异常、不影响 IDE |
| 可扩展性 | 新增 Wrapper 类型只需实现 Converter SPI（接口 + 注册），不修改展示层 |
| 可测试性 | 转换引擎与 UI 解耦，核心逻辑 100% 可单测（纯文本输入/输出） |
| 国际化 | 文案走 `messages` bundle（中文 + 英文），不使用硬编码字符串 |

## 5. 模块架构（与开发计划对应）

包结构沿用现有 Kotlin 工程（基础包 `cn.song.mybatisplus.visualizer`）：

```
src/main/kotlin/cn/song/mybatisplus/visualizer/
├── actions/          # AnAction：右键菜单、快捷键、悬停（F-04/05/06）
├── psi/              # PSI 解析：Wrapper 变量定位、调用链提取、实体/注解读取（F-13）
├── model/            # 内部模型：WrapperChain、Condition、SqlStatement（F-01 基础）
├── converter/        # 转换器 SPI + 各 Wrapper 实现（F-01/09/10/11/12/17）
├── sql/              # SQL 生成器 + 方言适配（F-14）+ 格式化器（F-03）+ 参数替换（F-02）
├── ui/               # 工具窗口、弹窗、高亮面板、复制（F-07/08）
├── config/           # Settings 页面与持久化（F-16）
└── util/             # 命名策略、缓存等工具（F-13/F-20）
```

依赖方向：`actions`/`ui` → `converter`/`config` → `model`/`psi`/`sql`（单向，禁止反向依赖）。
