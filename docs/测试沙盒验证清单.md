### 热替换本地验证（T-DynUpdate，不依赖 Gitee/市场）

1. 构建新版包（版本号高于 gradle.properties 的当前版本）：
   `./gradlew buildPlugin -Pversion=2026.9.11-beta.1`
2. 跑「Run IDE (Local Manifest)」（runIdeHotSwap 任务，共享默认沙盒、autoReload 已关防竞态）——
   本地服务随任务自动起停：doFirst 自动拉起 hotswap-local-server.py（端口被占则复用不接管），
   IDE 关闭/崩溃/任务失败都由 finalizedBy（hotswapServerStop）按 pid 文件停服务，只杀自有进程；
   服务日志在 build/hotswap-server.log。也可手动 `python dev-support/hotswap-local-server.py`。
4. 沙盒里设置 → 更新分区 → 检查更新 → 下载并安装 → 按上面第 3 条判定
5. 重置：停服务 → 重跑（prepareSandbox 每次覆盖沙盒插件目录）

注意：「从磁盘安装」（Install from Disk）测不出免重启——平台该流程不卸载已加载旧版，必提示重启（F0 反编译实证），不能据此判断功能无效。
