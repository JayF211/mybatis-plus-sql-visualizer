# 全量测试墙钟十三次压缩（T-TestPerf15）经验总结

> 2026-10-05，分支 `t-testperf15` 自 `t-testperf14` tip `1cca075`；台账与定案详版见计划文档 §七。
> 结论先行：本轮没有新物理杠杆——交付的是 **O-97 顺序依赖竞态的根因治理**（测试间全局设置态泄漏，两层修复）与 **auto-handicap 缺省翻转**（T14 D45 留案兑现）。修复前双类组合 41 秒复现 T14 补偿轮炸 20 例的形态；治理后触发轮四轮零 O-97、收口轮全绿 6395/0/0/9。同窗 A/B：off 中位 185.8s vs auto 中位 167.8s（−9.7%），失衡窗口自动兑现。

## 六条认知

1. **「排除结论」本身要进证据链复核**。T13 立案 O-97 时把 formatSql 排除了，理由「仅设置 UI/IO 消费，渲染链不读」——一处 grep 就能证伪：`SqlPreviewService.kt:1704` 的 `formatSql()` 直读全局态，渲染链真实消费。排查轮里「逐点核验后排除」的结论如果没带文件:行号出处，下一轮要先重验再采信；本轮根因定位的正向突破口恰是这条被排除的通道。

2. **恢复「进入时值」与恢复「出厂默认」是两种语义，前者会传递污染**。仓内既有恢复纪律大多是 `val old = state.x; try { … } finally { state.x = old }`——在进态已被前类污染时，finally 忠实地把污染恢复到位，泄漏穿透。治理两层由此分形：写入者快照/回放（照 ProjectPluginSettingsConfigurableTest 范式）管纪律，读者 setUp `resetToFactoryDefaults()`（`loadState(State())` 走 PersistentStateComponent 汇入点）管起点——后者新键自动同步、零维护，比逐键列缺省值清单稳。

3. **双类组合复现实验把全量轮的猜谜变成 41 秒的实证**。O-97 从 2026-09-29 立案到本轮钉死，差的不是工具是配对：`test --tests 污染源 --tests 受害者` 同 JVM 按字典序执行，修复前 OfficialApi 18/39 单行形态逐字复现，修复后同命令 39/0 绿——先红后绿两个读数把根因和修法同时钉死，比任何「逐点核验」都硬。

4. **auto 改分区的踩面在治理后归零，但 flake 判据必须与治理判据分离**。T14 auto 轮 3 轮 2 炸（O-97 20 例+O-93 族 1 例）；本轮触发轮 4 轮（R3/R3b/R5/R6）零 O-97 形态、收口触发轮全绿——治理效果以「目标形态零复现」计。同窗另有 4 例 5 站失败（FatalPassthrough×3、HistorySqlLog 面板族×2、AgentManagerPremain×1），全部落在 T9/T10 在册 flake 家族且定向复绿 4/4（log 包同 JVM 全跑 1m28s 零失败，排除族内顺序依赖）——在册家族的负载敏感竞态在本轮窗口频率偏高（FatalPassthrough 3/6 轮），按「失败集合⊆既有集+逐例定向复绿」判据处置，不影响治理结论。

5. **buildSrc 变更后的首个全量轮自带一次性税，不能进计时样本**。S4 翻缺省值后 R1 跑出 10m55s（warm 带的 3 倍）+flake，R2 立即回到 3m13s——buildSrc classpath 变更触发全量重配置与平台链重算，属于一次性；台账把 R1 记异常轮剔除，A/B 用同窗 warm 轮中位对账。反向教训：收口权威轮永远安排在机制变更后的第二轮以后。

6. **失败轮不落盘失衡历史（T14 设计语义）会在连续失败时放大注入寿命**。R3/R3b/R4/R5 四轮失败轮都没写 jsonl，注入的 3 连触发历史一直留在文件尾——R5/R6 在无人补注入的情况下继续触发。这本身是正确语义（失败轮不参与判定），但做触发类实验时要知道：**失败不会冲掉你的注入**，实验完记得清理（本轮收口后 jsonl 已还原真实历史行）。

## 地板声明更新（供下一轮立项对照）

5 片时长均衡栈的 warm 地板维持 ≈2m30s~3m00s @ 6395 例；本轮兑现的是**失衡窗口的自动补偿**（off 中位 185.8s vs auto 中位 167.8s，−9.7%；T14 A/B −7.7% 复现且略优）。物理面零入口维持（T9~T14 全清单）；机制面 auto-handicap 缺省开已在役，`-PtestShardAutoHandicap=false` 显式关保留退路。剩余可做：在册 flake 家族（FatalPassthrough/HistorySqlLog 面板族/agent 回调竞速）的时序加固——属测试稳定性域，不属于墙钟压缩域。
