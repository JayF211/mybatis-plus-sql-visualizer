### 1.2 缺口定义（请求级 vs 跨请求）

- **请求级（会话内）**：唯一请求边界是 requestTag，而它是**纯 opt-in**——全仓 grep `sqlvisRequestTag` 仅两处**读**点（MdcAccessor.java:14-28、SourceInterceptorTemplates.kt:94-97），**插件从不写该 MDC 键**，宿主应用不主动 set 则恒 null。一期 Web 过滤器 hook 未做（MdcAccessor.java:9）。无标签条目做不了请求级分组。
- **兜底边界缺失**：`LogSqlEntry` 无 threadName 字段（agent 事件有 `AgentEvent.kt:37`，Adapter :15-43 映射时**丢弃**）；控制台链的线程分桶（`log/LogThreadRouter.kt:9`，三解析器共享）只在解析期存在、不落条目。即无标签时既无请求边界也无线程边界，只能退化为时间窗滚动聚类。
- **跨请求（历史落盘）**：HistorySearchService 读回条目后 Hit 不含 structureKey/requestTag，按模板聚合需在检索侧逐条现算指纹再分组——面在，字段未通。

### 1.3 成本档：**M**（缩范围可 **S**）

- **S**：只做「同模板 ≥N 次疑似标记」——structureKey＋dedupeCounts 同款计数＋徽章复用，无请求边界（全量滚动窗口），资产全部现成。
- **M**：补请求边界——requestTag 命中时按请求分组（聚焦页签同域），无标签时时间窗兜底＋阈值文案降级（「疑似 N+1，无请求标签」）；含 agent Adapter 透传 threadName 的小改。
- 跨请求历史聚类（检索面加指纹分组）：另计 **M~L**，建议不并入首版。

### 1.4 建议＋差异化叙事

**建议立项，按 M 档做请求级首版**（S 档做保底）。前置②差异化叙事一句话（供实现时用）：

> Hibernate Debugger 的 N+1 是**运行期实时检测**（执行中告警）；我方做**捕获后聚类标记**——对已捕获的日志/agent 条目按结构指纹离线聚合标注，零运行时开销、同时覆盖控制台三链与 agent 历史，不做实时 profiler（红线）。

## 二、O-91（CRUD/回滚 SQL 可移植导出）前置：O-9 闸门 UPSERT 边界核对

开发计划 P2 表口径（计划 :90）：「标准语法优先＋方言形态标注；O-9 闸门 UPSERT 边界核对」。

### 2.1 UPSERT 现状锚点（MERGE / ON DUPLICATE / ON CONFLICT 三形态）

**O-9 闸门本体**：`execute/UnboundedWriteDetector.kt:24`（T-UnboundedWriteGuard / O-9），只分析 UPDATE/DELETE 的 WHERE 风险，**INSERT 系一律忽略**（:148「INSERT 不适用」），消费者＝确认流 `execute/ExecuteConfirmMessages.kt:19`（detect 入口）＋回滚链弱谓词警示（:37-38 KDoc 契约）。⇒ **三形态 UPSERT 均不进闸门视野**。

**CRUD 生成链（已有完整方言降级链——「标准语法优先」事实上已实现）**

- `model/BatchModel.kt:149-173`（BatchKind.UPSERT 渲染分支）：主键勾选时 `renderUpsertStatement`（整语句形态）→ `renderUpsert`（后缀形态）→ 纯 INSERT，**三级降级逐字在案**（:158-160 注释）。
- `sql/Dialect.kt:104-130`：两种形态的接口契约（null → 无原生简洁 upsert 即降级）；MySQL `ON DUPLICATE KEY UPDATE` :324-338（OceanBase/openGauss 同族 :330-333）；PG `ON CONFLICT (k) DO UPDATE` :342-354；H2 整语句 `MERGE INTO..KEY..VALUES` :519-551；**Oracle/SQL Server/DM 无原生简洁形态 → null 降级纯 INSERT**（:422-423、:612）；openGauss 是 MySQL 形态的族推定反例（:740-765，真机实证）。
- identity 包装：`Dialect.kt:147, 470-490`（SQL Server/DM8 `SET IDENTITY_INSERT` 共用形态），O-52 接线于 `BatchModel.kt:128-133`——导出产物含包装语句的剥离判据已备（`sql/IdentityInsertStatements`，闸门侧 :137 同源消费）。
- 注意：`generator/CrudSqlGenerator.kt:43-51` 的候选清单（SELECT×2/INSERT/UPDATE/DELETE/逻辑删除）**无 UPSERT 独立候选**——UPSERT 目前只活在面板勾选重建路径（BatchKind.UPSERT）。

**回滚链（三形态全部诚实拒绝，不产危险半成品）**

- 语句分发 `sql/rollback/RollbackSqlGenerator.kt:159-177`：INSERT→推导 DELETE；UPDATE/DELETE→`unableForDml`＋快照模板；其余类型（含 JSqlParser Merge）→ `rollback.unable.type`（:176）。
- **UPSERT 形态 INSERT 显式判据**：:188-193 `setUpdateSets/duplicateUpdateSets` 非空 → `rollback.unable.upsert`（:192），文案 zh「upsert（{0}）可能修改过已存在行，DELETE 回滚无法还原」（`messages/MpSqlVisualizerBundle_zh.properties:136`）；测试 `RollbackSqlGeneratorTest.kt:160-164`（MySQL ON DUPLICATE 用例）。
- H2 `MERGE INTO..KEY` 解析为 Merge → :176 else 分支诚实拒绝；**PG `ON CONFLICT` 在回滚链的行为仓内无测试覆盖**（JSqlParser 5.x 是否解析该子句未证实，不编造——立项后须补探针）。

### 2.2 与已交付 R4 导出的重叠面判定

R4＝`log/SqlExportService.kt:9-16`：历史/日志**行集**导出 CSV/TSV/TXT，SQL 原文透传（:42-93 三格式分发），零方言变换、零可执行性承诺。O-91＝CRUD/回滚 SQL 的**语义级**导出（方言形态标注、可移植）。**判定：不重叠**——重叠仅「导出文件」外壳动作，内容管线不相交；实现时把两个导出入口做同菜单分组即可避免按钮歧义，无需合并。

### 2.3 DBX 对照点回读（十七/十八轮 §7 表，各一句话对 O-91 的含义）

- **#154 SQL 导出列选择**（十七轮 §7 :181）：列子集交互可参照其 SqlInsertModeDialog 形态，但落点在 CRUD 候选生成（BatchModel 列勾选已有同构面）而非导出器本体。
- **#155 SQLServer 二进制 0x 字面量**（十七轮 §7 :182）：导出可回放性红线——二进制列须按方言字面量渲染；我方回滚链 `RollbackSqlGenerator.kt:590` 对 HexValue 已走 `toString()` 透传（0x 形态延续），导出实现时按方言复核即可。
- **#156 OB Oracle 模式 INSERT ALL**（十七轮 §7 :183）：多行批导出的第 4 类方言形态——同数据多行 INSERT 在 OB Oracle 模式须合成 INSERT ALL，属「方言形态标注」需标注的分叉点（可只标注不合成，缩范围）。
- **#169 postgres 索引保序/enum**（十八轮 §7 :174）：仅当 O-91 范误扩到 DDL 时成为硬判据；限定 CRUD/回滚 DML 则此条仅登记不阻塞。
- **#172 未加引号 postgres 表身份折叠**（十八轮 §7 :176）：导出侧标识符引用必须 quote-aware（折叠只发生在未加引号时）——我方 `quoteIfNeeded`＋`identifierCaseSource` 同一判定已是现成资产（O-51 半包教训在案，`BatchModel.kt:162-164`）。

### 2.4 成本档：**S~M**

生成面（方言渲染/降级链/identity 包装/回滚诚实拒绝）**全部现成**，缺口收窄为三件：①把候选面串成导出面（含 CrudSqlGenerator 候选清单补 UPSERT 候选或明确不补）；②「方言形态标注」文案（每条语句标「原生简洁/整语句/降级 INSERT」三态＋来源方言）；③两处解析行为探针（PG ON CONFLICT 在回滚链的 JSqlParser 行为、OB INSERT ALL 标注口径）。

### 2.5 建议

**缩范围立项**：首版只做「CRUD/回滚语句＋方言形态标注」的导出（复用 SqlExportService 外壳或平行服务），不做 DDL（#169 不阻塞）、不做 INSERT ALL 合成（#156 只标注）、不动 O-9 闸门（UPSERT 不进确认流属现状语义，是否把「UPSERT 改行风险」纳入闸门另立决策项，不捆进 O-91）。
