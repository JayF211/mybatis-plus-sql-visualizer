## §5 优劣势总评

**优势**：①能力矩阵独有列——免库 mock 预览、agent 字节码增强捕获（不依赖日志格式）、日志↔源码双向跳转、MCP 十工具+ACP 先发、11 方言含信创真机验证、回滚链 identity 包装、免费无激活摩擦；②质量基建——532 测试类、testShards 全量门禁、verifyGate 三目标兼容线、性能十三族红线；③发行执行力——v2026.9.23 从提交到 Marketplace 上传 12 小时走完，审核退回→动态代理化改造→重传申诉全链闭环。

**劣势（诚实面）**：①**分发是最大短板**——303 下载/0 评 0 票/品类词「mybatis sql」前 40 未入（品牌词「sql visualizer」第 1 可守），且**在架版本仍 2026.9.14**，含 MCP 十工具+premain 的 2026.9.23 至今未上架（服务端 API 零痕迹待后台确认）；②反馈盲飞——零评论零 issue，需求池数据不可程序化获取，功能排序缺一手信号；③单人总线+Marketplace 审核单点，发行管道任何卡壳都直接冻结全部工程价值；④工程治理债——编号三处并存（O-72 双占、O-73 暂占、O-60/O-61 盘点口径与交付侧互换）、盘点 35 版基线滞后、需求文档状态列失真（F-01~F-20 全写「未开始」）、k2j 三选一悬置成本持续上升。

**机会**：头部三强的差评周期（IDE 大版本升级窗口是固定抢量时机）；停更插件（Free MyBatis Tool 19 个月、MyBatis Log 3.5 个月）让出的量；AI/MCP 趋势验证我方先发方向。
