## 10. 风险

1. **审核滞留超历史节奏（本轮第一风险，从「时长不可控」升级为「已超时」）**。六连发期的当日/次日节奏已被打破，公开 API 只有两态读数、无进度回执；若滞留继续拉长，N-24/破零/跟版三条动作链全部压后，且「306→310」的正读数窗口（在售版尚能自然增长）迟早被「在售版过旧导致增长停滞」取代。缓解＝备战包前置（现在做）+ 超一周走人工问询。
2. **放行版携带未收窄 premain**（延续）：O-73 收窄不在在审 zip 内，放行版用户拿到的仍是未收窄形态，须随跟版出货；审核期间报障如实解释「下一版已修」。
3. **zMyBatis 类型产能空出**（§4.4 信号 ⑥）：整型域收割完，每天 2 型的产能转向何处是下轮关键观测——转向接线/发布链则威胁形态跳变，转向新类型域则维持现状。
4. **推送债 5 笔**：调研资产（含本报告）只在本地，掉线即丢；本轮 4 笔 docs 连续未推，下轮前清。
5. **2024.3 申诉余波**（延续）：2 条兼容问题申诉与单包定案绑定，若 JetBrains 坚持拆包牵动发行结构。
6. **k2j 锚点债 164 笔**：O-24 决断前不动作，债随 master 滚动（当前冻结期暂停扩大，代码线重启即复利）。
7. **冷启动第 38 天**：0 票 0 评论；+4/日正读数延续但量级微，破零只能靠放行后动作。
8. **main 验证时效弱化（zMyBatis 侧，对审计方法论的回响）**：对手砍掉合并后验证后，其 main 绿色读数时效性下降——我方对它的「仓库领先」判定今后须更依赖 release 分支与 tag 信号而非 main。
