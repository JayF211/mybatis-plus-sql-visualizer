## 10. 风险

1. **推送债 + Marketplace 断供双债叠加（本轮第一风险）**。master 201→213 提交未推是项目历史峰值，且内容恰是本轮最不可再生的资产（合流成果+发行链）；同一时段 Marketplace 在售版本落后两个发行代际（9.14 vs 9.18），公网用户与全部新改进之间只差一次上传。两笔债都是「动作缺失」型，修复成本极低、拖久后的不可逆风险（工作树事故/窗口流失）极高。
2. **冷启动剪刀差继续拉大**。+4/日（缓存口径下仍趋弱）与 0 票 0 评论第五周并存；每次发行窗口拖延，beta.1~4 + 正式版攒下的获客素材就闲置一轮——连续第二个月。
3. **CodeHelperPro 双线同版复活 + MCP 真实迭代**。付费版跳票结束回到与直装版同步节奏；其 MCP 工具已有修复型迭代与真实用户信号，validate 校验工具若在后续版本出场将直接覆盖「mapper 校验」需求面；我方十工具已出库但同样没到 Marketplace 用户手里。
4. **zMyBatis 接线冲刺的低概率高影响**。13 小时 5 连号是五个月来最快节奏，按依赖顺序在赶接线前置；若未来数周发版，「执行正确性+安全纵深」口碑可能快速起量——其安全纵深设计语言（Z-14/Z-15/Z-18）应通过 O-34/O-35/O-37 先行吸收为自身叙事。
5. **agent 通道竞争跨赛道升级**。DBX 把 MCP 养成一级产品面（两天五连发）+ CodeHelperPro MCP 真实迭代，工具质量竞争已是数据库工具与 IDEA 插件两个赛道的共同主线；我方锚点不变（IDE 深度集成/执行期确定性/字节码级捕获独占性），但十工具的「叙事先手」贬值速度在加快。

## 11. 落地优先级建议

如果只做三件事：**push 213+15 留底 + Marketplace 上传 2026.9.18 随行 N-24**（出场清账——本轮性质已从「有前置阻塞」降级为「动作缺失」，是八轮以来成本最低、单位收益最高的一次，没有理由再拖一轮）、**O-34 方案 C 语义对照测试集**（1~2 人天把 T-FidelityEval 的定案变成回归资产，顺带按 Z-14 加固隔离 loader——zMyBatis 最深的护城河就此转为我方的护栏）、**N-29 MCP 双通道审计闭环**（agent 通道竞争跨赛道升级的最快应手：SQL 历史链是现成的，补 source 标+落历史即成闭环）。
