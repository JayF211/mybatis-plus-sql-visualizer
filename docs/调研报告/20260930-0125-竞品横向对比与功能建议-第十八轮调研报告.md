## 9. 风险

1. **获客缺位（维持第一风险）**：0 票 0 评论第 42 天，N-24 连续第三轮零动作；本轮 +23 增长反衬问题本质——有流量、无信任资产，转化环节全空。静默窗口不会永远持续（MyBatisX 待审批版过审、官方 2026.3 铺开都是 Terminatoren）。
2. **交付/货架剪刀差创系列新高（升格第二）**：回流债 88 笔（46→88），其中用户可见的参数预设 UI、R3 Oracle 日期修复、语法高亮开关+批次 2~7 全部库存不在货架；R3 是「Oracle 用户日志还原报错」级真缺陷，在售用户仍会踩。

4. **官方化长期挤压（维持）**：Hibernate Debugger 周更未断、下载开始爬坡（50→52），2026.3（11 月）铺开倒计时约 5 周；JPA 话术与养词宜在铺开前落位。
5. **还原入口低门槛化（新增）**：DBX #167/#168 把「贴文本得 SQL」「看得到真实 SQL」做成默认期待；我方若停留在「装插件+开捕获」的入口心智，漏斗顶层流失给先手方。
