## §6 新用户可发现性痛点（第一公里视角，本轮新增维度）

1. **空面板起步是第一道坎**：主入口默认空态，「开启增强捕获」要过长确认弹窗（含 24 小时冷却的取消代价说明），首次体验=空面板+一篇授权文。
2. **MCP 十工具对两类用户都不可见**：未装 mcpServer 平台插件则整文件不加载；装了也要自己去平台「暴露工具」页找——插件内没有任何一处主动告知「你有 MCP 能力」，差异化最强的功能恰是可发现性黑洞。
3. **设置 9 页两层深**：帧过滤前缀这类决定源码跳转成败的排障项埋在最深处，「设置搜索可命中」的兜底本身就是问题自证。
4. **通用内嵌 SQL 第四通道无来路认领**：任意 XML 叶子标签自动挂图标，非 mapper 用户会困惑「哪来的图标」，现场解释只有 tooltip 一句。
5. **快捷模板三动作摘键位后无默认入口**：解决了键位冲突（诚实取舍），代价是从「冲突」变「隐藏」，只能翻两层设置找到。
