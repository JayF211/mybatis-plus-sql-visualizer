3. **2024.3 申诉余波**。2 条兼容问题（`McpToolset` 接口 + `SpillingKt`）的申诉与单包定案（`61f444c`）绑在一起；若 JetBrains 坚持拆包，牵动发行结构。
4. **未发行增量滚动累积**。master 一天 94 笔、[Unreleased] 16 条；若审核拖长，2026.9.23 放行时已落后 master 更多——「货在架下」从贬义叙事变成有明确化解路径的动作项（跟版）。
5. **zMyBatis 扳机就绪**（§4.4）：产品轴重启 + 发布序列全就绪，tag/GitHub Release 双信号出现即发行；其「首版带治理叙事」与我方「大版本+审核响应透明记录」的同台竞争取决于谁先进市场。
